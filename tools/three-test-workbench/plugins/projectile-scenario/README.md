# 弹体用例生成器

用于编辑 `src/test/resources/projectile-simulation/*.json` 的独立工作台插件。启动 `tools/three-test-workbench` 后，点击页首的 **弹体用例生成器 ↗**；也可以打开 `/plugins/projectile-scenario/index.html`。更新本插件的服务端代码后，需重启 `npm start`，再刷新页面。

## 使用

1. 搜索现有场景并“载入为副本”，或点“新建”。武器选项只读项目根 `limitless_vehicle/rvp/data/rvp/weapons/`，按 JSON 类型筛选六种可飞行实体；不读取 run 或废止的包目录。
2. 在“发射初态”设置位置、机头航向和俯仰。机头方向与初速输入分别设置；可输入 X/Y/Z 分量，也可启用初速后用速率、航向、俯仰换算。0 度朝 +Z，90 度朝 -X，俯仰正数抬头。
3. 在“目标运动”设置起点、初速度和恒定加速度，或选择静止、横穿、接近、远离、爬升、加速预设。距离为格，速度为格/秒，加速度为格/秒²；20 刻等于 1 秒。
4. 选择画面里的“发射点”“目标起点”或速度端点，拖动彩色坐标轴。拖动空白处旋转相机；三维、俯视、侧视适合观察不同分量。改动后可点“适配全景”重新取景。箭头长度为适配画面的示意比例，数值输入才是实际速度。
5. 拖动时间轴或播放，观察目标完整路线、当前坐标与速度。快捷键为空格播放/暂停、左右键逐刻、Home/End 跳首尾；在输入框内打字时不触发这些快捷键。
6. “环境 / 高级”完整保留当前 Java 场景字段，包括水面、平台速度/姿态、冷发射、母弹、布撒和已接管的智能引信目标。“JSON”页可直接修改当前格式并应用；也能导入场景或从真实弹体回放提取场景。
7. 点击“保存为新用例”直接创建 `src/test/resources/projectile-simulation/<id>.json`，或下载 JSON 自行放入该目录。相同 ID 或同名文件会拒绝保存；做对照例请点“复制为新用例”。有效参数会自动保存为当前浏览器的本机草稿。
8. 保存后点“复制仿真命令”，在项目根目录执行。生成结果写入 `build/projectile-simulation-editor/`，回到回放工作台“刷新目录”，在 **RVP 弹体仿真** 中选择该场景。此单例输出与常规全部场景的索引分开。

## 预览与真实仿真的边界

玫红线是目标脚本路线，金色箭头是机头朝向，青绿箭头是可选的 `initialVelocity` 输入；淡蓝箭头是目标初速度。目标按 Java 同一解析式 `p(t)=p₀+v₀t+½at²` 运动，正拖与倒拖均根据绝对时刻计算。当前 schema（数据格式约定）不支持航点、圆周或分段运动，编辑器不额外添加 Java 读不懂的键。

**编辑器不计算导弹未来轨迹。** `initialVelocity` 是传给实体生成上下文的输入，仍受真实 `initFromWeapon`、冷发射、平台速度继承和武器规则处理；不保证等于真实回放首帧的速度。冷发射速度是挂架本地坐标，画面不把它误画成世界初速。武器的气动、点火、制导和寿命参数始终由权威 JSON 和 Java 实体决定。

将场景 JSON 导入主工作台时，本插件也能提供“几何预览”记录：发射点保持静止、目标按脚本移动，所有检查都标为说明。需要导弹轨迹时使用 Java 输出的第 2 版 `rvp-projectile-simulation` 回放，不能把几何预览当作命中测试结果。

## 插件结构与保存边界

`plugin.json` 的 `tools` 声明工具页，`server` 声明服务端模块。通用主体只负责自动发现入口、提供静态 HTML/CSS 和分发 `/api/plugins/<id>/...`；表单、字段校验、几何预览与场景保存均在本目录，没有在主体按弹种或插件 ID 分支。

- `GET /api/plugins/projectile-scenario/catalog`：读取当前场景模板和权威武器目录，单个坏文件给出提示。
- `POST /api/plugins/projectile-scenario/scenarios`：正文为当前场景 JSON，仅限 128 KiB。完整校验字段和实际武器类型后，按 ID 独占创建新文件，不接受客户端给定目录、不覆盖文件、不修改武器、不执行外部命令。写请求拒绝其他网页的 Origin（浏览器标明的来源）。

网页侧整数种子只接受绝对值不超过 `9007199254740991` 的整数，避免 JavaScript 的数字精度悄悄改变随机种子。Java 支持更大的 long 整数；这样的现有文件会给出明确提示。

验证入口：工作台目录运行 `npm run check`、`npm test`。回归覆盖所有现有场景字段、目标与真实 Java 回放逐刻对照、坐标角度换算、预览时间轴、插件发现、创建/重复/越界/超大正文与权威文件只读。

2026-11-02 验证：工作台 46 项测试、语法检查和项目 `./gradlew build` 均通过。浏览器实际检查了位置/初速端点拖动、独立机头方向、加速目标首尾/倒拖和错误输入拦截；通过编辑页下载的用例成功运行 `projectileSimulation`，生成 190 帧真实实体记录，并由主工作台自动发现与回放，控制台无警告或错误。
