## ⚠️ 必读：冒烟测试新方法（旧方法会留杀不掉的服务端进程）

`./gradlew runServer` 后台启动 → 每 5 秒轮询日志（grep "Done ("）→ **见到 Done 立即**：
`wmic process where "name='java.exe' and commandline like '%ywzj%'" get processid` 取 PID →
`taskkill //PID <pid> //F` → **全路径** `/c/Windows/System32/tasklist.exe` 复验 java 进程为 0
（Git Bash 里 `tasklist`/`$SystemRoot`/`/FO` 会静默假阴性，必须用 `/c/Windows/System32/` 全路径）。
不要等 stdin EOF 自退。后台 gradle 包装任务在服务端被杀后 exit 1 属正常。
