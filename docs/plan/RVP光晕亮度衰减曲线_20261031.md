# RVP 光晕亮度衰减曲线

日期：2026-10-31。根据用户确认，曲线只影响光晕亮度；环境照亮继续使用原有淡出。保留原曲线、线性衰减与快降后保持；爆炸默认改为“高亮保持后淡出”：先按设定亮度照亮天空3刻，再平滑降到0。亮度、保持刻数、独立淡出刻数与范围均可调。

## 使用方式

F8 / `/rvptune` → 屏幕空间特效 → 爆炸照亮与光晕，可修改“广域光晕独立亮度”“光晕高亮保持时间”“光晕独立淡出时间”和“光晕半径倍率”。曲线按钮依次为“原有衰减 / 线性衰减 / 快降后保持 / 高亮保持后淡出”。爆炸默认第4项；其它来源默认原曲线。来源未单独覆盖时，优先继承全局显式设置，否则使用自己的默认值。

```text
/rvplight set explosion haloRadiusScale 1
/rvplight set explosion haloDecayCurve 3
/rvplight set explosion worldHaloIntensity 16
/rvplight set explosion haloPeakHoldTicks 3
/rvplight set explosion haloFadeOutTicks 29
/rvplight preview
```

爆炸光晕默认开启，炮口光晕默认关闭。`haloDecayCurve 1` 选择线性，`2` 选择快降后保持，`0` 选择原曲线。统一切换所有有限寿命光晕可显式设置 `global haloDecayCurve`，原本已经单独设置的来源仍以自己的覆盖为准。

高亮保持和独立淡出按实际游戏刻计算，20刻为1秒。默认3刻保持加29刻淡出，总计32刻。只调 `haloFadeOutTicks` 就能单独改变光晕消失速度，照亮寿命及其淡出完全不变。设为0时，自动使用照亮寿命减去保持时间的余量，至少保留1刻淡出。光晕更长时，管理器和效果包装器等待光晕结束；光晕更短时，环境照亮继续按自己的时间结束。

## 曲线函数

返回值是相对初始光晕亮度的比例；出生时为1，结束时为0。前三种曲线令 `t = 已过去的游戏刻 / 原光源实际寿命`；第4种曲线使用独立保持与淡出时间。修改参数均不会重设出生时刻。

高亮保持后淡出：`a` 是爆炸年龄（刻），`h = haloPeakHoldTicks`，`d = haloFadeOutTicks`。

```text
F(a) = 1                     (0 <= a <= h，保持设定亮度)
F(a) = r*r*(3-2*r)           (h < a < h+d，平滑归零)
       r = 1-(a-h)/d
F(a) = 0                     (a >= h+d)
```

两段交接与终点的亮度变化率均为0，避免3刻高亮结束后突然跳暗。空间分布继续使用已有函数：`q = 距光心距离的平方 / 光晕半径的平方`，`G(q) = exp(-6*q)*(1-q)^2`（半径之外为0）。中心的比例是1，往外单调下降，既能在天空上显示，又保持中心最亮。

线性衰减：

```text
F(t) = 1 - t                  (0 <= t < 1)
F(t) = 0                      (t >= 1)
```

快降后保持：`a = haloDropFraction`，`b = haloLowBrightness`，`c = haloHoldUntil`。

```text
F(t) = b + (1-b) * (1-t/a)^3   (0 <= t < a，快速降亮)
F(t) = b                      (a <= t <= c，保持低亮)
F(t) = b * r^2 * (3-2*r)       (c < t < 1，柔和消失)
       r = (1-t)/(1-c)
F(t) = 0                      (t >= 1)
```

快速段用三次函数，开始降得快，接近低亮时逐渐放缓。保持段亮度固定；最后一段在两端都平滑衔接。新函数直接替代原光晕包络（随时间变化的亮度比例），不再叠乘原曲线，否则低亮保持段仍会持续变暗。

| 参数 | 默认 | 允许范围 | 含义 |
| --- | --- | --- | --- |
| `haloDecayCurve` | 爆炸3，其它0 | 整数0～3 | 0原有，1线性，2快降后保持，3高亮保持后淡出 |
| `haloPeakHoldTicks` | 爆炸3，其它0 | 0～40刻 | 曲线3保持初始亮度的时间 |
| `haloFadeOutTicks` | 爆炸29，其它0 | 0～640刻 | 曲线3独立淡出时间；0自动使用照亮剩余寿命 |
| `haloDropFraction` | 0.1 | 0.001～0.5 | 快速降亮占总寿命的比例 |
| `haloLowBrightness` | 0.15 | 0～1 | 保持段相对初始亮度的比例 |
| `haloHoldUntil` | 0.8 | 0.5～0.99 | 保持结束在总寿命中的位置 |

选择曲线2时，按默认32刻照亮寿命计算：0～0.16秒从100%快速降至15%；0.16～1.28秒保持15%；1.28～1.6秒柔和归零。曲线0～2随 `decayScale` 伸缩；曲线3的显式保持/淡出刻数独立，不会被照亮倍率拉长。

## 接入范围

- `RVP_HaloDecayCurve` 是独立的共用函数，不依赖客户端或武器ID。
- `RVP_ScreenLightManager` 对全部有限寿命光源独立采样光晕，环境照亮、原始年龄与颜色保持原有规则。条目等待两路均结束再清理，迟包也按仍有效的光晕寿命判断。
- `RVP_RocketPlumeManager` 的有限时长预览提供独立 `haloStrength`；模糊光晕来源与广域橙晕使用它，直接显示的白热喷焰仍使用原 `strength`。
- 真实发动机、光电干扰机属于持续光，跟随燃烧事实或设备开关。它们没有固定倒计时，持续开启期间保持原有发光行为。
- 光晕四层模糊共享来源亮度；不为每层重新计算一次衰减。
- 命令、F8面板、本地预设和恢复默认使用同一覆盖表。选择项使用中文按钮；小数序号、非有限值和越界值都会被拒绝。

未修改本体、Mixin、结构模型、载具包或着色程序资源。实现与测试位于本附属模组中。
