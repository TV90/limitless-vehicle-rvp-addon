## 权威身份与计时

新增普通 Java 公共数据 `RVP_AuxiliaryHudSnapshot`：当前乘坐 UUID、ORDINARY/PARENT/CHILD、剩余冷却、已部署、部署许可、切换许可。

`RVP_AuxiliaryHudSyncService` 仅处理 ServerPlayer 的 PlayerTick.END，换乘实例立即推送；父/子每10tick更新，普通车首次或身份变化发送，随后不持续发普通快照。从 `RVP_LinkedUavStateTable.isDeployableUavInstance` 读取真实部署标记（与原切换功能一致），而非客户端车型猜测；母车读原 SavedData 的租约/冷却，沿用原服务的座位/实例配置/信号许可。配置重载变回普通身份时 LAST_ROLES 也会发送撤销，不因 UUID 相同保留旧按钮。下车/登出/停服清理服务器缓存。仅向该乘员 connection 发小快照，没有新增区块强载、实体扫描或 C2S 轮询。

`S2CAuxiliaryHudContext` 追加在消息表末尾，旧消息ID顺序保持；S2C方向与 DistExecutor 公共类安全桥。`RVP_ClientAuxiliaryHudState` 只接受当前乘坐 UUID 的包，拒绝旧车迟到快照；换车/下车/维度卸载/登出清空。尚未同步时只显示地图/状态，避免短暂把子机错当母车。包间用客户端世界游戏 tick 扣倒计时，暂停不按墙钟推进，时间回退不增长；不会因为本地计时到零而自行开放部署。

没有改现有 C2S 部署/切换控制、假玩家、无人机运动、回传/自爆时序或快修权限。本体 FakePlayer 实际 extends Mob，不是 ServerPlayer，不会进入新 HUD 玩家同步器。
