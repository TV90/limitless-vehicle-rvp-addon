# 载具武器「备弹 / 射速 / 倍率」总表（按武器去重版）

> **配套**：武器清单与《载具武器伤害总表_20261020》一致（173 个，含子弹药 ↳ 行）；换弹时间的调整走《非坦克载具换弹时间总表_20261012》，本表「换弹」列仅作现状参考。
>
> **口径**（新值列中的全角空格仅为撑宽占位，填写时直接覆盖；**留空 = 沿用现值**）：
> - **备弹** = `max_capacity`（发）；**间隔** = `shoot_interval`（已换算成秒，括号内 rpm=60000/毫秒值）；**换弹** = `reload.time`（tick，参考值）
> - **距离衰减（统一规则）**：`0-512 格:1.0→0.7`。**新距填 `0`**＝关闭距离衰减（原有规则一并停用）；**不填**＝套用统一规则。已按「只对 APFSDS/机枪/非爆炸机炮生效」预填：所有爆炸武器已填 0
> - **角度入射（统一规则）**：`30°→0.8；60°→0.5；70°→0.35；75°→0.2；80°→0.1；80° 以上跳弹`（分段线性）。新角不填＝套用统一规则；填 `0`＝关闭
> - **跳弹已落地（2026-10-22）**：52 个直射类武器（`rvp:machinegun` + `rvp:rocket`，含坦克炮弹/机炮/机枪/火箭弹/舰炮）写入 `bounce: 1` + `bounce_incidence_angle: 80` + `bounce_on_vehicle: true`（`bounce_strength` 默认 0.6）；命中载具时入射角 ≥80° 弹开且当次无伤。导弹/炸弹/鱼雷/吊舱/激光不跳。子弹药与破片战斗部（`*_frag`/`*_efp`/`*_sub`/`*_munition`/AHEAD 等 8 个）不配，因为靠落点爆炸杀伤。
> - **直击/爆炸倍率** = 对各机型的伤害倍率，写法 `默：1.2/履：1.35/轮：1.1`（默=vehicle_default，履=tracked，轮=wheeled，直=rotary_wing，固=fixed_wing）。已按类别预填：APFSDS 新直 轮/直/固 0.8；破甲弹/炮射导弹 新直 1.1+新爆 轮/直/固 2；高爆弹 新爆 轮/直/固 2；破甲类（直击>爆炸）新直 1.1+新爆 轮 1.2；高爆类（爆炸>直击）新爆 履 0.9/轮 1.2/船 2
>
> 倍率表武器名不带 id，与同节「备弹与射速」表逐行对应（id 见该表）。
