## 一、本体实现（调查结论）

尾焰是**模型+动画渲染**，不是粒子。三层：

1. **资源**：本体 jar 内置"尾焰三件套"（`InternalAssets` 全局加载，**不在武器文件里**）：
   - `models/bedrock/effect/rocket_motor_flame.json`（模型，命名空间 `ywzj_vehicle:effect/rocket_motor_flame`）
   - `animations/bedrock/effect/rocket_motor_flame.animation.json`（循环动画）
   - `textures/effect/rocket_motor_flame.png`（贴图）
   源码位置：`default_vehicle/assets/ywzj_vehicle/`（构建时打进本体 jar）。
2. **实体侧（客户端）**：`MissileEntity.readSpawnData` 创建 `AnimationRunner(flameAnimation, context)`
   + `LoopingState(System::nanoTime)` 循环，public 字段挂在弹体；显示门控 `isMotorBurning()`。
3. **渲染**：`RocketPropelledEntityRenderer.render`——super 画弹体模型后：
   `runner.tick()` → `applyPose(blend(bindPose, evaluate()))` → 绕实体 yaw/xRot 旋转 →
   平移 `engine_nozzle_offset`（武器 JSON 配置，惯例 `[0,0,-长度]`，Z- 为尾）→
   缩放 `caliber/1000` → `entityTranslucent + polyMeshCutout` 全亮渲染。

## 二、RVP 实现（资源零成本，不依赖本体导弹基类）

`RVP_BedrockProjectileEntityRenderer`（client 类）追加 `renderMotorFlame`：

- **门控**：`data.getProjectileData().hasRocketEngine()` 且 `projectile.isMotorBurningNow()`
  （两者均为 RVP 侧自有公共 API，与本体 MissileEntity 基类无关——RVP_BaseBullet 继承的是
  本体 AmmoEntity 机炮基类，本体 MissileEntity 的 animationRunner/nozzle 字段不可用也不需要）；
- **资源**：`ClientAssetsManager.INSTANCE.getInternalAssets()` 直取本体三件套（公开全局资源）；
- **动画 runner**：渲染器内 `static WeakHashMap<RVP_BaseBullet, AnimationRunner>`，每发弹
  客户端实例一个循环 runner，弹体销毁弱引用自动清理；不进公共类（Mixin 纪律/dist 安全）；
- **变换**：照搬本体公式（`-entityYaw` → `xRot` 插值 → 喷口平移 → 缩放 → 全亮渲染 + bindPose 复原）；
- **默认喷口 `[0,0,-1.2]`、缩放 `0.2`**：本体典型空空弹（pl_8）量级的固定默认值；
  不使用 `AmmoEntity.getCaliber()`（RVP 未覆写，默认 5.8 不可用）。

### 适用范围 / 参数（2026-09-14 定版）
- 所有 `projectile_data.has_rocket_engine: true` 的弹自动带尾焰（用户确认的全量口径）；
- **逐弹可调字段（已落码）**：
  - `projectile_data.engine_nozzle_offset`：`[x,y,z]` 喷口偏移（实体空间，Z- 为弹尾），默认 `[0,0,-0.5]`；
  - `projectile_data.flame_scale`：尾焰缩放，默认 `0.2`（对标本体 PL-12：其武器 JSON 未配 caliber，
    `MissileEntity.initMissile` 将 `caliber<40` 钳制为 200 → 缩放 200/1000=0.2；PL-12 实际
    `engine_nozzle_offset=[0,0,-1.48]` 可作配参参考）；
- **双脉冲支持**：`isMotorBurning()` 已覆盖二级脉冲窗口（一级燃烧→熄火间隔尾焰消失→
  二级点火重新出现→燃尽消失；客户端无 rvpData 时走同步的 motorBurnEndTick/SECOND_PULSE_* 同样支持）。
