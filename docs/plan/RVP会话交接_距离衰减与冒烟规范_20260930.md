## ⚠️ 必读：冒烟测试新方法（旧方法会留杀不掉的服务端进程）

`./gradlew runServer` 后台启动 → 每 5 秒轮询日志（grep "Done ("）→ **见到 Done 立即**：
`wmic process where "name='java.exe' and commandline like '%ywzj%'" get processid` 取 PID →
`taskkill //PID <pid> //F` → tasklist 复验 java 进程为 0。**不要等 stdin EOF 自退**。

## 一、本轮完成的功能（全部已实测/待实测清单见主文档各节实机清单）

1. **双雷达交替开关根治**（§41.2）：根因=同一按键两个门控不同写者（本体 InputEvent.Key
   回调 vs RVP isDown 轮询）的错位窗口（快按/REPEAT 假边沿/上下车）；重写=边沿改同源
   InputEvent.Key（PRESS+screen 门，LOWEST 晚于 base）只置 pending、下一 tick END 幂等
   校平、坏雷达同帧即时压回；
2. **炮管受损档精度**（§41.3）：扩散×10 改固定扩散+5（消费点本为加法）；
3. **部件爆炸损伤口径修订**（§38.4/§41.5/§41.6/§41.7 四轮迭代，最终态）：
   - 范围=设备+炮管+引擎三类（ERA 走机制二百分比不变）；虚拟骨（ecm_bone/__vehicle__）
     排除；视距判定（LOS 过滤+已爆 ERA 不作遮挡物）；
   - **入账口径=本段 hurt 实际血量损失**（重放前后 getHealth 差值，§41.7 根治）——外源
     mod 多段伤害（SBW 直击两段+延迟爆炸段）总和恒等于载具总掉血，杜绝超额；
   - 近炸直伤排除（inRvpDamage 窗口门，§41.5）；同 tick 同骨单次入账守卫（§41.6）；
4. **距离衰减**（§41.9，最新）：部件虚拟血量爆炸入账 ×mult，
   `mult = clamp(1−0.95×距离/半径, 0.05, 1)`——贴脸全额、半径处 5% 保底；半径来源
   RVP 弹 push/pop ThreadLocal（真实半径）/外源回退固定 24 格参考（常量可调）；
5. **快修默认维修优先级**（§40，用户定版固定序列）：炮管→发动机→雷达→干扰物→DIRCM→
   ECM→干扰机→APS→其它；面板配置队列仍绝对优先；桶内按 JSON 顺序；
6. **烟雾弹普及两批共 12 台**（§38.3/§38.7）：坦克系 7 台 + cssa5/zbl08a/lavad/lav25/
   ps1sm（第二轮：ps1sm 部件挂车体，余挂炮塔；全部 min_damage 20/factor 0.4/双语别名）；
7. **观瞄俯视图+F3+B 失效部件近黑线框**（§39，新 client Mixin
   VehicleRenderRenderHitboxMixin 已审批）；
8. **RVP 武器自毁距离**（§37）：projectile 配 self_destruct_distance（缺省 -1：MACHINEGUN
   默认 1024 米/其它 0）+ self_destruct_explode；TKB-1055 近炸半径 3.0→6.0 + 400 米自爆；
9. **DIRCM 摧毁红字 + 快修冷却/装填类 HUD 红字**（§34/§41.1 装填红字）；
10. **本体 0.6.0 接入**：libs 换 0.6.0-all.jar（构建需 JAVA_HOME=JDK21；新 jar 无 -all
    classifier 按坐标命名复制），build/冒烟通过。
