## 二、逐笔提交总结

### `1d04ec7` 一些调整和优化（2026-10-03 13:29，Ranpoes）

**新特性/行为变化（均本体侧，19 文件 +85/−24）：**

1. **弹体渲染旋转插值修复（视觉）**：`AmmoEntityRenderer` / `BulletEntityRenderer` / `RocketPropelledEntityRenderer` 三处 Y 轴旋转从 `Mth.lerp` 改 **`Mth.rotLerp`**（角度感知插值）——修复弹体 yaw 跨 ±180° 回绕时的渲染抖动/瞬转。
2. **导弹/火箭自动归正统一**：`MissileEntity`（无目标自由飞行段）与 `RocketEntity`（发动机燃尽后段）的手工 pitch/yaw 反算（`asin/atan2`）替换为 **`VectorUtil.vecToRot(velocity)` + `rotLerp`**——行为等价 + 同样修复回绕问题。
3. **悬挂部件 `detachable: false`**（10 个轮式载具：atv_coyoto/atv_mrzr4/cssa5/dump_truck/hiace/htf5980(16处)/lav_ad/motorcycle/ztl11/ztz99a）：悬挂部件标记为不可分离（配合本体上笔"悬挂越障优化"方向的数据收口）。
4. **突击艇螺旋桨有动力才转**（`assault_boat.js`）：`getPower() > 0` 门控螺旋桨骨骼旋转与累加。
5. **j10c 第三人称视距 16→17**；包 meta 版本行更新。

**RVP 接口影响：无。** 三个渲染器 RVP 均未继承（RVP 弹体用自研 `RVP_BedrockProjectileEntityRenderer extends EntityRenderer<T>`）；`MissileEntity`/`RocketEntity` 仅方法体内部改写（签名不变），RVP `RocketEntityMixin` 为 `tickMove` **HEAD+cancel 注入**（配置了 RVP 弹道的火箭整个方法被取消，本体改体不可达；未配置弹走本体新逻辑，注入点不受影响）；RVP 自有弹体 `RVP_BaseBullet extends AmmoEntity` 自持运动，不受上述改动波及。

### `adb4845` 优化过载机制（2026-10-03，Ranpoes）

**新特性/行为变化（5 文件 +32/−17）：**

1. **过载 G 值改服务端权威计算 + 同步数据下发**：`AbstractVehicle` 新增 `OVERLOAD` SynchedEntityData（Float，默认 1）+ `tickOverload()`（在 `tickPhysics` 之后、`VehicleMoveEvent` 派发之前执行：视在加速度=Δv+重力补偿，投影到载具主 OBB 上轴，除以 G）+ 公共 getter **`getOverload()`**（RVP 未来可消费的新 API）。
2. **客户端过载逻辑简化**：`LocalVehiclePlayer` 删除字段 **`lastVelocity`**（公共字段，已确认 RVP 无引用）与整段客户端自算 G 的代码，改读 `vehicle.getOverload()`；新增平滑显示值 **`displayG`**（`Mth.lerp(0.35f)` 渐近），`clear()` 时复位 G=1。
3. **HUD 过载警告改用 displayG**（`VehicleOverlay`）——G 表显示更平滑，不再跳变。
4. **载具撞击伤害低速门收紧**：`AbstractVehicle.impact()` 的早退条件 `velocity == 0` 改 **`velocity <= 0.1`**——载具速度 ≤0.1 格/tick 不再结算撞击伤害（此前仅完全静止跳过）。
5. **撞击倍率调参**：ah_6 `impact_multiplier` 3→**16**；四轴无人机（quadcopter）新增 `defense_stats`（damage_threshold 10 / impact_multiplier **32**）——脆弱载具被撞击更易受损。

**RVP 接口影响：无破坏性。** `lastVelocity` 字段删除经全源码 grep 确认 RVP 零引用；RVP 对 `LocalVehiclePlayer` 的 4 个 Mixin 注入 `handlePlayerTurn`/`switchViewType`/`tickAim` 三方法，均未被本次改动触及；`VehicleOverlayWeaponListSuppressMixin` 注入 `renderWeaponList`（未动）；`AbstractVehicle` 已无 Mixin 目标（B 批次移除），RVP 不覆写 `impact()`/`tickOverload()`。RVP 自动总距挂 `VehicleMoveEvent`，与 `tickOverload()` 仅时序相邻无耦合。
