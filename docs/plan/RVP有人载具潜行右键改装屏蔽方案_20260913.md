# RVP 有人载具潜行右键改装屏蔽方案（2026-09-13）

> 状态：已落码（动作拦截 + 武器列表 UI 隐藏），编译与 dev 服务端冒烟通过，**待实机行为回归**。
> 需求来源：用户要求——对已有玩家或 gunner 乘员的载具，屏蔽"手持改装工具 + 潜行 + 主手右键子武器站"的改装行为；
> 二次迭代（同日）：**同时隐藏本体 `VehicleOverlay` 的武器改装列表 UI**（空手/任何物品、步行/骑乘均生效），
> 消除"列表引诱改装、点击却被拦"的矛盾。

---

## 一、调查结论（前置事实）

本体改装工具共有三条使用链路，距离限制与乘员校验情况各不相同：

| 链路 | 入口 | 距离限制 | 乘员校验 | 归属 |
| --- | --- | --- | --- | --- |
| **潜行右键部件改装**（本次目标） | `PlayerInteractEvent.EntityInteract` → `VectorUtil.hitPartUnit`（硬编码 4 格视线射线，`AllEvents.java:124`）→ 服务端 `WeaponUnit.onInteract`（`WeaponUnit.java:655-665`）→ `switchWeapon(false, true, true)` | 有效上限 4 格（原版实体拾取约 4.5/5 格更松，非瓶颈） | **无** | 纯本体，RVP 原本无任何该链路代码 |
| 右键载具开改装屏 → RVP"改装武器"按钮 → `RVP_AuiVariantScreen` → `C2SSelectModdingSubWeapon` | `ModdingToolItem.interactEntity`（未潜行才开屏） | 原版拾取（开屏）+ RVP 服务端 `distanceToSqr > 256`（16 格） | `canModVehicle`（限速 <5kph + 无玩家/gunner 乘员） | RVP 自有包 handler，校验齐全 |
| 改装屏挂架分支点击 | 走本体 `ClientVehicleSelectPartWeapon` | 本体源码 `distanceToSqr > 256`（16 格；历史构建曾误写为非平方比较 ≈ 256 格） | 无（仅手持工具 + 索引范围） | 本体包 |

"有人"判定语义源：`RVP_VehicleExtendedConfigManager.canModVehicle` 内的乘员遍历
（`getPassengers()` 判 `Player || org.ywzj.rvp.entity.gunner.GunnerEntity`）。

## 二、实现（零 Mixin，Forge 事件总线）

### 2.1 新增 `org.ywzj.rvp.event.RVP_ModdingInteractGuard`

`@Mod.EventBusSubscriber(bus = FORGE)` 监听 `PlayerInteractEvent.EntityInteract`，
**`EventPriority.HIGHEST`**，双端执行。取消条件（全部满足才拦）：

1. 玩家潜行且 `hand == MAIN_HAND`（本体 `onInteract` 仅此组合改装）；
2. 主手持本体改装工具 `AllItems.MODDING_TOOL`；
3. 目标实体为 `AbstractVehicle`；
4. `RVP_VehicleExtendedConfigManager.INSTANCE.hasPilotOrGunnerPassenger(vehicle)` 为真（载具有玩家或 gunner 乘员）；
5. 本体公共射线 `VectorUtil.hitPartUnit(vehicle, eye, eye + look×4)` 命中的部件是 `WeaponUnit` 且 `isInteractive()`（与本体判定同源同参数，潜行右键门/装饰等非武器部件不受影响）。

命中 → `event.setCanceled(true)` + 客户端动作栏提示 `rvp.modding.vehicle_occupied`。

**拦截原理**：本体 `AllEvents.onEntityInteract` 是普通 `@SubscribeEvent`（NORMAL、
`receiveCanceled` 默认 false）——本监听 HIGHEST 先行取消后，本体 handler 被跳过，
`WeaponUnit.onInteract → switchWeapon` 不执行。客户端取消同时阻止
`ServerboundInteractPacket` 上行；服务端监听对改包客户端兜底（两条路径互斥，提示不会重复显示）。

**回退方式**：删除 `RVP_ModdingInteractGuard` 即恢复本体原行为。

### 2.2 "有人"判定抽取（单一语义源）

`RVP_VehicleExtendedConfigManager` 新增公共方法
`hasPilotOrGunnerPassenger(AbstractVehicle)`（原 `canModVehicle` 内的乘员遍历逻辑原样抽出），
`canModVehicle` 改为调用它。改装界面按钮显隐 / `C2SSelectModdingSubWeapon` 服务端校验 /
本守卫三处共用同一"有人"语义，避免判定漂移。

按用户要求**只按"有人"拦**：不引入 `canModVehicle` 的限速条件，
空车移动中仍可潜行右键改装（与改装界面换弹语义不同，属预期差异）。

### 2.3 语言文件

`assets/rvp/lang/zh_cn.json` / `en_us.json` 新增 `rvp.modding.vehicle_occupied`
（"载具已有乘员，无法改装" / "Vehicle is occupied, modding is disabled"）。

## 二·B（2026-09-13 二次迭代）武器改装列表 UI 隐藏

**背景**：动作拦截落码后，本体 `VehicleOverlay.renderWeaponList`（`VehicleOverlay.java:268`）
仍会在准星命中可改装子武器站时绘制多弹种列表，且与手持物品无关——形成"列表引诱改装、
点击却被拦"的矛盾。用户要求连 UI 一起屏蔽，**空手也生效**，且骑乘状态同样生效。

**实现**：`org.ywzj.rvp.mixin.VehicleOverlayWeaponListSuppressMixin`（**client 数组**），
`@Inject(method = "renderWeaponList", at = @At("HEAD"), cancellable = true, remap = false)`，
条件仅一条：`RVP_VehicleExtendedConfigManager.INSTANCE.hasPilotOrGunnerPassenger(weaponUnit.getVehicle())`
为真 → 取消绘制（空手 / 手持任何物品均生效；无人载具保持本体原行为）。

**为什么必须用 Mixin（agents.md L26 替代方案逐级排除）**：
① JSON 字段无法表达本体 HUD 渲染条件；② overlay 由本体 `ClientSetupHandler`
自行实例化注册（`ywzj_vehicle:vehicle`），无法继承/替换；③ Forge 唯一相关事件
`RenderGuiOverlayEvent.Pre` 只能按**整张 overlay** 取消——`render()` 里乘员组/罗盘/油量
等驾驶 HUD 与列表同一张 overlay，事件方案会连带杀掉驾驶 HUD（步行时也会连带隐藏指向
载具血条）；④ 纯客户端渲染无网络包路径；⑤ 无需访问私有成员，@Accessor 无意义。
→ 只有最小 `@Inject(HEAD, cancellable)` 可行，**经用户批准后落码**（L36）。

**带毒类安全**：目标 `VehicleOverlay` 是本体**纯客户端 GUI 类**，不在带毒清单
（带毒的是 `AbstractVehicle`/`WeaponUnit`/`MissileEntity` 等公共类）；
仅注册于 client 数组、只在客户端应用，专用服务端不会触碰该类；
句柄只调公共 API（`WeaponUnit.getVehicle()` / `hasPilotOrGunnerPassenger`），不注入任何带毒类。

**覆盖范围**：`renderWeaponList` 的调用点在本体 `render()` 开头的 `renderLookAt` 内、
`if (!onVehicle()) return` 之前，故**步行 / 骑乘均生效**；且仅取消列表这一块，
骑乘时自身驾驶 HUD 与指向载具血条不受影响。

**回退**：从 `ywzj_rvp.mixins.json` client 数组移除 `VehicleOverlayWeaponListSuppressMixin` 即恢复。

## 三、边界（不覆盖范围，均为有意为之）

- 右键载具打开的**本体改装屏**及其"武器选择"子页（走本体包，16 格）仍可对有人载具操作——本体链路，按需求范围不动；
- RVP"改装武器"按钮路径本就有 `canModVehicle` 复检（限速+无人），行为不变；
- 未持改装工具的潜行右键（登车/开门等）不受影响。
