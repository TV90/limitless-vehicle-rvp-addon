# 载具「武器伤害」总表（按武器去重版）

> **本版变化**：同一武器在多台载具下重复出现，现**每武器只保留一行**，新增「引用载具」列；已把 2026-10-20 深夜填充值与 `*` 备注**全部合并保留**。填充原文备份：`_bak/载具武器伤害总表_20261020_填充原文备份_2325.md`。
>
> **口径**：**留空 = 沿用现值**。
> - **直击** = `collision_data.direct_damage`（瞄准吊舱为 `—`；激光武器取根级 `damage`）
> - **爆炸 / 范围** = `detonate_data.explosion_data` 的 `damage` / `radius`（单位：格）；无爆炸弹头填 `无`
> - 子弹药以 `↳` 行挂在母弹下，值相互独立
> - 武器名列括号内即武器文件名（`data/rvp/weapons/<id>.json`，均 `rvp:` 命名空间；标注「本体:」的除外）
>
> **去重统计**：武器（含子弹药）共 **173** 个；已有填充值的武器 **7** 个；填充冲突 **0** 处。
