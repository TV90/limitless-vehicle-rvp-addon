# RVP 光源按环境明暗自适应

日期：2026-11-01。适用 Minecraft 1.20.1 / Forge，仅修改 RVP 客户端现有光照流程。

## 1. 已确认的行为

同一盏光在暗处保持现有调参效果，周围越亮，额外灯光越弱。默认各光源附近的 Minecraft 光照占70%，加入本套屏幕灯光前的画面明暗占30%；最亮环境保留10%的灯光计算输入。

| 通道 | 是否适应环境 |
| --- | --- |
| 方块、地面、实体表面及可选空气散射 | 是 |
| 普通粒子烟、炮口特殊贴图、体积尾烟受光 | 是，只调额外受光，保留烟本身颜色与透明度 |
| 爆炸/炮口外围扩散光晕、发动机柔化光晕和广域橙晕 | 是，扩散前只调一次 |
| 爆炸天空闪光 | 是，独立于原有天空保持和淡出时间线 |
| 爆炸白热核心及贴身发光团 | 否 |
| 发动机喷焰主体及其几何可见度 | 否 |

10%指输入强度倍率，不代表最终屏幕颜色也恰好变成原来的10%。最终显示继续使用原有颜色混合、亮度压缩和遮挡。

## 2. 采样与计算

`RVP_AmbientLightSampler` 只读取已加载区块的天空光和方块光，按原版 `LightTexture.getBrightness` 换算，包含维度基础环境亮度。天光再乘客户端实时 `getSkyDarken(partialTick)`；该值包含昼夜、雨和雷暴，闪电期间采用原版闪亮状态。无天光维度不额外加入天空光。

以邻近八个方块中心为节点，按位置距离做三线性插值，即分别沿三个方向连续混合，避免光源移动跨格时突然跳亮。有权重的任一样点所在区块未加载时，明确标记当地光照不可用，改为只参考画面，不主动请求区块加载。同一帧按光源世界位置缓存；烟雾重新筛灯、重排灯槽后仍绑定正确来源。换帧、卸载和资源重载清空缓存及世界引用。

画面输入复用 `RVP_ScreenFrameResources` 已保存的照明前颜色，读取当前像素及上下左右各相距2像素的五点平均明暗。同一像素的多盏灯共用这次画面采样，采样边缘限制在屏幕内。所有通道都只读这个副本，不把已经加上的RVP灯光再次算成环境亮度，也不在正常绘制中回读显卡数据。

```text
E = 当地光照可用 ? 游戏权重×游戏亮度 + (1−游戏权重)×画面亮度 : 画面亮度
t = smoothstep(0.2, 0.8, E)
倍率 = 1 − (1−最亮保留比例) × t^过渡指数
```

`smoothstep` 是两端变化较缓的连续过渡：E≤0.2时t=0，E≥0.8时t=1。关闭适应精确返回倍率1。半径、年龄、燃烧阶段、原有淡出、光晕收缩和灯数预算不随环境参数重置。

显卡共用 `rvp_ambient_light.glsl`。世界表面、粒子烟、体积烟、发动机外晕分别传入各来源的当地亮度，缺失用负值表示。自发光主体不乘环境倍率，光晕柔化后的最终合成不再重复乘倍率。

## 3. 调参入口

F8 → 屏幕空间特效 → 环境光与光晕总设置，或 `/rvplight set global <参数> <值>`：

| 参数 | 默认 | 范围 | 含义 |
| --- | --- | --- | --- |
| `ambientEnabled` | 1 | 0或1 | 环境适应开关，0恢复原效果 |
| `ambientWorldWeight` | 0.7 | 0～1 | 游戏光照权重，其余权重来自原画面 |
| `ambientMinStrength` | 0.1 | 0～1 | 最亮环境保留的灯光输入比例 |
| `ambientCurve` | 1 | 0.1～4 | 大于1更晚减弱，小于1更早减弱 |

参数下一帧生效；复用现有 `/rvplight status`、`copy`、`reset` 和F8预设保存/恢复，不新增TOML或武器JSON配置。原有开关未开启的效果不会被环境适应自动打开。

## 4. 验证

- 单元测试覆盖八点插值、跨格连续性、缺区块和无效值回退、同位置复用及灯槽重排、换帧/清理、禁用时跳过世界读取。
- 面板和指令测试覆盖四项参数、开关整数校验、预设往返恢复，以及修改环境参数不改变原有光源年龄、核心或寿命。
- `test_screen_light_gl.ps1` 使用实际生产显卡程序回读像素，覆盖默认70/30混合、暗处100%/最亮10%、缺区块、五点平均、单调连续过渡、八灯来源、照亮/光晕/天空/粒子烟，以及核心、贴身光团、喷焰和可见度不变。
- `test_rocket_trail_volume_gl.ps1` 在 `./gradlew classes` 或完整构建后运行，验证体积烟只对受光乘一次10%输入、暗处保持、缺区块回退、密度/底色/透明度不变；原有遮挡、DH正反深度和混合回归保留。
- 实机观感需在晴天、夜晚、雨天、洞穴、火把旁、不同维度和远处未加载区块分别核对；原版、DH远景及光影包组合仍需实际客户端确认，自动像素回归不等同于这些环境已全部实测。

构建按仓库规定的Java 17环境在项目根运行 `./gradlew build`。本轮不改本体、不新增Mixin、不修改载具或武器资产，也不向测试客户端复制文件。

2026-11-01自动验证记录：1132项单元测试全部通过；两套原生显卡像素脚本及 `screenEffectStateGpuRegression`、`lightingFrameGpuRegression`、`rocketTrailInteriorGpuRegression` 均通过，OpenGL错误数为0。游戏原生加载器另覆盖144组近景/DH遮挡场景、三类光源的左右箱体投影、八灯来源和旋转实体，帧资源回归覆盖颜色副本、窗口变化和状态恢复。

阴影对照脚本每种几何模式绘制前明确清回相同的原始背景，再捕获颜色；此前连续复用上一模式的灯光结果作为背景，会使环境适应读到不同明暗，造成对照条件不一致。该修正只在诊断脚本，不改正式遮挡算法。
