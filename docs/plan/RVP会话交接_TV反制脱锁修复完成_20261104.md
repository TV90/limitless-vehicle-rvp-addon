## 修复内容与行为

1. **烟雾/视线脱锁**：移除 BaseBullet / SaclosDesignation 在 TV 检查前刷新实体记忆的两条路径。TV 输入和持续跟踪复用 `RVP_HitlTvTargeting` 检查，通过后才更新坐标；不再出现制导源报告失败、惯性分支却读取隐藏目标实时坐标的情况。
2. **烟雾固定点**：沿用原设计，脱锁时在烟中心五格以内、实际烟体内生成一次偏移点，清实体、骨身份和旧运动记忆。目标和烟体之后移动都不会改变这个点；烟散不会自动重新追踪，但玩家可以重新指定可见目标/OBB。普通地形遮挡保留最后可见点，是否继续朝固定点制导仍遵从既有 `enable_inertial_guidance`。显式清除同时清惯性记忆。
3. **真实射线与 OBB**：共享光学检查用实际射线与遮挡体 AABB 相交，替代“大包围盒内有烟就遮挡”。仅展开后的 RVP 烟雾参与光学遮挡；可见方块表面不会被当作自身遮挡。TV 检查使用玩家选择的 OBB 点，不再拿另一个实体中心检查。客户端点选也能命中不可 pickable 的烟云，不能直接选穿烟后的实体。
4. **DIRCM**：`RVP_DircmEventHandler` 在白闪结束但 `dircmNoRedesignateTick > 0` 时继续推进计时。TV 在第 60 tick 白闪结束，禁锁剩余 60；第 120 tick 禁锁归零，实体/地面重新指定都恢复。指令线弹的 120 tick 干扰及恢复保持原有行为。
5. **速度脱锁**：保留原 3D 速度 `deltaMovement.length() × 72`、默认 72 km/h、严格大于阈值、0 禁用的规则；保留 OBB 弱点跟踪。烟雾与高速叠加时也不再保留隐藏实体跟踪。
6. **HUD 权威结果**：客户端发送指定请求不再立即生成乐观实体框，C2S 成功/拒绝后都会确认服务端结果。实体 ID / OBB / 脱锁变化立即同步，移动点常规最多每 5 tick 更新；DIRCM 原有白闪计时同步保留。状态缩写为 ENT/PNT/SMK/LOS/SPD/JAM。入镜重复消息保持当前锁点；HUD 不再回退出生包里的旧目标。禁锁期按键被消费，不积压到恢复后执行。
