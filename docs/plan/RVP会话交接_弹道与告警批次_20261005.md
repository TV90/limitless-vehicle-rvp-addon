## ⚠️ 必读 1：冒烟测试新方法（旧方法会留杀不掉的服务端进程）

`./gradlew runServer --console=plain > <日志名>.log 2>&1` 后台启动 → **每 5 秒轮询**日志
`grep -a "Done ("` → **见到 Done 立即**：
`wmic process where "name='java.exe' and commandline like '%ywzj%'" get processid` 取 PID →
`taskkill //F //PID <pid>` → **全路径复验** `/c/Windows/System32/tasklist.exe`（Git Bash 里裸
`tasklist` 会静默假阴性）确认 java 进程为 0。**不要等 stdin EOF 自退**。后台 shell 的
task-notification（exit 0）只是外层 bash 退出，不代表复验过。

## ⚠️ 必读 2：run 目录载具包暂不同步

`run/server`、`run/client_1` 等下的 limitless_vehicle 副本**暂时不与权威包
`limitless_vehicle/` 同步**——当前只做**代码启动测试**（runServer 冒烟），不校验载具数据行为。
权威副本铁律见 agents.md（排查/修复一律只看 `limitless_vehicle/`）。
