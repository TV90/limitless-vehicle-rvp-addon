## 1. 已修复的真根因（本轮排查结论，勿再走弯路）

1. **"绕大圈被强行扭弯/转弯率归零"的真根因 = `hitlLife` 指令生命期静默冻结**：
   `hitl_max_control_tick`（TL-17=600t/30s）从发射起无条件倒计时、无输入续命；耗尽后
   `tickHitlMouseInertia` 直接 return（舵量冻结），制导源继续读冻结航向 → 导弹沿旧指令
   直飞甩掉目标。**已修**：`rvp$setHitlSteeringInput`/`setHitlDesignatedTarget/Entity`
   收到有效输入即 `ywzj_rvp$refreshHitlLife()` 重置为上限——持续操控即持续可控。
2. **排除项（已证伪，勿重查）**：无累计转向角限制；slew 数学 wrap 正确；非 DIRCM/ECM
   干扰（用户单人无干扰机实测仍复现）；非 max_guidance_angle 贴边（修复后全程
   within=true 仍复现过——真根因是上面的生命期冻结）。
3. **电视弹（HITL_TV/KH-39/AGM-179/KD-88）从未有此 bug**——曾误加的 DESIGNATE 贴边
   钳制已撤销，电视弹保持原超角拒绝规则。

## 2. 现行操控模型（虚拟摇杆，2026-09-11 定稿）

- 客户端：鼠标增量 ×0.15（单帧钳 ±4°）累加为**转向偏移** `hitlYaw/hitlPitch`，
  钳制 **±45°**；每客户端 tick 偏移指数衰减（`STEER_OFFSET_DECAY = 0.6`，停手约
  0.3 秒回直飞——用户要求快速回中，从 0.92 加快到 0.6）；
- 服务端：舵量目标 = **弹体当前朝向 + 偏移**（`tickHitlMouseInertia`），以
  `hitl_max_turn_deg_per_tick`（TL-17=2.5°/t）slew；偏移保持 = 持续转向，回中 = 直飞；
- 偏移恒在锥角内（≤45° = max_guidance_angle），直控永不触发超角拒转；
- 指令源回退（`resolveCockpitCommand` 武器站炮轴）对 MOUSE 模式不生效（isHitlMouseSteering 门控）。
