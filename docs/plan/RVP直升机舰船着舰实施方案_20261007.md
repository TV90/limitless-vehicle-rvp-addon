# RVP 直升机舰船着舰实施方案与实施记录（2026-10-07）

> 状态：已实施，build+测试全绿（738/0/0）+冒烟通过+测试服已部署，待实机验证。
> 需求（用户）：舰船结构模型新增 helipad 特殊 OBB → 直升机 48 格内提示按 P → 自动飞向舰船吸附
> 着舰（随舰行驶）→ 再按 P 自动爬升 15 格后恢复操控。着舰过程免两车碰撞互毁。

---

## 一、三路调研结论（可行性依据）

1. **helipad OBB**：RVP 已有三类 per-骨骼配置先例（`physics_only_bone`/`bone_modules`/
   `hitbox_damage_factor`），骨名集合天然支持多 pad；世界系 OBB 用本体
   `OBB.getOBBsFromBone(bone, vehicle, namedBones)` 按舰船实时位姿现算（随舰转向自动成立）。
   工程惯例坑：新字段必须纳入 `parseVehicle` 的"全空→EMPTY"早退（§45 审计教训）。
2. **绑定方式**：本体 `AbstractVehicle.addPassenger` 只接受 LivingEntity，**载具骑载具不可行**
   （静默丢弃 + tickCount==1 踢光乘客）；用户提到的"叠加炮塔武器站"是同一载具内部部件树
   （WeaponUnit 纵向堆叠），非实体叠加。**采用方案 B：独立实体 + 每 tick 强制同步**
   （本体吊运 `RotaryWingVehicle.tickCargo` 每 tick teleport+清速度同款模式）。
3. **控制接管**：盘旋服务同款（ServerTickEvent 写 controlUnit，旋翼模拟偏航 yRot 无 driver
   检查）；输入屏蔽复用 `ControlUnitMixin`（服务端拦截）+ 客户端 suppress 双保险；P 键两仓库
   未占用；`collision` 是本体 public 开关（门控 push/support），`VehicleAttackEvent` 可拦撞击伤害。
4. **关键物理事实**：甲板（实体 OBB）不提供 onGround 支撑——着舰必须每 tick 全权接管
   （teleport + 清 deltaMovement/fallDistance），否则重力持续下拉穿舰；两车 OBB 重叠时
   `push()` 水平分离 + `impact()` 按吨位计伤（驱逐舰蹭直升机必毁）→ `collision=false` +
   `VehicleAttackEvent` 拦双向撞击。

## 二、行为规格（用户定版）

| 阶段 | 行为 |
|---|---|
| 提示 | 驾驶直升机 48 格内有带 helipad 舰船 → actionbar「按 P 降落在舰艇上」（每 10t 刷新） |
| APPROACH（按 P） | 服务端写 controlUnit 自动飞向 pad 上方 6 格悬停高度（yRot 模拟偏航+forward+up/down）；玩家运动输入双侧屏蔽；collision=false；水平 ≤5 格且高度差 <8 → 吸附 |
| DOCKED | 每 tick teleport 到 pad 世界中心 + 随舰 yaw？→（当前实现：仅 teleport+清速度；yaw 同步见 §五待办）不可操控；可被武器伤害（collision=false 不免疫武器）；再按 P → TAKEOFF |
| TAKEOFF | 每 tick up=true 爬升，相对甲板 ≥15 格 → 解锁（清 controlUnit、collision=true） |
| 兜底 | 舰船失援（死亡/卸载）100t 宽限后自动解除并恢复操控；APPROACH 中再按 P 取消；TAKEOFF 中不响应 |
| 多 pad | 取距直升机最近且未占用者；`isShipOccupied` 着舰互斥 |

## 五、待实机验证与已知边界

1. 舰船 structure.json 需**美术侧新增具名骨**（如 `helipad`，cube 定坪位/尺寸）+ 舰船载具 JSON 顶层加
   `"rvp_helipads": ["helipad"]`——两者都配好提示/着舰才会触发；
2. APPROACH 自动飞行手感（旋翼模拟偏航+脉冲高度控制，无姿态锁定——可能略晃）；
3. DOCKED 的 yaw 同步**暂未实现**（当前仅位置同步+清速度，直升机朝向保持自身值）——舰船转向时
   直升机朝向不跟随，待实机确认观感后决定是否补；
4. 着舰态可被武器伤害（用户定版保留）；弹体可否打中还取决于舰船 OBB 遮挡（直升机贴甲板可能被
   舰体 hitbox 挡住）——实机观察；
5. TAKEOFF 爬升段前飞脱离量较小，紧邻舰桥时可能再蹭——实机观察；
6. 多人：着舰锁只对驾驶员提示/响应，机上乘客被动跟随（不可操控本就如此）。
