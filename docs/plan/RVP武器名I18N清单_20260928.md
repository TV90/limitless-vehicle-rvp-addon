# RVP 武器名 I18N 清单（2026-09-28，等用户确认后批量迁移）

> 目标：武器 JSON `name` 双语化——**现有中文 `name` 迁移至 `name_CN`，`name` 改为推荐英文**
> （英文用军事术语缩写风）。机制已实现（§30.2）：中文环境显示 `name_CN`，其它语言显示 `name`。
> 本文为映射清单，**未动任何 JSON**；确认后用脚本批量执行并校验。

## 一、迁移规则

1. 现有 `name`（中文）→ 原样写入 `name_CN`；
2. `name` 替换为下表"推荐英文"列；
3. **已纯英文的武器不迁移**（A 组，name 不动、不写 name_CN）；
4. 彩蛋/架空名（B 组）给占位英文，用户可改。
