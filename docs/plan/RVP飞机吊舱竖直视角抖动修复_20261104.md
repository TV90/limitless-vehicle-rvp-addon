# 飞机吊舱竖直视角抖动修复

日期：2026-11-04。已完成输入和相机姿态修复；新日志确认新版站已启用，
本轮进一步修正左右/俯仰边缘的等价角切换，以及接近 180° 时的角度展开，待实机复验。

后续：2026-11-05，新版吊舱的实际转动与相机已接入[统一受约束视线](RVP吊舱统一受约束视线实施_20261105.md)。
本文保留历史根因、载具参数及旧轮次记录；当前执行和网络规则以新文档为准。

## 根因

权威载具包的相关观瞄站配置为俯仰 `-40°..120°`、左右 `-120°..120°`，并启用双向稳定器。
120° 俯仰表示视线能经过正下方，再看向机头后下方；配置本身没有过期或缺少这个能力。

本体 `WeaponUnit.tickRot` 会用 `worldVecToLocalRot` 把稳定器记住的世界方向换回局部角度。
原算法只返回俯仰在正负 90° 以内的一组角度：例如 `(俯仰 120°, 左右 0°)`
会被改写成同方向的 `(俯仰 60°, 左右 180°)`。
数学上两组视线相同，但第二组超出吊舱的左右止挡；再钳到 120° 就变成另一条视线。
在竖直附近，浮点尾差与稳定器逐刻纠正会反复触发该问题。

无窗口回归直接执行本体稳定器：从 89.5° 请求 90.5°，旧实现即错误地把左右目标推到 120°。
这解释了“向下看就乱晃”和“无法正确看向后方”为何同时出现。

另一处问题是 `RotatableUnit.worldZRot` 用反号俯仰计算横滚，而 `worldRot` 使用正号俯仰。
相机又将旋转拆成三个角度，竖直附近左右角与横滚不再能单独稳定确定，容易各跳半圈。
三个角来自不同姿态会把这种表示跳变变成实际画面翻转。

## 修复

- 注册部件类型 `ywzj_rvp:optical_weapon`，实现类 `RVP_OpticalWeaponUnit` 继承本体 `WeaponUnit`。
  复用现有武器站配置解析，包括 `crt_ui`；没有新增武器类型、数据字段或旧格式兼容。
- 覆写已有方法 `worldVecToLocalRot`、`worldZRot`，并在继承的 `tickRot` 链内标记刻首解角上下文。
  前者同时考虑两组等价角度，先保持机械转动连续，再由调用方执行限位；
  正上/正下方保留原左右角，避免浮点尾差决定朝向。
  稳定器、旋转限速、损坏/动力限制与网络同步仍执行本体代码。
- `RVP_ClientOpticalSight` 使用 Forge `ComputeCameraAngles` 事件读取完整插值姿态。
  通过前、右、上方向求连续角度，避免在竖直处直接调用不稳定的拆角方法。
  零横滚基准轴使用双精度三角函数，避免接近 180° 时的单精度半角误差。
- 普通输入和独立焦点统一按画面左右/上下旋转；普通镜头仍跟随实际机械视线，
  稳定器开启时只补偿看向目标所需的转动，不跟随机械偏航在竖直处旋转整幅画面。
  受损方向机相机沿用同一实际姿态；本体爆炸震屏仍在后续事件叠加。

未修改本体源码、结构模型、Mixin 类或注入点。
未扩展机械范围：原配置只能看向允许的后下方角度，不意味着能看向正后方水平线。

## sighting_system 观瞄吊舱参数速查

**修改位置**：根目录 `limitless_vehicle/rvp/data/rvp/vehicles/<载具>.json` 的 `parts[]`，
找到 `id` 为 `sighting_system` 的部件。双座飞机还要分别检查 `sighting_system_2`；
SUAV 的同类部件 `id` 叫 `seat`，但 `structure_bone` 仍为 `sighting_system`。
这里配置的是“玩家操作的观瞄站”，不是 `data/rvp/weapons/` 中的武器弹药数据。

下表“当前值”以 **J10C 主观瞄站**为例；“默认”指当前代码在字段省略时的定义，
不代表建议删掉显式配置。坐标和角度必须按本车模型核对，不能照搬另一架飞机的座位坐标。

### 1. 转动范围、速度与观瞄能力

| 参数路径 | J10C 当前值 | 省略时默认 | 含义、单位与改动效果 |
| --- | --- | --- | --- |
| `type` | `"ywzj_rvp:optical_weapon"` | 应显式指定 | 部件实现类型。使用本修复的连续观瞄站，不能改回 `ywzj_vehicle:weapon` 后仍期待普通输入和机械稳定修复生效。它不是武器弹药的 `type`。 |
| `rot_info.x_rot_min` | `-40` | `-90` | 俯仰下限，单位：度。基座水平且无固定偏角时，负角表示向上；`-40` 表示最多向上看约 40°。 |
| `rot_info.x_rot_max` | `120` | `90` | 俯仰上限，单位：度。同样条件下，`0` 为向前、`90` 为正下、`120` 为经过正下方再向后转 30°。改成 `90` 就会失去这部分后下方范围。 |
| `rot_info.y_rot_min` | `-120` | 无有限止挡，源码为 `-Float.MAX_VALUE` | 左右转向下限，单位：度。与上限共同控制吊舱绕基座的左右范围，不是世界地图上的绝对航向。 |
| `rot_info.y_rot_max` | `120` | 无有限止挡，源码为 `Float.MAX_VALUE` | 左右转向上限，单位：度。当前为左右各 120°；要扩大两侧范围，应一起检查上下限，而非只改一边。 |
| `rot_info.x_rot_speed` | `7` | `0` | 俯仰机械转速，单位：度/游戏刻。正常每秒 20 刻，`7` 约为 140°/秒的配置转速；`0` 表示该轴不能主动转动。实际仍受动力、损坏和限位影响。 |
| `rot_info.y_rot_speed` | `7` | `0` | 左右机械转速，单位：度/游戏刻。调大后实际转向更快，也会影响普通观瞄的鼠标输入尺度；不是单独的鼠标灵敏度开关。 |
| `rot_info.x_rot` | 未写，使用 `0` | `0` | 初始俯仰机械角，单位：度。不是转动上限；已有实体还可能从存档恢复角度，不能靠它强制复位。 |
| `rot_info.y_rot` | 未写，使用 `0` | `0` | 初始左右机械角，单位：度。不是世界朝向，也不改变左右限位。 |
| `rot_info.need_power` | 未写，使用 `true` | `true` | 是否需要载具动力才能驱动机械转动。设为 `false` 可取消这一动力条件，但不取消部件损坏限制。 |
| `with_stabilizer` | `true` | `false` | 双向稳定器。开启时补偿机体转动；新版观瞄还会保持画面横轴，避免机械偏航在正下方附近把整幅画面转来转去。 |
| `with_focus_locker` | `true` | `false` | 是否具备地面焦点锁定能力。开启后可由原有 R 键分流建立焦点；不是实体自动跟踪开关，当前武器的雷达/光电/GPS 分流仍可能优先处理 R 键。 |
| `with_thermal_imager` | `true` | `false` | 是否具备观瞄热成像能力，不控制倍率、转速或相机位置。 |
| `zoom_min` | 未写，使用 `1` | `1` | 低倍率，单位：倍。当前为 1 倍；开镜初始倍率使用它。建议显式保证 `0 < zoom_min <= zoom_max`。 |
| `zoom_max` | `12` | `8` | 高倍率，单位：倍。倍率切换在 `zoom_min` 与 `zoom_max` 间切换；这里不是最远可见距离，也不是锁定距离。 |
| `optical_sight_type` | `"crt_ui"` | 未指定，建议显式写 | `crt_ui` 保留观瞄准星和界面，关闭旧式显示器风格滤镜；`crt_ui_operator` 在此基础上让镜头位置随俯仰骨转动。改变它会影响镜头位置路径，详见下一表。 |

**角度要按基座理解**：上述“90° 为正下”以机体和观瞄基座水平、没有固定偏角为前提。
飞机抬头、侧倾或基座本身带旋转后，世界正下方不一定对应局部 `x_rot = 90`。
代码还会用模型的固定角 `xSelfRot/ySelfRot` 换算机械限位；它们来自现有结构，不是新增 JSON 字段。
本体机械角会折回正负 180° 范围，不能把 `x_rot_max` 填成 `360` 就当成俯仰可无限转圈。

### 2. 镜头位置、座位与挂骨

| 参数路径 | J10C 当前值 | 省略时默认 | 含义、单位与改动效果 |
| --- | --- | --- | --- |
| `id` | `"sighting_system"` | 应显式指定 | 本车部件的唯一标识。其他部件用它建立引用；不要只改名字而漏改关联。它不必与结构骨名相同。 |
| `name` | `"sighting_system"` | 通用部件名称 | 部件名称字段，不负责决定吊舱挂在哪根骨上，也不决定相机位置。 |
| `structure_bone` | `"sighting_system"` | `null` | 引用本车已经存在的结构骨。它提供基座和旋转参考；优先找同名加 `_barrel` 的骨作俯仰组，没有时回退到该骨自身。双座后站可为 `sighting_2_system`。 |
| `optical_sight_offset` | `[0,0,1]` | `[0,0,0]` | **开镜相机偏移**，单位：方块。普通 `crt_ui` 路径中，以该站结构枢轴为基准加偏移，再转换到世界坐标；不等于载具原点的绝对坐标。想移动吊舱镜头，先检查这一项。 |
| `operator_view_offset` | `[1.015625,2.7921875,1.315625]` | `[0,0,0]` | **操作员视点偏移**，单位：方块，相对于该站枢轴。主要用于操作员/座舱视角及选择了该位置路径的观瞄；当前 `crt_ui` 且 `optical_sight_offset` 有值时，不靠它移动开镜镜头。 |
| `seat_offset` | `[0,3.8125,5.8125]` | `[0,0,0]` | **乘员座位偏移**，单位：方块。本体按乘员眼高修正坐姿位置；改它移动的是乘员位置，不能把它当成吊舱开镜相机偏移。 |
| `seat_rot` | 未写，使用 `0` | `0` | **座位默认左右朝向**，单位：度，相对机头。`0` 表示朝机头；本轮飞机退出观瞄时也使用这一默认朝向，不使用吊舱当时的转角。 |
| `operator_on_weapon_unit` | `false` | `true` | 乘员座位是否跟随本站自身转动。飞机驾驶员/武器官通常保持 `false`，避免人跟着吊舱转；不等于关闭吊舱转动或观瞄稳定器。 |
| `is_seat` | 未写，使用 `true` | `true` | 是否作为可乘坐/操作的座位部件。独立后座通常显式写 `true`；不要为了隐藏部件把操作座位改成 `false`。 |
| `rvp_no_cockpit_view` | 未写，使用 `false` | `false` | 该座位是否跳过操作员/座舱第一人称。设为 `true` 后，常规视角循环为第三人称与观瞄；适合没有独立座舱视点的后座。 |
| `rvp_optical_sight_follow_pitch` | 未写，使用 `false` | `false` | 是否让开镜**位置**随俯仰骨旋转；`crt_ui_operator` 会自动补为 `true`。这是相机挂点行为，不是“鼠标能否向下看”的开关。 |
| `rvp_optical_sight_pivot` | 未写 | `null` | 自定义观瞄基准枢轴，单位：**模型像素**。代码先除以 16 换成方块，再加 `optical_sight_offset`；用于匹配已有渲染骨枢轴。不要与 `rvp_optical_sight_follow_pitch: true` 同时配置，两条位置覆盖路径不保证组合顺序。 |
| `rvp_disable_crt_effect` | 由 `crt_ui` 自动补为 `true` | `false` | 是否禁用旧式显示器滤镜；不关闭观瞄界面。显式配置会优先保留，例如写 `false` 可覆盖 `crt_ui` 的自动值。 |

位置数组统一按 `[x,y,z]` 填写：x 为左右轴、y 为上下轴、z 为前后轴，正负方向按本车模型坐标核对。
**三个位置不要混用**：镜头看出去的位置看 `optical_sight_offset`，座舱视点看 `operator_view_offset`，
乘员坐在哪里看 `seat_offset`。除 `rvp_optical_sight_pivot` 用模型像素外，上述偏移都是方块单位，
`1 方块 = 16 模型像素`。同名的部件枢轴、渲染骨枢轴和载具原点也不是一个点。
调位置优先改配置偏移；若确需修改结构模型的骨层级、枢轴或几何，仍须先确认并备份原文件。

### 5. 想改某种效果，优先看哪里

| 想调整的效果 | 修改位置 / 当前实现 |
| --- | --- |
| 向后下方看得更多或减少向上范围 | `rot_info.x_rot_min/max`；先区分局部机械角与世界角。 |
| 扩大左右观察范围 | `rot_info.y_rot_min/max`；保留最小值不大于最大值，实机检查两侧。 |
| 吊舱实际跟随更快或更慢 | `rot_info.x_rot_speed/y_rot_speed`；普通鼠标尺度也会受影响。 |
| 放大更多或初始就带倍率 | `zoom_max` / `zoom_min`；倍率不是测距或锁定距离。 |

现在先选与参考机械角距离最近的分支，再由原有调用方钳在当前分支的限位。
只有两组转动距离相等时，才用机械范围作平局判定；不会为了绕过边缘而令俯仰/偏航各跳近半圈。

另一处修正是先围绕参考角展开候选，再执行限位。例如从 +179° 请求到 +181°，
应停在 +179°，不能先把请求折成 -179° 后又钳到 -40°。

## 实机验收

1. 先同步 jar 与上述载具配置，用 F16V 或 J10C 打开吊舱观瞄，不按 R，缓慢从前下方转到正下方再转向后下方，反向重复。
2. 在正下方附近左右微调，松鼠标保持；分别用低倍和高倍检查有无前后左右跳动或画面翻滚。
3. 飞机同时转弯、爬升和倾斜时重复，不能只在水平静止姿态验收。
4. 在后下方按 R 锁点，再飞过脚下锁点并解锁；验证视线、GPS 选点和实际地面目标一致。
5. 切换双座观瞄、第三人称和电视导弹后回来，确认没有继承另一会话的方向。
6. 吊舱转向地面、侧后方后，分别用观瞄键和 V 键退出；默认朝向应回到机头。飞机倾斜时重复，反复进出后仍应正确，退出后鼠标环视应正常。
