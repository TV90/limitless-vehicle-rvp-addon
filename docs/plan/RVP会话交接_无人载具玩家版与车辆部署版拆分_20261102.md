# RVP 会话交接：无人载具玩家版与车辆部署版拆分（2026-11-02）

本文件是最新会话入口。当前 HEAD 仍为 `cabf25b0`，版本 `0.1.0f_beta_0.6.2`、网络协议 35。上一批座舱修复已推送 Gitee/GitHub；本批只有根载具包 JSON 和本地记录变化，没有 Java 或构建配置变化，不生成新 jar、不 bump 版本、不提交包资产。

## 用户指令和范围

- 将 C4/Recon/RPG 三种旋翼无人机分为车辆部署版和玩家版；部署版 `uav: false`，玩家版 `uav: true`，其它属性相同。
- 部署版像 IRIS-T SLM 雷达车一样在创造物品栏隐藏，玩家版可见。
- RAWR 同样分为两版；本轮按同一套标志处理：玩家版 `uav: true`，部署版 `uav: false`，部署版隐藏。
- 母车候选指向部署版。SUAV 本轮保持原配置。
- 主线程亲自完成，不派 Luna；本体只读，禁止真正删除。开发包仅根 `limitless_vehicle/`；旧 authoritative 目录和 run 沙盒不作诊断源，也未同步用户游戏目录。

## 两版 ID

| 类型 | 玩家版（原 ID） | 车辆部署版（新增 ID） |
| --- | --- | --- |
| RAWR | `rvp:rawr` | `rvp:rawr_deployed` |
| 自爆四轴机 | `rvp:uav_c4` | `rvp:uav_c4_deployed` |
| 侦察四轴机 | `rvp:uav_recon` | `rvp:uav_recon_deployed` |
| 武装四轴机 | `rvp:uav_rpg` | `rvp:uav_rpg_deployed` |

- 玩家版显式配置 `uav: true`、`rvp_hide_in_creative: false`。
- 部署版显式配置 `uav: false`、`rvp_hide_in_creative: true`。隐藏机制完全复用 `irist_slm_tads.json` 的字段及当前创造栏/搜索页过滤，不加入硬编码 ID。
- 两版除上述两个开关以外，数据 JSON 的所有字段完全相同，且逐项等于改动前模板：物理、血量、武器、燃料、座位、结构模型等没有调参。RAWR 原来未配置本体 uav，玩家版改 true 是本轮明确的行为变化。
- 四个新 display JSON 与原 display 逐字节相同，共享现有模型、贴图、槽位图、声音和动画控制器，没有复制/修改美术或结构资产。
- 根包 `assets/rvp/lang/zh_cn.json` 和 `en_us.json` 各增加 8 个新 ID 的名称别名，值与原 ID 相同，原有名称键和值全部保留。

## 母车引用

- ZBL08A、LAV25、ZTZ100：各 4 处候选 `vehicle_id` 改为 `_deployed`。
- M142、9K720：各 3 处旋翼候选改为 `_deployed`。
- 共 18 处。候选 `id`、显示名、默认选项、位置偏移、初速、冷却和其它母车字段保持原值，因此当前选中的候选 ID 不需要变更。
