# RVP 载具命中别名 I18N 清单（2026-09-28，等用户确认后批量迁移）

> 目标：载具 JSON `hitbox_display_name` 双语化——**现有中文值迁移至 `hitbox_display_name_CN`
>（新顶层对象，键不变），`hitbox_display_name` 值改为推荐英文**。机制已实现（§30.3）：
> 中文环境显示 CN 别名，其它语言显示英文别名。本文为映射清单，**未动任何 JSON**。
> 共 11 台载具；别名高度重复，先给通用词表，再给逐车差异行。

## 一、迁移规则

1. 现有 `hitbox_display_name`（中文值）→ 原样写入新顶层对象 `hitbox_display_name_CN`（键=骨名不变）；
2. `hitbox_display_name` 各值替换为下文推荐英文；
3. 同一中文词全 mod 统一同一英文（下表词表）。
