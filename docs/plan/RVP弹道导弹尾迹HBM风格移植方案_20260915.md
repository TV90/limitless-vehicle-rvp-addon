# RVP 弹道导弹尾迹 HBM 风格移植方案（2026-09-15）

> 状态：已实现，待实机验收。
> 模仿对象：HBM（Hbm's Nuclear Tech Mod，1.7.10）弹道导弹尾迹
> `com.hbm.particle.ParticleRocketFlame`（飞行尾迹）+ 发射台 `launchSmoke`
> （`ParticleSmokePlume`，`TileEntityLaunchPad`）。
> 用户诉求：现有尾迹（原版营火烟 / `rvp_smoke` 灰烟团）观感不像弹道导弹，
> 参考 HBM 弹道导弹的"先火后烟"柱状尾迹重做。

## 一、HBM 原机制调研结论

- **飞行尾迹**（`EntityMissileBaseNT.spawnContraolWithOffset`，客户端每 tick）：
  沿上一 tick→当前位置的路径每 1 格 1 粒（每 tick 1~10 粒防高速断档），
  初速沿弹轴反方向 ×1.0，`ParticleRocketFlame` 渲染 10 层抖动 quad 伪体积感，
  >350 格剔除；无高空淡化门控，浓淡全程一致。
- **颜色/寿命/尺寸**（`ParticleRocketFlame`）：
  `dark = 1 - min(age/(maxAge*0.25), 1)`；R=dark+rand*0.3、G=0.6*dark+rand*0.3、
  B=rand*0.3（前 25% 寿命亮橙焰 → 深灰随机烟）；α=sqrt(1-age/maxAge)×0.75；
  每层半宽 `(rand*0.5 + 0.1 + 2*ageRatio) × scale`（约 0.35 → 2.6 × scale 膨胀）；
  寿命 60+rand(20)t；位置抖动幅度 `((ageRatio)*4+1)^1.5` 随寿命急剧扩大（柱状→散开云）；
  阻尼 0.91/tick、亮度 240 全亮。
- **大小弹差异**：`getContrailScale()` 小弹 0.5 / 大弹 1.0；Tier3/4 大弹 3~4 条平行尾迹（多喷口）。
- **发射台烟浪**（`TileEntityLaunchPad`）：导弹在发射台上方 AABB 内时每 tick 15 粒
  `ParticleSmokePlume`：寿命 80+rand(20)、0.25 → 2.25 线性膨胀、膨胀量转浮升、
  水平径向冲刷初速 0.6~0.9、阻尼 0.925、随机灰度。

## 五、实机反馈调参（2026-09-15 第一轮）

实机反馈：烟太大、粒子过多、**末端烟呈彩色而非黑烟/白凝结烟**。

- **彩色烟根因 = 变色逻辑，非贴图**：`particle_base.png` 实测纯白（均值 RGB 255/255/255、
  通道零色散）；彩色来自照搬 HBM 的烟相位逐通道独立随机（R/G/B 各掷 0~0.3 → 每 tick
  随机色相，HBM 自身渲染管线多 quad 叠加会平均掉，单贴图 alpha 混合下则暴露为彩色噪点）。
  **修正**：烟相位改 R=G=B 单一中性灰（0.15~0.3，黑烟观感），橙色只保留在火焰相位且随机
  幅度收窄到 ±0.1；橙→灰用 `dark` 因子平滑插值。
- **烟太大**：半宽公式 `(rand*0.5+0.1+2×ageRatio)×scale`（末端 2.6×scale，配 9M723 的 1.5
  倍率 ≈ 3.9 半宽）改为 `(0.2+rand*0.3+1.0×ageRatio)×scale`（末端 ≈1.5×scale），
  9M723 `particle_scale` 1.5 → 1.0。
- **粒子过多**：二级段 12 格/tick × step 1.0 = 12 粒/tick；step 1.0 → 2.0（6 粒/tick），
  TRAIL 寿命 60~80t → 45~65t（同屏存活约 -45%），发射烟浪 6 → 4 粒/tick。

## 五B、实机反馈调参（2026-09-15 第二轮：大发散只归属地面烟浪）

实机反馈：发射时烟太小太稀疏；空中尾迹末端发散太大、观感古怪——大发散应该只用于
刚发射时冲刷地面，空中尾迹末端不必这么大。

- **根因确认**：TRAIL 渲染层间抖动幅度 `(1+4×ageRatio)^1.5` 寿命末端 ≈11 倍
  （Y 向单层 ±5.6 格）——HBM"柱状→散开云"设计在单贴图管线下的观感即"末端炸散"；
  而地面 WASH 反而没有发散。与用户期望正好相反。
- **修正（大发散只归属 WASH）**：
  - TRAIL 末端发散收敛为线性 `1 + 1.5×ageRatio`（最大 2.5×），空中尾迹保持柱状；
  - TRAIL 基准半宽 0.2 → 0.3（发射段火焰观感稍饱满）；
  - WASH 加密 4 → 8 粒/tick、尺寸 0.25→2.25 改 0.3→3.0 × scale（地面铺开发散的主力）；
  - **烟浪前置到燃烧门控之前**：冷发射弹点火前（flightTick ≤ coldLaunchTimeTick，
    弹射气体段）也出地面烟——新增 `spawnLaunchWash`，从 `spawnMissileNativeTrailParticles`
    内部（燃烧门控之后）移到 `spawnTrailParticles` 开头（门控之前）。
- **发射段稀疏的物理原因**（记录）：一级弱推力下初速 0.3~3 格/tick，路径采样点天然少
  （每 tick 0~1 粒），发射段观感主要靠 WASH 地面烟撑起。

## 五C、渲染状态修复（2026-09-15 第三轮：烟雾不透明挡死载具）

实机反馈：透过半透明烟雾完全看不到载具实体。

- **根因 = 深度写 + 层间 α 叠加双重问题**：
  1. RENDER_TYPE 用了 `depthMask(true)`（抄自 MchrSmoke 模板）——项目内半透明大烟雾的
     既定约定是**深度只测不写**（`RVP_ExplosionVisualManager` 核爆云 L197、
     `RVP_NuclearShockwaveRenderer` L107、`RVP_MchrFlareParticle` L56 均为 `depthMask(false)`）；
  2. 每粒子 3 层抖动 quad 每层全量 α0.75，叠加等效不透明度 ≈ 1-(0.25)³ ≈ 98%——烟柱即实心墙。
- **修正**：RENDER_TYPE 改 `depthMask(false)`（深度测试保留，地形仍遮挡烟）；
  TRAIL 层间 α 按 1/3 分摊（叠加后 ≈58%，半透明可透见载具）。

## 五D、实机反馈调参（2026-09-15 第四轮：烟柱太细）

实机反馈：近地面烟浪扩散观感好，但喷出的烟太细。根因：一级弱推力下弹体爬升慢，
近地面烟柱由"年轻"小粒子主导（出生半宽仅 0.3~0.6）。修正：TRAIL 半宽曲线
`(0.3+rand·0.3+1.0·ageRatio)·scale` → `(0.5+rand·0.3+1.3·ageRatio)·scale`
（出生 0.5~0.8、末端约 1.8~2.1×scale），整条烟柱加粗，仍远小于第一版的 3.9。

## 五E、实机反馈调参（2026-09-15 第五轮：地面烟浪中末期趋白 + 尺寸联动）

新需求：① 冲刷地面的气浪中末期要白一点（凝结云观感）；② 滞留时长和扩散范围随
"HBM 尾迹大小（`missile_native_trail_particle_scale`）× 发射段加粗（`launch_boost`）"提升。

- **趋白**：WASH 出生定脏灰基调（0.25~0.75），寿命 30%~70% 间 smoothstep 向近白（0.95）
  过渡、混合封顶 0.9（保留灰底纹理）；α 淡出曲线不变。
- **尺寸联动**：`spawnLaunchWash` 的 sizeScale 改为 `particle_scale × launch_boost 衰减系数`
  （新增 `resolveLaunchBoostFactor` 供尾迹/烟浪共用）；粒子侧寿命 = (80+rand20) × sizeScale
  （钳制 [40, 600]），膨胀末端 3.0 × sizeScale——发射段 boost 1.6 时滞留约 128~160t、
  末端半宽约 4.8，烟更大滞留更久；加粗窗口过后逐步回落常规。
- 加粗衰减计算抽为 `RVP_BaseBullet.resolveLaunchBoostFactor`，尾迹与烟浪共用同一系数。

## 五F、实机反馈调参（2026-09-15 第六轮：烟浪抖动 + 白云压扁）

- **地面气浪高频抖动（bug）**：render() 的高斯层间抖动对 WASH 单层大 quad 也在每帧重掷
  （±0.2/±0.5 格 @60fps+ = 肉眼可见颤动）。修正：抖动收敛为 TRAIL 专属（体积感），
  WASH 位置只由径向初速 + 浮升驱动，完全稳定。
- **白云扩散期压扁**：WASH billboard 随寿命在本地纵轴线性压扁 1.0 → 0.45 高宽比
  （`WASH_FLATTEN_END`）——初始脏灰烟 1:1 圆团，扩散发白期横铺为贴地扁白云，
  与趋白过渡（30%~70%）同步。

## 样式路由调整：rvp_rocket_flame = 固体发动机凝结云款（2026-09-19 用户定版）

按用户需求重排样式路由：凝结云款成为 `rvp_rocket_flame` 的默认观感（三弹 JSON 无需改动）；
原液氧煤油黑烟款转为技术储备，改由新样式名 `rvp_kerosene_black_smoke` 路由（配置可选）。

- **`rvp_rocket_flame`（默认款，生效弹：9k720_9m723 / bukm3_9m317ma / f14a_iriaf_aim23b / f14d_aim54c / irist_sl / j16_yj80 / su57_kh38 / su57_kh58，后五者 09-19 新配 9m317ma 同款参数）**：
  火焰相位（寿命前 25%）亮橙黄不变；烟相位出生**中灰 0.55~0.70** 并随寿命 smoothstep（20%~70% 窗口）
  渐变到 **0.9 凝结云灰白**；寿命延长 **120~180t（6~9 秒）**——飞过的整段弹道都留有凝结云；
  α 曲线改为**前 45% 寿命保持 ~0.75、之后 smoothstep 缓缓散开淡出**；WASH 贴地烟浪共用。
- **`rvp_kerosene_black_smoke`（技术储备款）**：09-19 之前的原始观感——寿命 45~65t、烟相位深灰黑烟
  （0.15~0.30）、α 全程平方根淡出。
- 实现方式：粒子类烟色调参数化（`smokeGreyMin/smokeGreySpread/smokeWhiten` 实例字段 +

  桥接 `addRocketFlameTrailParticle`（凝结云）/ `addKeroseneBlackSmokeTrailParticle`（黑烟）双门面。
- **距离 LOD**（仅凝结云款长寿命场景需要）：>256 格 TRAIL 退化单层渲染（顶点省 3 倍）+ 尺寸 1.25×

### 凝结云持久化与距离 LOD（2026-09-19 追加，用户需求：飞过的整段弹道都留凝结云、缓缓散开）

- **寿命**：固体款 TRAIL 240~340t（12~17 秒，液氧煤油款 45~65t）——飞行沿途全程留有凝结云（2026-09-19 二次加长）；
