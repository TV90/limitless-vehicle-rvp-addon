# 爆炸伤害倍率「按机型」改造 —— 实现文档 + 提示词

> 日期：2026-10-12　目标仓库：`ywzj_rvp`
> 需求：让 `detonate_data.explosion_data.explosion_damage_factor` 像 `collision_data.direct_damage_factor` 一样**按目标实体类型（机型）**给倍率。
> 现状：它只能给**一个统一值**（对所有载具生效），无法区分轮式 / 旋翼 / 固定翼。
> 本文给完整改动方案；文末第 §6 是**可直接整份转交代码 agent 的提示词**。

## 2. 目标 JSON 形态（**向后兼容**，同一个键支持两种写法）

```jsonc
// ① 旧写法（数字）：对所有载具统一倍率 —— 语义完全不变
"explosion_data": {
  "damage": 10,
  "radius": 1,
  "explosion_damage_factor": 2.0
}

// ② 新写法（对象）：按机型给倍率 —— 与 direct_damage_factor 完全同构
"explosion_data": {
  "damage": 10,
  "radius": 1,
  "explosion_damage_factor": {
    "vehicle_default": 1.0,
    "vehicles": {
      "ywzj_vehicle:wheeled_vehicle": 2.0,
      "ywzj_vehicle:rotary_wing_vehicle": 2.0,
      "ywzj_vehicle:fixed_wing_vehicle": 2.0
    }
  }
}
```

- 数字形态 = 等价于 `{"vehicle_default": <该数字>}`（旧语义：**对所有载具**统一缩放）；
- 对象形态 = 复用 `RVP_DamageFactor` 的既有语义（未命中 `vehicles` 回退 `vehicle_default`）；
- `null` / 缺省 / `isConfigured()==false` ⇒ **1.0（不缩放）**，与现状一致。

## 3. 改动清单（5 处；**不新增 Mixin**）

### ① 新增 `weapon/data/RVP_DamageFactorAdapter.java`

只挂在 `RVP_Explosion` 的那**一个字段**上（字段级 `@JsonAdapter`），**不影响** `RVP_CollisionData.direct_damage_factor`。

```java
package org.ywzj.rvp.weapon.data;

import com.google.gson.JsonDeserializationContext;
import com.google.gson.JsonDeserializer;
import com.google.gson.JsonElement;
import com.google.gson.JsonNull;
import com.google.gson.JsonObject;
import com.google.gson.JsonSerializationContext;
import com.google.gson.JsonSerializer;

import java.lang.reflect.Type;

/**
 * 让 {@code explosion_damage_factor} 同时接受两种 JSON 形态（2026-10-12 按机型改造）：
 * <ul>
 *   <li>数字：{@code 2.0} ⇒ 等价于 {@code vehicle_default = 2.0}（对所有载具统一，保持旧语义）</li>
 *   <li>对象：{@code { "vehicle_default": 1.0, "vehicles": { "<实体类型ID>": 2.0 } }} ⇒ 按机型</li>
 * </ul>
 * 仅通过字段级 {@code @JsonAdapter} 生效，不改动 <b>类型级</b> 解析，
 * 因此 {@code collision_data.direct_damage_factor} 的行为完全不受影响。
 */
public final class RVP_DamageFactorAdapter
        implements JsonSerializer<RVP_DamageFactor>, JsonDeserializer<RVP_DamageFactor> {

    @Override
    public RVP_DamageFactor deserialize(JsonElement json, Type typeOfT, JsonDeserializationContext context) {
        if (json == null || json.isJsonNull()) {
            return null;
        }
        // 数字形态 → 包装成 {"vehicle_default": v}
        if (json.isJsonPrimitive() && json.getAsJsonPrimitive().isNumber()) {
            float v = json.getAsFloat();
            if (!Float.isFinite(v) || v <= 0f) {
                return null;
            }
            JsonObject wrapper = new JsonObject();
            wrapper.addProperty("vehicle_default", v);
            return context.deserialize(wrapper, RVP_DamageFactor.class);
        }
        if (!json.isJsonObject()) {
            return null;
        }
        return context.deserialize(json, RVP_DamageFactor.class);
    }

    @Override
    public JsonElement serialize(RVP_DamageFactor src, Type typeOfSrc, JsonSerializationContext context) {
        return src == null ? JsonNull.INSTANCE : context.serialize(src, RVP_DamageFactor.class);
    }
}
```

> ⚠️ 必须**同时**实现 `JsonSerializer` 与 `JsonDeserializer`：Gson 的字段级 `@JsonAdapter` 若只实现一侧，另一侧会退化甚至报错。武器数据只读不写，`serialize` 写回对象形态即可。

### ② 改 `weapon/data/RVP_Explosion.java`

```java
// 新增 import
import com.google.gson.annotations.JsonAdapter;

// 字段：Float → RVP_DamageFactor，并加字段级 adapter
@JsonAdapter(RVP_DamageFactorAdapter.class)
@SerializedName("explosion_damage_factor")
private RVP_DamageFactor explosionDamageFactor;

// getter：返回类型同步变更；null = 未配置（= 1.0）

    return explosionDamageFactor;

```

同时**更新该字段的 javadoc**：说明现在支持"数字=全体载具统一 / 对象=按机型"两种写法。

### ③ 改 `weapon/effects/RVP_ExplosionDamageFactor.java`（窗口存"倍率表"而非算好的值）

```java
package org.ywzj.rvp.weapon.effects;

import org.ywzj.rvp.weapon.data.RVP_DamageFactor;

/**
 * "弹药爆炸伤害倍率"窗口：窗口激活期间，{@code RVP_VehicleHurtScalingHandler} 的爆炸分支
 * 会按<b>受击载具的实体类型</b>从窗口中的 {@link RVP_DamageFactor} 求倍率，乘进本体距离衰减后的
 * 爆炸伤害（仅载具目标）。
 *
 * <p>2026-10-12：由 {@code ThreadLocal<Float>} 改为 {@code ThreadLocal<RVP_DamageFactor>}，
 * 以支持按机型给倍率；窗口外 {@code current()} 返回 {@code null}（等价 1.0）。</p>
 */
public final class RVP_ExplosionDamageFactor {

    private static final ThreadLocal<RVP_DamageFactor> FACTOR = new ThreadLocal<>();

    private RVP_ExplosionDamageFactor() {}

    /** 当前窗口倍率表；窗口外返回 {@code null}。 */
    public static RVP_DamageFactor current() {
        return FACTOR.get();
    }

    public static void run(RVP_DamageFactor factor, Runnable action) {
        RVP_DamageFactor previous = FACTOR.get();
        FACTOR.set(factor);
        try {
            action.run();
        } finally {
            // 保存/恢复而非直接 remove：支持窗口嵌套（原地实现会丢掉外层窗口）
            if (previous == null) {
                FACTOR.remove();
            } else {
                FACTOR.set(previous);
            }
        }
    }
}
```

### ④ 改 `weapon/damage/RVP_VehicleHurtScalingHandler.java`

```java
// 新增 import
import org.ywzj.rvp.weapon.data.RVP_DamageFactor;

// 原： float weaponExplosionDamageFactor = RVP_ExplosionDamageFactor.current();
// 改为：按【受击载具 self】求倍率
RVP_DamageFactor weaponExplosionFactorTable = RVP_ExplosionDamageFactor.current();
float weaponExplosionDamageFactor = weaponExplosionFactorTable == null
        ? 1f
        : weaponExplosionFactorTable.getFactor(self);
```

- 该文件里其余位置（`:186` 的重放门槛 `weaponExplosionDamageFactor == 1f`、`:209` 的 `desiredFinal` 乘算）**都不用改** —— 它们用的仍是这个 `float` 局部变量，只是现在它已经是"按当前受击目标求过值"的结果。
- 因为 `self` 在本分支内固定，**一次求值即可**，不会有性能问题。
- 语义保持"仅载具"：`self` 必然是载具，所以 `RVP_DamageFactor` 里配 `vehicles` / `vehicle_default` 会命中，配 `player` / `living` 在这条路径上**不会**生效（见 §4 已知限制）。

### ⑤ 改 `entity/projectile/RVP_BaseBullet.java`（两处）

**取值处（现 :4287-4292）：**
```java
// 原：float explosionDamageFactor = ... ? rvpExplosion2.getExplosionDamageFactor() : 1f;
// 改为：直接取倍率表（null = 未配置）
RVP_DamageFactor explosionDamageFactor = explosion instanceof RVP_Explosion rvpExplosion2
        ? rvpExplosion2.getExplosionDamageFactor()
        : null;
```

**包装处（现 :4170-4178）：**
```java
/**
 * 弹药爆炸对载具的伤害倍率窗口（武器侧 {@code explosion_data.explosion_damage_factor}）：
 * 已配置（{@code isConfigured()}）时把爆炸调用包进 {@link RVP_ExplosionDamageFactor} 窗口，
 * handler 爆炸分支按受击载具机型求倍率。
 */
private static Runnable wrapExplosionDamageFactor(Runnable action, RVP_DamageFactor damageFactor) {
    return (damageFactor != null && damageFactor.isConfigured())
            ? () -> RVP_ExplosionDamageFactor.run(damageFactor, action)
            : action;
}
```

> ⚠️ 改完请 **grep `wrapExplosionDamageFactor(`** 把所有调用点同步（现在传的是 `float`，需改传 `RVP_DamageFactor`）。

## 4. 兼容性与风险

| 项 | 结论 |
| --- | --- |
| 现有 JSON | **本包（含本体）零处配置 `explosion_damage_factor`** ⇒ 改造后行为完全不变 ✅ |
| 旧数字写法 | 由 adapter 包装成 `vehicle_default` ⇒ **语义与改造前完全一致** ✅ |
| `direct_damage_factor` | 用的是**类型级**解析 + 另一个字段，**不受字段级 `@JsonAdapter` 影响** ✅ |
| API 破坏性变更 | `RVP_Explosion.getExplosionDamageFactor()` 返回类型 `Float → RVP_DamageFactor`；全仓仅 **1 处**调用（`RVP_BaseBullet:4289`），已列入改动清单 ✅ |
| 线程安全 | adapter 在**反序列化期**完成解析（无惰性缓存），`RVP_Explosion` 实例加载后只读 ⇒ 无线程安全问题 ✅ |
| 窗口嵌套 | 由"保存/恢复"替代 `remove()`，比原实现更正确 ✅ |
| 已知限制 1 | 爆炸倍率仍**只作用于载具**（分支位置决定）；`player` / `living` 键在此路径不生效。若将来要让爆炸也能按类型作用于玩家/生物，需改到本体爆炸伤害路径（超出本次范围） |
| 已知限制 2 | 受击方自己的 `vehicle_explosion_damage_factor`（per-bone 减伤）**保持不变**，两者仍相乘（`desiredFinal = ... × 武器侧 × 载具侧`） |

## 5. 验收标准

1. **编译通过**（`gradlew :ywzj_rvp:build`）。
2. **回归**：随便找一发现有弹药（如 `ah64_hydra70`）打靶 ⇒ 伤害与改造前一致（因为没人配该字段）。
3. **旧写法生效**：临时给某弹药写 `"explosion_damage_factor": 2.0` ⇒ 对**所有**载具爆炸伤害 ×2。
4. **新写法生效**：改成对象写法，只给 `ywzj_vehicle:rotary_wing_vehicle: 2.0` ⇒
   - 打直升机：爆炸伤害 ×2；
   - 打坦克（履带）：爆炸伤害 **不变**（回退 `vehicle_default: 1.0`）；
   - 这是本次改造的核心验收点 ✅
5. **未配置**：删除该键 ⇒ 爆炸伤害不变（1.0）。
6. `explosion_damage_factor` 写成 `0` 或负数 ⇒ 视为未配置（1.0），不产生"0 伤害"。

【任务】在 ywzj_rvp 里把「弹体爆炸伤害倍率」从"单一数值"改造成"可按目标机型给倍率"。

【仓库】ywzj_rvp（Minecraft 1.20.1 Forge）。源码根 src/main/java/org/ywzj/rvp/。
本体 ywzj_vehicle 只读，不要改。设计依据见 docs/plan/爆炸倍率按机型_实现文档_20261012.md。

【背景】
现在 detonate_data.explosion_data.explosion_damage_factor 只能填一个数字（对所有载具统一倍率）。
需求：让它也能填对象，形态与 collision_data.direct_damage_factor 完全一致：
  { "vehicle_default": 1.0, "vehicles": { "ywzj_vehicle:wheeled_vehicle": 2.0, ... } }

该分支里的 self 就是"被打的那台载具"，所以只要让窗口里存"倍率表(RVP_DamageFactor)"，

   - 约 4287-4292 取值处改为 RVP_DamageFactor explosionDamageFactor = (explosion instanceof RVP_Explosion r ? r.getExplosionDamageFactor() : null);
