# RVP 自动盘旋与载具级无人机修复计划（2026-11-01）

## 范围与约束

Luna 实现范围仅包含本任务授权的 RVP UAV guidance/manager/service、关联事件与 C2S 网络包、既有 `ControlUnitMixin` 辅助修正、相关单元测试，以及本计划和 `docs/调试与修复规范.md` 的功能影响记录。`ywzj_vehicle` 只读；不改载具包 JSON/资源、导弹/光照及其它工作区 WIP、`gradle.properties`。不新增 Mixin/注入点，不执行删除或清理构建。主线程在 Luna 停写后负责版本 bump、完整 build、runServer 冒烟和本批 Git 提交。

## 实施步骤

1. 修正 yaw 象限公式、固定翼偏航符号、阶段转移/捕获条件和中心重捕获；半径保存为用户请求值，按实际气动和高度计算可行值；地形预采样有限前视，目标高度保留“圆心偏移与地形净空取最大”。
2. 增加固定翼连续杆量适配：利用现有 public `setPitchInput`/`setYawInput`/`setRollInput` 在 server tick 消费前设置预补偿值，三个轴持续给方向键避免本体自动俯仰/偏航/滚转操纵回正；零 yaw 保留本体基于相对气流的尾舵回正。节流输出互斥、按速度/高度闭环；旋翼机分支不走固定翼适配。
3. 把部署父子身份、双向 UUID、部署角色/返回座位和盘旋计划写入实体 `persistentData`；join 只恢复 UUID/NBT 运行态，实体部件和配置操作延迟到可用 tick。卸载仅移除运行态，保留持久关系；服务器 stopping 时先同步持久化再清静态表，stopped 再做最终清理。明确永久销毁才清关系，不以暂时查不到子实体判定销毁。
4. 修复目标 UAV 选择和控制权切换语义；母车优先选择飞行子机，F 键只在实际骑乘可盘旋载具时生效，已有盘旋计划在控制权切换后保留，显式标点才重新捕获。
5. 修复信号越界暂停/恢复、永久失联回收一次性、座位锁/跨维自动上车重试递减和玩家换车/维度/离线时终止；修复 LinkRegistry 双向重链接与幂等清理、control packet operator 校验、实体生成失败 rollback。
6. 更新定向回归测试，覆盖朝向象限与符号、连续控制消费、相斥节流、requested/effective radius、高度相关气动解算、阶段捕获/超界重捕获、计划保留、持久化重载、信号恢复/回收、重试衰减/跨维度。按显式 JDK 21 与 `--offline` 执行相关测试；完整 build 与服务端冒烟由主智能体负责。

## 连续控制消费约定

本体只读源码确认 setter 同时更新私有杆量与同步数据且不 clamp；`AbstractVehicle.tick` 顺序为能量/动力/引擎、`tickMove`、物理积分。RVP 在 tickMove 前构造每轴 `(heldDirection, compensatingInput)`，使本体 `tickMove` 对输入增加 `±inputStep` 后得到目标杆量，并保证中性指令也持续指定一个方向。120 秒回归模型包含本体油门 thrustK 超 100 的 1.3 分支、空速阻力后的 `aRaw`、升力/失速、尾舵力、操纵面阻力、侧滑偏航阻尼、neutral 尾舵、失速尾旋、姿态更新顺序和重力；测试约束全程不低于 Y=66，并测量最后 20 秒高度、动态有效半径误差、速度范围与 LOITER 占比。

## 功能影响与恢复

- 预期修复：无人和有人驾驶下盘旋输入连续一致，不因十 tick 脉冲空档触发本体自动俯仰/偏航/滚转操纵回正；错误转向、过量油门、阶段盲推进、卸载丢状态、误清链接和过期自动上车均收口。
- 有意行为变化：盘旋请求半径保持不变并单独显示/计算物理可行半径；高度/失速边界会扩大转弯半径或执行恢复控制；信号暂时恢复时仅恢复被信号暂停的自动计划，不会恢复用户手动关闭的计划。
- 回退方向：按本计划的改动文件整体回退对应 RVP UAV 实现与测试；持久化数据分别使用 `rvpLinkedUav`、`rvpLoiterPlan` 和世界 SavedData；禁用新读取可回到无持久化旧语义。勿回退无关工作区改动。
