# RVP 近炸机枪弹过滤与雷达锁定近炸（2026-09-13）

> 状态：已落码，编译与 dev 服务端冒烟通过，**待实机行为回归**。
> 需求来源：①近炸引信会被 RVP 机枪弹丸触发（弹幕飞过即提前引爆），要求精确过滤——RVP 全部武器
> 共用一个弹体基类，不得 instanceof 基类一刀切；②新增"雷达锁定近炸"参数，近炸只认有效雷达锁定目标，
> 判定口径参考 SARH 半主动照射源。

---

## 一、背景（调查结论，2026-09-13）

- RVP 近炸三条触发路径全部汇聚于 `RVP_BaseBullet`：锁定目标分支（`tickProximityFuse`）、
  探测盒分支（`level().getEntities`，检测盒膨胀 `proximity_radius` 并沿弹道后移）、
  扫掠近炸（`findProximityTargetOnSegment`，tickHit 内防高速飞越）。
- 触发目标过滤链 `canDamageEntity` **没有实体类型/体积过滤**：除干扰物、发射者一侧、
  同发射载具弹药、本车载具乘客、贴地目标外，任何存活实体（含其他载具的机枪弹丸、掉落物、箭等）均可触发。
- 对比：攻顶引信有白名单 `isTopAttackTarget`（仅 `AbstractVehicle`/`LivingEntity`），
  注释明说掉落物/弹射物能过 `canDamageEntity` 但不该触发——近炸此前未做同等处理。
- 本体 `AmmoEntity.tickHit` 的近炸在 RVP 弹体上不执行（`RVP_BaseBullet` 完全重写且不调 super），
  不存在双系统；本调查仅涉及 RVP 侧过滤增强。

## 二、改动一：机枪弹丸不触发近炸（全局行为，无需配置）

`RVP_BaseBullet.isAmmoIgnoredByProximityFuse(Entity)`，三条近炸触发路径统一接入：

- 目标为 `RVP_BaseBullet` 且 `rvpData.getWeaponKind() == RVP_EnumWeaponKind.MACHINEGUN` → 忽略。
  **同基类下按弹种精确判**（判定方式与 `RVP_AheadProgrammer.isAheadWeapon` 一致），
  RVP 导弹/火箭/航弹/布撒弹不受影响——"近炸拦截敌方导弹"能力（`detonateFuseAt` 对弹药目标
  引爆/销毁）完整保留；
- 目标为本体 `org.ywzj.vehicle.entity.weapon.BulletEntity`（机炮弹专用类；本体导弹/火箭
  各有独立类不在其中）→ 忽略；
- 干扰物（`RVP_Decoy`）、贴地（`proximity_fuse_height`）、已直击/已近炸目标排除维持不变；
- 攻顶引信走自身白名单（弹药本就进不来），不改。

## 三、改动二：`proximity_fuse_require_radar_lock`（默认 false）

`RVP_FuseData` 新增字段（`@SerializedName("proximity_fuse_require_radar_lock")`），
默认 **false = 现行为零变化**。

开启后三条近炸触发路径的目标均须通过 `RVP_BaseBullet.isRadarIlluminatedTarget(Entity)`：

```
发射武器站根（getShooterWeaponUnit().getRootParentWeaponUnit()）
  ├─ 来源 1：手动雷达锁  RVP_RadarRoleHelper.getLockedRadarEntity(root)（玩家锁定键写入 RadarUnit.lockedEntity）
  ├─ 来源 2：外置雷达锁  RVP_WeaponLockStateTable.getExternalRadarLockedEntityId(root)（外置雷达控制器/AI 炮手写入）
  └─ 目标与锁定实体经 ywzj_rvp$resolveCollisionRoot 取碰撞 root 后比较（兼容载具部件 PartEntity）
```

- 判定口径与 SARH 半主动照射源一致（`RVP_RuntimeSarhGuidanceSource.getManualIlluminatedTarget`）：
  **雷达 TWS 自动跟踪与导引头自锁带来的目标不算数**（防"雷达扫到就算锁定"）；
  雷达扫描的中继制导（外置雷达锁）**算数**——用户明确要求该来源可触发；
- ECM 干扰期近炸本就被 `isJammedByDecoy()` 抑制关闭，不重复判定；
- 与 SARH 一致的取舍：`WeaponUnit.lockedEntity` 不作为来源（会被 ARH/IR 导引头自动锁定污染、
  被切武器清空）。

## 四、JSON 示例

```json
"fuse_data": {
  "proximity_radius": 8,
  "proximity_fuse_tick": 10,
  "proximity_fuse_require_radar_lock": true
}
```

## 六、回退

- 机枪弹过滤：删除三处 `isAmmoIgnoredByProximityFuse(...)` 调用即恢复；
- 雷达锁参数：参数默认 false，不配置即无影响；彻底回退删除三处
  `isProximityFuseRequireRadarLock()` 条件与 `isRadarIlluminatedTarget` 方法。
