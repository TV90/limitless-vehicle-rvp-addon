## 二、面板刷新架构（第四版，用户确认"成功了大半"）

**AUI 渲染机制（反编译+实测闭合）**：
- 渲染每帧读 DOM 当前态，但 **init 之后 append 的新子树不进渲染**（markDirty/refresh/
  requestStyleRecalc 均无效——运行中增删行必然不显示）；
- `Document.refresh()/refreshStyles()` 是**模板热重载**（重新解析 HTML+CSS，非轻量刷新，
  调用即全面板重布局闪烁）；
- `markDirty(element, RELAYOUT|REPAINT)` 只对 **init 时已构建**的元素上屏有效
  （本体改装屏 `applyFilter` 同款）；对运行中新增子树无效。

**最终架构（`RVP_EquipPanelScreen`）**：
1. `rebuildCategories` 加**首建守卫**（`catBodyByKey` 非空直接 return）——栏目/行只在
   init 首建一次，行 Element 缓存 `rowElementsByKey`（键 = 栏目 title|骨名）；
2. `refreshDynamic` → **`updateDynamicRows()`**：遍历目标行按缓存键取已建 div **原地写入**
   （别名/附加/状态/失效样式）+ `categoryScroll`/hp 元素 `markDirty(RELAYOUT|REPAINT)` 上屏；
3. `buildRow` **恒建 extra 槽**（空文本占位，原地更新按固定子序 children[0..3] 写入）；
4. init **不清缓存**（Document 同实例，元素引用跨 init 有效）；
5. **行点击入队监听读 holder 当前行**（AtomicReference，原地更新后语义同步）。
