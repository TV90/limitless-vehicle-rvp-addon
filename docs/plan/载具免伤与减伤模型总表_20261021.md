# 载具免伤与减伤模型总表（RVP 全部载具）

> 统计时间：2026-10-21 ｜ 数据源：`limitless_vehicle/rvp/data/rvp/vehicles/*.json`（42 台）
> **留空/未配 ≠ 0**：`armor_max_damage` 未配 = 不封顶；`core_distance_scale_multiplier` 未配 = 默认 1.0。

## 一、三问三答

**1）全部载具的免伤（`armor_min_damage`，每次直击先固定扣掉的伤害）**

| 免伤值 | 台数 | 适用 |
|---|---|---|
| **15** | 9 | 其它、坦克 |
| **14** | 1 | 坦克 |
| **12** | 13 | 坦克、舰船、轮式 |
| **5** | 19 | 固定翼、旋翼机 |

**2）有没有「中心向外衰减减伤」**：**代码里有，但绝大多数车已经把它关掉了。**

- 本体 `DamageSystem` 对非爆炸直击会乘一个 `(distanceMax − 距核心垂距) / distanceMax` 的系数：打主 OBB 正中 = ×1.0，打最外缘 = ×0，即「中心→外缘线性衰减」。
- RVP 用 `core_distance_scale_multiplier` 调制它：**0 = 完全抵消（打哪都一样）／1 = 本体原样／0~1 = 部分保留**。
- 现状：`未配(默认1.0)` × 1 台；`0` × 41 台 ⇒ **41 台已无中心衰减**（含全部坦克/飞机/舰船），只有 `ucavlauncher` 仍按本体衰减。

**3）减伤主要用本体的还是 RVP `armor_min` 的**：**两者互斥，配了装甲就由 RVP 主导。**

| 条件 | 生效模型 | 本体 `damage_threshold` |
|---|---|---|
| `armor_min_damage` 或 `armor_max_damage` > 0 | **RVP 装甲层**（`applyArmor`） | 被屏蔽为 0.1（只剩保底，不再拦伤害） |
| 两者都没配 | 本体模型 | 原样生效（低于阈值固定只吃 0.1） |

- 现状：**42/42 台都配了 `armor_min_damage`** ⇒ 全部由 RVP 装甲层主导；本体阈值只剩"最低 0.1"的保底作用。
- 只有"中心衰减"仍由本体那段公式算，再由 `core_distance_scale_multiplier` 决定保留多少（见上）。

## 二、减伤链路（谁在什么时候乘什么）

**本体 `DamageSystem.hurt`**（`ywzj_vehicle/vehicle/DamageSystem.java`）

| 顺序 | 动作 | 位置 |
|---|---|---|
| 1 | 部件损伤：部件自己的 `damage_threshold` 拦截，再乘 `damage_transfer_coefficient` 传给载具 | `:65-74` |
| 2 | `amount < 载具 damage_threshold` ⇒ 直接改 0.1 | `:76-77` |
| 3 | 否则：`hitPos==null` ⇒ ×0.2；非爆炸 ⇒ ×（中心距离衰减系数） | `:78-92` |
| 4 | `amount *= scale` 后正式扣血 | `:92` |

**RVP `RVP_VehicleHurtScalingHandler`**（Forge `VehicleAttackEvent`，先于本体扣血）

| 顺序 | 动作 | 位置 |
|---|---|---|
| 1 | physics-only 碰撞过滤（纯物理骨不参与命中） | `:145-151` |
| 2 | 取命中箱倍率 `hitbox_damage_factor`（按命中骨）× 核心衰减调制 `coreMult` | `:153, :181` |
| 3 | 预测本体结算结果，并按 `coreMult` 抵消/保留中心衰减 | `:197-212` |
| 4 | **直击 → `applyArmor`**；爆炸 → 只乘两侧爆炸倍率（绕过装甲） | `:218-220` |
| 5 | `applyArmor`：先乘 ≤1 的命中箱倍率 → **−armor_min** → 保底 0.1 → 乘 >1 倍率 → **封 armor_max** → 再保底 | `:383-406` |
| 6 | 装甲生效时把本体 threshold 临时换成 0.1 再重放扣血（防跨分支失真） | `:236-241, :417-430` |

## 五、中心向外衰减的公式与现状

```
本体（非爆炸直击）：
  distanceToCore = 弹体位置 → 主 OBB 中心 的垂距
  distanceMax    = 主 OBB 最大半轴 × 2
  falloff        = (distanceMax − distanceToCore) / distanceMax   # 1.0 中心，0 最外缘

RVP 调制（core_distance_scale_multiplier = m）：
  实际系数 = 1 + (falloff − 1) × m
  m = 0 → 恒 1.0（完全取消衰减）；m = 1 → 本体原样；0<m<1 → 部分保留
```

- 现状 **m = 0**（41 台）⇒ 命中核心与命中裙板/翼尖伤害相同，位置不再影响直击伤害。
- `ucavlauncher` 未配 ⇒ 默认 1.0 ⇒ **仍按本体公式衰减**（唯一一台）。

## 六、易踩的四个点

1. **爆炸完全绕过装甲**：`RVP_VehicleHurtScalingHandler:214-220` 明确爆炸不走 `applyArmor`，所以 `armor_min_damage` 对爆炸伤害无效；本体对爆炸也不做中心衰减（只有直击才乘 falloff）。
2. **免伤是"载具级"的，不是部件级**：`armor_min_damage` 只作用在载具总血量；各部件仍用部件自己的 `defense_stats`（RVP 载具都没配部件级，走本体默认 `damage_threshold=50` / `transfer=1.0`）。
3. **`armor_max_damage` 全未配 = 不封顶**：大口径/高伤弹可以一发打出远超免伤阈值的伤害（免伤只做减法）。
4. **撞击伤害不是这套模型**：车撞车/撞人走 `impact_multiplier`（`DamageSystem:141`），RVP 现状：3 × 15 台、2 × 4 台、未配（默认 0.1）× 23 台，与免伤无关。
5. **`rvp_armor_type` 只改「攻击方倍率查表键」，不动免伤/命中箱**：配置后武器的 `direct_damage_factor` / `explosion_damage_factor` 的 `vehicles` 表按该实体类型查（如履带车按轮式装甲结算），查表收口 `RVP_DamageFactor.getFactor`；`armor_min_damage`、`hitbox_damage_factor`、`vehicle_explosion_damage_factor` 仍按本车自己的配置走。现状：`bukm3`→`wheeled_vehicle`、`ps1sm`→`wheeled_vehicle`。
