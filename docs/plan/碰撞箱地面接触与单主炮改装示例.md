# 碰撞箱地面接触与单主炮改装示例

本文档给出两套本次新增能力的最小示例：

1. `ground_contact_part_ids`：让指定 `generic part` 参与载具“着地/支撑地面”物理。
2. `modding_only_multi`：让单主炮栏内部的 AP variant 只能在改装工具里二选一，而不是运行时用 `F` 键切换。

## 1. ground_contact_part_ids 示例

适用于已经存在 `generic part` 的结构骨骼，例如履带、侧裙、滑橇、浮筒等。

```json
"physics_info": {
  "can_destroy_block": true,
  "ground_contact_part_ids": [
    "track"
  ]
}
```

对应的 `parts` 里需要有同名 `generic part`：

```json
{
  "id": "track",
  "name": "track",
  "type": "ywzj_vehicle:generic",
  "structure_bone": "track",
  "is_seat": false
}
```

说明：

- `ground_contact_part_ids` 填的是 `part id`，不是 `structure_bone` 名称。
- 它不会把这些 part 变成新的主刚体，而是给 `mainCubeOBB` 追加底部接地点。
- 更适合车体固定结构，不建议直接给会大幅独立旋转的炮塔附属件使用。

## 2. 单主炮栏 + 改装工具二选一示例

下面示例对应“一个主炮栏，运行时只切 AP / HE；AP 内部 variant 只能在改装工具里切换”。

```json
{
  "id": "turret",
  "type": "ywzj_vehicle:weapon",
  "structure_bone": "turret",
  "weapons": [
    {
      "ids": [
        "rvp:t90m_3bm59",
        "rvp:t90m_9m119m1"
      ],
      "save_id": "main_gun_ap",
      "modding_only_multi": true
    },
    {
      "ids": [
        "rvp:t90m_3of26"
      ],
      "save_id": "main_gun_he"
    }
  ]
}
```

说明：

- 整个主炮仍然只有一个 `WeaponUnit`。
- 第一条 entry 是 AP family，内部多个 `ids` 构成一个 `VehicleMultiWeapons`。
- `modding_only_multi: true` 后，运行时不会再被 `F` 键切 AP 子弹种。
- 改装工具界面会对当前 AP family 显示左右 variant selector，用来切 `sub weapon`。

## 3. M1A2SEP / T90M 本次落地方式

本次坦克配置的实际落地方式如下：

- `t90m`：直接使用已有的 `track` generic part，并在 `physics_info` 中加入 `ground_contact_part_ids: ["track"]`
- `m1a2sep`：补出 `track` generic part，并在 `physics_info` 中加入 `ground_contact_part_ids: ["track"]`
- 两车主炮 AP family 都使用 `modding_only_multi: true`

## 4. 使用建议

- 如果某台车只有 `structure_bone: "track"`，但 `parts` 里没有对应 `id: "track"`，要先补 `generic part`，否则 `ground_contact_part_ids` 无法命中。
- 如果一个 AP family 需要持久保存改装结果，建议始终补 `save_id`。
- 如果一个武器 entry 不希望运行时显示为可切子弹种，就用 `modding_only_multi: true`，不要再额外拆第二个主炮位。
