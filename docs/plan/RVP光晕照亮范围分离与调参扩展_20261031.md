# RVP 光晕/照亮范围分离与调参扩展

> 同日后续：[爆炸广域光晕与短光时间线](RVP爆炸广域光晕与短光时间线调参_20261031.md) 已将爆炸默认照亮亮度/半径倍率改为20/5、增加独立广域光晕亮度，并让decayScale伸缩整盏爆炸/炮口光源。本文保留范围拆分阶段的默认值与构建记录，当前参数以最新调参指南为准。

日期：2026-10-31。本轮落实三项：爆炸、炮口、发动机各自的光晕和照亮范围分开；扩大游戏内可调范围；爆炸光寿命改为32刻（正常20刻/秒下1.6秒），基础衰减指数改为0.3。

## 1. 范围怎样分开

三类光源均支持：

```text
/rvplight set explosion radiusScale 4
/rvplight set explosion haloRadiusScale 0.5
/rvplight set muzzle radiusScale 2
/rvplight set muzzle haloRadiusScale 1
/rvplight set engine radiusScale 0.5
/rvplight set engine haloRadiusScale 3
```

`radiusScale` 只缩放方块、实体和烟雾的照亮半径；`haloRadiusScale` 只缩放光晕的世界半径。两者都从未调参的基础半径计算，实际结果为 `min(8192, 基础半径×各自倍率)`。设为0可分别关闭；两者同时为0时不提交该光源，未过期条目保留，恢复参数后仍按原年龄继续显示。发动机光晕关闭时保留白热喷焰。

原发动机口径公式 `min(500, 20+口径毫米数×0.1)` 保留为基础预设，500格不再是游戏内调参后的上限。喷焰长宽仍只由原来的 `flame_scale` 控制。

此前光晕直接取自环境受光结果，仅新增两个参数仍会互相影响。本轮新增独立光晕来源纹理，分为两路：

- 照亮路：用照亮半径生成真实表面受光，存入 `lightTexture`，用于最终环境光合成。
- 光晕路：爆炸/炮口用各自光晕半径生成镜头式径向发光贡献，发动机用真实喷焰提供近层光晕，并以独立世界半径绘制广域橙晕；光晕来源不读取照亮路的颜色。

四层光晕继续使用上一阶段的连续过滤和固定基础权重。光晕边缘会经过后处理柔化，因此不是最终屏幕像素的硬裁切边界。光晕不表示空气真的在三维世界发光；完全隐藏的光心仍被近景/DH 深度和既有 CPU 方块查询拒绝，源可见时可以跨邻近轮廓产生镜头式扩散。

爆炸/炮口的光强和颜色仍统一控制其环境光与光晕，范围独立。发动机核心、外围橙焰和广域橙晕继续保留各自亮度参数。

## 2. 放宽后的范围

| 参数 | 新范围 | 生效说明 |
| --- | --- | --- |
| 三类 `radiusScale` / `haloRadiusScale` | 0～1024 | 分别计算0～8192格实际半径；取消旧20格调参下限和500格调参上限 |
| `brightness` / `smokeBrightness` | 0～256 | 光强和烟雾受光倍率 |
| `red` / `green` / `blue` | 0～16 | 颜色分量倍率；最终标准色分量仍限制为0～1，亮度使用独立倍率 |
| `surface` | 0～16 | 表面/烟雾受光权重，不再被旧权重1的上限截断 |
| `decayScale` | 0～64 | 乘基础衰减指数；0表示到期前不衰减，不改变寿命 |
| 发动机 `haloIntensity` / `worldHaloIntensity` | 0～60000 | 外围橙焰与广域橙晕独立亮度 |
| `bloom inputPeak` | 0.00001～60000 | 喷焰送入四层模糊前的软压缩峰值 |
| `bloom blurScale` | 0～32 | 各层额外高斯柔化间距；0保留缩小和回升过滤 |
| `bloom nearStrength` / `farStrength` | 0～256 | 近两层和远两层各自的能量倍率 |
| `global distanceScale` | 0.0001～128 | 调参后观察距离1～32768格 |
| `preview` 半径输入 | 0.01～8192格 | 输入再分别乘两种范围倍率 |
| `engine` 预览缩放输入 | 0.001～256 | 只改变预览喷焰几何 |

白热核心保持0～60000；所有中间高亮贡献在写入半精度纹理前限制到60000，拒绝 NaN/无穷输入。扩大数值范围不等于提高同时绘制的八灯预算。

## 3. 爆炸时间线

真实爆炸预设和 `/rvplight preview` 都使用32刻、基础指数0.3。亮度为：

`初始光强 × (1 - 已过去刻数/32)^(0.3 × decayScale)`

越小的正指数越晚变暗；第32刻仍会准时归零和清理。游戏暂停时冻结，渲染帧数不会延长寿命。网络迟到按已过去的年龄追赶，不从收到时重新播放1.6秒。默认爆炸效果包装器原本就按预设寿命保留灯光，本轮沿用这一逻辑。
