## 2. 目录职责（data 管物理、assets 管表现）

```
limitless_vehicle/rvp/
├── vehicle_pack.meta.json
├── pack.png
├── data/rvp/                      ← 服务端：逻辑 / 物理 / 弹道 / 配方
│   ├── vehicles/                  载具主控数据
│   ├── weapons/                   武器数据（服务端弹道）
│   ├── models/bedrock/vehicle/    结构模型（骨 + 物理 + 受击盒）
│   ├── recipes/  recipe/          打印配方（两个目录并存，命名不统一）
│   ├── gunner/                    AI 炮手配置（air/default/enemy/friendly/ground/mixed/team）
│   └── ui_presets/                武器站 UI 预设
└── assets/rvp/                    ← 客户端：外观 / 动画 / 文案 / 音效
    ├── display/vehicle/           载具显示主控
    ├── display/weapon/            弹体显示
    ├── display/decoration/entity/ 挂架显示（weapon_mount_*）
    ├── models/bedrock/entity/     渲染模型（bedrock geometry）
    ├── animations/bedrock/entity/ 骨骼动画
    ├── animation_controllers/     动画控制器
    ├── scripts/                   客户端骨骼驱动 JS
    ├── textures/entity/           载具 / 弹药贴图（含 ammo、lod、weapon_mount 子目录）
    ├── textures/slot/             创造栏图标
    ├── lang/                      zh_cn.json / en_us.json
    └── sounds/  sounds.json       音效
```

**最容易混的一处**：同为 bedrock JSON 格式，`data/.../models/bedrock/vehicle/<id>.structure.json` 管物理/骨/受击盒，`assets/.../models/bedrock/entity/<id>.json` 管外观。两者路径、命名空间、用途都不同。

## 3. 新增一台载具所需的全部文件

`<id>` 全部小写，与载具 id 同名。**蓝色为必需，灰色可省。**

### 3.1 data/rvp/ —— 服务端物理层

| 文件 | 必需 | 说明 |
| --- | --- | --- |
| `data/rvp/vehicles/<id>.json` | ✅ | **载具主控**。部件、属性、受击盒、干扰物、RVP 扩展字段全在这里 |
| `data/rvp/models/bedrock/vehicle/<id>.structure.json` | ✅ | **结构模型**。骨层级 + pivot + cube 几何，决定物理、发射点、受击盒。由 `structure_model: "rvp:vehicle/<id>"` 引用 |
| `data/rvp/weapons/<weapon>.json` | ✅ | 武器数据，每个挂弹一份。载具要开火就得有 |
| `data/rvp/recipes/<id>.json` | ⬜ | 载具打印配方。`ywzj_vehicle:vehicle_printing` + `materials[]` + `printingTime` + `result.nbt.YwzjVehicleId`。现有 32 台中仅 12 台有 |

> ⚠️ **结构模型铁律**：`*.structure.json` 的骨层级 / 骨枢轴 / cube 几何 / 父级关系属于资产，**任何修改必须先向用户请示、获确认后动手，且动手前先备份**（`*.structure.json.bak`）。禁止擅自重构骨层级或批量改写 cube。

### 3.2 assets/rvp/ —— 客户端表现层

| 文件 | 必需 | 说明 |
| --- | --- | --- |
| `assets/rvp/display/vehicle/<id>.json` | ✅ | **显示主控**。模型、贴图、图标、音效、特殊骨特效、创造栏位 |
| `assets/rvp/models/bedrock/entity/<id>.json` | ✅ | **渲染模型**（bedrock geometry）。display 里写作 `rvp:entity/<id>` |
| `assets/rvp/textures/entity/<id>.png` | ✅ | 载具外观贴图 |
| `assets/rvp/textures/slot/<id>.png` | ✅ | 创造栏 / 物品栏图标，与载具**一一对应** |

### 3.3 assets/rvp/ —— 行为层

| 文件 | 必需 | 覆盖率（实机 32 台） |
| --- | --- | --- |
| `assets/rvp/animation_controllers/<id>_controller.json` | ✅ | 30/32 —— 实质必需 |
| `assets/rvp/animations/bedrock/entity/<id>.animation.json` | ✅ | 29/32 |
| `assets/rvp/scripts/<id>.js` | ⬜ 视载具 | 29/32（IDE 包中仅 `ucavlauncher` 无）。按 bbmodel 骨名写 `updateBones` |
| `assets/rvp/lang/zh_cn.json` + `en_us.json` | ✅ | 各加两条 key：`entity.rvp.<id>`、`rvp.<id>` |

### 3.4 挂武器时额外需要

| 文件 | 说明 |
| --- | --- |
| `assets/rvp/display/weapon/<weapon>.json` | 弹体显示：模型 / 贴图 / 展开动画 |
| `assets/rvp/display/decoration/entity/weapon_mount_*.json` | 挂架显示（`type: ywzj_rvp:weapon` + `bedrock_backend: rvp`） |
| 载具 json 内 `rvp_custom_mounts` | 挂架装配：`rack_bones` / `missile_bones` / `replace_weapon_display` / `ammo_slot` / `attach_part_unit_id` |

## 4. 引用链（照此对齐不会错）

```
data/rvp/vehicles/<id>.json
  ├─ structure_model ──────────→ data/rvp/models/bedrock/vehicle/<id>.structure.json
  └─ parts[].weapons ──────────→ data/rvp/weapons/<weapon>.json
                                    └──→ assets/rvp/display/weapon/<weapon>.json

assets/rvp/display/vehicle/<id>.json
  ├─ model                ────→ assets/rvp/models/bedrock/entity/<id>.json
  ├─ texture              ────→ assets/rvp/textures/entity/<id>.png
  ├─ slot_texture         ────→ assets/rvp/textures/slot/<id>.png
  ├─ animations           ────→ assets/rvp/animations/bedrock/entity/<id>.animation.json
  └─ animation_controller ────→ assets/rvp/animation_controllers/<id>_controller.json
                                   └─ script ──→ assets/rvp/scripts/<id>.js
```

### 命名空间陷阱

| 文件 | `type` 命名空间 |
| --- | --- |
| `data/rvp/vehicles/<id>.json` | `ywzj_vehicle:tracked_vehicle` / `wheeled_vehicle` / `fixed_wing_vehicle` / `rotary_wing_vehicle`（**本体**注册表） |
| `assets/rvp/display/vehicle/<id>.json` | `ywzj_rvp:tracked_vehicle` / `wheeled_vehicle` / `fixed_wing_vehicle` / `rotary_wing_vehicle`（**RVP** 注册表） |

两套命名空间**故意不同**，写串会加载不出来。

## 5. `vehicles/<id>.json` 字段结构

### 5.1 顶层（以 t90m / suav 实测）

| 字段 | 说明 |
| --- | --- |
| `type` | 载具大类，决定 `attributes` 的字段集 |
| `attributes` | 运动参数。履带/轮式：加速度、`max_speed_*`、`max_turn`；固定翼：`thrust`、`ceiling`、`air_drag_k_*`、`lift_to_drag_k`、`angle_of_attack_*`、`vortex_offsets` 等 |
| `max_health` | 载具总血量 |
| `defense_stats` | `damage_threshold`（伤害门限）、`impact_multiplier`（撞击倍率） |
| `view_info` | 第三人称偏移/距离（含 `_zoomed` 变体）、`sound_distance` |
| `energy_info` | 能量容量 / 每 tick 消耗 / `engine_particle_offsets` 排气粒子位置 |
| `physics_info` | `can_destroy_block`、`physics_only_bone` |
| `structure_model` | 结构模型引用 `rvp:vehicle/<id>` |
| `parts[]` | **部件数组**（见 5.2） |
| `hitbox_damage_factor_default` / `hitbox_damage_factor` | 分部位乘伤，键为结构骨名 |
| `hitbox_display_name` | 分部位中文名（命中提示用） |
| `bone_modules` | 骨级功能模块：ERA 爆炸反应装甲（`damage_factor` / `min_damage` / `explosion` / `modules:["era"]`）、`ecm_bone`（`ecm_active.ammo_jam_radius` / `vehicle_jam_radius`） |
| `hide_passenger` / `show_skeleton` | 乘员隐藏、骨架显示 |
| `center_offset` | 载具中心偏移 |
| `core_distance_scale_multiplier` | 核心距离缩放 |
| `landing_gear_part_id` | 起落架部件 id（航空器） |
| `rvp_loiter_*` | **RVP 扩展**：无人机盘旋。`rvp_loiter_enabled` / `_radius` / `_altitude_offset` / `_terrain_clearance` / `_min_safe_altitude` / `_fixed_wing_min_bank` / `_auto_on_takeoff` |
| `rvp_auto_landing_gear` | **RVP 扩展**：自动起落架 |

### 5.2 `parts[]` 条目

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 部件 id |
| `type` | `ywzj_vehicle:weapon` / `generic` / `radar` / `landing_gear` / `weapon_bay` / `airbrake` / `switchable` |
| `structure_bone` | **绑定的结构骨名**，必须与 `*.structure.json` 中的骨名完全一致 |
| `is_seat` | 是否座位 |
| `seat_offset` / `operator_view_offset` / `optical_sight_offset` | 座位/视角/瞄准具偏移 |
| `rot_info` | `x_rot_speed` / `y_rot_speed` / `x_rot_max` / `x_rot_min` / `y_rot_min` / `y_rot_max` / `need_power` |
| `base` | 父部件 id（子武器站跟随父级转动） |
| `parent_weapon_unit_aim` | 是否跟随父武器站瞄准 |
| `operator_on_weapon_unit` | 操作者是否坐在武器站上 |
| `fire_control_lock_type` / `fire_control_sensor_type` | 火控锁定方式 / 传感器类型（`eo` 等） |
| `optical_sight_type` | `crt` / `none` |
| `with_stabilizer` / `with_thermal_imager` / `with_focus_locker` | 稳定器 / 热像仪 / 聚焦锁定 |
| `zoom_min` / `zoom_max` / `crosshair_style` | 倍率与准星样式 |
| `weapons[]` | 见 5.3 |
| `rvp_follow_parent_only_part_unit_ids` | **RVP 扩展**：随父部件转动的部件白名单（避免爆反/裙板错位） |

### 5.3 `weapons[]` 两种写法

```jsonc
// 单武器
{ "id": "rvp:mbt_762", "part_unit_id": "turret_machine_gun", "secondary": true }

// 多弹种同槽位
{ "ids": ["rvp:t90m_3bm59", "rvp:t90m_9m119m1"], "save_id": "main_gun_ap", "modding_only_multi": true }
```

| 键 | 说明 |
| --- | --- |
| `id` / `ids` | 单个 / 一组武器 id |
| `part_unit_id` | 绑定的子部件 id（决定发射点与朝向） |
| `save_id` | 存档标识（改装记忆用） |
| `secondary` | 副武器 |
| `merge_into_previous_slot` | 合并进上一个武器槽位（HE 弹这类） |
| `modding_only_multi` | 仅改装界面可选多弹种 |
