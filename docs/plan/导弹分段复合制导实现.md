# 导弹分段/复合制导 — 实现说明

## 运行时流水线

1. `RVP_BaseBullet.tickGuidance()` → `RVP_GuidanceController.tick()`
2. `RVP_GuidancePhaseSelector.selectActive()` — 对 `stages[]` 逐条用 **activation 策略链**（AND）求值，返回所有同时激活的阶段
3. 单阶段 → `RVP_GuidanceCompositor.applyStage()`；多阶段重叠 → `applyOverlappingPhases()` 跨阶段加权混合
4. 不兼容制导类型由 `RVP_GuidanceCompositeCompatibility` + `phase_resolve_policy` 消解
5. `RVP_GuidanceSourceRegistry` → `RVP_GuidanceIntent` → `RVP_GuidanceMath.applyIntent()`

## 关键类

| 路径 | 职责 |
| --- | --- |
| `weapon/data/RVP_GuidanceData.java` | `stages`、`phase_resolve_policy` |
| `weapon/data/RVP_GuidanceStageData.java` | 单阶段：`activation`、`seeker`、`steering_data`、`sources` |
| `weapon/data/RVP_GuidanceActivationData.java` | 阶段激活条件 |
| `weapon/data/RVP_GuidanceSeekerData.java` | 阶段导引头（**无顶层 seeker_data**） |
| `guidance/activation/*ActivationStrategy.java` | tick / 目标距离 / 实体距离 / 高度 / 照射等策略 |
| `guidance/RVP_GuidancePhaseSelector.java` | 多阶段选择 + 粘性 `enter_once` |
| `guidance/RVP_GuidanceCompositeCompatibility.java` | 跨阶段复合兼容规则 |
| `guidance/RVP_GuidanceCompositor.java` | 阶段内 + 跨阶段复合 |
| `guidance/source/*.java` | 十种制导源 |
| `scripts/migrate_guidance_phases.py` | `seeker_data` 下沉、`stages`→`phases`、扁平条件→`activation` |

## Mi-28 火箭挂架基础制导测试弹 T01–T10

挂载于 `mi28.json` → `sighting_system.weapons`，`part_unit_id: "rocket"`。资源 ID 仍为 `rvp:mi28_s13_t01_cluster` … `t10`（文件名保留历史 ID，内容为单型制导测试弹）。

| ID | 名称 | 主制导 | 测试要点 |
| --- | --- | --- | --- |
| T01 | 主动雷达弹 | ARH | 全程弹载雷达 + IOG 备份 |
| T02 | 红外弹 | IR | 锁定热目标，`require_lock: true` |
| T03 | 半主动雷达弹 | SARH | 需平台持续照射 |
| T04 | 线导弹 | MCLOS | 炮塔/视角线导 |
| T05 | 反辐射弹 | ARM | `params` 写扫描/记忆；寻辐射源 |
| T06 | 电视制导弹 | TV | `params` 写控制距离/画面模式 |
| T07 | GPS制导弹 | GPS | 需 GPS 目标点 |
| T08 | 激光驾束弹 | SACLOS | 激光指示点制导 |
| T09 | 惯性弹 | IOG | 记忆点/目标点惯性 |
| T10 | GPS+末段红外 | GPS → IR | 120m 内 `enter_once` 切 IR |

**测试提示**：T03 需照射；T06 需 TV 视角；T07/T10 需 GPS 指示；T02/T09 建议先锁定再发射。
