# DH 开启时屏幕空间特效导致黑屏：排查与修复

日期：2026-10-30。用户确认故障发生在 **开启 DH、没有开启光影** 时：冲击波或屏幕光照偶尔使天空与远景变黑，特效结束后恢复。

本次找到并修复了可复现的显卡状态交接缺陷，隐藏显卡测试已通过；没有重放用户的游戏故障帧，实机偶发问题是否完全消失仍待复测。

## 1. 故障机制

OpenGL 是显卡当前实际采用的状态；Minecraft 的 `RenderSystem` / `GlStateManager` 另外保存一份状态记录，用于省略重复操作。DH、RVP 的离屏模型绘制和屏幕特效都会使用这些状态。

旧 `RVP_DhGlStateScope.close()` 通过原生 OpenGL 恢复深度、混合、纹理等，却没有同步引擎记录。例如：

1. 进入 DH 作用域前，实际深度写入开启。
2. 作用域内通过引擎关闭深度写入，实际值与缓存都变为关闭。
3. 旧实现退出时只恢复实际值为开启，缓存仍记录关闭。
4. 后续再次请求“关闭深度写入”，引擎认为已经关闭，省略调用；显卡仍然开启。

旧冲击波作用域也存在同类恢复缺口，并且没有保存混合方程和独立采样器。混合方程决定新旧颜色是相加、相减还是取最大值；独立采样器可以覆盖纹理自身的过滤规则。

光照与冲击波都会输出**已经包含背景的完整颜色**，应该关闭混合直接写回。旧实现只调用 `RenderSystem.disableBlend()`；如果缓存记为关闭、实际却开启，这次关闭会被跳过。残留减法混合可以把相同的源背景和目标背景相减成黑色。纹理或深度状态不一致也会进一步干扰场景复制和后续绘制。

这个机制依赖此前各绘制通道的调用顺序，符合偶发、特效活跃时出现的表现。不过，没有采集到用户故障帧的实际混合方程，不能把测试构造的减法方程当作现场记录。

## 2. 修复落点

| 文件与入口 | 改动 |
| --- | --- |
| [RVP_GlStateSync](../../src/main/java/org/ywzj/rvp/client/render/RVP_GlStateSync.java#L22) | 新增统一状态交接方法：先设置真实 GL，再调用引擎入口同步缓存；覆盖纹理、FBO（保存绘制结果的显卡目标）、程序、深度、混合、剔除、裁剪及颜色写掩码 |

| [RVP_PressureWavePass.State.close](../../src/main/java/org/ywzj/rvp/client/visual/shockwave/RVP_PressureWavePass.java#L352) | 完整恢复混合方程、采样器及所有借用状态；FBO 和程序恢复经过引擎入口，使已安装但未启用光影的 Oculus 也能同步记录 |

本次只修改 Java 与诊断脚本/文档。没有新增 Mixin，没有修改本体、DH、Shader 文件或载具包资产。

## 3. 真实显卡复现与修复对照

诊断入口：[ScreenEffectStateGpuRegression](../../scripts/diagnostics/ScreenEffectStateGpuRegression.java)。使用真实 Minecraft 类路径、生产 `ShaderInstance`、生产帧资源与冲击波实现，在隐藏的 OpenGL 上下文中绘制和回读像素。GPU 为 NVIDIA GeForce RTX 4070 Laptop GPU。

| 检查 | 修复前 | 修复后 |
| --- | --- | --- |
| DH 作用域退出后再次申请关闭深度写入 | 实际仍开启，断言失败 | 正确关闭；深度测试、剔除、混合和纹理后续调用也正确 |
| 零盏灯、构造“缓存关闭但实际开启”的残留减法混合 | 天空像素变为 `[0,0,0,0.5]`，确实变黑 | 保留原值 `[0.125,0.25,0.5,0.5]`，世界深度仍为 1 |
| 冲击波作用域内改变混合方程 | RGB 方程未恢复，断言失败 | RGB/Alpha 分别恢复，下一次引擎状态请求也正确 |
| 完整冲击波，零雾量/零折射，外部颜色采样器要求多级纹理 | 新增覆盖项 | 逐像素保留天空与透明度，并交回外部采样器；再画非零白雾确认特效实际执行，深度不变 |

“多级纹理”是同一纹理的小尺寸副本。冲击波临时背景只分配原尺寸一级，不能继承外部要求多级纹理的采样器，否则可能取到黑色。

原有 `lightingFrameGpuRegression` 也通过：近景/DH 深度、最终颜色与透明度复制，多个颜色输出目标、偏移视口、喷焰一像素可见度、同编号纹理重建及状态恢复全部保留。生产 Shader 显卡回归也通过，包括 DH 正/反深度、遮挡、发动机高亮/光晕、烟雾受光和炮口材质。
