## 8 动画控制器与脚本

- `animation_controllers/j16_controller.json`（参考 `j15_controller`）：
  - `script: "rvp:j16"`；`switchable_animations.landing_gear`（`part_id: landing_gear`、`animation: landing_gear`）
  - 可选：j16 渲染模型有 `jsb*` 减速板骨骼 + `jsb` 动画，若需减速板配 `airbrake` part（`structure_bone` 用 `vehicle_body`）+ 顶层 `airbrake_part_id` + `switchable_animations.airbrake`（`animation: jsb`）。是否加由你定。
- `scripts/j16.js`（参考 `j15.js`，**骨骼名不同**）：j16 渲染模型用 `wing0/1/2/3`（舵面）+ `ctrl`（操纵杆），按 j16.bbmodel 确认各骨用途后写 `updateBones`。

## 9 风险与注意

- 贴图小写：`j16.png`；display 精确引用。
- `decoy_flare_barrel`：j16 结构骨骼名与 j15（`decoy_flare`）不同。
- `sighting_system_barrel` 存在但不发射，不参与 bolt 配置。
- 动画只用 `animations/bedrock/entity/j16.animation.json`；`animations/bedrock/j16.animation.json`（146B 占位）建议删除。
- 对地两组挂点（`variable_agm` 挂点1/2、`variable_agm_2` 挂点3/4）在 `rvp_custom_mounts` 的 `part_unit_id`/`attach_part_unit_id` 必须一一对应。
- akf98a display 需带 `animations` 字段引用 `missile_akf98a.animation`（弹翼展开），否则导弹显示无展开动画。

## 10 贴图尺寸调整计划（新增）

**范围**：仅 `assets/rvp/textures/entity/ammo/` 目录下**尺寸 >500×500** 的图片，缩放到 **500×500**；**不触碰其它目录**。

### 需调整的文件（8 个，均为正方形）

| 文件 | 当前尺寸 | 目标 |
|---|---|---|
| `bomb_gb3.png` | 1000×1000 | 500×500 |
| `missile_aam_aim54c.png` | 2000×2000 | 500×500 |
| `missile_akf98a.png` | 1000×1000 | 500×500 |
| `missile_kh_39.png` | 2000×2000 | 500×500 |
| `missile_stormshadow.png` | 1000×1000 | 500×500 |
| `missile_tl17.png` | 1000×1000 | 500×500 |
| `missile_yj80.png` | 1000×1000 | 500×500 |
| `missile_yj91.png` | 1000×1000 | 500×500 |

> ammo 目录其余文件（500×500、128×128、250×250、500×250 等）均 ≤500，不动。

### 方法（Python PIL，先备份）

```python
from PIL import Image
import os, shutil, time
d = 'assets/rvp/textures/entity/ammo'
os.makedirs(d + '.bak_' + time.strftime('%Y%m%d'), exist_ok=True)
for f in sorted(os.listdir(d)):
    p = os.path.join(d, f)
    if not f.lower().endswith('.png'):
        continue
    im = Image.open(p)
    if im.size[0] > 500 or im.size[1] > 500:
        shutil.copy2(p, os.path.join(d + '.bak_' + time.strftime('%Y%m%d'), f))  # 备份
        im = im.resize((500, 500), Image.LANCZOS)
        im.save(p)
        print('resized', f)
```

### 注意事项

- 缩放仅改分辨率，不改通道/格式（保持 RGBA）。
- Bedrock 模型若用 `normalized_uvs`，UV 按比例缩放，贴图分辨率变化不影响映射；若个别模型用绝对 UV，需检查该模型是否错位（本包模型多为 normalized）。
- 缩放后引用这些贴图的 display 无需改动（路径不变）。
- 备份目录（`.bak_日期`）不入 git。
