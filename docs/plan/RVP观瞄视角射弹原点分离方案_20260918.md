# RVP 观瞄视角射弹原点分离（rvp_sight_fire_disguise）方案（2026-09-18）

> 状态：已完成代码与试点配置，待实机验证
> 需求：观瞄视角离炮闩枢轴较远，抵近射击偏差大——观瞄视角下实际弹药从观瞄相机位置射出
>（以该坐标为俯仰枢轴），视觉上仍看着从炮管射出；第三人称/座舱不变。
> 参考：MCH-Reforged `AddTurretWeapon`（射出坐标与火花坐标分离，无弹药伪装）；本方案为动态观瞄相机版 + 弹药伪装。

---

## 一、参数放哪：武器站侧（用户三问定版）

**载具 JSON 武器站（WeaponUnitPojo）字段 `rvp_sight_fire_disguise`**：

```json
"rvp_sight_fire_disguise": {
  "disguise_ticks": 4,
  "blend_ticks": 3,
  "max_distance": 32
}
```

| 字段 | 默认 | 含义 |
|---|---|---|
| `disguise_ticks` | 1 | 伪装期：实际弹渲染被平移为"从炮口射出的平行弹道"的时长（1tick 后即开始迁移，2026-09-19 用户定版） |
| `blend_ticks` | 3 | 合流 tick：伪装位置向真实弹道 smoothstep 缓入缓出过渡的时长（≥1；延长过渡提升平滑度，2026-09-19 用户定版） |
| `max_distance` | 32 | 服务端距离帽：观瞄射出点距载具原点超过即拒绝覆盖 |

**为什么不是弹药（武器）侧**：①观瞄是站属性（optical_sight_type/offset 同层）；②武器 JSON 跨载具共享，观瞄行为会泄漏给其它用同弹的车；③改装弹种每变体一文件，弹侧配置需逐变体添加且易漏。
**与自定义弹种（modding_only_multi）的兼容保证**：改装弹种开火时客户端走 `VehicleMultiWeapons.doClientShoot` 代理自行组上下文直传（不经 RVP 子武器方法），但服务端始终走子武器自己的 `shoot → dispatchShots → RVP_ProjectileSpawner`——**覆盖点在服务端 spawn 层、按射手观瞄状态判定**，与客户端上传链路无关，站上现有与未来弹种统一生效，改装切换零配置。若将来需按弹种排除，预留弹侧覆盖字段即可（本期不做）。

## 二、机制（零新增 Mixin，网络包+侧表+数据层标准模式）

1. **观瞄状态上行**（`C2SScopeViewSync`，协议 12→13）：客户端 `RVP_ScopeViewSyncClient` 差分 `LocalVehiclePlayer.viewType == SCOPE` + 操作根站（`getOwnOperatorUnit`），变化即发、观瞄中 30t 心跳；服务端 `RVP_ScopeViewStateTable`（键=玩家 UUID，90t 过期）。过期/缺失=普通出弹（优雅降级）。
2. **服务端出弹覆盖**（`RVP_ProjectileSpawner` 旧入口 muzzle 取值处）：门=站配置启用 + 状态表命中本站（根站匹配）+ `worldOpticalSightPosition`（OPERATOR 型用 `worldOwnerViewPosition`）距载具 ≤ max_distance；`spawnMuzzle = 观瞄相机坐标`，方向不变=炮管指向=准星方向（所见即所得）。aimContext 不动 → 本体枪口烟特效天然留在炮口。
3. **伪装数据落弹**（`RVP_ProjectileSpawnContext` 新组件 + `RVP_BaseBullet.rvp$applySightFireDisguise`）：addFreshEntity 前烙上；生成包同步 visualMuzzle(3d)+disguiseTicks/blendTicks(2 varint)；客户端按 readSpawnData 时 `position()` 冻结平移常量（visualMuzzle − actualSpawn）。
4. **渲染伪装**（`RVP_SightFireDisguiseRender`，两个弹体渲染器入口一行接入）：disguise 期内 PoseStack 平移常量（模型/曳光/尾焰同 Pose 生效，画在炮口平行弹道上），blend 期 factor 线性降 0 平滑合流（两端弹道平行，无硬跳变）。
5. **尾迹抑制**：服务端 `broadcastTrailParticles` 与客户端本地尾迹在 `tickCount < disguiseTicks` 期间跳过（避免真实弹道尾迹出卖伪装）。
6. **观瞄准星 RVP 弹道适配（2026-09-19 全局化定版）**：本体 SCOPE 准星画在 `weaponHitPos` 的屏幕投影上，而对 RVP 武器本体只会做无下坠直线射线（CCIP 分支 instanceof 只认本体 `VehicleCannon/Rocket/AerialBomb` 且用本体物理，RVP 武器永远落兜底）→ 低初速高重力弹（如 t90m 3of26：velocity 12 / gravity -0.01）远距下坠数格而准星不知，高初速弹（APFSDS）偏移小看不出来——**准星 RVP 弹道适配无条件生效，不要求 rvp_sight_fire_disguise 配置**。实现：`RVP_ScopeViewSyncClient.adaptScopeCrosshair` 每客户端 tick 覆写操作站 `weaponHitPos/weaponHitPosO`；`RVP_CcipUtil.computeBulletImpact` 按 kind 走与真实弹完全相同的积分器（MACHINEGUN→`stepCannon` 先移动后摩擦重力；BOMB→`stepBomb`、MISSILE/ROCKET→`stepProjectile` 先受力后移动，含 drag_in_air/恒速/最小最大速度钳制——与炮火支援解算同一积分器 `RVP_UnguidedBallisticMath`），逐 tick 段内用本体 `VectorUtil.hitPosition`（方块+实体 AABB+遮挡）求交，寿命钳 [10,120]；LASER/TARGETING_POD/DISPENSER 与本体武器不 march（原逻辑）。**march 原点跟随实际出弹点**：站配了伪装且距离帽内=观瞄相机（与服务端覆盖同源），否则=炮口。**平滑**：上一帧覆写值表（键=vehicleId+站序），O 帧=上一帧值、当前帧=新值，恢复本体准星 lerp 帧间插值（覆写同值会逐 tick 硬跳，2026-09-19 用户实测反馈后修复）；条件失效清表回本体值。`aimLocationDistance` 距离文本仍本体原逻辑（差 1~3 格观感级）。
7. **RVP 机枪弹道物理 march（2026-09-18 初版，19 日全局化取代）**：初版仅 MACHINEGUN 且要求站配置，用户实测 t90m 3of26 仍偏 → 定位为 t90m 未配置（opt-in 门挡住准星适配）+ 平滑缺失 + march 无实体命中，19 日按上方 §6 全局化重构。RVP 既有 `RVP_MachinegunLeadSolver`+预瞄圈（物理正确）仅服务锁定目标工作流，与本准星适配互补。

## 三、边界与不做

- **适配范围收敛（2026-09-19 用户定版）：仅 MACHINEGUN 类（机枪/机炮/榴弹/APFSDS）走观瞄出弹覆盖与准星弹道 march**；火箭/导弹/炸弹暂不适配——观瞄中回到本体原行为（炮口出弹、本体直线准星），出弹覆盖在 spawner 按 kind 短路、准星 march 在客户端按 kind 短路；`computeBulletImpact` 的分 kind 积分分支保留备用，将来放开按 kind 恢复即可；
- 冷发射（VLS）弹不排除出弹覆盖但观感场景罕见（点火前本就静止）；未排除，实测异常再门控；
- gunner AI/未配置载具/未开镜/第三人称/座舱零变化；距离帽防伪造包滥用（包 handler 另有乘车校验）；
- `particle_projectile_data` 粒子弹与伪装同配时，粒子仍走真实弹道（组合罕见，未处理）；
- 线导锚点随新出弹点走（观瞄射出，符合直觉）；
- 协议 12→13：旧客户端无法连新服（与 0917 激光致盲 11→12 同惯例）。

## 六、第四轮迭代（2026-09-19，用户实测三项反馈）

1. **同轴开火误驱动 railgun 蓄力"回归"**：真凶不是 0917 的 `chargeOwnInput` 门失效，而是**输入源** `RVP_WeaponFireController.isFireKeyDown` 用 `getCurrentWeapon() == weapon` 恒等比较选键——Multi 组内的 dtc251 恒等比较恒假 → 落进"任意开火键"兜底，打同轴（副键）时 railgun 的 fireDown 也为 true，而 chargeOwnInput 门在"railgun 正是当前主武器"时放行。修复：`RVP_WeaponResolveHelper` 新增 `currentSecondary`（unwrap），`isFireKeyDown` 主/副选中判定全部改解包比较。教训：**恒等比较代理包装武器必错，凡"当前选中"判定一律走 resolve helper**。
2. **伪装过渡**：disguise_ticks 1（1tick 后即开始迁移）+ blend_ticks 3（延长过渡）+ smoothstep（3t²−2t³）缓入缓出替代线性。
3. **准星对天空垂落**：march 无命中时原返回寿命终点（可数千格外）→ 准星大幅下垂。修复：march 增加飞行距离帽 512 格，全程无命中返回 null；`adaptScopeCrosshair` 对 null 置 `origin + dir×512`（投影≈屏幕中心）准星居中，上下过渡由 O 帧插值平滑。
