## 修复内容与边界

1. `RVP_AcceleratedMeshBridge.wrap` 加入与 SBM canRender 一致的公开阶段/配置判定。此前在普通命中展板中，SBM 不允许加速而回退 CPU 顶点，RVP 却已将 holder 替换成 raw AR builder，产生混合提交与大量 GL 对齐错误。修复后此时原消费者原样返回，不创建额外 AR 批次。
2. 大块主体单面 mesh 在 SBM 的 BakedGeometryChunk 回调处调用 **SBM 已有 StaticMeshRenderer API**，缓存未变换的局部三角形；每台车、每帧仅传当前骨骼矩阵、光照和 overlay。缓存键只有 chunk + 实际材质，运动/相机/实体 ID/光照均不产生新键。两块大几何（车体、发射架）不再逐实例展开进 AR 的临时输出和 staging 池。
3. 不支持的姿势、非均匀缩放、剪切、特殊法线、非白色、热成像、活动光影、GUI/手持物及特殊材质沿用原流程。单面材质、透明/特效骨、骨骼遍历、弹仓隐藏均未改。没有新增 Mixin、没有修改第三方 jar/AR 全局参数。
4. 生命周期、上传预算和释放由 SBM 管理。PENDING 表示已接管本帧，不再叠加原图；UNSUPPORTED 才回退。公开 API 采用局部几何共享，并非硬件实例化。
5. 配置新增 `mesh.sharedOpaqueMesh=true`，需要原 `acceleratedDenseMesh=true`；共用 `acceleratedDenseMinVertices=32768`。关闭 sharedOpaqueMesh 保留 dense 作对照，关闭 acceleratedDenseMesh 则整个桥回退。A1 首次启动会由 Forge 补默认项，无需改数据包。
