# RVP 无人机自动盘旋功能调研（2026-10-05）

> 现象：用户反馈车载无人机自动盘旋"感觉很多 bug"，未给具体症状。
> 结论：**用户感觉正确**。代码级确认 16+ 项真实缺陷，其中 4 项高危可直接解释"UAV 直线飞走/
> 不盘旋/失联/疯爬"类现象。全部为 RVP 侧可修（本体行为仅 FixedWingVehicle 无人驾驶 yRot 覆写
> 一处需 RVP 侧绕开）。本文档只报事实与证据，修复方案待用户确认优先级后另立。

---

## 一、实现机制概述（证据行号）

- 盘旋核心：`RVP_UavLoiterTickService`（ServerTickEvent END，每 tick）→ `RVP_UavLoiterGuidance`
  （CLIMB/TRANSIT/APPROACH/LOITER 四阶段制导）→ 状态存 `RVP_UavLoiterManager`（静态 Map，无持久化）。
- 驱动方式：`controlUnit.reset()` 后写布尔杆量 + `controlUnit.yRot`（目标航向）；**不写位置/速度**。
  固定翼靠 yRot 偏差→本体自动滚转转弯；旋翼靠 up/down 脉冲控高。
- 圆心两模式：followParent（每 tick 跟母车实时位置）/ markedCenter（战术地图标记）。
  半径 JSON `rvp_loiter_radius`（suav=100），高度 = max(圆心+altOffset, 正下方地表+clearance, minSafe)，
  **只采样 UAV 正下方**（前方地形采样常量 `TERRAIN_SAMPLE_*` 是死代码，方案承诺未实现）。
- 配置：全包仅 `rvp:suav`（fixed_wing！）有盘旋配置（suav.json:60-66，auto_on_takeoff）；
  母车 lav25/9k720/m142/zbl08a，出生偏移全 [0,100,0]。

## 二、高危缺陷（P0）

### P0-1 无人固定翼盘旋完全不转向 → 满油门直线飞走（最可能的主诉）

RVP 制导唯一转弯手段 = 写 `controlUnit.yRot` 目标航向 + 本体自动滚转。但本体
`FixedWingVehicle.tickMove`（ywzj_vehicle FixedWingVehicle.java:317-319）在 **getDriver()==null 时
每 tick 强制 `controlUnit.yRot=getYRot(); xRot=0`**，之后 aim/滚转协调（:320-360）才读值——
RVP 写入（上一 tick END）在无人驾驶时被覆写，yRotDiff≈0 → 滚转回平 → **永不转弯**。
suav 是 fixed_wing，`auto_on_takeoff=true` 的标准用法（N 键放飞不登机）整体失效。
旋翼机无此覆写（除非 hoverMode 残留，见 P1-1）——"有的 UAV 盘旋正常、有的飞走"的分界。
方案文档 `RVP无人机自动盘旋功能方案.md:139,821` 自己记录过该覆写行为，实现仍采用了被覆写的通道。

### P0-2 F 关盘旋后 controlUnit 锁存 → 按旧指令永久直飞

`C2SToggleUavLoiter.disable`（:52-54）只置 active=false，**不清 controlUnit**；无人载具从不自动
reset → 最后一次制导输出（油门/forward/yaw）被锁存，UAV 按旧指令直飞漂走（方案文档 :141-145 自述）。

### P0-3 区块卸载/重启 → 链接、盘旋、锁、冷却全部毁坏或孤儿化（三叠加）

1. **卸载不发 leave 事件**（Forge 1.20.1 实证：unload 走 `RemovalReason.UNLOADED_TO_CHUNK`，
   `shouldDestroy()==false` 不触发 EntityLeaveLevelEvent）→ 链接表残留，但
   `RVP_UavLoiterTickService.java:76-79` 发现实体查不到 → **静默 remove 盘旋** → 重载后
   "链在、旋没了"，M 能切 F 状态错乱。
2. **真移除路径误伤**：`onEntityLeaveWorld`（RVP_LinkedUavEventHandler.java:190-218）不区分
   移除与卸载（万一触发）→ 清链 + **误启动重部署冷却**（"刚部署完就进冷却"）。
3. **零持久化**：StateTable/LinkRegistry/LoiterManager/座位锁/冷却全是静态内存表；重启后
   UAV 孤儿化（引擎按 NBT 恢复可能满油门直飞），N/M/F 全失效，singleInstance 失效可重复部署。
4. **UAV 自身区块保活链脆弱**：suav.json 无 `"uav":true` 也无 `rvp_persistent_chunk_lease` →
   只剩远距租约服务（需同维度观察者+视觉授权+每维 32 载具预算），任一环断即卸载。

### P0-4 母车上按 F 开盘旋 → 高度参数错用，UAV 疯狂爬升

`C2SToggleUavLoiter.java:64` 把 `uav.getY()`（**绝对高度**）当 altitudeOffset 传
`enableFollowParent` → 目标高度 = 母车Y + UAV绝对Y（叠加错误），对比正确路径
`RVP_DeployableUavService.java:207-213`（传 loiterAltitudeOffset）。母车按 F 路径必现。

## 三、中危缺陷（P1）

| # | 缺陷 | 证据 |
|---|---|---|
| P1-1 | **hoverMode 残留杀死旋翼盘旋**：玩家在 UAV 上开过悬停，下车不清零、不落 NBT → 每 tick 覆写 yRot+自动配平总距，与制导对打 | 本体 RotaryWingVehicle.java:65,229-240,532-537；RVP 无清理 |
| P1-2 | **无前方地形采样**：只采正下方，盘旋圆切山必撞；方案承诺的前方扫描未实现（TERRAIN_SAMPLE_* 死代码） | RVP_UavLoiterTickService.java:44-48,250-262 |
| P1-3 | **骑盘旋 UAV 时鼠标瞄准被吞**：ControlUnitMixin 取消整个操控包只回填 functional 四布尔，xRot/yRot（瞄准）一起丢；F 键与原版副手交换同键双触发 | mixin/ControlUnitMixin.java:44-51；RVP_Keys.java:47 |
| P1-4 | **震荡检测量错对象**：updateOscillation 拿绝对目标航向的符号当"误差"符号（每圈过 0°/±180° 必翻转），误触发后 `radius *= 1.1` 无上限累积 | RVP_UavLoiterTickService.java:208-233 |
| P1-5 | **固定翼半径-速度外漂无恢复**：实际半径随速度增长（V²/g·tanBank），LOITER 永不超时、无回圆心分支、径向修正封顶 ±10°；自动扩半径只对旋翼生效 | RVP_UavLoiterTickService.java:264-274,282；RVP_UavLoiterGuidance.java:238-239 |
| P1-6 | **手动下车被劫持**：任何下车（含主动 Shift）都强制传送回母车+自动上车，无法在 UAV 旁留下；且任何玩家可登上他人飞行中的 UAV（无归属校验） | RVP_LinkedUavEventHandler.java:255-293,299-314 |
| P1-7 | **自动上车重试永不递减 + 只查主世界**：retryLeft 初值 60 从不减，母车被毁后条目每 tick 永久重试；异维度母车永不解析 | RVP_DeployableUavService.java:47,593-625；RVP_UavSeatLockEventHandler.java:29-37 |
| P1-8 | **切回母车覆盖标记圆心 + 标记高度存而不用**：enableFollowParent 置 markedCenter=false，地图标的圆心被静默改回跟随；state.altitude 从不参与高度计算（标山顶=强制爬山顶+35） | RVP_UavLoiterManager.java:70-87；C2SSetLoiterCenter.java:71-84；RVP_UavLoiterTickService.java:250-257 |

## 四、低危缺陷（P2/P3）

- 残骸仍被制导驱动（tick 服务只查 isAlive/isRemoved，DESTROYED 未 discard 也 alive）；
- 燃料耗尽无声坠落（suav ≈83 分钟续航，power=0 后无推力，无 RTB/告警）；
- 出生点无空间检查（母车 [0,100,0] 偏移可能卡进天花板/桥洞），initial_speed 立即前飞；
- 切回母车自动盘旋路径不开引擎（部署路径也只对固定翼开引擎，旋翼缺口）；
- 盘旋圆每 10 tick **全服广播**（含实体 id）；ControlUnitMixin 不校验 sender==operator（任意玩家
  的 functional 输入可写入盘旋中的 UAV）；
- disable 不删 LoiterManager 条目（长期运行缓慢累积）；
- 母车安全保持（切走后母车姿态驻留）从未实现（调研文档列为第 3 步）；玩家掉线重连不保留绑定。

## 五、与设计文档的偏差（docs/plan）

- `RVP无人机自动盘旋功能方案.md`：:139/821 记录了本体无人 yRot 覆写（P0-1 根源，实现仍用该通道）；
  :470-477 计划"玩家重进无人机自动关盘旋"——现行实现**相反**（Mixin 屏蔽输入+盘旋继续）；
  :561-579 前方地形采样——未实现；:486 引擎检查——未做。
- `载具放飞无人机与母车_无人机切换控制可行性调研.md`：母车安全保持、掉线重连保留绑定等
  兜底清单均未实现。
- `部署无人机操作员模型重构方案_20260809.md`：未实施的评审稿；若未来恢复 suav `"uav":true`
  会触发本体 FakePlayer 伤害转移（RVP 无防呆）——回归隐患。

## 六、症状映射推测（待用户确认）

| 用户可能看到的现象 | 最可能根因 |
|---|---|
| UAV 放飞后不盘旋、满油门直线飞走 | P0-1（无人固定翼 yRot 被覆写） |
| 按 F 关盘旋后 UAV 直飞不停 | P0-2（controlUnit 锁存） |
| UAV 飞远后再也 M 不回来/盘旋消失/能重复部署 | P0-3（卸载/持久化） |
| 母车按 F 后 UAV 疯狂爬升 | P0-4（绝对高度当偏移） |
| 旋翼 UAV 盘旋乱转/不转向 | P1-1（hoverMode 残留） |
| 盘旋圆切山撞山 | P1-2（无前方采样） |
| 骑在盘旋 UAV 上没法瞄准开枪 | P1-3（瞄准输入被吞） |
| 盘旋半径越来越大 | P1-4/P1-5（震荡误判+外漂） |
| 想下车留在 UAV 旁被强制拉回母车 | P1-6（下车劫持） |
