# 提示词：RVP `eo_ccip` 武器开镜时锚定母武器站（准星随动）

> 可直接整段交给执行 Agent。配套方案：`docs/plan/开镜随动_parent_weapon_unit_aim_动态覆盖_方案_20261012.md`

---

## 任务

在 `ywzj_rvp` 里实现：**配了 `rvp_fire_control_sensor_mode: "eo_ccip"` 的武器，在 SCOPE（开镜）视角下把 `parent_weapon_unit_aim` 当 `true` 用**（弹着点/准星锚定母武器站 ⇒ 准星随动）；其他视角保持武器站静态配置。**不改任何数据 JSON、不新增任何 Mixin。**

## 背景

- 现象：AH1Z `rocket` 站静态 `parent_weapon_unit_aim: false`（因不想让 CCIP 常驻跟随观瞄站），导致 APKWS（激光制导火箭弹）**开镜时准星定死**在火箭站自身指向。
- 根因：本体 `WeaponUnit.currentWeaponHitPosition()`（`ywzj_vehicle/.../WeaponUnit.java:838`）用 `currentWeaponUnit.isParentWeaponUnitAim()` 决定弹着点沿"母武器站方向"还是"武器站自身方向"算。开镜时 `eo_ccip` 会把传感器切成 `EO`，直接跳过 CCIP 分支落到 `aimHitPosition()` ⇒ 就是那个恒定的自身方向。
- **已有机制（不要重造）**：RVP 早就实现了武器级 `parent_weapon_unit_aim_override`（`RVP_WeaponData.java:150`），解析在 `RVP_WeaponResolveHelper.resolveParentWeaponUnitAimOverride()`，并有**两个既有 Mixin** 调用它：
  - `mixin/WeaponUnitParentAimOverrideMixin.java`（公共数组）→ 改 `currentWeaponHitPosition` 内那次 `isParentWeaponUnitAim()`；
  - `mixin/VehicleAimAtOverlaySeekerColorMixin.java:137`（client 数组）→ 改 HUD 准心同款调用。

  ⇒ **只改解析函数一处，两个消费点同时生效。**

## 改动清单（4 个文件）

### 1. `src/main/java/org/ywzj/rvp/client/bridge/RVP_IClientActions.java`

```java
/**
 * [RVP] 查询本地操作者是否处于 SCOPE（开镜）视角。
 *
 * <p>目的：公共侧解析 {@code eo_ccip} 武器的弹着点锚定方向时需要判断"是否开镜"，
 * 而公共代码不得直接引用 {@code @OnlyIn(CLIENT)} 的

 * 专用服务端为 NOOP，恒返回 false。</p>
 *
 * @return 本地玩家正在操作载具且视角为 SCOPE 时 true，否则 false

boolean isLocalOperatorInScopeView();
```

### 3. `src/main/java/org/ywzj/rvp/client/bridge/RVP_ClientActions.java`
实现该桥接方法（该类已实现 `RVP_IClientActions`）：

```java
@Override
public boolean isLocalOperatorInScopeView() {
    // 调用本体客户端状态类，读取本地玩家是否正在操作载具及其视角类型。
    LocalVehiclePlayer player = LocalVehiclePlayer.instance;
    return player != null
            && player.onVehicle()
            && player.viewType == LocalVehiclePlayer.ViewType.SCOPE;
}
```

> 若该类未 import，补 `import org.ywzj.vehicle.vehicle.LocalVehiclePlayer;`。

### 4. `src/main/java/org/ywzj/rvp/util/RVP_WeaponResolveHelper.java`
改写 `resolveParentWeaponUnitAimOverride(@Nullable AbstractVehicleWeapon<?> weapon)`（约 55-62 行）为三段式：

```java
/**
 * 解析武器级 {@code parent_weapon_unit_aim_override}（弹着点/准心锚定方向）。
 *
 * <p>优先级：① 武器显式 {@code parent_weapon_unit_aim_override}（写了就以它为准，保证可预测）
 * → ② {@code eo_ccip} 动态语义：SCOPE 视角按"电视/激光指示"处理，弹着点必须锚定母武器站
 * （准星随动）→ ③ 返回 null，由调用方回退武器站静态 {@code parent_weapon_unit_aim}。</p>
 *
 * <p>传入武器建议先经 {@link #currentPrimary} 解包（Agent/Multi → 具体武器）。</p>
 */
@Nullable
public static Boolean resolveParentWeaponUnitAimOverride(@Nullable AbstractVehicleWeapon<?> weapon) {
    if (!(weapon instanceof RVP_WeaponBase rvpWeapon)) {
        return null;
    }
    // 调用本项目武器数据模型，读取覆盖配置与传感器模式。
    RVP_WeaponData data = rvpWeapon.getData();
    // ① 显式配置优先。
    Boolean explicit = data.getParentWeaponUnitAimOverride();
    if (explicit != null) {
        return explicit;
    }
    // ② eo_ccip + 开镜 ⇒ 锚定母武器站；桥接查询避免公共代码引用客户端类型。
    if ("eo_ccip".equalsIgnoreCase(data.getFireControlSensorMode())
            && RVP_ClientActionsAccess.isLocalOperatorInScopeView()) {
        return Boolean.TRUE;
    }
    // ③ 回退武器站静态值。
    return null;
}
```

> 需要新增 import：`org.ywzj.rvp.client.bridge.RVP_ClientActionsAccess`；若使用显式类型还需 `org.ywzj.rvp.weapon.data.RVP_WeaponData`（用 `var` 可省）。
