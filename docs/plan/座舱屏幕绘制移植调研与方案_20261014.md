# 座舱屏幕（雷达/RWR/战术地图）实施定稿 — 2026-10-14

> 状态：**已实施**（本文为最终方案与配置指南）。
> 前置调研：MCHR（`D:\MCHR\MCH-Reforged`）模型贴屏实现考古 + 本体渲染挂点三路并行调研（结论已吸收进本文）。

## 1. 功能

载具座舱模型上的屏幕骨（cube/mesh 均可）实时显示三类动态界面：

| 屏型 | RL（display 引用） | 刷新率 | 内容 |
| --- | --- | --- | --- |
| 雷达屏 | `rvp:cockpit/radar` | 20Hz（每 tick） | 探测罗盘：量程圈+旋转扫描线+探测方块+速度矢量 |
| RWR 屏 | `rvp:cockpit/rwr` | 20Hz | 威胁罗盘：同心圆+方位射线+距离映射+机型文字+导弹/锁定告警闪烁 |
| 战术地图屏 | `rvp:cockpit/map` | 5Hz | 地形瓦片+本车/探测图标（**去**照射扇形与按钮侧栏，按用户定案） |

- **仅本地玩家乘坐的载具绘制**：其它载具的屏骨显示建模静态贴图（建议美术给屏骨一张"熄屏"底图）；
- **纯客户端开销**：数据全部来自既有客户端本地状态（本体 `WarningReceiver.targets`、`RadarUnit.getDetectedEntities`、`RVP_TacticalMapCache` 瓦片），服务端/网络零新增；三类屏全开 <0.5ms/帧+3MB 显存。

## 2. 配置层（用户操作指南）

**唯一的配置层 = display 文件的 `special_bone_effects`**，无 RVP 自有配置：

```json
"special_bone_effects": [
  { "bone": "illum_cockpit_radar", "texture": "rvp:cockpit/radar", "type": "transparent" },
  { "bone": "illum_cockpit_rwr",   "texture": "rvp:cockpit/rwr",   "type": "transparent" },
  { "bone": "illum_cockpit_map",   "texture": "rvp:cockpit/map",   "type": "transparent" }
]
```

- `texture` 三选一固定填上表 RL（**RL 的 path 就是屏型**，RVP 内容渲染器按它分发）；这些 RL 由 RVP 客户端注册的 512² DynamicTexture 提供，本体 `TextureStateShard` 每帧按 RL 实时 bind；
- `bone` = 建模的屏幕骨名（**mesh/poly_mesh 原生支持**，现有载具模型即大量使用 poly_mesh；cube 亦可）；屏面形状与 UV 由建模决定，内容纹理 0-1 整面映射；
- 建议屏骨名 `illum_` 前缀（本体既有自发光命名约定，屏面不受环境光变暗）；
- 同车多块同类屏 = 多条目同 texture（内容车级共享）；
- display 需带 `animation_controller`（baked 特殊骨前置，RVP 现有 display 均满足）。

**已配车辆**：suav、j16d（各三屏；屏骨名 `illum_cockpit_*` 为约定占位，**美术建模时对齐骨名**，或建好后改 display 的 bone 字段）。

## 3. 亮度语义（type 可选项）

- `transparent`（V1 采用）：半透明+光照——内容 alpha=1 区域为实心，暗处屏随环境变暗（真实 CRT 感）；
- `muzzle_flash`：加法混合恒亮无光照——暗处屏醒目，但白天亮背景会过曝；想切换直接改 type 字段，代码无感。

## 4. 架构与实现（新 5 文件，`rvp/client/cockpit/`）

| 类 | 职责 |
| --- | --- |
| `RVP_CockpitScreenManager` | 注册三张 DynamicTexture；ClientTick 降频驱动（20/20/5Hz）；仅本车判定（非乘载→熄屏灰） |
| `RVP_CockpitCanvas` | RT 离屏渲染封装（bindWrite+GUI 正交+GuiGraphics+endBatch）与回灌（`downloadTexture`→`setPixels+upload`；`FLIP_DRAW_Y` 开关供实机校方向） |
| `RVP_RwrScreenRenderer` / `RVP_RadarScreenRenderer` / `RVP_MapScreenRenderer` | 三屏内容（原语搬自 `RVP_RadarOverlay`；地图=瓦片 blit+图标层） |

渲染贴面由本体 `VehicleBedrockModel.renderSpecialBones` 完成（RVP 零渲染 Mixin）。

## 5. 已知限制与 V1 不处理项

1. **串显**：动态纹理为全局共享 RL——其它玩家的同款配屏车在本客户端会显示本车屏内容；打样后再评估是否加守卫；
2. 扫描线为匀速旋转简化版，HUD 雷达的三态相位（HMD/相控阵/机械）后续迭代接入；
3. `FLIP_DRAW_Y` 方向开关需实机校验一次（内容上下颠倒时改此开关）；
4. 战术地图屏比例为固定 2 格/像素（1024 格视野），缩放交互不做。

## 6. 实机验证清单

- suav/j16d 座舱屏出现内容（方向正确性：`FLIP_DRAW_Y`）；
- 三屏 20/20/5Hz 流畅度与暗处亮度（transparent 语义）；
- 非本车串显现象确认（决定是否加守卫）；
- j16d AKF-98A 空射条目联动（前一批次）一并验证。
