# MCHR 爆炸特效移植到 RVP（重写 v2）

> 源 MOD：`MCH-Reforged`（mcheli 1.7.10 Forge）→ 目标 MOD：`ywzj_rvp`（1.20.1-Forge 47.4.13，`mod_id=ywzj_rvp:0.5.9`）  
> 调研时间：2026-09-02 · 调研人：Muse Spark · 重写原因：v1 定位错误（误放 HBM 侧），v2 修正
> **✅ 2026-09-02 已落码**（实现记录与偏差见 §8），编译通过、runServer 冒烟 Done (2.254s) 零新增报错。

## 0 定位澄清（对 v1 的纠正）

- **RVP 武器的爆炸是继承本体 `ywzj_vehicle` 的**：`RVP_BaseBullet.triggerExplosion()`（`RVP_BaseBullet.java:3476`）最终走本体 `VehicleExplosion.explode()`（伤害 + 方块破坏 + 客户端分级爆炸视觉 `VehicleExplosion.java:458-529`），并叠加 RVP 的 vanilla 粒子补充 `RVP_ProjectileParticleEffects.spawnExplosion`（`RVP_BaseBullet.java:3588`）。
- **HBM 桥（`detonate_data.hbm_effect_data` → `RVP_HbmEffectBridge`/`RVP_HbmVisualService`）是第三方 HBM 特效**，与 RVP 自身爆炸视觉无关，v1 把参数加在 HBM 侧是**错误位置**。本方案**不触碰 HBM 桥**。
- 目标：把 MCHR 爆炸特效做成 **RVP 武器（机枪 / 火箭 / 导弹 / 炸弹）的默认爆炸视觉**，粒子数值**不开放配置**，而是按最终爆炸半径 `radius`（格）**内置自动计算**（照抄 MCHR `MCH_Explosion.effectExplosion` 由 `explosionSize` 驱动的公式）。
- 参数位置：唯一参数放在**视觉工厂**（`detonate_data.visual_effect_data`，即 `RVP_VisualEffectData`）那一侧，用于“屏蔽将要实现的 RVP 默认爆炸、改走本体特效”。

## 1 MCHR 默认爆炸数值（供移植的权威公式）

来源：`MCH_Explosion.effectExplosion`（`MCH_Explosion.java:73-273`）。以下 `size` = MCHR `explosionSize`，移植时令 `size = radius`（RVP 最终爆炸半径，格）。

### 1.1 闪光（`:123-127`）
```java
if (size >= 2.0F && isSmoking) spawnParticle("hugeexplosion");  // 大十字 4×4 帧
else                            spawnParticle("largeexplode");   // 小十字
```
- 全亮（`getBrightnessForRender=15728880`），贴图 `textures/entity/explosion.png`（原版 4×4 帧）。
- RVP 移植：`radius >= 2` → 大十字；否则小十字/小闪光。

### 1.2 方块碎屑（`:204-223`）
```java
if (spawnCount % 4 == 0) {
    float dustVelocity = min(size / 3.0F, 2.0F) * (0.5F + rand * 0.5F);
    spawnParticleTileDust(...  // 每 4 个受影响方块位 1 个，带方块贴图
        motion = sin(angle)*dustVelocity, 0.5 + dirY/5*dustVelocity, cos(angle)*dustVelocity,
        scale = min(size / 2.0F, 3.0F) * (0.5F + rand * 0.5F));
}
```
- `MCH_EntityBlockDustFX` = 原版 `EntityBlockDustFX` + `setScale`（`MCH_EntityBlockDustFX.java:7`）。
- RVP 移植：直接用 vanilla `BlockParticleOption(ParticleTypes.BLOCK, state)`，数值照抄公式。

### 1.3 扩散灰黄大烟（`:226-268`）
```java
int modInterval = (int) Math.max(size, 4.0F);          // 采样步长
if (size <= 1.0F || spawnCount % modInterval == 0) {   // 每个采样方块位生成一簇
    dir 方向调整（随机纵向或横向为主）
    MCH_ParticleParam p = new MCH_ParticleParam(w,"explode", x, y, z, dirX, dirY, dirZ,
        size < 8.0F ? (size < 2.0F ? 1.5F : size * 1.5F) : 12.0F);   // 粒子尺寸
    p.r = p.g = p.b = 0.3F + rand * 0.4F; p.r += 0.1F; p.g += 0.05F; // 灰黄
    p.a = 0.4F + rand * 0.4F;                                       // 半透明
    p.age = (int)((float)(5 + rand.nextInt(10)) * Math.max(size / 2, 6.0F)); // 寿命(最大数百 tick)
    p.gravity = 0.001f; p.diffusible = true;                        // 逐帧放大扩散
}
```
- 粒子类型：`MCH_ParticlesUtil.spawnParticle` 对非 `"Splash"` 一律走 `MCH_EntityParticleSmoke`（`MCH_ParticlesUtil.java:213-243`），贴图 `textures/particles/smoke.png`（8×8 帧，`MCH_EntityParticleSmoke.java:119`），8 帧渐淡 + `diffusible` 每帧 `particleScale += 0.8` + `toWhite` 渐白 + `motionYUpAge` 后上浮（`:32-50`）。
- RVP 移植：烟粒子数量近似 = 受影响方块数 ÷ `max(radius,4)`。RVP 服务端可用半径采样方块（简化：对 `int(radius)+2` 立方体采样，跳过空气），客户端由 `radius` + `seed` 确定性生成即可，避免服务端逐块遍历。

### 1.4 曳光火星（`:181-201`，仅大爆炸）
```java

    double flareSpeed = Math.min(size / 16.0F, 0.6D) * (0.5F + rand * 0.5F);
    spawnEntityInWorld(new MCH_EntityFlare(w, x, y+2, z,

- RVP 移植：`radius >= 6`，数量 `max(radius-1, 10)`；用粒子替代实体（免实体同步）。

### 1.5 水中水花（`effectExplosionInWater`，`:364-390`）
- 半径 `int(size)+1` 内扫描水体，每格 0~1 个 `MCH_EntityParticleSplash`（白色水珠、重力下落、入水溅 vanilla `splash`/`bubble`）。

### 1.6 音效（`:68-71`）

```
- RVP 现状本体 `VehicleExplosion` 已按 radius 分级播 `GENERIC_EXPLODE`（音量 2/4/8/14）；RVP 默认爆炸视觉保留本体音效，不重复加。

## 2 RVP 现状（继承本体的默认爆炸 = 要替换的对象）

### 2.1 本体 `VehicleExplosion` 客户端分级视觉（`VehicleExplosion.java:458-529`）
| radius | 视觉 |
|--------|------|
| ≤2 | small：FLASH + 2×EXPLOSION + campfire smoke + LARGE_SMOKE，音量 2 |
| ≤8 | medium：8×FLASH + 10×LARGE_SMOKE + 40×campfire + 40×SmokeCloudOption，音量 4 |
| ≤32 | large：60×FLASH + 120×campfire + 200×SmokeCloud + 冲击波环，音量 8 |
| >32 | nuclear：蘑菇云（stem/cap/fallout）+ 冲击波环 + FLASH，音量 14 |

这就是用户觉得“不好看”的默认视觉：依赖 vanilla 粒子 + `SmokeCloudOption`，缺 MCHR 的“大十字闪光 + 方块碎屑 + 翻滚灰烟 + 火星”。

### 2.2 RVP 叠加的 vanilla 补充（`RVP_ProjectileParticleEffects.spawnExplosion`，`RVP_BaseBullet.java:3588`）
仅 `!resolvedSuppressNative` 时执行：`ParticleTypes.EXPLOSION_EMITTER`/`EXPLOSION` + 按 `effects` 配置的小烟。

### 2.3 视觉工厂（v2 方案落点）
- 数据：`detonate_data.visual_effect_data[]`（`List<RVP_VisualEffectData>`，`RVP_DetonateData.java:63`）。
- 服务端：`RVP_VisualEffects.publishDetonation(context, list)`（`RVP_VisualEffects.java:51`）→ `RVP_DefaultDetonationVisualResolver`（`supports` 要求 `enabled && effectType 合法`，`RVP_DefaultDetonationVisualResolver.java:14`）→ `RVP_VisualEffectEvent`（含 `baseExplosionRadius/seed/scale/density`）→ `RVP_NetworkVisualEventPublisher` → `S2CVisualEffectEvent` 广播。
- 返回 `RVP_VisualPublishResult(publishedCount, shouldSuppressNativeExplosionEffect)`（`RVP_VisualPublishResult.java:9`）；`RVP_BaseBullet.java:3530` 已用它联动 `RVP_ExplosionVisualSuppression`。
- 客户端：`RVP_ClientBootstrap` 里 `RVP_VisualEffectEndpoint.install(RVP_ClientVisualEffectDispatcher::accept)` + 按 `effect_type` 注册工厂（已有范例 `RVP_ThermobaricEffectFactory`，`RVP_ClientBootstrap.java:32`）；`RVP_ClientVisualEffectDispatcher` 调 `factory.create(level, event)` → `RVP_ClientVisualEffect`（`Optional.empty()` 直接忽略，`RVP_ClientVisualEffectDispatcher.java:57`）；生命周期由 `RVP_ClientVisualEvents`（FORGE bus）驱动。

**结论**：视觉工厂通道天然携带 `baseExplosionRadius`，正好用于“按爆炸范围自动确定粒子数值”，是最合适的落点。

## 3 移植方案（v2 推荐）

### 3.1 设计原则
1. **默认开启**：RVP 四类武器（机枪/火箭/导弹/炸弹）一旦触发爆炸，默认走新 RVP 默认爆炸视觉（MCHR 风格）。
2. **数值内置**：粒子数值全部由 `radius` 在代码内自动推导（§1 公式），JSON 不暴露任何粒子参数。
3. **唯一参数放视觉工厂**：`RVP_VisualEffectData` 加一个布尔，用于“屏蔽 RVP 默认爆炸、改走本体特效”。
4. **联动**：视觉工厂其它特效（如温压）一旦发布成功，自动屏蔽 RVP 默认爆炸。
5. **不碰 HBM 桥**：`hbm_effect_data` 保持独立（HBM 全权接管时 RVP 默认爆炸自然不触发，现状 `RVP_HbmEffectBridge.apply` 返回 `realExplosionApplied` 时 `return`，`RVP_BaseBullet.java:3482`）。

### 3.2 数据层（仅 1 个参数）

`RVP_VisualEffectData` 新增：
```java
/** 为 true 时屏蔽将要实现的 RVP 默认爆炸视觉，该武器改走本体 ywzj_vehicle 爆炸视觉。默认 false。 */
@SerializedName("suppress_rvp_default_explosion")
private boolean suppressRvpDefaultExplosion = false;
```
- 配置示例（`detonate_data.visual_effect_data`）：
```json
"visual_effect_data": [
  { "suppress_rvp_default_explosion": true }
]
```
- 缺省（不配置任何 `visual_effect_data`）→ RVP 默认爆炸启用。
- 该条目不配 `effect_type` 时，`RVP_DefaultDetonationVisualResolver.supports` 返回 false，不会误发布视觉事件，仅作为屏蔽标记（`RVP_BaseBullet` 单独 `anyMatch` 读取）。

### 3.3 服务端流程改造（`RVP_BaseBullet.triggerExplosion`，`RVP_BaseBullet.java:3476`）

```java
// 1) HBM 桥（现状保留，全权接管时直接 return，不触发 RVP 默认爆炸）
if (detonateData != null && detonateData.hasHbmEffect() && ...) {
    RVP_HbmEffectBridge.Result hbm = RVP_HbmEffectBridge.apply(...);
    if (hbm.realExplosionApplied()) return;
    hbmSuppressNative = hbm.visualApplied() && ...;
}

// 2) 视觉工厂（温压等）
RVP_VisualPublishResult visualResult = RVP_VisualEffects.publishDetonation(context, detonateData.getVisualEffectData());

// 3) 判定是否屏蔽“将要实现的 RVP 默认爆炸”：
//    a) 视觉工厂其它特效发布成功（publishedCount>0）→ 屏蔽（温压已完整替代爆炸视觉）
//    b) 任一 visual_effect_data 显式 suppress_rvp_default_explosion=true → 屏蔽（走本体）
boolean suppressRvpDefault = visualResult.publishedCount() > 0
        || detonateData.getVisualEffectData().stream()
              .anyMatch(RVP_VisualEffectData::isSuppressRvpDefaultExplosion);

boolean resolvedSuppressNative;
if (!suppressRvpDefault) {
    // 默认：广播 RVP 内置 MCHR 爆炸视觉（数值按最终半径自动算），并压住本体/vanilla
    RVP_DefaultExplosionVisualService.spawn(serverLevel, pos, radius, waterFlag);
    resolvedSuppressNative = true;
} else {
    resolvedSuppressNative = hbmSuppressNative || visualResult.shouldSuppressNativeExplosionEffect();
}

// 4) 本体伤害结算（现状保留）
VehicleExplosion ex = ...;
if (resolvedSuppressNative) RVP_ExplosionVisualSuppression.run(ex::explode);
else ex::explode;

// 5) vanilla 补充：仅未压制时走（suppress_rvp_default=true 且无温压 → 走本体 + vanilla）
if (!resolvedSuppressNative && serverLevel != null && rvpData != null)
    RVP_ProjectileParticleEffects.spawnExplosion(serverLevel, pos, rvpData.getEffectsData(), radius);
```

**屏蔽矩阵**：
| 场景 | RVP 默认(MCHR)爆炸 | 本体 `VehicleExplosion` 视觉 | RVP vanilla 补充 |
|------|------------------|----------------------------|------------------|
| 默认（无 `visual_effect_data`、无 HBM） | ✅ 启用 | 屏蔽 | 屏蔽 |
| 温压等视觉工厂发布成功 | 屏蔽 | 按温压条目 `suppress_native_explosion_effect` | 按同 |
| `suppress_rvp_default_explosion=true`（无 effect_type） | 屏蔽（改走本体） | ✅ 本体 | ✅ vanilla 补充 |
| 温压 + `suppress_rvp_default_explosion=true` | 屏蔽 | 温压条目决定 | 温压条目决定 |
| HBM `hbm_effect_data` 生效 | 不触发（HBM 全权） | 按 HBM `suppress` | 按 HBM |

### 3.4 客户端（复用视觉工厂通道 + 4 个自注册粒子）

**新增服务端广播** `RVP_DefaultExplosionVisualService`（`weapon/visual` 包，服务端安全，不引用客户端类型）：
```java
// 构造公共领域事件（effectType=rvp:mchr_explosion, preset=rvp:default,
//      baseExplosionRadius=radius, seed/scale/density=1, sound/flash 按配置）
// → 直接复用 RVP_NetworkVisualEventPublisher / S2CVisualEffectEvent 广播
```

**新增客户端工厂** `RVP_DefaultExplosionFactory`（`client/visual` 包，实现 `RVP_ClientVisualEffectFactory`），`RVP_ClientBootstrap.onClientSetup` 注册：
```java
RVP_ClientVisualEffectDispatcher.register(
    ResourceLocation.fromNamespaceAndPath("rvp", "mchr_explosion"),
    new RVP_DefaultExplosionFactory());
```
`create(level, event)` 内按 `event.baseExplosionRadius()`（+ `event.seed()`）**内置计算**（§1 公式）并 `level.addParticle(...)` 生成一批粒子，返回 `Optional.empty()`（粒子生命周期交给 minecraft 粒子系统，无需自管实例）。

**新增 4 个自注册粒子**（仿 `RVP_WhitePhosphorusParticle.java:34` 直接绑定纹理的 `SingleQuadParticle` + 自定义 `ParticleRenderType`）：

| 粒子 | 复刻自 | 贴图 | 参数（由 radius 推导） |
|------|--------|------|------------------------|
| `rvp:mchr_explosion_flash` | `MCH_EntityParticleExplode`（4×4 帧） | `minecraft:textures/entity/explosion.png`（原版自带，不拷贝） | `radius>=2` 生成 |
| `rvp:mchr_smoke` | `MCH_EntityParticleSmoke`（8×8 帧，扩散+转白+上浮） | `minecraft:textures/particles/smoke.png` | size=`radius<8?radius*1.5:12`；age=`(5+rand10)*max(radius/2,6)`；色 r=g=b=0.3+rand*0.4(+0.1/+0.05)，a=0.4+rand*0.4；gravity 0.001 |
| `rvp:mchr_flare` | `MCH_EntityFlare`（火星，拖烟，死亡烟爆） | 亮色圆点（可复用 `textures/nuclear/flare.png`） | `radius>=6` 且数量 `max(radius-1,10)` |
| `rvp:mchr_splash`（可选） | `MCH_EntityParticleSplash` | `textures/particles/smoke.png` | `waterFlag` 时生成 |

**生成逻辑**（对齐 `MCH_Explosion.effectExplosion:73`）：
1. 闪光：爆心 1 个 `flash`。
2. 碎屑：对 `int(radius)+2` 立方体采样方块，每 4 个采样位 1 个 `BlockParticleOption`，方向 = 采样位−爆心归一化，速度/尺寸照抄 §1.2。
3. 大烟：采样方块位 / `max(radius,4)` 个 `smoke`，位置 = 采样位与爆心中点，速度照抄 §1.3，数量按 `density` 缩放。
4. 火星：`radius>=6` 时 `max(radius-1,10)` 个 `flare`，速度照抄 §1.4。
5. 水中：`waterFlag` 时 `splash` + vanilla `SPLASH/BUBBLE`。

### 3.5 注册与生命周期

- `RVP_Particles`（`all/RVP_Particles.java:17`）注册 4 个 `SimpleParticleType`（命名空间 `rvp`）。
- `RVP_ClientBootstrap.onRegisterParticleProviders` 注册 4 个 Provider（仿白磷）。
- 分发：`RVP_VisualEffectEndpoint` 已安装（`RVP_ClientBootstrap.java:28`），`RVP_ClientVisualEffectDispatcher.accept` 按 `effect_type=rvp:mchr_explosion` 命中新工厂；tick/渲染/清理走 `RVP_ClientVisualEvents`（无需新增事件类）。

## 6 风险与验证

- **协议**：复用 `S2CVisualEffectEvent`（`SCHEMA_VERSION=1`），不新增网络消息、不动 `RVP_Network.PROTOCOL`。
- **@OnlyIn(CLIENT)**：新粒子/工厂全在 `client` 包；服务端 `RVP_DefaultExplosionVisualService` 不引用客户端类型（`agents.md:38`）。
- **粒子预算**：大半径（炸弹 radius>32）时烟/火星数量需钳制上限（参照 `RVP_ThermobaricParticleBudget`），并受 `event.density()` 缩放。
- **确定性**：`create()` 用 `event.seed()` 派生 `Random`，保证多客户端观感一致（与 `RVP_VisualEffectEvent` 语义一致）。
- **兼容存量**：未配置 `visual_effect_data` 的存量武器自动获得 RVP 默认爆炸（行为变化需在更新日志说明）；配置了温压/HBM 的武器不受影响；`suppress_rvp_default_explosion=true` 可精确回退到本体。

### 8.2 与方案的偏差
