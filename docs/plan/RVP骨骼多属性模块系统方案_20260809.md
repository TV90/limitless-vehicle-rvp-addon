# RVP 骨骼多属性模块（Bone Module）系统方案

## 背景与目标

当前 `hitbox_era` 把三种语义耦合在一张配置表里：

1. **通用命中属性**：`damage_factor`（减伤倍率）、`min_trigger_damage`（触发阈值）
2. **ERA 专有行为**：被击毁后该骨块不再阻拦弹药（后续弹药穿透）
3. **特效参数**：`explosion`（触发特效强度）

这种耦合导致无法表达：

- 履带骨块：被打坏失去动力，但**仍然有碰撞**（弹药照常命中）
- 光电干扰机骨块：被打坏失去干扰功能，但**仍然有碰撞**
- t84bm 场景：光电干扰机架在反应装甲上，同一块骨**同时**有 ERA（击毁后穿透）和干扰机（击毁后失功能）两种属性，且需**独立判定、独立消耗、独立同步**

目标：把"骨块状态"从单一 ERA 布尔升级为**骨块 × 多属性**的模块化模型，ERA 退化为一种行为模式。

## 核心设计：BoneModuleType 行为分派

```java
public enum BoneModuleType {
    ERA,      // 击毁后：该骨块不再参与碰撞（弹药穿过）—— ERA 专有行为
    TRACK,    // 击毁后：仍参与碰撞，但失去动力（功能损失）
    JAMMER;   // 击毁后：仍参与碰撞，但失去干扰功能（功能损失）
}
```

每种属性两种能力，由类型决定：

| 能力 | ERA | TRACK / JAMMER |
|:--|:--:|:--:|
| 击毁后穿透（不再阻拦弹药） | ✅ | ❌（保持碰撞、照常减伤） |
| 击毁后功能回调 | 仅特效 | ✅（动力中断 / 干扰关闭） |
| 爆炸范围百分比破坏 | ✅（默认参与） | 可配置是否参与 |

## 配置格式（统一，替代 hitbox_era 的耦合）

```json
{
  "bone_modules": {
    "ERA0": {
      "damage_factor": 0.55,       // 通用：减伤倍率
      "min_damage": 100.0,         // 通用：触发"击毁"的伤害阈值
      "modules": ["era", "jammer"],// 叠加：一块骨同时挂多个属性，独立失效
      "era": { "explosion": 2 }    // 仅 ERA 的触发特效参数
    },
    "TRACK_L": {
      "damage_factor": 0.3,
      "min_damage": 60.0,
      "modules": ["track"]
    },
    "JAMMER_R": {
      "damage_factor": 0.9,
      "min_damage": 30.0,
      "modules": ["jammer"]
    }
  }
}
```

要点：

- `damage_factor` / `min_damage` 提升为**所有模块骨块通用**，不再属于 ERA
- `modules` 数组决定叠加关系，`["era","jammer"]` 即 t84bm 场景
- 兼容：解析器把旧的 `hitbox_era` 映射成 `modules: ["era"]`，旧配置无需改动
- `explosion.radius > 5` 的 HE 仍走百分比破坏；`explosion` 参数归属 `era` 子对象

## 运行时状态模型（核心升级）

### 现状

```java
// RVP_EraStateTable：一个骨块只有"ERA 是否失效"一维状态
Map<UUID, Set<String>>  // 车辆UUID → 已失效的 ERA 骨块名
```

### 升级后

```java
// RVP_BoneModuleStateTable：每个骨块可独立失效多个属性
Map<UUID, Map<String, Set<BoneModuleType>>>  // 车辆UUID → 骨块名 → 已失效属性集合
```

操作接口：

```java
boolean isModuleDestroyed(UUID vehicleId, String boneName, BoneModuleType type);
boolean destroyModule(UUID vehicleId, String boneName, BoneModuleType type); // 返回是否首次消耗
void retainModules(UUID vehicleId, Map<String, Set<BoneModuleType>> valid);  // 配置热重载清理
```

失效骨块的**命中判断**逻辑变化：

- `isModuleDestroyed(..., ERA)` → 该骨块从碰撞候选中剔除（穿透）→ 与现有 `candidate.era() && !candidate.eraActive()` 等价
- `isModuleDestroyed(..., TRACK/JAMMER)` → 骨块**继续保留**在候选中，正常减伤，仅功能回调不触发

现有 [RVP_VehicleHitboxFactorManager.java#L516-L610](file:///d:/ywzj/ywzj/ywzj_rvp/src/main/java/org/ywzj/rvp/weapon/damage/RVP_VehicleHitboxFactorManager.java#L516-L610) 的 `resolve()` 中，候选项携带 `era/eraActive` 布尔：


升级后，`HitCandidate` 携带骨块上的**属性集合**：

```java
record HitCandidate(
        double distance,
        Vec3 hitPoint,
        String boneName,
        float factor,
        Set<BoneModuleType> modules,          // 该骨块挂的所有属性
        Set<BoneModuleType> destroyedModules  // 已失效的属性
) {
    /** ERA 失效 → 该骨块对弹药无碰撞（穿透）。 */
    boolean passThrough() {
        return destroyedModules.contains(BoneModuleType.ERA);
    }
}
```

`resolve()` 候选循环：

```java
for (HitCandidate candidate : candidates) {
    if (candidate.passThrough()) {
        continue; // 仅 ERA 失效穿透；TRACK/JAMMER 失效仍命中减伤
    }
    ...
}
```

`HitboxDamageResult` 泛化：

```java
record HitboxDamageResult(
        boolean enabled,
        float factor,
        float defaultFactor,
        String hitBoneName,
        ResourceLocation structureModel,
        int missingConfigBones,
        double distance,
        Vec3 hitPoint,
        Set<BoneModuleType> modules,          // 命中骨块挂的属性
        Set<BoneModuleType> destroyedModules, // 其中已失效的
        float minTriggerDamage,               // 通用触发阈值
        float explosion                       // ERA 特效参数（era 子对象）
)
```

## 功能消费点（TRACK / JAMMER 的"失去功能"落点）

与 ERA（只影响碰撞）不同，TRACK / JAMMER 要影响**行为**，需要在功能逻辑处查询状态：

| 属性 | 消费位置 | 行为 |
|:--|:--|:--|
| TRACK（履带断动力） | ywzj_vehicle 本体动力/移动计算 | 查询 `isModuleDestroyed(vehicle, bone, TRACK)` → 减速/禁止推进。需最小 mixin 或挂钩本体移动逻辑（受 `rvp-avoid-mixin` 约束，优先查本体现有钩子） |
| JAMMER（干扰机） | RVP 自身干扰/光电逻辑 | 查询 `isModuleDestroyed(vehicle, bone, JAMMER)` → 干扰失效。纯 RVP 侧实现，无需碰本体 |

## 兼容与迁移

1. **配置兼容**：`hitbox_era` 解析保留，自动映射为 `modules: ["era"]`；新字段 `bone_modules` 优先
2. **存档兼容**：`rvp_era_state` 旧格式（`Set<String>`）读取时映射为 `{bone: [ERA]}`
3. **JS 兼容**：`rvp_isEraActive` 保留，委托给通用接口
4. 新增属性（TRACK/JAMMER）属于增量，不影响现有 ERA 行为
