## 配置与伤害规则

```json
"hitbox_explosion_damage_factor": {
  "turret_top": 1.5,
  "Periscope": 1.5
}
```

键是实际结构骨名，缺省 1。它独立于直击 `hitbox_damage_factor`，也不替代已有 `vehicle_explosion_damage_factor`（后者仍按原有爆心到车体中心射线选骨），与其它现有爆炸倍率相乘一次。

RVP 弹体在真实碰撞（且未跳弹）时记录目标 UUID/骨/cube/tick，包括零直伤 HE；同 tick 对应爆炸用该骨倍率，不因为爆心偏移而换骨。可嵌套 ThreadLocal 只在同步爆炸窗口存在，离开恢复，波及其它车不借用直击骨。近失/无碰撞上下文爆炸，在**全部可受击 OBB**中比较爆心至真实表面的最短距离，未配置弱点的车体照样参与并取默认 1，避免隔空挑最近的已配置弱点。重叠同距取体积较小的 OBB。Forge VehicleAttackEvent 重放只加倍率一次，覆盖本体爆炸及带爆炸 tag 的其它来源、无射手爆炸，0 倍可取消伤害，不引入直击装甲扣减。
