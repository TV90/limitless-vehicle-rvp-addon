## 范围与目标

本文档用于统一讨论「GPS 炸弹末端制导扩展」和「反辐射导弹」的架构落地方案，目的是：

- 使末端制导类型可扩展，避免实体逻辑持续硬编码某一种导引头；
- 使反辐射导弹采用与 GPS 炸弹、电视制导导弹一致的「独立武器类型 + 独立实体」模式，降低对 Mixin 的依赖；
- 统一命名：反辐射使用 `anti_radiation_*` 前缀，避免 `arm_*` 引发歧义。

本文不承载「新增参数字段说明」（该类内容应写入 `RVP包新增参数字段说明.md`）。

---

## 现状说明

### GPS 炸弹

GPS 炸弹不依赖对本体导弹的 Mixin：

- 注册独立武器类型 `ywzj_rvp:gps_bomb`；
- `VehicleGPSBomb` 发射 `GPSBombEntity`；
- 目标点、弹道与 `terminal_ir_*` 末段逻辑在 `GPSBombEntity` 内完成。

### 反辐射导弹（已落地）

反辐射导弹已采用与 GPS / TV 相同的模式：

| 层级 | 类 / ID |
|------|---------|
| 武器类型 | `ywzj_rvp:anti_radiation_missile` |
| 武器 | `VehicleAntiRadiationMissile` |
| 数据 | `VehicleAntiRadiationMissileWeaponData`（字段 `anti_radiation_*`） |
| 实体 | `AntiRadiationMissileEntity` |
| 索敌 | `AntiRadiationSeekerHelper` |

`MissileEntityMixin` 仅对 `AntiRadiationMissileEntity` 转发 `tickTrack`（与 `TVMissileEntity` 转发制导/运动同类），不再在本体 `MissileEntity` 上注入完整反辐射逻辑。

### 电视制导导弹（已落地）

- 武器类型 `ywzj_rvp:tv_missile`，实体 `TVMissileEntity`，字段 `tv_missile_*`。

## 推荐路线

### A. GPS 炸弹末端制导：策略化（Terminal Guidance Strategy）

目标：把 `GpsBombEntity` 内部的末端 IR 逻辑抽象成可插拔策略，未来新增末端制导方式时不修改实体核心流程。

推荐形态：

- 定义末端制导接口 `TerminalGuidance`（或同义命名）：
  - `void tick(GpsBombEntity e)`
  - `Vec3 getAimPointOrNull(GpsBombEntity e)`
  - `boolean isTerminalActive(GpsBombEntity e)`
- `GpsBombEntity` 内只保留「制导目标选择」的最小逻辑：
  - 先取 `terminalGuidance.getAimPointOrNull()`（若返回非空则优先）
  - 否则回退到 GPS 目标点 `targetPos`
- 将现有 IR 末制导完整迁移成 `IrTerminalGuidance` 实现（等价迁移，不改变行为）。

数据层建议：

- 引入结构化字段 `terminal_guidance`：
  - `terminal_guidance.type = IR / LASER / TV / ARH ...`
  - 参数都收敛在 `terminal_guidance.*` 下
- 兼容策略：
  - 继续支持现有 `terminal_ir_*`；反序列化阶段将旧字段映射成 `terminal_guidance.type=IR`，避免一次性破坏存量包。

### B. 反辐射导弹：维护独立类型（已完成主体）

当前实现要点：

1. 武器类型 `ywzj_rvp:anti_radiation_missile`，数据类 `VehicleAntiRadiationMissileWeaponData`
2. `VehicleAntiRadiationMissile` 发射 `AntiRadiationMissileEntity`，预选目标保存在武器实例上（非 `WeaponUnit` Mixin）
3. `AntiRadiationSeekerHelper` 负责辐射源扫描、脉冲记忆与排序
4. 载具包 JSON 使用 `anti_radiation_*`；反序列化时 `arm_*` 自动映射为新字段名

后续可选工作：

- GPS 末端制导策略化（见 A）
- 进一步减少 `MissileEntityMixin` 挂钩方式（若本体开放 `tickTrack` 覆写则可去掉转发注入）

## 命名规范

- 对外显示：反辐射 / Anti-Radiation（语言文件 `message.ywzj_rvp.anti_radiation.*` 等）。
- 对内标识：
  - 武器类型：`anti_radiation_missile`
  - 配置字段：`anti_radiation_*`
  - 不再新增 `arm_*`；读取时可将 `arm_*` 映射到 `anti_radiation_*`
- `homing_mode` 推荐 `ANTI_RADIATION`（兼容读取 `ANTI_RADAR`）。
