## 一、背景与目标

- 模组：**`ywzj_rvp`**（Minecraft 1.20.1 Forge）。源码根：`ywzj_rvp/src/main/java/org/ywzj/rvp/`。
- 依赖本体模组 `ywzj_vehicle`（源码 `ywzj_vehicle/src/main/java/org/ywzj/vehicle/`）。**本体只读，一律不要改。**
- **现象**：坦克死亡后炮塔会作为独立残骸实体 `VehiclePart` 飞出（"飞头"）；此时**炮口焰 `turret_muzzle_flash` 会跟着残骸渲染出来**——正常整车状态下它被 `static` 动画压成不可见，但残件不跑动画。
- **目标**：让**残件渲染时可隐藏指定渲染骨**（数据可配），并在 VT4 / T-90M / ZTZ99B 上生效。

### 为什么必须改代码（别尝试纯数据方案）

1. 整车渲染 `VehicleBedrockModel.renderToBuffer(...)` 首行会 `setSpecialBoneVisible(instance, false)`，把特殊骨从主通道摘掉、只在 `renderSpecialBones` 里单独画。
2. 残件走的是**另一个渲染器** `VehiclePartRender`：它直接 `modelInstance.renderSingleBone($weapon0)`，**没有**这一步 ⇒ 特殊骨被当普通几何画出来。
3. 残件**不跑动画控制器**（`VehiclePart` 未实现 `IAnimationEntity`，`VehiclePartRender` 也不调 `applyAnimationPose`）⇒ `static` 动画压不下去。
4. 本体自带的"排除骨"通道 `VehiclePart.getExcludedBoneNames()` 依赖私有推导 `PartUnit.getAttPartUnits()`，**实测拿不到内容**（该路线已试过，无效）。
5. 把 `turret_muzzle_flash` 移出 `$weapon0` 子树 ⇒ 整车时会不再跟随炮管俯仰，表现坏掉。

⇒ **采用下面的「方案 A」：零新增 Mixin，新增 2 个纯 Java 类 + 改 2 处现有文件。**

## 二、改动清单（4 处）

### ① 新增 `src/main/java/org/ywzj/rvp/config/RVP_PartHiddenBonesCache.java`

> 放在 `config` 包，与项目现有 `*Cache`（`RVP_LoiterConfigCache` 等）保持一致；
> 这样 common 侧的 mixin 引用它也不會牵扯客户端类。

```java
package org.ywzj.rvp.config;

import net.minecraft.resources.ResourceLocation;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

/** 残件隐藏骨配置：vehicleId -> (partId -> 渲染骨名列表)。数据包重载时整表重建。 */
public final class RVP_PartHiddenBonesCache {

    private static volatile Map<ResourceLocation, Map<String, List<String>>> TABLE = Map.of();

    private RVP_PartHiddenBonesCache() {}

    public static void clear() {
        TABLE = Map.of();
    }

    public static void put(ResourceLocation vehicleId, Map<String, List<String>> byPartId) {
        Map<ResourceLocation, Map<String, List<String>>> copy = new HashMap<>(TABLE);
        copy.put(vehicleId, Map.copyOf(byPartId));
        TABLE = Map.copyOf(copy);
    }

    /** 取该载具该部件的隐藏骨；无配置返回空表。渲染热路径只读 volatile 字段，不额外分配。 */
    public static List<String> get(ResourceLocation vehicleId, String partUnitId) {
        Map<String, List<String>> byPartId = TABLE.get(vehicleId);
        if (byPartId == null) return List.of();
        List<String> bones = byPartId.get(partUnitId);
        return bones == null ? List.of() : bones;
    }
}
```

### ② 新增 `src/main/java/org/ywzj/rvp/client/render/RVP_VehiclePartRender.java`

```java
package org.ywzj.rvp.client.render;

import com.github.mcmodderanchor.simplebedrockmodel.v2.common.model.runtime.BakedModelInstance;
import com.github.mcmodderanchor.simplebedrockmodel.v2.common.model.runtime.BoneState;
import com.mojang.blaze3d.vertex.PoseStack;
import net.minecraft.client.renderer.MultiBufferSource;
import net.minecraft.client.renderer.entity.EntityRendererProvider;
import net.minecraftforge.api.distmarker.Dist;
import net.minecraftforge.api.distmarker.OnlyIn;
import org.ywzj.rvp.config.RVP_PartHiddenBonesCache;
import org.ywzj.vehicle.client.render.entity.vehicle.VehiclePartRender;
import org.ywzj.vehicle.entity.misc.VehiclePart;
import org.ywzj.vehicle.vehicle.part.PartUnit;

import java.util.List;

/**
 * 残件（脱落部件）渲染器：按载具 JSON 的 {@code rvp_part_hidden_bones} 把指定渲染骨隐藏，再走本体渲染。
 * <p>
 * 起因：本体 {@link VehiclePartRender} 直接 {@code renderSingleBone} 而不做
 * {@code setSpecialBoneVisible(false)}，导致特殊骨（炮口焰等）被当普通几何画出来；
 * 又因残件不跑动画控制器，{@code static} 动画压不下去。
 * 这里在渲染前把骨置 {@code visible = false}，渲染库 {@code renderBone} 会连同整棵子树一起跳过。
 */
@OnlyIn(Dist.CLIENT)
public class RVP_VehiclePartRender extends VehiclePartRender {

    public RVP_VehiclePartRender(EntityRendererProvider.Context context) {
        super(context);
    }

    @Override
    public void render(VehiclePart part, float pEntityYaw, float pPartialTick,
                       PoseStack pPoseStack, MultiBufferSource bufferSource, int pPackedLight) {
        // 注意：VehiclePart 没有 getPartUnitId()，用公开的 getPartUnit().getId() 取
        PartUnit<?> unit = part.getPartUnit();
        List<String> hidden = unit == null
                ? List.of()
                : RVP_PartHiddenBonesCache.get(part.getVehicleId(), unit.getId());
        if (!hidden.isEmpty()) {
            BakedModelInstance instance = part.getVehicleModelInstance();
            if (instance != null) {
                for (String boneName : hidden) {
                    BoneState bone = instance.getBone(boneName);
                    if (bone != null) {
                        bone.visible = false;   // 不需要恢复：残件渲染器是本实例的唯一消费者
                    }
                }
            }
        }
        super.render(part, pEntityYaw, pPartialTick, pPoseStack, bufferSource, pPackedLight);
    }
}
```

> 符号已核实：`AbstractVehicle.getVehicleId()`（public，`AbstractVehicle.java:485`）、
> `VehiclePart.getPartUnit()`（public，`VehiclePart.java:204`）、`PartUnit.getId()`（public，`PartUnit.java:526`）
> ⇒ **不需要再加 accessor**。`part.getPartUnit()` 极端情况下可能为 null（部件数据未就绪），已做判空。

**b) 循环内，紧跟现有 `VehicleUIPresetCache.putShowSkeleton(...)` 之后：**

```java
// 残件隐藏骨：rvp_part_hidden_bones = { "<partId>": ["bone", ...], ... }
Map<String, List<String>> partHiddenBones = new HashMap<>();
JsonElement hiddenEl = obj.get("rvp_part_hidden_bones");
if (hiddenEl != null && hiddenEl.isJsonObject()) {
    for (var e : hiddenEl.getAsJsonObject().entrySet()) {
        if (e.getValue() == null || !e.getValue().isJsonArray()) continue;
        List<String> bones = new ArrayList<>();
        for (JsonElement b : e.getValue().getAsJsonArray()) {
            if (b != null && b.isJsonPrimitive()) {
                String name = b.getAsString().trim();
                if (!name.isEmpty()) bones.add(name);
            }
        }
        if (!bones.isEmpty()) partHiddenBones.put(e.getKey(), List.copyOf(bones));
    }
}
RVP_PartHiddenBonesCache.put(vehicleId, partHiddenBones);   // 空表也要 put，便于重载时清干净
```

## 三、数据格式（由数据侧负责，你**不要改任何 JSON**）

写在载具 JSON **顶层**，与 `ui_preset` 并列：

```jsonc
"rvp_part_hidden_bones": {
  "turret": ["turret_muzzle_flash"]
}
```

- 键 = `parts[].id`（如 `turret`）；
- 值 = **渲染模型**里的骨名数组（可多个）。

## 五、验收标准

1. **编译通过**，客户端启动日志无新增异常。
2. 打爆 **VT4 / T-90M / ZTZ99B**：
   - 飞出的炮塔残件上 **不再出现炮口焰面片**；
   - **整车开炮时炮口焰仍然正常显示**（没有被误伤）。
3. **未配置 `rvp_part_hidden_bones` 的车**（如 m1a2sep）行为完全不变。

### 如果第 2 条不生效

说明 `visible=false` 在 `renderSingleBone` 这条路径上未被检查（渲染路径与本方案假设的 `renderBone` 不同）。此时**停下回报**，附上 `BakedModelInstance.renderSingleBone(...)` 的实际实现（可用 `javap -p -c` 反汇编 `simplebedrockmodel` 的那个类），再决定改用哪种手段（例如临时把该骨从渲染索引里剔除）。
