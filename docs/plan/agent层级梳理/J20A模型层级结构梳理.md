## 坐标约定（推测）

- `+X` = 机身右侧，`+Y` = 上方，`+Z` = 机头方向（前）

## 骨骼命名约定（重要）

- 带 `$` 前缀的翼面骨骼（`$wing0/$wing1/$wing4/$wing5/$wing6/$wing7/$wing8/$wing9`）只是**角度修正用的定位父骨骼**，用于给子骨骼烘焙后掠/外倾等基础姿态，本身不含网格
- **后续做动画一律驱动其子骨骼**（`wimg0/wimg1`、`wing4~wing9`），不要动 `$` 父骨骼
- 特例：`wimg2/wimg3`（鸭翼）与 `$steering_wheel4`（操纵杆）直接挂在 `J20A` 下，自身即网格骨骼，可直接做动画

## J20A 结构特点

- 典型**鸭式布局**：前部鸭翼 + 大后掠三角主翼 + 全动外倾垂尾，无水平尾翼
- 舵面骨骼采用“`$XX` 定位骨骼 + `xx` 网格骨骼”双层结构，动画统一驱动子网格骨骼（注意与 su57 相反：su57 是 `$` 骨骼自身带网格）
- 主翼后掠角由父骨骼 rotation 预烘焙（±48.5°），前缘襟翼与舵面网格局部坐标几乎平铺，旋转轴均为 X（俯仰偏转），垂尾为 Y（偏航）
- 起落架骨骼命名沿用 lg0~lg8 惯例，与动画 `landing_gear` 一一对应
- 导弹采用 PL-15（wb0~wb3，主弹舱）+ PL-10（wb4~wb9，侧弹舱/翼下）布局，`pl15`/`pl10` 动画已就绪
- ⚠️ 新版动画 `air_brake` 复用了鸭翼与副翼骨骼，需与后续 JS 舵面脚本做取舍

## 对后续配置的意义

- 舵面脚本建议按 j10c.js 风格编写：前缘襟翼 `wimg0/1`、副翼 `wing8/9`（差动滚转）、襟翼 `wing6/7`、鸭翼 `wimg2/3`、垂尾 `wing4/5`（偏航）、操纵杆 `$steering_wheel4`
- 控制器 `j20a_controller.json` 建议挂 `landing_gear` 与 `air_brake` 两个可切换动画（air_brake 是否保留见舵面动画文档）
- 显示配置 `display/vehicle/j20a.json` 建议对座舱骨骼（`cop_door` / `J20B_Cop_Gate1`）做透明座舱效果，参照 f22a 的 `$canopy0/$canopy1` 写法
- 载具配置 `data/rvp/vehicles/j20a.json` 的 `parts` 需按上表结构骨骼定义，导弹武器可参照 j16d 的 PL-10/PL-12 写法 + j10c 的 `rvp_custom_mounts` 挂架显示
