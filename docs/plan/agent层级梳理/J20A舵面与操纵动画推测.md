# J20A 舵面与操纵动画推测

本文档基于载具包现有战机的 JS 渲染脚本（`j10c.js`、`su57.js`）与 J20A 模型骨骼结构，**推测** J-20A 各舵面（前缘襟翼、副翼、襟翼、尾翼/鸭翼、垂直尾翼、操纵杆）的动作脚本应如何编写。

> 说明：本页为推测稿，骨骼↔舵面归属见《J20A模型层级结构梳理.md》；具体角度符号需进游戏实测确认方向，正负号可能翻转。

> **骨骼约定**：J20A 中带 `$` 前缀的翼面骨骼（`$wing0` 等）只是角度修正定位父骨骼，**动画一律驱动其子骨骼**（`wimg0/wimg1`、`wing4~wing9`）。下方推测脚本已全部使用子骨骼，无需再套 `$` 前缀。

## 参考：包内现有战机的写法

### j10c.js（舵面最全的参考）

```js
function updateBones(context) {
    const pitchInput = context.getPitchInput()
    const yawInput = context.getYawInput()
    const rollInput = context.getRollInput()
    const builder = createPoseBuilder();

    // 前缘襟翼：随俯仰输入偏转
    builder.setRotation("qyjy1", -14 * pitchInput, 0, 0);
    builder.setRotation("qyjy2", -14 * pitchInput, 0, 0);

    // 副翼：俯仰 + 差动滚转
    builder.setRotation("fy1", -14 * pitchInput + 14 * rollInput, 0, 0);
    builder.setRotation("fy2", -14 * pitchInput - 14 * rollInput, 0, 0);

    // 襟翼：随俯仰输入偏转
    builder.setRotation("jy1", -14 * pitchInput, 0, 0);
    builder.setRotation("jy2", -14 * pitchInput, 0, 0);

    // 尾翼（垂直尾翼方向舵）：偏航
    builder.setRotation("wy", 0, -5 * yawInput, 0);

    // 操纵杆（仅视觉反馈）
    builder.setRotation("ctrl", -14 * pitchInput, -5 * yawInput, 14 * rollInput);

    return builder;
}
```

### su57.js（鸭式布局，与 J-20 最接近）

```js
function updateBones(context) {
    const pitchInput = context.getPitchInput()
    const yawInput = context.getYawInput()
    const rollInput = context.getRollInput()
    const builder = createPoseBuilder();

    builder.setRotation("ctrl1", -8 * pitchInput, 0, 8 * rollInput);        // 操纵杆

    builder.setRotation("tlw", 0, -yawInput * 16, 0);                      // 左垂尾（偏航）
    builder.setRotation("trw", 0, -yawInput * 16, 0);                      // 右垂尾（偏航）

    builder.setRotation("tlw2", pitchInput * 16 - rollInput * 8, 0, 0);    // 尾翼（俯仰+差动滚转）
    builder.setRotation("trw2", pitchInput * 16 + rollInput * 8, 0, 0);

    builder.setRotation("$tlw3", -pitchInput * 10, 0, 0);                  // 鸭翼（俯仰）
    builder.setRotation("$trw3", -pitchInput * 10, 0, 0);

    builder.setRotation("$tlw4", -rollInput * 16, 0, 0);                   // 副翼（差动滚转）
    builder.setRotation("$trw4", rollInput * 16, 0, 0);

    builder.setRotation("$tlw5", pitchInput * 10, 0, 0);                   // 襟翼（俯仰）
    builder.setRotation("$trw5", pitchInput * 10, 0, 0);

    return builder;
}
```

### 约定总结

| 项目 | 轴 | 驱动方式 | 参考幅度 |
| --- | --- | --- | --- |
| 前缘襟翼/襟翼 | X（俯仰偏转） | 对称，随 `pitchInput` | 10~14° |
| 副翼 | X | 差动，`∓ rollInput`（可叠加俯仰） | 14~16° |
| 鸭翼/前翼 | X | 对称，随 `pitchInput` | 10° |
| 垂直尾翼方向舵 | Y（偏航） | 对称，随 `yawInput` | 5~16° |
| 操纵杆 | X/Y/Z | `-pitch, -yaw, +roll` | 8~14° |

## 推测的 j20a.js 脚本

```js
// === J20A 渲染脚本 ===
// 舵面动画通过 JS 脚本实现，起落架/导弹舱沿用动画 JSON

function updateBones(context) {
    const pitchInput = context.getPitchInput()
    const yawInput = context.getYawInput()
    const rollInput = context.getRollInput()
    const builder = createPoseBuilder();

    // --- 前缘襟翼（leading edge flap）：随俯仰输入偏转 ---
    builder.setRotation("wimg0", -14 * pitchInput, 0, 0);   // 右前缘襟翼
    builder.setRotation("wimg1", -14 * pitchInput, 0, 0);   // 左前缘襟翼

    // --- 副翼（aileron）：俯仰 + 差动滚转 ---
    builder.setRotation("wing9", -14 * pitchInput + 14 * rollInput, 0, 0);   // 右副翼
    builder.setRotation("wing8", -14 * pitchInput - 14 * rollInput, 0, 0);   // 左副翼

    // --- 襟翼（flap）：随俯仰输入偏转 ---
    builder.setRotation("wing7", -14 * pitchInput, 0, 0);   // 右襟翼
    builder.setRotation("wing6", -14 * pitchInput, 0, 0);   // 左襟翼

    // --- 鸭翼（canard）：随俯仰输入偏转 ---
    builder.setRotation("wimg2", -10 * pitchInput, 0, 0);   // 右鸭翼
    builder.setRotation("wimg3", -10 * pitchInput, 0, 0);   // 左鸭翼

    // --- 垂直尾翼方向舵（rudder）：偏航 ---
    builder.setRotation("wing4", 0, -5 * yawInput, 0);      // 右垂尾
    builder.setRotation("wing5", 0, -5 * yawInput, 0);      // 左垂尾

    // --- 操纵杆（仅视觉反馈） ---
    builder.setRotation("$steering_wheel4", -14 * pitchInput, -5 * yawInput, 14 * rollInput);

    return builder;
}
```

## ⚠️ 关键冲突点：air_brake 动画

新版 `j20a.animation.json` 中已存在 `air_brake` 动画（时长 1s），其绑定的骨骼为：

| 骨骼 | 旋转 |
| --- | --- |
| `wimg2` / `wimg3`（鸭翼） | [35, 0, 0] |
| `wing8` / `wing9`（副翼） | [17.5, 0, 0] |

若控制器同时挂 `airbrake` 可切换动画（j10c 的做法），`wimg2/3`、`wing8/9` 会被动画与 JS 双重驱动，产生叠加/拉扯。**取舍建议（三选一，需确认）：**

1. **不启用 airbrake**：控制器只挂 `landing_gear`/`pl15`/`pl10` 三个动画，JS 全权接管鸭翼/副翼。最简单，推荐。
2. **保留 airbrake，JS 跳过这几个骨骼**：即鸭翼/副翼不进 JS，air_brake 动画旋转时直接充当减速板效果（鸭翼/副翼下偏即增阻减速）。
3. **保留 airbrake，JS 也驱动**：观察叠加效果，若可接受可继续（不推荐）。

> 另注意：`assets/rvp/animations/j20a.animation.json`（旧版副本）无 `air_brake` 且 `landing_gear` 中无 `youmen` 位移动画，与 `animations/bedrock/entity/` 下的新版不一致，接入时以 `display` 配置引用的那份为准。

3. 幅度系数（14/10/5）为 j10c/su57 参考值，可按手感调整
