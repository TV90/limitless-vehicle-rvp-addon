## 一、履带左右相反：调研结论（先说清原因）

> ✅ 2026-09-02 已应用：`vt4.json` 的 track_config 已互换为 `left: tread_r_move / right: tread_l_move`。

**现象**：VT4 的 `track_config` 按直觉配 `left_track: "tread_l_move"`，游戏里左右是反的。

**原因**：核心模组的"左/右履带"与模型骨骼命名约定是**镜像**的。实证：

- BMP-72（唯一在用的双侧履带车）：`tread_l_0` 骨骼在 **+X** 侧、`tread_r_0` 在 **−X** 侧——与 VT4 新模型完全同约定（`tread_l_0` +27.97 / `tread_r_0` −27.11）；
- 而 BMP-72 能正常工作的配置是 `left_track: "tread_r_move", right_track: "tread_l_move"`——**左右互换着配**；
- 其余单侧链坦克（M1A2SEP/T90M 等）左右都填 `tread_r_move`，从未暴露此问题。

**改法**（`assets/rvp/display/vehicle/vt4.json`）：

```json
"track_config": {
  "left_track": "tread_r_move",
  "right_track": "tread_l_move",
  "module_length": 0.25,
  "track_width": 3.0
}
```

### 2.3 顶层新增 `countermeasure.smoke`（RVP 烟雾弹，照 T90M 备份逐键）

> ✅ 2026-09-02 已通过 `scripts/migrate_core_smoke_to_rvp.py --apply` 全包落地（含 m1a2sep/t84bm/t90m/vt4 四车，本体烟雾弹全删、countermeasure.smoke 全部统一 T90M 数值；顺带恢复 m142 丢失的 ecm_bone）。

```json
"countermeasure": {
  "smoke": {
    "launcher_parts": ["turret_smoke_grenade_l", "turret_smoke_grenade_r"],
    "total": 4,
    "per_round": 2,
    "burst_rounds": 2,
    "launch_interval_tick": 4,
    "reload_tick": 250,
    "smoke": {
      "lifetime_tick": 100, "radius": 10.0, "speed": 1.0, "gravity": 0.01,
      "explode_tick": 10, "rise_speed": 0.0, "opacity": 1.0, "drift": 0.0
    },
    "decoy": { "glow_color": 16777215, "halo_scale": 4.0 }
  }
}
```

要点：`launcher_parts` 直接填 2.1 里两个发射件的 id（发射方向跟随炮塔 + 上仰，代码里写死）；`total`=总弹数、`per_round`=每次按压出弹数、`burst_rounds`=一次齐射轮数、`reload_tick`=整轮装填。数值全部先照搬 T90M，之后你再调。
