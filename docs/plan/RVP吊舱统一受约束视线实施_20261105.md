# RVP 吊舱统一受约束视线实施

日期：2026-11-05。仅接入 `ywzj_rvp:optical_weapon` / `RVP_OpticalWeaponUnit`。
普通 `WeaponUnit` 及其他类型观瞄保留原有输入、相机和选点分支；不按载具或武器 ID 划分。

## 行为与边界

- 普通鼠标与焦点只提供请求，镜头、吊舱模型和屏幕选点共同读取实际轨迹。
- 正下方横移时先保持视线、原地调整偏航，再沿请求方向离开；有限轴速下允许等待，不能承诺零延迟。
- 接近正下方按可达进度沿视线弧推进；每刻固定 32 个细分步，渲染不推进状态。
- 有限轴在展开机械区间中寻路，例如 `-119 → 0 → +119`；不会因圆周近路反复撞到 `-120` 止挡。
- 稳定器持续尝试保持世界视线，补偿与手动输入共用轴速预算，不再继承本体 5° 误差门。
- 开始、制动、反向受加速度约束；损坏降低额定轴速或失去动力时硬约束立即优先。
- 关闭稳定器时保存基座局部请求，画面随基座转动，不会逐刻又恢复成世界方向锁。
- 真实焦点从现有镜头挂点求方向；未知距离仍只锁方向，不把 4096 格代理当作真实世界点。
- 解锁只更换请求来源并受控制动，不在两台镜头之间回交；飞机退出观瞄仍沿用已有默认前方复位。

## 实现入口

| 位置 | 职责 |
| --- | --- |
| `vehicle/RVP_OpticalSightMotion` | 纯双端运动计算、极点转轴、有限区间路线、限速和细分轨迹 |
| `vehicle/RVP_OpticalWeaponUnit` | 覆写真实转动与远端目标接入、保存点/方向语义、存档恢复、共用模型采样 |
| `client/state/RVP_ClientOpticalSight` | 统一灵敏度、真实相机、观瞄射线、本地预测及确认重放 |
| `client/state/RVP_ClientFocusLock` | 保留 R 键分流、真实点/方向锁、DH 查询和过期结果隔离；新版分支不再覆盖相机 |
| `client/firecontrol/RVP_ManualSightInput` | 新旧入口共同调用原全自动抑制与半自动微调记录，普通站资格保持原样 |
| `client/state/RVP_ClientGPSUtil` / `RVP_ClientWeaponTargets` | 仅新版吊舱改读本帧实际射线；原站保留原分支 |
| `client/gui/RVP_ScopeOverlay` | 固定屏幕位置提示转轴、转动、限位和无法转动 |

本体 `scopeAimPos` 仍被原生光电选择使用，既有 `fireControlLock` HEAD 经安全桥准备新版吊舱同帧逻辑角。
没有新增 Mixin 类、注入点或 Accessor；原鼠标 Redirect 只转发提取后的同等火控规则。
共享类和网络包通过 `RVP_ClientActionsAccess` 与客户端交互，不直接引用 `Minecraft` 或 `LocalVehiclePlayer`。

## 参数与载具包

- 保留现有 `rot_info` 的范围、初态、速度、动力开关和结构固定偏角，不改模型和配置中的机械能力。
- `ywzj_rvp-client.toml`：`opticalSight.sensitivity`，默认 `1.0`，范围 `0.05..10`。只影响新版吊舱。
- 一倍基础角增量为 `0.065625°/输入量`，普通/焦点统一；按实际显示视野的正切比例缩小，不再乘机械追赶误差或帧间时间。
- `ywzj_rvp-common.toml`：`opticalSight.accelerationSeconds`，默认 `0.1` 秒，范围 `0.01..2`，由服务端随快照下发。
- 无新增载具 JSON 字段，无历史键兼容或迁移；已使用新版类型的权威载具包无需为本轮重写。

## 联机

网络协议从 47 提升为 **48**，客户端与服务器必须一同更新。

- `C2SOpticalSightCommand`：维度、实体 ID/UUID、站索引、会话 UUID、单调序号、方向和可选真实点。
  稳定器关闭且无真实点时方向为基座局部方向，否则为世界方向。
- 服务端校验当前乘员与所属站、会话、顺序、有限单位方向及世界点范围；实际角始终由服务端计算。
- 专用会话接管后，原生角度包不再抢写；本体发射用途保留。换操作者后丢弃旧请求与会话。
- `S2COpticalSightState`：实际角轨迹、速度、阶段、初始横轴、两帧基座、权威请求、确认序号及加减速时间。
  初始横轴后续由基座和角轨迹重建，固定长度报文，单站测试报文小于 500 字节。
- 活动状态每两刻同步一次；静止每秒保活。本地最多每刻一份请求，未确认历史上限 64 份。
- 客户端按维度、实体 UUID、站、会话和状态刻隔离旧消息；拒绝旧快照发生在改请求、裁剪预测队列之前。
- 收到确认后恢复权威状态并重放之后的输入；显示校正由模型、相机和屏幕选点共同采样。

## 实机复验

1. 双端安装同一份协议 48 jar，用权威包已有新版吊舱类型的 J10C/F16V 检查前下、正下、后下方向。
2. 正下方只横移鼠标，应先原地转轴，再向鼠标方向移动，不先上下拐；高倍、低倍和倍率过渡都检查。
3. 快速反向和撞左右/俯仰止挡，确认不会翻半圈或长期卡在错误止挡；反向按加减速制动。
4. 机体转弯、爬升、倾斜时锁住真实地面点；超出机械能力时应显示实际限制，不能让镜头独立越界。
5. R 锁定/解锁、换座、暂停、电视导弹返回以及退出观瞄复位，检查会话不串用。
6. GPS/光电从画面中心选点；子武器准星仍表示真实武器方向。检查全自动抑制、半自动微调保持。
7. 对照普通坦克/步战本体观瞄；再用两个客户端观察吊舱模型，并检查带网络延迟时的连续校正。
