## 新参数及运行行为

在guidance_data.terminal_guidance内新增：

```json
{
  "retain_main_guidance_until_capture": true,
  "seeker_search_distance_range": "[[0,900]]"
}
```

- retain_main_guidance_until_capture默认true，无单位，对末段IR（含AIR别名）、ARH、ARM生效。到达原有切段条件后先搜索，未真实捕获则继续执行原主段完整配置、目标输入、操纵与相应干扰规则。捕获后单向交接，后续脱锁不回到主段；false保留到末段即接管的旧行为。
- seeker_search_distance_range单位格，默认null，沿用guidance_target_distance_range。仅限制搜索/截获及重捕获，不缩减持续跟踪距离或max_guidance_angle。显式末段区间不再被旧256格重锁扫描上限截断，仍只遍历已加载/既有权威虚拟目标，不申请远方区块。
- 搜索锥角仍用max_lock_angle（全锥角，捕获半角为其一半）；持续跟踪转向角仍用max_guidance_angle。IR首次捕获拒绝箔条，ARH继续使用RCS、开机距离与原反制门，ARM必须本刻真实发现辐射源，记忆/预选坐标不算新捕获。
- 捕获接管模式不发“主动雷达/红外导引头开机”，仅在首次真实捕获边沿提示“反辐射/主动雷达/主动红外导引头已捕获目标”。中英语言键已补齐；公共弹体入口兼容导弹和制导炸弹。
- 接管锁存保存到普通NBT、虚拟运行态和已有远程NBT数据；阶段与操纵源分开，未捕获时雷达中继、GPS巡航/重力及已有操作手入口仍读取主段快照。
- SACLOS主段的父类每刻清实体锁逻辑已收窄：末段接管后允许保留红外实体锁，否则会“捕获一刻，下一刻清锁”。失败搜索恢复原点使用setGuidanceTargetPos，避免再次叠加GPS散布。
- 末段搜索等待期间不提前启动末段ARH无目标自毁。上一轮普通AIR的隐身/RCS中段约束、失援即红外搜索、到开机距离才开始无目标计时等行为保留。
