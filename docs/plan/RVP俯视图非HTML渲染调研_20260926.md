# RVP 俯视图非 HTML 渲染调研（2026-09-26）

> 背景：辅助设备面板（O 键 AUI）的俯视图目前用 HTML div 注入绘制。实测发现 AUI 的 div
> **无法绘制倾斜线框**（不支持 transform 旋转），导致"视图随炮塔旋转/实时姿态"类需求不可行。
> 本文调研不用 HTML 绘制俯视图的可行路径，供定稿。**仅调研，未动手。**

## 一、div 路线实测硬约束清单（本会话全部实证，后续任何 UI 工作通用）

1. **只能画轴对齐矩形**：不支持 transform 旋转 → 倾斜线框不可画（旋转后方块只能画外接矩形，必然糊）；
2. **绝对定位 div 的嵌套子元素内联样式不渲染**：双层 div 做空心会退化成实心色块；
3. `inset` 简写不支持（元素会失去尺寸）；
4. `Document.refresh()` = 按 HTML 模板重建整个文档，作废全部 Element 引用与注入内容（出现"全空+闪烁"）；
5. **init 之后的 DOM 变更是惰性绘制**：`requestStyleRecalc`/`invalidateStyle` 只重算样式不触发重绘，
   需 pendingRepaint → 程序化 `resize()` 强制重绘（走窗口缩放同款完整重布局路径）；
6. Ctrl+滚轮缩放按页面持久化在 `config/apricityui/viewport-zoom.properties`。

含义：**div 路线下俯视图只能是 bind-pose 静态图**（固定朝向、无倾斜、无实时炮塔姿态）。

## 二、非 HTML 方案对比

| 方案 | 做法 | 倾斜线框 | 实时姿态 | 改动面 | 风险 |
|---|---|---|---|---|---|
| **A. AUI 骨架 + 俯视图区域原生 scissor 绘制（推荐）** | 面板 HTML/栏目/队列全部不动；仅 `#skeleton-canvas` 区域改回 GuiGraphics 原生绘制：PoseStack `mulPose(旋转)` + 空心矩形（本体观瞄小图 `drawRectByCorner` 同款）；矩形几何仍由 `RVP_EquipSkeletonRenderer` 产出（投影/骨链变换/着色代码全复用） | ✓（PoseStack 旋转天然支持任意角度） | ✓（可实时炮塔跟随，每帧重绘） | 仅替换绘制层，数据层零改动 | 三次"原生不可见"根因未定位——需先做最小验证实验（见 §三） |

## 三、方案 A 的关键事实与最小验证实验

**本项目内已有的两个"scissor 原生渲染"实证**：

1. `RVP_AuiVariantScreen.renderVehiclePreview`：AUI 屏内 scissor + PoseStack
   translate/scale/rotate + `EntityRenderDispatcher.render` 真实载具实体 + `flush` + 清深度
   ——**同一 AUI 屏内原生渲染可行**（实机验证过）；
2. 本体 `VehicleScopeOverlay.renderVehicleHeading`：PoseStack `mulPose` 旋转 +
   `drawRectByCorner` 逐 cube 空心矩形——**旋转线框画法可行**。

**未定位疑点**：此前三次原生绘制不可见（fill + flush 后仍无），与 div 路线对比排除了
坐标换算问题（同一 rect 计算 div 可见）。候选根因：AUI 文档视口变换残留在 GuiGraphics
PoseStack 上（原生坐标被二次变换）、或 AUI 在 super.render 后整体重绘覆盖原生内容、
或 rrls 等 mods 对 GUI 渲染管线的介入。

**最小验证实验（10 分钟级，定路线用）**：在现面板 `render()` 的 scissor 内画一个与数据无关的
固定纯色矩形（如左上角 40×40 红块），按结果分流：

1. 矩形可见 → 原生绘制通路无问题（此前问题在几何/数据）→ 直接切方案 A；
2. 不可见且无报错 → AUI 在 super.render 后覆盖/重绘了文档区域 → 尝试把绘制挂到 AUI
   渲染后时机（查 AUI 是否提供 Screen 渲染后钩子），或换方案 B/C；
3. 位置错误 → GuiGraphics 存在残留 PoseStack 变换 → `pushPose + setIdentity` 后绘制；
4. 另用无 mods 纯 dev 环境对照，排除 rrls 等第三方介入。

## 四、方案 A 实施清单（批准后）

1. 最小验证实验定位上屏时序（上表 1-3）；
2. `RVP_EquipSkeletonRenderer.buildRects` 改为输出"带视图旋转角"的矩形
   （cube 静态 footprint + θ=炮塔跟随或 0；θ≠0 时用 PoseStack 旋转，倾斜线框可行）；
3. 分层绘制：白底实心（fill）→ 彩色线框（rotate + drawRectByCorner）；
4. 失效颜色仍按签名刷新；俯视图每帧重绘（原生无 DOM 重建开销）；
5. div 版实现保留在 git 历史（8095e023 及后续）作回退点。
