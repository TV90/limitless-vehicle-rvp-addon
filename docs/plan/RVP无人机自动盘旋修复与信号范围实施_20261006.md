## 一、修复明细（全部 RVP 侧，零 Mixin 零新增包，协议不变）

### 1. P0-1 无人固定翼盘旋不转向（核心，直线飞走根因）

- **根因**：本体 `FixedWingVehicle.tickMove` 在 `getDriver()==null` 时每 tick 覆写
  `controlUnit.yRot=getYRot(); xRot=0`（ywzj_vehicle FixedWingVehicle.java:317-319），旧制导
  100% 依赖 yRot 通道（leftYaw/rightYaw/left/right 恒 false）→ 无人时制导航向被短路 →
  滚转回平、永不转弯、满油门直飞。suav 为 fixed_wing + auto_on_takeoff，主场景整体失效。
- **修复**：`RVP_UavLoiterGuidance` 固定翼四阶段改**布尔杆量闭环**——
  `computeFixedWingControls(headingError, currentBank, altError, tickCount)` 纯函数：
  ①|误差|>30° → leftYaw/rightYaw（偏航角速度通道，不受覆写）；
  ②坡度闭环：目标坡度 = −clamp(误差×0.6, ±25°)（左转=左坡=zRot 负），与当前 zRot 比较超
  死区 3° 后按占空脉冲 left/right（累加式输入必须脉冲化，防滚转过冲）；
  ③高度 up/down 与油门 forward/backward 脉冲保留（占空按误差分档 4/2/1 per 10 tick）。
  `applyControlUnit` 固定翼不再依赖 yRot 生效（仍写期望航向：无人时被覆写无副作用，
  玩家在机时供本体瞄准协调逻辑）。旋翼路径（模拟偏航）零改动。

### 2. P0-2 关盘旋后油门/航向锁存直飞

新增 `RVP_UavLoiterTickService.stopLoiterAndResetControls(uav)`（disable + `controlUnit.reset()`），
所有关闭点统一走它：F 键（C2SToggleUavLoiter）、信号范围失联、（实体移除路径本就 remove）。

### 3. P0-4 母车按 F 高度错用（疯狂爬升）

`C2SToggleUavLoiter` 旧版把 `uav.getY()`（绝对高度）当 altitudeOffset 传 enableFollowParent
→ 目标高度=母车Y+UAV绝对Y。改传 `config.loiterAltitudeOffset()`（与部署路径一致）；
无母车的固定圆心分支同步修正（圆心Y = 当前高度 − 偏移，维持按 F 时高度）。

### 4. P1-4 震荡检测删除（盘旋半径越转越大根因）

`updateOscillation` 用绝对目标航向符号当"误差"符号（每圈过 0°/±180° 必误判），误判后
`radius×1.1` 无上限累积。整体删除：updateOscillation + OSCILLATION_* 常量 +
MutableState.signFlipCounter/lastYawError 字段。半径不再自扩张。

### 5. 卸载宽限（飞远卸载后盘旋静默消失）

tick 服务实体查不到不再立即 remove 状态——per-UAV 宽限 **100 tick**（ENTITY_MISSING_GRACE_TICKS），
宽限内实体（区块重载/换维度回来）无缝续飞，超时才移除。制导纯几何无相位状态，续飞无跳变。

### 6. suav 区块保活兜底

suav.json 加 `rvp_persistent_chunk_lease: true`（052d 先例，RVP 自有机制，避免本体
`"uav":true` 的 FakePlayer 伤害转移副作用）。

## 二、信号范围（新功能，用户定版：失联→回收进冷却）

- **配置**：母车 JSON `deployable_uav_signal_range`（格，默认 **512**，≤0=无限），
  `RVP_DeployableUavConfig.signalRange` + `effectiveSignalRange()`。
- **检查**：`RVP_DeployableUavService.checkSignalRange(uav)`（tickVehicles 对部署实例每 tick 调用，
  水平距离比较）。守卫拒绝：M 切到 UAV（switchToLinkedUav）、F 盘旋（C2SToggleUavLoiter）、
  战术地图标点（C2SSetLoiterCenter）——actionbar 提示"无人机超出信号范围，已失联"。
  M 切回母车**允许**（人员撤离通道）。
- **失联瞬间**：盘旋关闭+清杆（防锁存直飞）。
- **回收（持续 60 tick = 3 秒防抖）**：机上乘客 stopRiding（触发 dismount 回传母车链）→
  UAV `discard()` → `handleDeployableUavRemoved`（清盘旋/StateTable/LinkRegistry）→
  进 `deployable_uav_redeploy_cooldown_tick` 冷却 → 母车操作者提示"已自动回收（冷却中）"。
- 母车实体暂不可用（卸载中）不判超范围；AC130 等无部署配置的自身盘旋不受约束。

## 三、参数精简（9 键 → 4 键，用户定版）

算法参数收敛为类常量：`TERRAIN_CLEARANCE=20`、`LOITER_BANK=25`、`LOITER_DIRECTION=1（右）`、
`FIXED_WING_MIN_BANK=25`、`ROTARY_MIN_RADIUS=30`。`min_safe_altitude` 删除

### 5.3 三次修复（2026-10-06 用户截图实锤：向外倾斜 + 持续爬升 + 半径巨大同源）

**根因（方向配对错误，截图后定位）**：盘旋切线公式 `atan2(−dz,−dx)` 是**左转圆**（俯视逆时针）
的切线——MC 系 look=(−sinYaw,cosYaw)，圆东点验证：该式给 yaw=180°（朝北，指向圆外）——而
LOITER_DIRECTION=1 输出右压坡度（正 zRot=右倾=右转）。**坡度方向与圆周方向相反 → 飞机向外
倾斜**（截图实锤）：离心外飞 → 永远切不进圆 → 卡 TRANSIT（无条件满油门"加力"）→ 高速下
升力富余 2 倍+ → 持续上飘没有定高。三个症状一个根因。

修复（RVP_UavLoiterGuidance）：
1. **切线按盘旋方向取向**：`tangentYaw(dx,dz,dir)`——右盘旋（dir=1，俯视顺时针）=
   `atan2(dz,dx)`（圆东点 → yaw0 朝南 ✓）；左盘旋（dir=−1）= `atan2(−dz,−dx)`。推导含
   单元测试（圆东/圆南切线方位 + 切线⊥位置向量点积=0，tangentYaw 包内可见可测）。
2. **对齐阶段速度上限**：CLIMB/TRANSIT 的 forward 不再恒 true——复用固定翼节流阀脉冲
   （超解算速度 1.05 倍收油 4/10 占空刚性、欠速 0.7 倍或需爬升给油 2/10），TRANSIT 不再
   满加力放飞上飘；LOITER 速度闭环原样。
3. 旋翼分支径向修正补方向符号（`LOITER_DIRECTION × clamp(radialError×0.12)`）。
验证：build 732/0/0（+切线方向/垂直性测试），冒烟 Done (2.025s)，0 失配，进程杀净。

### 5.2 二次修复（2026-10-06 用户实测反馈：TGT 未修 + 盘旋半径/高度失控）

1. **TGT 面板视距内退化（此前只调研未修复，本批补上）**：①速度——`resolveEntitySpeedKmh`
   反转死代码条件（旧 `!isClientSide()` 对客户端实体恒 false），客户端实体优先查
   `RVP_ClientRemoteAmmoState` 快照实时速度（快照 6144 格含视距内弹、每 5t 刷新），回退冻结值；
   ②名称——`resolveMarkerDisplayName` 本地 RVP 弹优先武器全名（与视距外同源），NCTR 短标签
   仅回退；③GPS——`getMarkerTargetPos` 优先快照 `guidancePos()`（出生快照 targetPos 冻结）。
2. **盘旋半径失控**：旧 `resolveActualRadius = max(配置, V²/g·tan25°)`——按速度反算的最小半径
   覆盖用户配置（旧极速下近千格；且 max(80,…) 硬下限）。改为**配置半径权威**：新增
   `resolveFixedWingLoiterSolution` 可持续盘旋解算器——按气动参数推 v_min
   （=sqrt(G·m/(k_min·liftToDrag))，TickService 从 FixedWingVehicle 公开字段+physicsEngine.mass
   读取），解出满足升力约束 sinφ ≥ v_min²/(gR) 的（实际半径， 临界坡度 asin 封顶 40°，
   目标速度 sqrt(Rg·tanφ)）；坡度超上限才放大半径（物理兜底）。`LOITER_BANK` 25→40°，
   新增 `ALIGN_BANK_CAP=25°`（对齐阶段）。**盘旋节流阀速度闭环**：超解算速度 8% 收油（4/10
   占空，刚性）、欠速 30% 或需爬升给油——半径/坡度/速度三者自洽，任意气动调参自动适配
   （用户自调的 suav 高阻力参数下自动解为 R≈130/φ40°/118kph，不再硬撑 100 格）。
   实际半径同步回 state.radius，战术地图圆环如实显示。
3. **高度控制振荡（飞天/摔地）**：纯高度误差脉冲无阻尼 + 升力随速度²波动。改为**垂直速度
   二级闭环**：目标爬升率 = clamp(高度误差×0.08, ±4 m/s) → 按（目标 − 实际 vy）误差脉冲
   up/down（死区 ±0.6 m/s，占空 1~5/10）——垂直速度即时阻尼消除过冲。
4. suav.json：用户已自行重调气动（thrust 24444/阻力 16.296/ltd 3/mass 4074），**尊重不动**；
   解算器自动适配其参数。
   （注：本批早先给 suav 配的 thrust 17 / lift_to_drag_k 13.5→15 已被用户手动调参覆盖，以用户值为准；
   上文 §5.1 第 1 条的 100kph 调参推导保留作参考，现行极速由用户参数决定 ≈139~159kph。）

### 5.1 追加调参（2026-10-06 用户需求，同批）

1. **suav 极速 →100kph（不损失升力）**：本体固定翼无极速字段，极速=推力/阻力平衡
   （v=sqrt(thrust×throttleK/(400×k_min))）。原 thrust 100.4 → 极速 ≈243kph。
   **升力=阻力×升阻比，随速度²缩放**——suav 升阻比 11 时最小平飞速度恰 ≈98kph，
   直接压极速到 100kph 会让巡航贴失速边界（25° 盘旋坡度必掉高度，即用户警示的"损失升力"）。
   故两键同调：**thrust 100.4→17.0**（极速 ≈100kph）+ **lift_to_drag_k 11→13.5**
   （100kph 巡航升力余量 1.28 倍重力，25° 坡度转弯仍 1.16 倍，无失速风险）。
   推力/质量比降约 7 倍 → 加速变慢属预期代价（出生自带 initial_speed 1 ≈72kph，盘旋 CLIMB 可用势能）。
2. **信号范围默认 512→2048**（`DEFAULT_SIGNAL_RANGE`，用户定版；JSON 键仍可按母车覆盖）。
3. **4 台母车（lav25/9k720/m142/zbl08a）配母车级盘旋参数**（rvp_loiter_* 4 键，值同 suav
   radius100/alt35/auto_on_takeoff）——resolveConfig 母车优先即生效，此后单台母车可独立调参。
4. **进入无人机文案**：M 切入（C2SSwitchDeployableUav）与手动骑上（handleMount）盘旋中的
   无人机时 actionbar 提示"已进入无人机：自动盘旋接管飞行（按 F 退出盘旋后可手动驾驶）"
   （lang 键 message.ywzj_rvp.uav.switch_to_child_loitering，非盘旋状态仍发原提示）。
