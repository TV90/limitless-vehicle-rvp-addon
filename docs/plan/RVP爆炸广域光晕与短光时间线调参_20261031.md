# RVP 爆炸广域光晕与短光时间线调参

日期：2026-10-31。落实三项：爆炸广域光晕亮度独立可调；`decayScale` 伸缩 explosion/muzzle 整盏光源的寿命并平滑淡出；爆炸默认照亮亮度倍率20、照亮半径倍率5。

## 当前行为与指令

```text
/rvplight set explosion worldHaloIntensity 16
/rvplight set explosion decayScale 0.5
/rvplight set muzzle decayScale 2
```

- 爆炸 `worldHaloIntensity` 默认16，范围0～60000；只控制广域光晕，设为0不会关掉照亮。
- 爆炸 `brightness` 默认20、`radiusScale` 默认5；不随广域光晕亮度变化，修改它们也不反向改变光晕亮度。
- 爆炸基础半径仍按原预设计算，照亮半径乘5，光晕半径默认乘1。例如基础12格时，照亮60格、光晕12格，原有独立范围规则保留。
- 爆炸基础寿命32刻，正常20刻/秒时1.6秒；炮口基础寿命按类型为2或3刻。倍率越小整盏光源越长，越大越短，照亮与光晕同步结束。

实际寿命为 `max(1刻, 基础寿命/max(0.05, decayScale))`：

| 爆炸 decayScale | 整盏光源持续时间 |
| --- | --- |
| 0.5 | 64刻，约3.2秒 |
| 1 | 32刻，约1.6秒 |
| 2 | 16刻，约0.8秒 |
| 0 | 按最低0.05倍速度计算，640刻，约32秒后结束 |

基础衰减指数仍为爆炸0.3、炮口1.6。寿命和衰减都跟随倍率；最后20%寿命再乘一段平滑归零曲线，避免强光在最后一帧突然切黑。这里调整的是整盏光源，包含方块/实体/烟雾受光及其光晕。发动机不支持 `decayScale`，仍由真实燃烧阶段和心跳控制。

`reset explosion` 恢复20/5/16默认值；修改参数不重置出生年龄。迟包按实际已过去的年龄采样，已经结束或被显式取消的条目不会因之后改参数复活。总亮度仍可统一影响爆炸照亮和光晕；两路分离指的是 explosion 组本身的照亮亮度与广域光晕亮度。

## 实现入口

| 行为 | 文件与方法 |
| --- | --- |
| 新默认值、爆炸广域光晕指令元数据 | [RVP_LightRuntimeTuning](../../src/main/java/org/ywzj/rvp/light/RVP_LightRuntimeTuning.java)：`Parameter`、`apply`。爆炸无临时覆盖时也必须应用20/5默认倍率 |
| 整盏短光的寿命与平滑包络 | [RVP_TransientLightTimeline](../../src/main/java/org/ywzj/rvp/light/RVP_TransientLightTimeline.java)：`durationTicks`、`fade` |
| 动态结束、迟包、采样、句柄存活 | [RVP_ScreenLightManager](../../src/main/java/org/ywzj/rvp/client/light/RVP_ScreenLightManager.java)：`lifetimeTicks`、`Entry.sample`、`Entry.finished`、`hasTransient` |
| 独立光晕强度与有效范围预算 | [RVP_ScreenLight](../../src/main/java/org/ywzj/rvp/client/light/RVP_ScreenLight.java)、[RVP_ScreenLightBudget](../../src/main/java/org/ywzj/rvp/client/light/RVP_ScreenLightBudget.java) |
| 分别上传照亮和光晕强度 | [RVP_ScreenLightPass](../../src/main/java/org/ywzj/rvp/client/light/RVP_ScreenLightPass.java)：`uploadLightSlots` |
| 避免固定32刻提前取消或拖长光源 | [RVP_DefaultExplosionEffectInstance](../../src/main/java/org/ywzj/rvp/client/visual/RVP_DefaultExplosionEffectInstance.java)、[RVP_LitVisualEffect](../../src/main/java/org/ywzj/rvp/client/visual/RVP_LitVisualEffect.java)：`isFinished` 查询管理器实际句柄存活 |

照亮和光晕共用同一进度、颜色和淡出包络，仅初始亮度分别取各自参数。快照新增独立 `haloIntensity`；着色程序通过 `LightHaloColorIntensity0..7` 接收，光晕模式不再读取照亮强度，因此20倍照亮不会额外放大爆炸广域光晕。

默认爆炸的声音控制和其他爆炸效果继续独立运行；包装器等待对应光源实际结束，而不是套固定32刻。显式取消、换世界、时钟倒退和预算淘汰仍可正常释放。
