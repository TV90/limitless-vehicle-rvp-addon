## 二、★冒烟测试方法（必须遵守，防服务端孤儿——用户重申）

`TaskStop`/杀后台 shell 只杀外层 bash，Gradle fork 的 JVM（`GradleWrapperMain` + `BootstrapLauncher`）会孤儿化。标准流程：

1. `./gradlew build > build_xxx.log 2>&1` 确认成功后再后台启动 `./gradlew runServer --console=plain > server_smoke_xxx.log 2>&1 &`；
2. **每 10 秒轮询日志**，`Done (Xs)!` 即通过；grep 中文加 `-a`；
3. **结束后必须显式清理并复验（一律 jps，tasklist 管道不可靠）**：
   ```bash
   PIDS=$("C:/Program Files/Java/jdk-21.0.11/bin/jps.exe" -l | grep -i "BootstrapLauncher\|GradleWrapperMain" | awk '{print $1}')
   for p in $PIDS; do "/c/Windows/System32/taskkill.exe" //F //PID $p; done
   "C:/Program Files/Java/jdk-21.0.11/bin/jps.exe" -l   # 复验干净
   ```
4. runClient 冒烟（到主菜单 `Sound engine started`）结束同样按此清理。
