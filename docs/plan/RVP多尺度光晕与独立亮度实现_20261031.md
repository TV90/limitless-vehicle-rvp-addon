# RVP 多尺度光晕与独立亮度实现

> 同日后续：[光晕/照亮范围分离与调参扩展](RVP光晕照亮范围分离与调参扩展_20261031.md) 已继续拆分三类光源的两种半径，爆炸光改为1.6秒、衰减0.3。本文保留第一阶段实现和构建记录，当前参数以最新游戏内调参指南为准。

日期：2026-10-31。范围为用户确认的第 1、2 项：让光晕沿整条亮焰扩散，并分开控制喷焰外围、近层光晕、远层光晕和喷口广域橙晕。烟雾参与高亮扩散与真正的局部空气散射留待后续。

## 1. 当前效果

- 白热核心保留原有最高 60000 的显示前高亮数值，喷焰长宽和推进阶段继续使用原逻辑。
- 模糊光晕由四种尺寸组成：宽高分别为原画面的 1/2、1/4、1/8、1/16。前两层形成贴近亮焰的亮边，后两层形成向周围消散的辉光。
- 所有层只读取 RVP 自己的光贡献，不从最终世界颜色中筛选雪地、天空或界面文字。
- 原有喷口广域橙晕继续使用口径决定的共同世界半径 20～500 格，亮度与外围橙焰分开控制。

光晕是明亮颜色在画面上的扩散，可跨过邻近物体轮廓；它不表示那里的空气在三维世界中实际受光。源完全被近景或 DH 地形遮住时，不会留下独立广域光团。部分露出的尾段继续参与可见覆盖计算。

首层使用原有 0.08 亮部门槛与 0.04 平滑过渡，过滤光贡献中允许进入光晕的部分。后续层不再次扣门槛，逐层缩小并执行横纵高斯柔化，再从最小层连续放大回升。

基础权重为 `0.4、0.3、0.2、0.1`，合计为一；前两层乘近层强度，后两层乘远层强度。关闭近层不把能量补给远层，反之亦然。各中间输出限制在 60000 以内，避免手动最高增强把半精度纹理写成无穷大。最终继续使用原有共同峰值映射保留橙色色比，并保留场景 Alpha。

四层各有两张纹理，逐轮读写不同附件；只使用现有三个纹理采样单元。没有逐光源分配金字塔，也没有增加背景或深度复制次数。窗口尺寸变化、资源重载和世界清理继续走统一释放入口。默认四层额外使用的颜色显存约为旧光晕的 1.33 倍；绘制轮数增加，实际帧耗需在游戏内测量。

新版喷焰以单位辐射计算真实可见几何覆盖，再独立应用广域橙晕亮度，避免调整外围橙焰时连带改变可见比例。喷流形状、采样步数及近景/DH 深度重建沿用原实现。

## 3. 游戏内调参

```text
/rvplight set engine haloIntensity 16
/rvplight set engine worldHaloIntensity 4
/rvplight set bloom nearStrength 1
/rvplight set bloom farStrength 2
/rvplight engine 0.3 300
```

- `haloIntensity`：喷焰外围橙焰，默认 16。
- `worldHaloIntensity`：喷口广域橙晕，默认 16；设为 0 只关闭这层橙晕。
- `nearStrength`：贴近亮焰的两层光晕，默认 1，范围 0～8。
- `farStrength`：向周围消散的两层辉光，默认 1，范围 0～8。
- `blurScale`：每层额外高斯柔化范围；0 时仍保留缩小和回升必需的连续过滤。

上面的 4/1/2 是便于观察整条亮焰扩散的试调值，未写为新默认。调参下一帧生效，只影响本机，不写配置或武器 JSON。使用 `/rvplight reset engine`、`/rvplight reset bloom` 分别恢复两组；完整说明见 [游戏内调参指南](../RVP视觉工厂架构/RVP光照与光晕游戏内调参.md)。
