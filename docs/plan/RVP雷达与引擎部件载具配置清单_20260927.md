# RVP 雷达/引擎骨骼部件载具配置清单（2026-09-27）

> 配套：`docs/plan/RVP雷达与引擎骨骼部件实施_20260926.md`（实现与生效链路）。
> 本文以载具包实际 JSON 配置为准（脚本扫描生成），列出全部配置了 RADAR / ENGINE
> 骨骼模块的载具与骨目。共 **28 台载具、32 条骨目**（bukm3、ps1sm 雷达+引擎双配）。
> 载具包不进 git；本文为快照，改动请同步更新。

## 一、模块语义速查

- **RADAR 雷达部件**：直击单发伤害 ≥ `min_damage`（统一 40）即打坏该雷达骨 → 对应
  雷达被服务端强制关闭（gunner/玩家均无法重新开机，20t 巡检兜底）；修好自动开机。
  多雷达载具按雷达骨分粒度（跟踪/搜索互不影响）；外置雷达中继车雷达被打坏，
  母车自动失去外置雷达。面板失效红框、入辅助设备维修队列。
- **ENGINE 引擎部件**：引擎骨**窗口内累计直击伤害**（30 秒线性衰减，停火自然回落）
  ≥ 60 → 受损（功率 ×0.5）；≥ 150 → 瘫痪（功率清零，进失效表）。
  不关发动机、不压 POWER——方向机/高低机/武器/雷达照常。两档均可被快修修复。
  阈值/倍率/窗口可在骨条目 `engine` 子对象覆盖（`threshold_light`/`threshold_heavy`/
  `power_multiplier_damaged`/`damage_window_ticks`），当前全部走 Java 缺省值。
- 引擎骨 `damage_factor` 照抄各车 `hitbox_damage_factor` 现有 Engine 值（命中伤害倍率，
  与引擎部件功能无关）；雷达骨 `min_damage` 沿用 fa18f 雷达骨先例 40。

## 四、未配置 / 边界说明

1. **m1agds**：结构模型有 Engine 骨，但载具包无 `m1agds.json`（无载具数据文件）→ 未配。
2. **直升机/固定翼配 ENGINE 不生效**：其动力走本体 POWER 比例路径，字段覆写不适用
   （实施文档"已知边界"2）；当前也没有任何飞机/直升机配引擎。
3. **爆炸波及不累计引擎伤害**：只累计直击（弹体/激光/本体武器重放三链路）。
4. **TRACK 履带模块**仍为占位（全包未配置，功能未实现，用户确认暂不做）。
5. 其余 24 台载具（lav25/lavad/m142/9k720/zbl08a 等）未配雷达/引擎骨，
   面板"无设备不画"对应栏目不出现。

## 五、运维备忘

- 单车调整阈值/倍率：在该车 `bone_modules.<骨>.engine` 子对象覆盖对应字段即可。
- 单车摘除雷达/引擎部件：删除对应骨的 `bone_modules` 条目（radar 骨同时留意
  `hitbox_damage_factor` 的既有倍率键，勿误删）。
- 配置随 `S2CVehicleRvpConfig` 全量下发客户端（面板自动跟随），/reload 生效。
