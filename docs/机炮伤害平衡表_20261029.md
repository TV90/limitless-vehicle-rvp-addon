# 机炮单发伤害平衡表（2026-10-29）

> 数据源：`data/rvp/weapons/*.json`（`type=rvp:machinegun`，口径 20~40mm）+ `data/rvp/vehicles/*.json` 装甲字段。
> 所有数字都是**百分比数值，不带 % 号**。留空 = 不改动。

## 一、填法与反推（直伤不动，只改倍率）

你填「新」，我把百分比反算成机型倍率写进 `direct_damage_factor.vehicles`：

```
目标总伤   = 新值 / 100 * HP
直击目标   = 目标总伤 - 爆炸现值(explosion_data.damage * 爆炸倍率 * 0.6)
新直击倍率 = (直击目标 + armor_min) / direct_damage
```

| 机型 | armor_min | HP 基准 | 倍率查表键 |
|---|---|---|---|
| 固定翼 | 5 | 500 | `ywzj_vehicle:fixed_wing_vehicle` |
| 直升机 | 5 | 500 | `ywzj_vehicle:rotary_wing_vehicle` |
| 轮式 | 12 | 800 | `ywzj_vehicle:wheeled_vehicle` |
| 履带 | 15 | 1200 | `ywzj_vehicle:tracked_vehicle` |

- 四个机型各自独立反推，互不影响；`vehicle_default` 建议留 1.0 兜底。
- 若某格「直击目标 <= 0」（爆炸本身已超过目标值），说明该机型得压 `explosion_data.damage` 或 `explosion_damage_factor`，我会单独标出来问你。
- 反推出的倍率我按 2 位小数写入。

## 二、当前值的算法

```
直击 = direct_damage * direct_damage_factor[机型] - armor_min_damage   （下限 0.1）
爆炸 = explosion_data.damage * explosion_damage_factor[机型] * 0.6     （0.6 = 实战口径，见下）
合计 = 直击 + 爆炸；百分比 = 合计 / HP * 100
```

假设：正入射 0°、近距离、命中车体主命中箱（hitboxMult=1）、首次穿透。
- 角度：`RVP_DamageDecayUtil.angleFactor:71`，入射角 < 30 恒为 1.0；空中载具 `hitbox_max_incidence_angle_default:20` 钳制，永远满角度伤害。
- 距离：各武器 distance 段 `start_factor` 均为 1.0。
- 装甲：`armor_max_damage` 全包无车启用（不封顶）；`damage_threshold` 全包 0.1 且配装甲后被屏蔽。
- 爆炸绕过 `armor_min_damage`，且叠加在直击目标上。
- **爆炸按 0.6 折算**：机炮爆炸半径只有 1~3 格，命中大载具时爆心到锚点几乎总在边缘外，
  按满伤估算会虚高；本表统一按 `damage × 倍率 × 0.6` 计入（2026-10-29 定）。

血量实际范围：固定翼 500（suav 80）；直升机 ah64/mi28=500、ah1z/z10=400；轮式 800（6 台）、900（lav25/zbl08a）、600（9k720/m142）；履带 1200（多数）、1000（bmpt72/ztz100）。

例外：`bukm3`、`ps1sm` 的 type 是 tracked，但配了 `rvp_armor_type: ywzj_vehicle:wheeled_vehicle`，倍率按**轮式**键查表，armor_min 是 12 不是 15。
