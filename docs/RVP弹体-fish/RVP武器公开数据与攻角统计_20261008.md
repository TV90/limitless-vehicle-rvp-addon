# RVP 武器公开数据与最大攻角统计

> 统计对象：`limitless_vehicle/rvp/data/rvp/weapons/` 下截至 2026-10-08 的全部 JSON，共 **162** 项。本文只读统计，未修改任何武器 JSON。

## 口径

- **重量（kg）**：导弹/火箭/炸弹/鱼雷为单枚弹药的整弹质量；机枪/机炮为单发整装弹药的近似质量。它不是 RVP `projectile_data.mass`：后者是本项目运动学使用的归一化游戏参数。目标指示吊舱、激光器无抛射体，记为 `—`。
- **最大攻角（°）**：建议写入当前 schema 的 `projectile_data.rvp_attack_angle_limit_deg`，含义是弹轴相对速度轴的总攻角上限，不是 `guidance_data.max_off_axis_lock_angle` 或 `max_guidance_angle`。仅 `rvp:missile` 实体会进入当前攻角模型；普通炮弹、火箭、炸弹、鱼雷、吊舱和激光器的该列为“不适用”。
- 公开资料很少直接给出导弹最大攻角，因此质量优先采用公开/厂商或政府资料，未查到时依次使用 DCS 数据、战争雷霆数据和用户提供的 WT 性能表，最后才用工程推算；攻角在没有直接公开值时按同类最大过载、控制面/布局和 RVP 当前准三自由度模型做保守工程值。带 `≈` 的重量不是精确制造值。
- 本轮以用户提供的《WT导弹与设备性能表.xlsx》为 `W2` 来源，仅覆盖表内有明确同型号或同系列标识的质量数据；表内“尾翼攻角”是控制面参数，“最大过载”是 G 值，均不直接改写本文定义的 RVP 最大攻角。
