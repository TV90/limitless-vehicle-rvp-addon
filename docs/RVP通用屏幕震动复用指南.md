# RVP 通用屏幕震动复用指南

温压弹与冲击波抵达反馈共用“参数调度器 + 执行器”。代码位于
`src/main/java/org/ywzj/rvp/client/visual/shake/`，仅供客户端主线程调用。

## 分工

- `RVP_ScreenShakeParameters`：一次震动的持续时间、三轴最大角度和摆动频率。不可变，可重复使用。
- `RVP_ScreenShakeScheduler`：每个调用方长期持有一个实例，接收不同参数的任务，管理事件去重、距离衰减、开始时间、到期和取消。
- `RVP_ScreenShakeExecutor`：计算三轴偏移，通过现有 `RVP_ClientVisualEvents.onComputeCameraAngles` 写入相机。提交任务会自动登记执行器，无需调用方新增事件监听。

同一调度器先叠加所有活动任务，再乘该调用方的实时强度倍率，最后限制每轴角度。
不同调度器各自限幅后相加，因此一个调用方关闭震动、取消事件或达到上限，不会影响其他调用方。
各调用方上限相加后可以超过任意单方上限；不存在隐藏的全局两度限制。

## 调用示例

以下字段与方法放在调用方的客户端类中；`level` 为客户端世界，事件键应在同一次事件重发时保持相等。

```java
/** 该调用方每轴最多叠加 1.5 度，实时倍率固定为 1；也可改为自身客户端配置的读取方法。 */
private static final RVP_ScreenShakeScheduler SHAKES =
        new RVP_ScreenShakeScheduler(1.5F, () -> 1.0D);

/** 持续 20 刻（正常速度下 1 秒），三轴振幅 0.4/0.8/0.2 度，频率 1.4/2.0/1.1 弧度每刻。 */
private static final RVP_ScreenShakeParameters PARAMETERS =
        new RVP_ScreenShakeParameters(20, 0.4F, 0.8F, 0.2F, 1.4D, 2.0D, 1.1D);

// 提交立即开始的震动；distance 为接收者到震源的距离，80 为影响半径，单位均为格。
double now = level.getGameTime();
SHAKES.schedule(eventKey, now, now, seed, distance, 80.0D, PARAMETERS);

// 如需延迟 5 刻开始，提交时把第三个参数改成 now + 5；补播则改成 now - 已过去刻数。
// 同一活动事件键不会重启或替换任务，schedule 返回 false；过期后可再次使用该键。

// 取消指定事件，不影响其他事件或其他调用方。
SHAKES.cancel(eventKey);
```

三轴分别为左右转动（yaw）、上下转动（pitch）、画面倾斜（roll）。
角频率表示每个游戏刻正弦波相位推进多少弧度，数值越大摆动越快；振幅为零可以关闭该轴。
所有任务沿用温压弹的平方衰减：剩余寿命减半时，振幅降至四分之一。
距离采用线性衰减：爆心为完整强度，半径一半处为一半强度，到达影响半径为零。

持续时间必须大于零；振幅、频率、叠加上限必须为有限非负数。
无效时间、无效范围、范围外或已完整过期的任务不会创建。
非有限距离沿用温压旧规则视为零；实时倍率非有限或小于零时视为零。
强度为零期间任务仍会按世界时间结束，不会在重新打开时重播。

执行器在世界卸载、切换和退出时统一清空全部调用方的任务。正常到期的空调度器会从活动集合移除，
之后提交新任务时自动重新登记。调用方自己的结束逻辑可用 `cancel` 或 `clear` 提前撤销。
服务端若需要触发，应通过现有客户端消息链路到达客户端后提交，不可直接引用此包。

## 温压弹参数保持不变

| 项目 | 原值及当前值 |
| --- | --- |
| 开始时机 | 原声音控制器判定声波抵达的时刻 |
| 持续时间 | 12 游戏刻，正常速度下 0.6 秒 |
| 三轴振幅 | 0.90° / 0.70° / 0.50° |
| 三轴角频率 | 2.17 / 2.63 / 1.91 弧度每刻 |
| 距离范围 | `max(48, max(0, visualRadius) × 12)` 格 |
| 时间衰减 | 剩余寿命比例的平方 |
| 叠加上限 | 乘实时倍率后，每轴限制在 ±2° |
| 实时倍率 | 原 `getThermobaricShakeIntensity()` |
| 随机相位 | 原种子的第 8、24、40 位起各取 16 位 |

温压闪光仍由 `RVP_ThermobaricScreenFeedback` 处理。声音到达判断、闪光参数、
其他现有特效的震动流程均保持原样。此次没有新增 Mixin、资源文件或 JSON 配置项。

回归测试覆盖原温压固定数值样本、叠加上限、不同调用方及参数隔离、实时倍率、
延迟/补播/到期、事件去重与取消、世界清理和非法参数。

## 冲击波抵达反馈（2026-11-01）

`RVP_ShockwaveScreenShake` 为每个波面保存一次性抵达状态，普通与自动冲击波由
`RVP_ShockwaveShakePropagation` 独立管理传播时间。在已有相机角度事件中，
每帧读取玩家当前插值位置，计算玩家到真实爆心的三维直线距离；距离不大于当前波面
对应的震动传播半径时，立即提交一次震动。自 2026-11-06 本轮修订起，普通及自动冲击波的
最大震动半径独立扩大为可见最大半径的 **2 倍**，**传播速度不乘 2**。可见寿命内的传播半径
逐时刻沿用原扩张曲线；可见寿命结束后，从原可达半径出发，按同一快照的基础扩张速度
继续传播到新边界。视觉尺寸、绘制速度、寿命和单次震动时长保持原值，震动独立延长存活。
非匀速调参仍在原寿命内使用原曲线，追加外圈按该配置的基础匀速继续。第三人称镜头远近、
视线朝向及墙体遮挡都不改变抵达判断。
这里不采用固定声速，也不在爆炸生成时固定玩家距离；靠近会提前抵达，远离会延后抵达。

- 普通爆炸、载具击毁、温压弹与核爆附带的自动冲击波，以及显式威尔逊球形冲击波，
  统一使用创建时调参快照，原范围内保留原到达时刻，外圈由独立传播状态继续计算。
- 温压自身的透明压力球壳、白色凝结云墙不新增此反馈；温压只跟随自动追加的冲击波。
- 核爆独立折射球壳沿用原公式：初始半径 1 格，每刻扩张 2.25 格，寿命 220 刻，
  最大可达半径及震动半径仍为 496 格，不使用普通冲击波的 2 倍倍率。若同次爆炸另有自动冲击波，
  各波面分别触发一次。
- 新反馈与既有震动独立；不修改原来的声音到达震动或威尔逊震动，也不改旧 `shake` 开关。

距离强度为 `clamp(1 - 抵达瞬间距离 / 最大震动半径, 0, 1)`：爆心最强，一半距离为一半，
边界处为零。普通球形波的最大震动半径取**实际寿命结束时的可见半径 × 2**，先按扩张倍率、
曲线、尺寸与 2048 格上限计算可见范围，再独立放大震动范围；只放慢扩张而不延长寿命时，
不会误用尚未到达的理论完整范围。默认 32 格爆炸的可见最大半径约 113.29 格，震动最大半径
约 **226.58 格**；113.29 格处距离强度为一半，226.58 格边界处为零。
默认传播速度仍约为 6 格/游戏刻（120 格/秒），170 格处约在第 28.33 刻（1.42 秒）到达，
不再像上一版那样在第 14.17 刻提前收到；玩家移动仍以每帧实际距离为准。

新反馈持续 12 刻（正常速度下 0.6 秒），三轴振幅为 0.90° / 0.70° / 0.50°，角频率为
2.17 / 2.63 / 1.91 弧度每刻，时间衰减沿用剩余寿命比例的平方。所有新增波面共用独立
调度器，每轴叠加上限 ±2°，实时倍率读取 RVP 爆炸震动设置 `explosionShakeIntensity`，
而非温压专属设置。倍率为零也会消耗该波面的抵达机会，不会在波面离开后重新触发。

视觉实例结束或因数量预算被移除后，独立震动传播仍继续，最多保留 32 个轻量事件，
不占可见空气层的 8 个实例预算。网络事件晚于视觉寿命但仍在外圈传播期限内时也会登记，
沿爆炸原时间继续传播。已提交的震动由通用执行器独立播放完 12 刻；世界卸载、换维度或
退出游戏仍统一清空尚未抵达的传播与已提交的震动。
本地 `/rvpshockwave preview` 使用相同波面，因此也能预览新增抖动；没有伤害或地形破坏。
