# HITL 远程相机配置片段

这里两个 JSON 是武器 `guidance_data` **对象内部的片段**，不是完整武器文件。把所需字段合入已有 `guidance_data`，保留原有导引角、控制转速、引信和发动机等设置。只适用于 `HITL_TV` 和 `HITL_CLOS_TV`，两者均可自行选择 `RADIO` / `FIBER`。

示例操控距离 2048 格，导弹相机半径 6 区块；飞行路径不会一直保留，母车与原玩家仍使用原版近处区块。距离不受实际观察窗口面积影响，实际射程仍受燃料、速度、`life` 与制导段限制。没有配置 `enabled: true` 的武器保持原链路。

默认 `load_chunks_per_tick=1` 适合慢速尝试：半径 6 的窗口沿单轴每跨 1 区块新增 13 区块；仅按中心请求量估算，1 格/tick 约需 0.81 新中心/tick，3.5 格/tick 约需 2.84。原有飞行路径保活、预取、地图生成速度会影响实际表现，这不是 TPS 保证。高速弹可测试 `load_chunks_per_tick=3`、`send_chunks_per_tick=4`，仍受全服预算约束；首次进入未生成地形、多人同时使用时重点观察 MSPT 与地形补齐速度。

`RADIO` 默认跳过未加载路径段；它没有证明未知段不存在山体。启用 `require_loaded_radio_path=true` 后，未知地形会按阻断处理，不会为检查无线电而同步生成整条路线。

当前根载具包已为 CM-502、KH-39、AGM-179、AGM-84H/K、KD-88、TL-17、弹簧刀启用此功能：控制上限 2048 格、life=2400 tick（120 秒），窗口半径 32（4225区块），加载/发送预算为24/32每tick，供扩大相机地形视野测试。上方片段仍是默认保守预算的示例；实装清单见 [七种武器配置记录](../../plan/RVP_HITL长航程载具包配置_20261102.md)。客户端和服务端需要同版 RVP（网络协议 37），测试请使用 0.1.0o（协议37），同步完整根载具包，并把 [半径32测试配置](radius32/ywzj_rvp-hitl-remote.toml) 复制到实际运行环境的 `config/ywzj_rvp-hitl-remote.toml`（先备份旧文件），重启生效；客户端渲染距离设32。该TOML限制同时1个相机，窗口逐步补齐，实际邻域工作量可能更多。
