# 半径 32 的 HITL 相机测试

本配置将导弹相机周围的观察半径设为 32 区块，约 512 格，完整窗口 65×65=4225 区块。七种根武器 JSON 已配置半径32、加载24/发送32每tick；控制距离仍为2048格，life仍为2400tick。

1. 客户端与服务端使用 `ywzj_rvp-1.20.1-0.1.0o_beta_0.6.2-full.jar`（协议37）。
2. full内嵌的是已经清理的当前发布包；需手动同步时使用 `build/rvp-pack/`，并核对源/构建/内嵌/客户端meta版本一致为0.1.0o_beta_0.6.2。根源包含工程文件与备份，不要不加筛选地整拷到游戏目录。
3. 备份运行环境原有 `config/ywzj_rvp-hitl-remote.toml`，使用本目录的同名测试配置替换，重启生效。已有配置的半径上限8和加载预算4不会随jar升级自动变为测试值。
4. 客户端渲染距离设32；普通服务端视距可以较小，远程会话通过原版通知单独放开此客户端的相机地形视区，结束后恢复。

测试配置同时只允许一个远程相机，全服每tick最多24个新增票据中心、32个完整区块包，未就绪中心最多64。窗口逐步补齐，实际邻域依赖会增加工作量。高速实弹、未生成复杂地形和多人负载仍需实机观察。

回退时将七种武器的半径恢复6、加载/发送恢复原分组（4/6、3/4、2/3），并恢复原TOML。本轮原配置备份路径记录在项目根 `_tmp_hitl_radius32_state_20261102.json`，不需要删除文件。
