# RVP 告警状态机（地面载具 / 飞行器）

> 说明：告警按“威胁类型”分成若干**独立状态**，可同时存在多个（例如一边被雷达锁定、一边被 IR 导弹追踪）。
> 各状态由各自的计时窗口驱动，过期自动退出；进入条件持续满足则持续刷新。
> 两类载具差异：**地面载具没有屏幕文字**，只有音效 + 雷达界面符号 + 自动规避；**飞行器额外有血条上方红闪文字**。

---

## 一、状态一览（输入 → 输出）

| 状态 | 进入条件 | 玩家感知（音效 / 文字 / 雷达界面） | 退出 |
|---|---|---|---|
| **① 无告警** | 无威胁 | 静默 | 任意威胁触发即进入对应状态 |
| **② 雷达搜索** | 敌雷达探测到本车 | 一声“嘀” + 雷达界面搜索弧线 | 敌雷达丢失本车 |
| **③ 雷达锁定** | 敌雷达已锁定本车 | 持续循环警报音 + 雷达界面锁定符号 | 锁定解除 |
| **④ 导弹来袭(RWR)** | **仅主动雷达弹(ARH)** 开机追踪本车 | 最高优先级循环警报音 + 雷达界面导弹指示 | 导弹消失/失锁 |
| **⑤ 导引头追踪** | 导弹导引头(IR/AIR/ARH)正在咬住本车 | IR/AIR：RWR 蜂鸣；飞行器还显示红闪文字；ARH 不另播音（被④覆盖） | 导弹丢失目标 |
| **⑥ 激光照射** | 被敌方激光指示器照中 | **无任何告警提示** | 照射停止 |

优先级（音效互相覆盖）：④ 导弹来袭 ＞ ③ 雷达锁定 ＞ ② 雷达搜索。

---

## 二、地面载具状态机

```
         敌雷达探测到本车
  ① ─────────────────────► ② 雷达搜索
  敌雷达锁定本车               │
  ① ─────────────────────► ③ 雷达锁定
  ARH 导弹开机追踪本车          │
  ① ─────────────────────► ④ 导弹来袭(RWR)
  IR/AIR 导弹追踪本车           │
  ① ─────────────────────► ⑤ 导引头追踪（只有蜂鸣，无文字）
  被激光照射                    │
  ① ─────────────────────► ⑥ 激光照射（完全静默）
                                   │
          任意威胁满足时 ───────┘（gunner 同步触发自动抛烟）
```

**地面各状态表现**

| 状态 | 音效 | 屏幕文字 | 雷达界面 | 备注 |
|---|---|---|---|---|
| ② 雷达搜索 | 嘀（一次性） | 无 | 搜索弧线 | — |
| ③ 雷达锁定 | 持续循环音 | 无 | 锁定符号 | — |
| ④ 导弹来袭 | 循环音 | 无 | 导弹指示 | **仅 ARH 触发**；IR 弹不报 |
| ⑤ 导引头追踪 | IR/AIR：RWR 蜂鸣 | 无 | — | 坦克被 IR 咬住只有蜂鸣没有字 |
| ⑥ 激光照射 | 无 | 无 | 无 | 仅触发 gunner 自动抛烟 |

**自动规避（行为，非屏幕告警）**：gunner 在 ②/④/⑥ 任一威胁下会**自动抛洒烟雾弹并驶入烟中停车**；其中 IR 锁定与激光照射还会让导弹进入“烟雾脱锁不复锁”逻辑。

## 三、飞行器状态机

飞行器在地面所有状态基础上，**额外在血条上方显示红色闪烁文字**（逐行排列），文字按键提示对应规避物：

| 状态 | 音效 | 血条上方红闪文字（中文 / 英文） |
|---|---|---|
| ③ 雷达锁定 | 持续循环音 | 战机被雷达锁定，按[箔条]释放箔条 / Radar locked, press [%s] to release chaff |
| ④ 导弹来袭 | 循环音 | （同③引流弹，无独立文字） |
| ⑤ ARH 追踪 | ④ 的循环音 | 战机被雷达制导导弹锁定，按[箔条]释放箔条 / Locked by radar-guided missile… |
| ⑤ IR/AIR 追踪 | RWR 蜂鸣 | 战机被红外导弹锁定，按[热焰弹]释放热焰弹 / Locked by IR missile…（AIR 共用此行） |
| ⑥ 激光照射 | 无 | 无 |

> 文字中 %s 自动替换为“释放箔条 / 释放热焰弹”的对应按键。

---

## 四、需要知道的缺口

1. **激光照射完全无告警**：地面与飞行器都静默，只靠 gunner 自动抛烟兜底。
2. **地面载具无锁定文字**：被 IR/ARH 锁定只有音效，屏幕不提示。
3. **纯 IR 导弹无“导弹发射”级 RWR**：`MISSILE_LAUNCH` 只由 ARH 触发，Kh-39T 这类 IR 弹来袭只能靠 IR 蜂鸣区分。
4. **大角度钳制**：雷达类告警由 RVP 无钳制补发覆盖（俯仰差 >45° 也能收到），激光告警若未来加入需同样处理。

---

## 五、一句话总结

- **地面**：听音效 + 看雷达界面 + 看 gunner 自动抛烟；没有屏幕文字。
- **飞行**：在地面基础上，血条上方红字告诉你“被什么锁了、按哪个键放干扰弹”。
- **激光**是唯一的“哑”威胁——任何载具都不会告警，只能靠自动规避。
