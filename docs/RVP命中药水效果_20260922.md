# RVP 命中药水效果：直击 + 爆炸距离衰减（2026-09-22）

## 意图

移植 MCHeli（MCHR）"命中敌人添加药水效果"机制（`AddPotionEffect`）到 RVP，并超出 MCHR 原能力：
①直击命中施加药水；②命中载具波及**全体乘员**（同激光致盲语义）；③**爆炸兼容**且时长按
**离爆心距离线性衰减到 30%**（爆心满时长 → 杀伤半径边缘保留 30%）；④列表配置，可叠加多种效果。

MCHR 原机制为 1.7.10 API（`PotionEffect`/数字药水 ID），仅直击生效、爆炸无效果、无衰减；
移植时 API 翻译为 1.20.1 `MobEffectInstance`/字符串注册 ID，爆炸与衰减为本轮新增。

## 改动点

| 文件 | 改动 |
|---|---|
| `weapon/data/RVP_PotionEffectEntry.java`（新增） | 单条效果配置：`effect`/`duration_ticks`/`amplifier`/`targets`（all/players/hostile/non_allied，默认 all） |
| `weapon/data/RVP_CollisionData.java` | 新增 `hit_potion_effects` 列表（直击药水）+ getter + 计入 isSpecified |
| `weapon/data/RVP_Explosion.java` | 新增 `potion_effects` 列表（爆炸药水）+ getter |
| `weapon/effects/RVP_HitPotionEffectService.java`（新增） | 直击/爆炸两个施加入口 + 距离衰减纯函数 `scaledDuration` + 药水 ID 解析（缺省命名空间补 minecraft:） |
| `weapon/effects/RVP_DetonateApplier.java` | `matchesTarget` 改包级可见供服务复用（逻辑零改动） |
| `entity/projectile/RVP_BaseBullet.java` | 两个调用点：`applyEntityHitDamage` 尾部（直击）、`triggerExplosion` 爆炸结算后（爆炸，仅杀伤爆炸一次） |
| `src/test/java/.../RVP_HitPotionDurationDecayTest.java`（新增） | 衰减纯函数 7 用例 |

## JSON 配置示例

```json
{
  "collision_data": {
    "hit_potion_effects": [
      { "effect": "minecraft:slowness", "duration_ticks": 200, "amplifier": 1 }
    ]
  },
  "detonate_data": {
    "explosion_data": {
      "radius": 5,
      "potion_effects": [
        { "effect": "minecraft:weakness", "duration_ticks": 300, "amplifier": 0, "targets": "non_allied" },
        { "effect": "minecraft:poison", "duration_ticks": 200, "amplifier": 1 }
      ]
    }
  }
}
```

## 机制要点

- **直击**：`applyEntityHitDamage` 尾部、服务端侧。命中载具 → `getPassengers()` 全体乘员满时长
  （同 `RVP_LaserBlindService` 枚举范式）；命中普通 LivingEntity → 本体满时长。
- **爆炸**：`triggerExplosion` 杀伤爆炸结算后，半径盒内全体 LivingEntity（乘员作为独立实体
  按各自离爆心距离判定），`时长 = duration_ticks × (1 - 0.7 × 距离/半径)`——**衰减到 30%**
  （爆心满时长、半径边缘 30%，2026-09-22 用户定版），缩放后 <20t 不施加。
  destroy_radius 双爆炸场景只施加一次（地形爆炸 A 不涉及）。衰减公式与本体伤害衰减
  （`VehicleExplosion:416`）同形不同底（伤害边缘 50%，药水边缘 30%），差异是有意的。
- **与既有 `detonate_data.potion_effect_data`（落点范围均匀时长药水）互补共存**：后者不动；
  前者是"武器爆炸本体携带、按距离衰减"的新能力。
- **目标过滤**：复用 `RVP_DetonateApplier.matchesTarget`（all/players/hostile/non_allied，
  non_allied 排除发射者本人与其载具乘员）。
- 现有武器不配新键 = 零行为变化。

## 预期影响

- 武器包可给任何弹配置"命中上负面状态"的能力（燃烧弹 Slow+Poison、烟幕弹 Blind 类组合等）。
- 高爆弹爆炸圈内的软目标获得随距离递减的负面状态，远离爆心即减轻——符合手感的爆破压制模型。

## 验证方式

- `gradlew build` 通过（2026-09-22），新增单测 `RVP_HitPotionDurationDecayTest` 7/7 通过。

- 实机项（待验证）：直击锁慢速目标上效果；命中载具观察乘员中毒；爆炸圈边缘目标时长明显短于爆心。
