# 弹体运动学开发与测试

说明 RVP 扩展包中 `projectile_data` 在运行时的行为、与本体 `ywzj_vehicle` 的对应关系，以及如何设计可对比的测试武器。

字段逐项说明见 [RVP包新增参数字段说明.md](./RVP包新增参数字段说明.md) 的「`projectile_data` 弹体运动学」章节。

---

## 1. 配置写在哪里

所有弹体运动学参数写在武器 JSON 的 **`projectile_data`** 对象里（不要散落到已废弃的顶层 `acceleration` 等键）。

```json
{
  "type": "rvp:rocket",
  "velocity": 10,
  "projectile_data": {
    "velocity": 6,
    "gravity": -0.005,
    "drag": 0.01,
    "has_rocket_engine": false
  }
}
```

- **`projectile_data.velocity`**：弹体初速；若写了且 > 0，优先于武器顶层 `velocity`。
- 推进参数（`mass`、`thrust` 等）推荐写在 `projectile_data`；未写的键在 `has_rocket_engine: true` 时，加载阶段会从 JSON **顶层**同名键补全（与本体 `VehicleMissileWeaponData` 字段名一致）。

## 2. 运行时走哪条弹道

实体类：`RVP_BaseBullet`（及子类）。每 tick 在服务端调用 `tickMotion()`，按下面顺序**只进入一条分支**：

```
                    tickMotion()
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
   rvp:machinegun   usesPropulsion()   其余
         │          == true             │
         ▼               ▼               ▼
 tickCannonMotion   tickPropulsion   tickBallistic
 (≈ BulletEntity)   Motion           Motion
                    (≈ MissileEntity  (gravity + drag
                     tickMove)        + 可选 constant_speed)
```

### 2.1 机炮弹道（`rvp:machinegun`）

- **实现**：`RVP_BulletEntity`，与本体 `BulletEntity` 相同思路。
- **客户端**：本地按 spawn 速度积分（`setShouldReceiveVelocityUpdates(false)`），不依赖网络速度包。
- **每 tick**：`位置 += 速度` → `速度 *= (1 - friction)` → `速度.y -= gravity`。
- **`projectile_data`** 常用：`velocity`、`gravity`、`drag`、`rotate_to_motion`。
- **不生效**：`has_rocket_engine`、`mass`、`constant_speed`、`max_speed`（机枪专用逻辑忽略这些）。

### 2.2 推力弹道（`has_rocket_engine` 且参数有效）

`usesPropulsion()` 为 true 的条件：

- `has_rocket_engine == true`
- 且 `mass > 0`、`thrust > 0`、`motor_burn_time > 0`（解析后的最终值）

**每 tick（点火后）** 近似：

1. 沿朝向加速：`Δv += lookDir * (thrust / mass)`（燃烧时间内）
2. 二次阻力：`Δv -= drag_coefficient * |v|²`（沿速度反方向）
3. 重力：默认 `PhysicsEngine.G`；若写了 `projectile_data.gravity` 则用该值
4. `位置 += 速度`；可选 `max_speed` / `min_speed` 钳制

**与本体**：`RVP_ProjectileMotion` 对齐 `MissileEntity#tickMove()`（推力沿 `getLookAngle()`，`rotate_to_motion` 时先对齐速度）与 `BulletEntity#tick()` 的 `atan2` + `lerpRotation`；制导朝向用 `VectorUtil.vecToRot`。

**客户端**：运动在服务端计算，客户端通过实体同步插值显示（与 `MissileEntity` 一致，不在客户端跑 `tickMotion`）。

### 2.3 简化弹道（默认）

未开机炮分支、且 `usesPropulsion()` 为 false 时使用。

- **每 tick**：`速度.y += gravity` → MCH 式水平阻力（`motionX/Z -= (motion/|v|)*drag`，不减 `motionY`）→ 可选 `constant_speed` → `位置 += 速度`。
- 适用于：无发动机火箭、滑翔弹、以及 `has_rocket_engine: true` 但缺少 mass/thrust/燃烧时间（会打日志并退回简化弹道）。

## 3. 与本体对照

| RVP | 本体（只读参考） | 说明 |
| --- | --- | --- |
| `RVP_BulletEntity` | `BulletEntity` | 机炮积分、双端预测 |
| `tickPropulsionMotion` | `MissileEntity#tickMove` | 推力 + 二次阻力 + 重力 |
| `tickBallisticMotion` | 部分火箭/导弹简化配置 | RVP 统一入口 |
| `RVP_ProjectileData` | `VehicleMissileWeaponData` 顶层 mass/thrust… | 名同；RVP 推荐放进 `projectile_data` |

---

## 4. 加载期自动处理

`RVP_WeaponTypes` 在反序列化前会归一化 JSON：

| 旧/辅助逻辑 | 行为 |
| --- | --- |
| `projectile_data.acceleration` | 合并为 `velocity` |
| `speed_factor` + `speed_factor_end_tick` | 换算为 `mass` / `thrust` / `motor_burn_time` 并打开 `has_rocket_engine` |
| 顶层或弹体存在 mass/thrust/motor_burn_time | 若未写 `has_rocket_engine`，自动设为 `true` |
| `resolvePropulsionFallback` | `has_rocket_engine` 时，弹体未写的推进键从武器 JSON 顶层补全 |

## 5. 调试建议

### 5.1 先固定变量

对比弹道时，建议一次只改一类参数，其余保持一致，例如：

- 同一 `gravity`、同一 `drag`
- 只改 `velocity` 或只改 `thrust`

对比时可自建临时武器 JSON（复制现有武器改 `projectile_data.velocity`），挂载到测试载具的 `weapons` 列表。

### 5.2 机炮仍「抽搐」时检查

- 顶层 `velocity` 是否为默认 **10** 且与 `projectile_data.velocity` 冲突（非默认顶层会覆盖弹体初速）。
- `spread` / `inaccuracy` 是否过大。
- 载具包是否改在 `run/client_1/limitless_vehicle/rvp/`（当前开发唯一维护路径）。

### 5.3 火箭/导弹轨迹异常时检查

- `has_rocket_engine` 是否为 true 但 mass/thrust/燃烧时间未配齐（会走简化弹道）。
- 推力模式下 `rotate_to_motion` 是否与制导同时改朝向（制导改 `deltaMovement`，推力沿 `lookAngle`）。
- 客户端勿依赖速度同步包；实体类型已设 `setShouldReceiveVelocityUpdates(false)`。

### 5.4 日志

`has_rocket_engine: true` 且推进参数不齐时，服务端会 warn：

`has_rocket_engine=true but missing mass/thrust/motor_burn_time; using simplified ballistics`

## 6. 最小配置示例

**机炮（初速 16）**

```json
"projectile_data": {
  "velocity": 16,
  "gravity": -0.005,
  "drag": 0.01,
  "rotate_to_motion": true
}
```

**无发动机火箭（初速 6，简化弹道）**

```json
"projectile_data": {
  "velocity": 6,
  "gravity": -0.005,
  "drag": 0.01,
  "rotate_to_motion": true
}
```

**有发动机火箭（低初速 + 推进）**

```json
"projectile_data": {
  "has_rocket_engine": true,
  "velocity": 3,
  "gravity": -0.005,
  "rotate_to_motion": true,
  "mass": 0.01,
  "thrust": 0.0012,
  "motor_burn_time": 200,
  "drag_coefficient": 0.008
}
```
