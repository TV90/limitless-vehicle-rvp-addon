# RVP 载具炮口烟实现与调试

> 更新：2026-11-05。记录当前代码实际使用的开火烟路径、F8参数及验证边界。2026-10-02的最初实现后来换成了自绘烟；当前大口径白烟不再调用旧的 MCHR 白烟工厂。

## 1. 作用范围与默认行为

炮口烟消费本体确认成功的客户端开火事件，不创建服务器实体，不增加网络包或伤害。

- RVP机枪/机炮读取真实弹体口径 effects_data.caliber；本体火炮读取类型化火炮数据的口径。
- 0＜口径＜45毫米：保留小口径即时灰烟，寿命15～25刻。
- 口径≥45毫米：独立的延时白烟管理器排队，默认等待10～20刻，再持续喷烟15～20刻。
- 白烟队列每刻推进一次，默认每刻8枚，沿炮口前方0～3格出生；烟团初速现已实际读取0.12～0.15格/刻，即2.4～3格/秒。
- 单枚白烟寿命现已实际读取40～60刻，逐枚随机；之前实际生成函数写死为36刻，并未使用排队保存的寿命。
- 每次成功开火保存整份参数，后续改动仅作用于下一次开火或预览。已经排队及已经生成的烟不跳变。
- 新增旋涡、口径比例、风、继承运动、膨胀变薄和环境光混合默认关闭或保留原值，供用户逐项调试；没有自动套用拟真预设。

20刻=1秒。白烟只负责开火后的余烟，不改变炮口闪光、爆炸或殉燃系统。

## 2. 正式调用链

~~~text
VehicleFireEvent.Post（客户端确认成功）
  → RVP_DelayedMuzzleSmokeEmitter
      → 解包实际武器，按数据类型和真实口径筛选
      → 保存整份参数快照、武器站与实际炮口对象
      → 延迟期间也逐刻采样实时炮口位置，计算平移及转动速度
      → RVP_DelayedMuzzleSmokeLogic
          → 喷烟渐强/泄劲、距离烟量、小数累积
          → 出生位置、逐枚寿命、尺寸、浓度与运动继承
      → RVP_WreckMuzzleSmokeSelfRenderer.spawnDelayed
          → 同炮口活跃数量上限
          → 现有静态烟片及自绘/热成像管线
~~~

小口径路径仍使用 RVP_MuzzleSmokeEmitter → RVP_MchrSmokeParticle.ofMuzzle。

延时白烟使用现有殉燃喷火贴图集合的白色轮廓，不新增、替换美术资产。白烟与殉燃共用粒子类，但只有开火白烟传入扩展快照；殉燃继续走原构造器、运动及淡出计算。

## 3. F8 使用与参数生效

1. 进入世界，按F8，左侧选择“延时炮口白烟”。
2. 参数分为四组，共38项。滑条、数值输入、搜索、逐项/分组/分类重置、撤销和保存均由既有面板提供。
3. 右键“时序与喷烟节奏”组标题，选择“预览45毫米白烟”或“预览125毫米白烟”。预览会收起面板，在玩家前方4格、视线下方0.5格设置静止烟源，按设定延迟播放；不生成弹体，不造成伤害。
4. F8或Esc返回。观察移动和炮塔转动时的速度继承，需要真实载具开火；静止预览的炮口速度为0。
5. “本地配置 → 保存本地”保存到当前游戏目录 config/ywzj_rvp-tuning-client.json，下次启动自动读取。仅关闭面板不自动写盘。

F8把向前初速、上浮及水平风速显示为“格/秒”；内部和 /rvpmuzzlesmoke 指令继续使用“格/刻”。完整保存键为 muzzle_smoke/分组键/参数键，保存的是F8显示单位。其余刻数仍用20刻=1秒。

整刻/整枚控件四舍五入。面板调整最小值越过最大值时，会同步推开最大值，反向同理；指令继续严格拒绝倒置范围。恢复默认时，只有与配对端冲突才一并清除配对覆盖。合法预设不受JSON键恢复顺序影响。

## 4. 全部参数

以下默认值、范围和单位对应F8面板。指令中的速度值需除以20；“格/刻²”表示每刻追加的速度变化量，1格/刻²相当于400格/秒²。

| F8名称 | 参数键 | 默认值 | 范围 | F8单位 | 作用 |

| 最短开火延迟 | `delayMin` | 10 | 0～600 | 刻（20刻=1秒） | 开火后最早何时开始出烟。 |
| 最长开火延迟 | `delayMax` | 20 | 0～600 | 刻（20刻=1秒） | 开火后最晚何时开始出烟。 |

| 最长喷烟时间 | `emitDurationMax` | 20 | 1～600 | 刻（20刻=1秒） | 从第一缕烟开始计算的最长喷烟时长。 |
| 最短烟团寿命 | `particleLifetimeMin` | 40 | 4～1200 | 刻（20刻=1秒） | 每枚烟团至少保留多久；逐枚随机，避免整批同时消失。 |

## 5. 控制项怎样作用于画面

- **渐强与泄劲**：同一个强弱曲线同时控制每刻烟量、浓度与向前喷出速度。泄劲强度为0时保留均匀喷烟；“收尾保留烟量”只有启用泄劲才有作用。
- **近口出生**：把生成长度缩短至0～0.2格，可让烟从炮口自行运动形成长度；不会继续瞬间铺满原来的3格区域。横向散布使用当前炮管的两条横向轴，竖直炮管也不会产生无效方向。
- **连续旋涡**：按烟所在世界位置、共同世界时间采样解析旋涡场。邻近烟团在同一片气流中一起翻卷；强度为0时不采样旋涡。它改变烟团运动，现有静态贴图内部仍没有新增动画帧。
- **扩散变薄**：尺寸增长时，按相对出生尺寸额外降低浓度，可与淡入、寿命淡出分别调整。
- **局部受光**：混合原固定天空亮度和烟所在位置的方块光、天空光，两个光照通道分别混合。既有RVP烟雾受光和热成像绘制入口继续保留。
- **口径与连续开火**：仅使用真实口径，不使用武器ID分支。125毫米为比例基准；不同炮口预算独立，同一实际炮口的连续开火共享存活上限。达到上限丢弃本刻新烟，之后不集中补发。
- **远处减量**：64格内完整，64～256格线性过渡。小数烟量跨刻累积，避免每刻不足一枚时被全部舍弃。

本轮保持深度只测不写、静态贴图分组、自绘排序和统一烟雾受光结构。没有添加结构模型改动、JSON迁移或Mixin。

## 6. 指令与安全上限

~~~text
/rvpmuzzlesmoke show
/rvpmuzzlesmoke set <参数键> <数值>
/rvpmuzzlesmoke reset [参数键]
~~~

指令覆盖与F8立即互通，且可以通过F8显式保存。所有参数拒绝非有限数及越界值，指令中的刻数/数量还要求整数。

- 同一载具、武器站和炮口在同一游戏刻只排队一次，齐射各炮口独立。
- 轮射只跟踪当时实际炮口；齐射跟踪所有有效炮口。
- 延时任务队列最多512条；超过上限淘汰最早任务。
- 自绘粒子全局保留原2048枚上限；正常消散、全局淘汰及世界切换都会同步释放延时白烟的炮口计数。
- 离开世界、切换维度、载具或炮口移除时停止对应任务。
- 炮口一刻移动超过16格按瞬移处理，不继承异常巨大速度；这不改变载具实际运动。
