# RVP 程序尾焰 F8 调参

日期：2026-11-05。新增独立的“程序尾焰”分类，六组35项，均接入正式程序喷焰。此次只开放参数，**不填写推荐数值、不建立推荐预设、不新增图片、模型或动画**。面板显示的起点来自当前实现；新增倍率使用不改变现有效果的中性值，只有主动编辑后才产生本地覆盖。

这里的程序尾焰指用显卡计算形状和颜色的导弹、火箭发动机喷流，不是后方留下的尾烟，也不是载具残骸的殉燃火柱。

## 入口与生效方式

- 按F8或输入`/rvptune`，左侧选择“程序尾焰”。支持搜索、滑条、数字输入、单项/分组/分类恢复和撤销。
- 每项均有中文名称、作用和单位；有效修改下一显示帧生效，已存在的喷流也能立即观察，无需重新发射。
- 右键任意分组标题，选择“两秒稳态预览”或“两秒启停预览”。两者均在准星附近侧向展示，不创建真实弹体，不造成伤害。
- 稳态预览沿用原有两秒预览的降亮与独立光晕曲线；启停预览按两秒有限燃烧窗口展开、收束，到期自动清理。过渡时间太长时两端会重叠。
- “保存本地”写入当前游戏目录的`config/ywzj_rvp-tuning-client.json`；仅关闭面板只保留本次会话。打开面板不会自动填写或保存参数。

亮度峰值、外围焰亮度、广域光晕亮度及其开关、照亮/光晕半径仍在**“屏幕空间特效 → 发动机喷焰与照亮”**。多层模糊光晕继续使用原有专门分组，没有复制第二套绑定。

## 参数清单（不填写推荐数值）

表中键名用于搜索和本地预设。完整键为`rocket_plume/<分组>/<参数>`。

| 分组 | 参数键 | 面板名称 | 调节作用 |
| --- | --- | --- | --- |
| `shape` | `lengthScale` | 喷焰长度倍率 | 以武器原有`flame_scale`为基础，独立调长度 |
| `shape` | `widthScale` | 喷焰粗细倍率 | 独立调半径，不联动长度 |
| `shape` | `axialOffset` | 喷焰沿尾轴偏移 | 沿喷流方向移动喷焰与其光晕，不修改真实喷口配置 |
| `shape` | `nozzleWidth` | 喷口根部粗细比例 | 调根部相对整条喷流的粗细 |
| `shape` | `expansionPower` | 喷流鼓起位置 | 调最饱满的位置靠前或靠后 |
| `shape` | `tipPower` | 尾端收尖强度 | 调末端变细的快慢 |
| `shape` | `axialFade` | 沿喷流亮度衰减 | 调亮焰向尾端延伸的程度 |
| `shape` | `rootFade` | 根部柔和过渡长度 | 调喷口从暗到亮的过渡范围 |
| `layers` | `coreWidthScale` | 白热核心粗细倍率 | 独立调内部亮芯宽度 |
| `layers` | `coreEdgePower` | 核心边缘集中程度 | 调亮芯中心与边缘的明暗变化 |
| `layers` | `coreFill` | 核心白热饱满程度 | 调亮芯中达到峰值的区域大小 |
| `layers` | `outerEdgePower` | 外焰边缘集中程度 | 调外焰径向明暗变化 |
| `color` | `coreRed` / `coreGreen` / `coreBlue` | 核心红/绿/蓝色分量 | 核心独立配色；峰值很亮时会趋白，可先降低原有核心亮度观察 |
| `color` | `outerRed` / `outerGreen` / `outerBlue` | 外焰红/绿/蓝色分量 | 外焰独立配色，局部模糊柔光继承可见焰色 |
| `color` | `haloRed` / `haloGreen` / `haloBlue` | 广域光晕红/绿/蓝色分量 | 仅调外围大范围柔光，不修改环境照明颜色 |
| `motion` | `animationSpeed` | 喷流流动速度 | 调轮廓和亮节的总体流速，可冻结动画 |
| `motion` | `waveStrength` | 轮廓起伏强度 | 调外轮廓粗细波动的幅度，可取消波纹 |
| `motion` | `waveDensity` | 轮廓波纹密度 | 调同一长度内的粗细起伏数量 |
| `motion` | `shockDensity` | 喷流亮节密度 | 调轴向亮暗结节数量；这种纹理也叫激波纹 |
| `motion` | `shockContrast` | 喷流亮节明暗对比 | 调连续亮焰与分节亮焰的区别 |
| `motion` | `shockSharpness` | 喷流亮节集中程度 | 调亮节是宽软还是窄集中 |
| `motion` | `shockDrift` | 亮节相对流动速度 | 独立调亮节移动，不联动轮廓波纹 |
| `transition` | `ignitionTicks` | 点火展开时间 | 从真实点火开始渐显，可改为立即展开 |
| `transition` | `burnoutTicks` | 燃尽前收束时间 | 在真实燃尽前渐隐，可保持到燃尽再移除 |
| `transition` | `lengthResponse` | 启停长度收束曲线 | 调展开、收束期间的长度变化 |
| `transition` | `widthResponse` | 启停粗细收束曲线 | 独立调展开、收束期间的粗细变化 |
| `transition` | `brightnessResponse` | 启停明暗过渡曲线 | 在高亮映射后调显隐，白热核心也能渐隐 |
| `halo` | `haloFalloff` | 光晕中心集中程度 | 调中心集中或向外铺开的程度 |
| `halo` | `haloEdgePower` | 光晕边缘收软程度 | 调边缘向零亮度过渡的方式 |

建议按“轮廓 → 核心与外焰 → 配色 → 亮节与流动 → 启停 → 光晕”的顺序逐组调节，再用真实发射观察不同距离。此处只给调节顺序，不给推荐数值。

## 实现边界

- JSON的`has_rocket_engine`、喷口位置、`flame_scale`和真实燃烧时间继续生效；不按武器ID分支，不改推进、制导、命中或网络协议。
- 临时长宽倍率和轴向偏移在可见性筛选之前应用，因此屏幕裁剪与实际绘制采用相同几何。轮廓起伏不超出最大半径。
- 点火/燃尽时长只改变视觉过渡，不延长真实燃烧窗口。断流心跳、实体移除、换世界和时钟回退仍按原规则清理。
- 核心和外焰支持分别调到零亮度；取消核心不会连带取消仍有亮度的外焰。
- 原近景、远景地形深度（DH提供的远景遮挡）、手持物遮罩和透明度合成规则继续使用；绘制数量预算不变。
- 只修改现有生产着色程序`rocket_plume_ranges`（负责在显卡上算形状与配色）及其参数声明；没有新增美术资源、本体改动或Mixin注入。
