# RVP 光照与光晕游戏内调参

日期：2026-10-30。

现有光照、遮挡、短光衰减、程序喷焰、亮部提取和模糊算法全部保留。`/rvplight` 只临时修改这些算法的输入，默认画面沿用当前代码和客户端画质配置。无需修改武器 JSON 或重新编译即可对比效果。

这些是客户端指令，单机和联机都能使用，不需要服务端管理员权限。只影响自己的画面，不改变伤害、发动机燃烧时间或 Minecraft 的方块光等级。修改在下一显示帧生效，已存在的光源也会响应；重连、换维度保留，**完全重启游戏后恢复默认**。

## 1. 先用这些命令

按顺序单独执行，每次改一个参数便于对照。发动机预览位于准星附近，持续两秒；朝天空检查喷焰和外晕，朝墙面检查受光。需要时重新执行预览。

```text
/rvplight help
/rvplight status engine
/rvplight engine 0.3 300
/rvplight set engine haloIntensity 8
/rvplight engine 0.3 300
/rvplight set engine radiusScale 2
/rvplight engine 0.3 300
/rvplight reset engine
```

上例原口径为 300 mm，共同半径为 `20+300×0.1=50` 格。`radiusScale 2` 后半径为 100 格，环境照明与广域橙色光晕一起调整；喷焰本身仍长 3 格、最大直径 0.9 格。

## 2. 指令形式

| 指令 | 用途 |
| --- | --- |
| `/rvplight` 或 `/rvplight status` | 活动光数、实际画质开关、最终环境光总倍率、最终观察距离和近景/DH 输入状态 |
| `/rvplight help` | 中文用法和常用示例 |
| `/rvplight status <组> [参数]` | 查看当前值、默认值、范围、中文含义及是否有临时覆盖 |
| `/rvplight set <组> [参数]` | 不填数值时只查询，便于先看范围 |
| `/rvplight set <组> <参数> <数值>` | 修改一项；支持 Tab 补全，非法数值不会覆盖原值 |
| `/rvplight reset [组] [参数]` | 恢复全部、一组或单项的原始设置，下一帧生效 |
| `/rvplight copy` | 将当前覆盖值复制成可重放的命令清单，首行包含 reset；可保存到笔记，下次逐条执行 |
| `/rvplight preview [半径]` | 保留原有一秒无伤害短光预览；半径为调参前的输入，使用 explosion 组 |
| `/rvplight engine [喷焰缩放] [毫米口径]` | 保留原有两秒发动机预览，默认缩放 0.3、口径 0 |
| `/rvplight clear` | 清除当前光和预览，保留调参值；真实燃烧中的发动机会继续登记 |

`reset` 只清临时调参。总开关和光晕开关没有覆盖时，重新尊重 `ywzj_rvp-lighting-client.toml` 中原有选择；其余参数恢复倍率 1 或对应代码数值。不会写任何配置文件。

## 3. 参数分组

### global：环境照明总设置

| 参数 | 默认 | 范围 | 中文含义 |
| --- | --- | --- | --- |
| `enabled` | 沿用客户端 `screenLight` | 0 或 1 | 环境受光总开关；喷焰保持原先独立的显示行为 |
| `brightness` | 1 | 0～8 | 在客户端 `intensity` 基础上再乘此倍率；爆炸、炮口、发动机环境光和烟雾一起变化 |
| `distanceScale` | 1 | 0.0625～4 | 在客户端 `maxDistance` 上乘倍率，最终仍限制为 16～1024 格；喷焰不受此距离预算限制 |
| `smokeBrightness` | 1 | 0～8 | 额外调节烟雾及炮口特殊贴图受光；不改变墙面和地面受光 |

### explosion / muzzle / engine：三类光源

以下参数三个组都支持，数值乘在既有口径规则、颜色和亮度上。

| 参数 | 默认 | 范围 | 中文含义 |
| --- | --- | --- | --- |
| `brightness` | 1 | 0～8 | 该类光源环境照明亮度倍率；0 暂时不照亮环境，reset 可恢复仍未过期的光 |
| `radiusScale` | 1 | 0.05～16 | 该类光源影响半径倍率，先调范围再做距离/画面裁剪和八灯预算 |
| `red` / `green` / `blue` | 1 | 0～4 | 环境光红/绿/蓝分量倍率，最终颜色限制为 0～1；爆炸原有变色继续生效 |
| `surface` | 1 | 0～4 | 表面受光权重倍率，最终权重限制为 0～1；烟雾沿用同一权重 |

只有 `explosion` 和 `muzzle` 另外支持：

| 参数 | 默认 | 范围 | 中文含义 |
| --- | --- | --- | --- |
| `decayScale` | 1 | 0.1～8 | 在原有年龄衰减指数上乘倍率；大于 1 更快变暗，小于 1 更晚变暗，寿命不变 |

发动机的 `radiusScale` 同时作用于环境照明与广域橙晕，最终始终限制在 **20～500 格**。不会改变喷焰几何长宽、燃烧阶段或二脉冲包络。`red/green/blue` 只调环境光颜色，喷焰自身继续使用现有橙色色比。

只有 `engine` 另外支持：

| 参数 | 默认 | 范围 | 中文含义 |
| --- | --- | --- | --- |
| `coreIntensity` | 60000 | 0～60000 | 白热核心显示前的高亮数值，即 HDR 辐射亮度；原有阶段和燃尽倍率继续相乘。现有算法以核心为发光源，设为 0 会关闭整条喷焰及它的光晕 |
| `haloIntensity` | 16 | 0～256 | 橙焰外围及广域橙色光晕的显示前亮度；0 关闭这部分橙色分量，白热核心仍可进入模糊光晕 |

核心是局部发光体，`engine brightness` 是附近地面、墙面和烟雾的受光强度，两者可分别调。高亮数值经现有显示映射后会饱和，所以把核心从 60000 改为 30000，肉眼亮度可能差别很小；需要明显对比可试 10、1、0.1 等低值。

### bloom：现有模糊光晕

| 参数 | 默认 | 范围 | 中文含义 |
| --- | --- | --- | --- |
| `enabled` | 沿用客户端 `bloom` | 0 或 1 | 同时开关模糊光晕与发动机广域橙晕，白热喷焰保留 |
| `inputPeak` | 12 | 0.001～64 | 喷焰送进模糊前的软压缩亮度上限；调高一般使这层光晕更亮。不会改变核心直接显示或独立的广域橙晕，也不改变普通爆炸/炮口光的提取亮度 |
| `blurScale` | 1 | 0～8 | 当前高斯模糊采样间距的倍率；增大扩散范围，0 不向周围扩散；不改变核权重和采样次数 |

`bloom blurScale` 调的是屏幕上的模糊范围，`engine radiusScale` 调的是按世界格数计算的广域光晕范围，两层用途不同。原有亮部提取门槛 0.08、平滑过渡 0.04 和最终合成强度 2.0 保持不变。

## 4. 实现与验证入口

- `light/RVP_LightRuntimeTuning.java`：唯一参数表、有限数校验、不可变临时覆盖和分组重置，不引用客户端类型。
- `client/light/RVP_ScreenLightDebugCommands.java`：复用现有客户端命令，参数节点由上面的定义生成。
- `client/light/RVP_ScreenLightManager.java`：从原始光源预设每帧重新采样，调参后再裁剪和排序；不反复累计倍率，不重置年龄。
- `client/light/RVP_RocketPlumeManager.java`：采样时应用同一发动机半径，保持喷焰长宽、强度包络和独立预算。
- `client/light/RVP_RocketPlumePass.java`：只向现有 `PlumeEmission` 上传核心、橙焰和光晕输入亮度。
- `client/light/RVP_ScreenLightPass.java`：只将模糊范围倍率乘到已有横/纵采样间距。
- `client/light/RVP_SmokeLightPass.java`：对已有烟雾受光输入增加单独的亮度倍率。
- `config/RVP_LightingConfig.java`：保持原有客户端配置作为基础，运行时叠加开关、亮度和距离覆盖。

以上 Java 路径均相对 `src/main/java/org/ywzj/rvp/`。本轮只修改 Java 和文档，没有写入或替换 Shader、贴图、模型、音效、载具包，也没有新增 Mixin。

自动化验证覆盖：默认预设与配置回退、已存在短光即时变化和原始年龄、先调半径再裁剪、亮度为零后恢复、发动机两种半径同步及 20/500 格边界、喷焰尺寸和推进阶段不变、分组/单项重置、非法值不覆盖、原指令兼容与命令参数节点。

本轮按仓库指定的 Java 17 环境执行完整 `./gradlew build`，**1027 项测试通过，0 失败、0 错误、0 跳过**。随后运行现有 `scripts/diagnostics/test_screen_light_gl.ps1`，在 NVIDIA GeForce RTX 4070 Laptop GPU 上通过生产着色程序、近景/DH 遮挡、喷焰核心/橙晕、广域半径及烟雾受光回归，OpenGL 错误为 0。该脚本只写 `build/` 下的诊断产物，没有改资源源文件。

实机仍需对照原版、DH、光影、DH+光影四种组合，使用真实爆炸、炮口和发动机检查画面。调参不绕过原有热成像和兼容性限制；`/rvplight status` 继续报告实际输入状态。
