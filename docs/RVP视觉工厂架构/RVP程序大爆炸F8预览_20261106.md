# RVP 程序大爆炸：F8 手动预览

2026-11-06。新增 **F8 → 程序大爆炸**，5组28项。画面包含快速撑开的白热火球、相连圆鼓火瓣、橙红冷却、翻卷黑烟、局部闪光和向外扩散的热浪。

当前仅由F8手动触发。真实载具击毁、弹药爆炸、伤害、声音和网络包均未接入；不会生成爆炸实体、粒子或修改方块。本轮不修改本体源码、载具包、结构模型，不新增Mixin。

## 使用

1. 进入世界，按 **F8 → 程序大爆炸**。
2. **右键任意分组标题 → 在准星处预览 / 重播**。面板临时收起；F8返回继续调参。默认在28格内寻找准星方块表面，没有命中则放在视线末端。
3. 连续调形状时，先在“预览位置、定格与画质”打开 **循环重播**，再预览。两轮间隔0.6秒；始终只有一团，不累积效果。
4. 查看具体阶段时打开 **定格观察**，拖动 **定格时间进度**。0为点火，1为散尽；默认0.08对应6秒寿命的0.48秒。定格同时冻结内部噪声、空气壳和烟团漂移，仍可走动观察。
5. **停止爆炸预览**立即清除；单次播放默认6秒后结束。单次已播完时，修改循环/定格不会自动重新创建，需要再次点预览。
6. **本地配置 → 保存本地**沿用 `config/ywzj_rvp-tuning-client.json`。支持搜索、撤销、单项/分组/分类恢复默认；打开分类不产生覆盖，保存参数也不会自动播放。

除“预览放置距离”在下次放置时读取外，其余参数在当前效果下一帧生效。关闭定格会从所选进度继续播放；循环时间过长也不受电脑墙上时钟影响，游戏暂停时动画随游戏停止。换世界、登出和资源重载清除预览，参数仍保留。

## 绘制方式与边界

“屏幕空间体积”是在屏幕每个像素沿视线取16～64个点，计算这些点穿过多少火焰和烟，再合成到场景；位置和噪声坐标仍在世界中，因此转头、走近时具有体积和透视。形状、颜色、烟和噪声都由数学函数生成，没有新增火焰图片或动画序列。

- 复用现有近景和DH远景深度。深度描述当前画面前方表面的位置；墙、载具等不透明物体会截断后方火球，镜头在火球内部也能绘制。
- 只在保守包围球投影的矩形内绘制；只有一团手动预览，采样硬上限64。无预览、结束或停止后不为本效果复制场景、积分或申请额外显存。
- 热浪仅重采样屏幕已有背景，无法显示画面外或原本被挡住的内容。偏移后若读到前景或手持物，撤销该偏移，减少边缘串色。
- 先完成现有灯光和尾烟，再复制最新合成颜色给热浪；不覆盖其它效果的背景。所有输出保留原场景Alpha（透明度），不写世界深度。
- 延续现有屏幕空间通道的热成像限制：本体热成像开启时不画彩色爆炸，本轮不新增热源。
- 透明玻璃、水面、粒子以及其它半透明烟团之间不做完整三维排序；只有当前画面提供的不透明深度能参与可靠遮挡。
- 本轮没有全场景泛光、真实烟内多次光线散射、碎片、贴花或屏幕震动。现有“爆炸照亮、光晕与天空”参数不会自动套入本预览。
