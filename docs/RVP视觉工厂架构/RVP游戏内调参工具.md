# RVP 游戏内调参工具

实现日期：2026-10-31。第一阶段接入屏幕空间特效：环境光总设置、爆炸照亮与光晕、炮口照亮与光晕、发动机喷焰与照亮、多层柔化光晕，以及球形冲击波的空气折射。这里的“屏幕空间”指在客户端最终画面上合成效果，不修改服务器伤害或 Minecraft 的真实方块光照。

2026-11-05新增独立的 **“延时炮口白烟”** 分类：四组38项，覆盖喷烟时序、生成范围、烟量、初速、上浮、空气阻力、连续旋涡、风、运动继承、尺寸、浓度、消散、灰度和局部受光。原有8项指令参数和新增30项均实际接入白烟；完整清单见[载具炮口烟实现与调试](RVP载具炮口烟实现与调试_20261002.md)。沿用现有贴图，不增加美术资产。

## 使用方式

- 游戏内按 **F8**，或输入客户端指令 **`/rvptune`**。不要求乘坐载具，不需要服务器管理员权限。按键可在原版控制设置的 YWZJ RVP 分类里修改。
- 也可以从 **Mods → RVP → 配置** 进入。
- 外观按参考图绘制：灰紫色不透明浮窗、居中的“— 配置”标题、顶部搜索与右侧操作按钮、左侧窄分类栏，以及名称/滑条/数值框同一行。初次打开时左边约在屏幕宽度36.1%、顶部在高度62.5%、窗口宽约48.2%，右侧保留世界画面；小窗口或较大的GUI缩放会限制最小宽高，避免输入框无法操作。
- 拖动标题栏移动窗口，拖动四条外边框、边角或右下角手柄调整大小。初始窗口贴近屏幕底部，可以直接拖动上边框向上扩展。最小尺寸为280×110个GUI像素（即Minecraft按界面缩放换算后的尺寸），窗口始终限制在屏幕内，内部两栏同步调整可视范围。
- **F8、Esc或菜单关闭后再打开，会恢复本次客户端会话中上次的位置、大小、所选分类、搜索文本、折叠状态和两栏滚动位置。** 改变分辨率或GUI缩放时，窗口按原来的相对位置和尺寸换算并限制在屏幕内。这份界面记忆不跨客户端重启保存，也不影响“撤销本次”的参数快照。
- 左侧切换分类；右侧点击分组标题折叠或展开。两栏独立滚动，鼠标只能操作当前列表区域内的项目。
- 搜索支持中文名称、参数键和说明；输入后跨全部分类搜索，多个空格分开的词需要同时命中。`Ctrl+F` 定位搜索框。
- 拖动滑条或直接输入合法数值即修改。首批参数滑条统一按声明的上下限线性赋值：最左端为下限，最右端为上限，中点为两者平均值（例如0～256的中点为128）。持续拖出滑条或面板后仍由原控件处理，数值夹紧到上下限，松开后结束拖动。未编辑的数值框固定从整数开头显示，长小数不再自动滚到末尾造成“数字乱跳”；完整文本保留供手动编辑，回填和移动光标不写回参数。红色文本表示尚未应用，原来的有效值仍保留；非法输入不会进入渲染器，也不能直接保存。支持小数和科学计数法。
- 悬停可查看宽黑底浅色细边的说明，包含作用、单位、默认值、范围和生效时机。**右键参数行**清除单项覆盖；**右键分组标题**打开该组的预览与“恢复本组默认”菜单，左键仍折叠/展开。
- 搜索框右侧的 **本地配置** 菜单提供保存、撤销、恢复当前分类、观察画面和关闭。恢复分类只操作左侧选中的分类，即使搜索结果包含其它分类也不会连带重置。
- 从分组菜单点预览后自动收起面板，方便观察短暂效果。**F8、Esc 或右上角“返回调参”** 回到原面板，搜索、滚动和当前参数仍保留。“本地配置 → 观察画面”也可以手动切换。

面板不暂停单人世界。关闭面板保留当前会话的调整；光照、光晕和喷焰参数下一显示帧生效。**冲击波在生成时取得整份数值，必须重新预览或等待下一次爆炸，正在播放的效果不跳变。** 地面环和马赫杆仍由原代码关闭，本阶段不提供无效控件。

**延时炮口白烟在下一次成功开火或预览时取得整份参数，已排队和已生成的烟继续使用原数值。** 右键“时序与喷烟节奏”组标题可选45毫米或125毫米无伤害预览；它是玩家前方的静止烟源，运动继承需要真实载具开火观察。白烟速度在F8显示为格/秒，原 `/rvpmuzzlesmoke` 指令仍使用格/刻。面板整刻/整枚输入会四舍五入，最小值越过最大值时同步推开另一端，反向同理。

若原版“平滑视角”（电影式缓慢跟随鼠标的视角）也绑定F8，打开面板时仅消费这一冲突动作的待处理点击，避免首次打开后视角变得粘滞。工具不修改原有按键绑定，也不强制关闭玩家已经主动开启的平滑视角；单独绑定其它按键时仍由原版处理。

发动机照亮与外晕沿用 `ywzj_rvp-lighting-client.toml` 的选择，默认关闭；面板不会因为打开或浏览就开启它。白热喷焰仍独立保留。“HDR”如出现在说明中，表示显示映射前的高亮数值，数值减半不一定等于肉眼亮度减半。

## 独立日志

错误和操作信息统一输出到**当前客户端游戏目录的 `logs/rvp-tuning.log`**，默认记录，不需要额外开调试开关。文件使用UTF-8中文编码，启动时追加，不清空已有记录；错误包含完整异常堆栈和原因链。

- `BOOT ui=reference-20261031-v5`：当前客户端确实载入了数值框回填与光标误写修复，以及实际gameDir、Java版本；包含此前的滑条、缩放、记忆和F8修复。
- `REGISTER`、`PRESET_LOAD`、`PRESET_SAVE`：已注册的分类/参数数、预设文件路径、实际覆盖和加载/保存结果。
- `SCREEN_CREATED`、`LAYOUT`、`PANEL_MOVED`、`PANEL_RESIZED`、`SCREEN_CLOSED`：界面创建、真实画面像素、GUI缩放、窗口与参数区坐标、移动或缩放后的坐标、关闭时的覆盖和平滑视角状态。
- `VIEW_STATE_SAVE`、`VIEW_STATE_RESTORE`：关闭或重建时保存与恢复的窗口、分类、搜索、折叠和滚动位置。
- `HOTKEY_CONFLICT_SUPPRESSED`：已拦截同键的平滑视角动作，包含消费点击数与当时的平滑视角状态；打开与关闭也会记录该状态，便于检查是否被误切换。
- `SEARCH`、`SELECT_MODULE`、`GROUP_TOGGLE`、`MENU_OPEN`、`ACTION`：搜索、分类切换、折叠和菜单操作。
- `PARAM`、`PARAM_RESET`、`INPUT_REJECT`：包含完整参数键的有效修改、恢复和非法输入原因。滑条只在松开后记录一次最终值、0～1位置和上下限，不逐帧记录拖动过程；相同的未完成输入原因也不会逐字重复警告。
- `*_FAILED`：初始化、模块注册、渲染、预览、写入及文件读写失败，随后附完整异常链。

排查时优先阅读该文件最后一次 `BOOT` 之后的记录。仅有 `BOOT` 而没有 `REGISTER`，说明尚未完成客户端初始化；正常渲染每一帧不写日志。独立日志本身写盘失败时只向主日志报告一次故障，不会让调参工具崩溃。

2026-11-05白烟接入后的登记回归为 `REGISTER bus=MOD modules=[screen_space, muzzle_smoke] options=141`，其中白烟4组38项，其余为屏幕空间特效参数。注册回归保留“游戏总线尚未启动”的真实条件，按生产订阅注解选择加载总线并执行实际回调；后续扩展会继续增加数量。

## 保存与撤销

| 操作 | 结果 |
| --- | --- |
| 本地配置 → 关闭面板 / F8、Esc关闭 | 保留当前会话的有效调整、窗口和浏览位置，不自动写盘 |
| 保存本地 | 保存到当前游戏目录 `config/ywzj_rvp-tuning-client.json`，下次启动客户端自动载入 |
| 撤销本次 | 恢复本次打开面板前的会话覆盖；不修改已经保存的预设文件 |
| 逐项 / 分组 / 分类重置 | 清除对应覆盖，重新使用代码默认值或原有客户端 TOML；需要再点保存才改变下次启动的设置 |

预设只接受当前 `schema_version: 1` 格式。所有已知值完整校验后才统一应用；如果坏文件、越界值或业务层拒绝导致载入失败，之前的有效状态保留，界面和日志会给出原因。未注册扩展的参数会跳过并报告数量；重新保存时只输出当前已注册参数。保存先写同目录临时文件，完成后再替换原文件。

界面与 `/rvplight set/reset`、`/rvpshockwave set/reset`、`/rvpmuzzlesmoke set/reset` 直接共用各自的业务存储。命令的修改也可用面板保存；命令重置仍只清除会话覆盖，只有显式“保存本地”才更新磁盘文件。因此未保存的命令改动在重启后会被上次保存的预设替代。参数底层定义见 [光照与光晕调参](RVP光照与光晕游戏内调参.md)、[冲击波调参](RVP冲击波游戏内调参.md) 和[炮口白烟调参](RVP载具炮口烟实现与调试_20261002.md)。

## 后续分类如何接入

采用“增加模块，不改通用面板”的方式，也就是开闭原则：扩展功能时，原来的界面、搜索、重置和保存代码保持稳定。

1. 新建 `RVP_TuningModule` 实现，提供稳定 `id`、显示名、说明和不可变 `Group` 清单。稳定键只接受英文大小写、数字、下划线，不能用显示名称做保存键。
2. 每项使用 `RVP_TuningOption` 绑定**现有业务层**的默认值读取、覆盖读取、写入、单项重置。不存在覆盖用 `OptionalDouble.empty()`，不要把所有默认值提前写回业务存储。默认值可以动态读取 TOML。
3. 数值选用 `Control.NUMBER`，开关选用 `Control.TOGGLE`（严格0/1），有限选项选用 `Control.CHOICE` 并传入中文选项列表（保存从0开始的整数序号，按钮循环选择）。同时提供中文名称、作用、生效条件、单位、范围。现有数值模块统一传入`sliderScale=0`，让滑条位置与上下限之间的数值成正比。通用接口保留正数尺度供未来明确需要对数换算的模块选用；文本输入不受滑条精度限制。
4. 需要按钮时添加 `Action`，操作直接调用本地业务方法并返回可读结果；失败抛出可读异常。`showWorldAfter=true` 表示成功后临时收起面板观察，普通操作可用三参数构造器保持面板打开。不要把服务端管理命令藏在这里。
5. 用 `@Mod.EventBusSubscriber(value = Dist.CLIENT, bus = MOD, modid = RVP_MOD.MOD_ID)` 监听 `RVP_RegisterTuningModulesEvent`，调用 `event.register(new YourModule())`。启动器在客户端setup的主线程任务中通过`ModLoader.postEvent`向MOD加载总线发布一次事件，之后封存目录、加载预设。**这里必须使用MOD总线**：Forge游戏总线直到客户端加载完成才启动，setup时向游戏总线发布会被忽略，日志表现为`REGISTER modules=[] options=0`。按键、客户端命令等运行期事件仍监听FORGE总线。

不需要给 `RVP_TuningScreen`、`RVP_TuningPresetStore` 或启动器增加业务 `switch`，也不需要新增 Mixin。完整参数键由 `分类id/分组id/参数id` 组成；重复键或非法默认值在注册阶段明确报错。模块的读写器只在客户端主线程使用。业务层需自行维持跨参数约束，并保证对旧状态的恢复仍然合法。

### 代码入口

以下路径相对 `src/main/java/org/ywzj/rvp/`：

| 文件 | 职责 |
| --- | --- |
| `client/tuning/RVP_TuningModule.java` | 分类、分组和可选操作的扩展接口 |
| `client/tuning/RVP_TuningOption.java` | 参数元数据、业务绑定、校验及滑条数值换算 |
| `client/tuning/RVP_TuningRegistry.java` | 目录、跨分类搜索、只保存覆盖的快照和失败回滚 |
| `client/tuning/RVP_RegisterTuningModulesEvent.java` | MOD加载总线上的客户端扩展注册事件 |
| `client/tuning/RVP_ScreenSpaceTuningModule.java` | 首批屏幕空间特效适配器 |
| `client/tuning/RVP_MuzzleSmokeTuningModule.java` | 延时炮口白烟四组38项、格/秒换算和无伤害预览 |
| `client/tuning/RVP_TuningPresetStore.java` | 当前格式预设的读取和临时文件替换保存 |
| `client/tuning/RVP_TuningClient.java` | 客户端启动、F8、命令和 Mods 配置入口 |
| `client/tuning/RVP_TuningInputGuard.java` | 同键平滑视角点击的消费策略，保留原来的视角设置 |
| `client/tuning/RVP_TuningViewState.java` | 会话级窗口/浏览快照、可见范围限制与四边缩放计算 |
| `client/screen/RVP_TuningScreen.java` | 只读取通用描述的可滚动界面，不引用具体特效类 |
| `client/tuning/RVP_TuningTheme.java` | 灰紫浮窗与紧凑控件绘制；数值框隔离只读回填与真正文本编辑，不参与参数业务 |
| `client/tuning/RVP_TuningLog.java` | 独立UTF-8操作和错误日志；每次写入即刷新，日志自身故障不影响游戏 |

自动化测试覆盖业务绑定、默认值与显式覆盖的区别、非法输入、内置滑条的上下限和线性中点、真实输入框的长小数回填/光标事件/缩放后显示、搜索、重复注册、失败回滚、真实预设文件往返、命令共用值、冲击波快照生命周期、窗口缩放边界、会话记忆及首次/反复打开时的平滑视角点击冲突。实机验收还应分别在常用 GUI 缩放档检查输入、拖出后的松开、缩放/移动、关闭再打开、滚动、折叠、工具提示与预览。
