# RVP 殉燃喷焰与火星 F8 调参

2026-11-05。本轮为现有地面载具殉燃增加 **“载具殉燃”分类、8组73项**，其中原有21项指令参数进入面板，新增52项实际连接喷焰与火星。继续使用现有静态火焰贴图和 `textures/nuclear/flare.png`，未新增或替换美术资产。

## 1. 使用与生效时机

1. 进入世界，瞄准64格内的地面载具。
2. 按 **F8 → 载具殉燃**；右键 **“喷焰形状与消散”组标题 → 预览准星载具殉燃**。这是本地无伤害预览，不击毁载具。
3. 面板会临时收起；按F8返回后继续调整。预览沿用原有殉燃总时长，默认残骸寿命60秒、殉燃比例40%时，一次约24秒；结束后可再次点击预览。原控制器最多60秒的预览观察窗口没有延长实际燃烧时长。
4. “本地配置 → 保存本地”保存到当前游戏目录 `config/ywzj_rvp-tuning-client.json`；下次启动自动读取。关闭面板只保留会话值。撤销、单项/分组/分类重置沿用现有机制。

喷口形状、数量、喷发强弱下一刻作用于新生成粒子；**每刻只建立一份不可变参数快照，已有火焰和火星保持出生参数**。整体渐强时间作用于当前未收尾的火柱，整体收尾时长在开始收尾时锁定；这些值都不会改变服务端决定的殉燃总时长。

F8中的速度显示为 **格/秒**；`/rvpcookoff set <参数> <数值>` 保持 **格/刻**，20刻=1秒。加速度仍显示为“格/刻²”，意思是每刻给速度增加多少。拖影用秒，比例和权重不换算。表中默认值与范围全部使用面板单位。

所有上下限在同一业务存储中联动，整刻和整次输入四舍五入。新变化默认关闭或保持原值：间歇喷发0、连续翻卷0、分层配色0、火星冷却0、拖影0、轻/中/重权重0/100/0；新增控件不会仅因打开面板而写入覆盖。

原炮口灰烟的启动值与旧reset值不一致，本轮统一以原启动值为默认：数量0.8、向前速度0.18格/刻、上浮0.08格/刻、摆动0.003格/刻²。F8恢复默认与启动现在使用同一份定义。

## 2. 参数清单

完整预设键为 `wreck_cookoff/<分组键>/<参数键>`；指令直接使用最后一段参数键。每项悬停均显示中文作用、单位、默认值、范围和生效条件。颜色以红色分量固定为1的暖色为基础，再用绿色、蓝色和亮度调节；这些数值控制火焰与火星本身的颜色，不创建环境灯。

## 3. 可供比较的调参起点

以下是手动比较用的美术起点，**没有自动套用，也不是最终定稿**：

- 间歇喷发强度0.35，基本间隔30刻，集中程度2，不规则程度0.35。
- 火焰分层配色占比0.6；开启末端自然消散，末端消散起点0.7。
- 连续翻卷强度0.003、尺度2格、变化速度1；远端世界向上占比0.5。
- 火星基准半宽0.07格、随机差异0.35、冷却强度1、冷却曲线0.8、拖影时间0.025秒、最大拖影0.35格。
- 细小/中等/较大碎屑权重70/25/5；再根据实际画面调整数量与亮度。

三类的固定相对倍率：

| 类别 | 尺寸 | 初速 | 寿命 | 空气阻力 |
| --- | ---: | ---: | ---: | ---: |
| 细小 | 0.45 | 0.65 | 0.35 | 1.7 |
| 中等 | 1 | 1 | 1 | 1 |
| 较大 | 1.8 | 0.8 | 1.4 | 0.5 |

三类使用同一重力；短寿命表现轻颗粒更早冷却，空气阻力体现轻重差异。所有权重为0时回退中等火星。拖影只拉伸现有贴图在画面内的速度方向，不延长真实飞行、不扩大碰撞盒，也不会把朝镜头飞行的速度误画成横线。纹理本身仍是现有放射光斑，想消除原有尖刺轮廓仍需后续美术素材。

## 4. 接入范围与实现

- 控制器继续使用原有遍历、自动挂点、距离分档、单车与全局粒子预算，未增加世界实体遍历。舱盖火柱、接缝只喷火星、炮口只出灰烟的分工保持。
- 同一舱盖结构盒上的三处采样点与火柱共用稳定压力相位；不同出口错开。压力连续变化，联动生成量、喷焰高度、初速和浓度。
- 火焰保留每颗固定静态贴图；新增程序配色、连续气流和可选末端消散。循环模式中重铺位置会同步上一帧坐标，避免插值形成逆向贯穿柱身的移动。
- 殉燃火星使用新增 `spawnCookoff` 入口；装甲命中仍调用原 `spawn`，其原颜色、重力、弹跳与淡出不读取殉燃覆盖。
- 未加入动画贴图、热扭曲、额外环境照亮或声画峰值同步；本轮面板没有为尚未实现的功能放置空控件。
- 未新增Mixin、网络包或协议变更，未修改本体源码、结构模型或载具包资产。
