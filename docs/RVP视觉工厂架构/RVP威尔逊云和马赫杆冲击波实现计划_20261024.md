## 一、增加服务端冲击波参数

新增一个运行时数据结构，例如：

```
RVP_ShockwaveProfile
```

建议包含：

```
hitClass       爆炸类型：AIR、GROUND、BURIED
groundY        爆心附近地面高度
solidity       地面包围程度，0 到 1
reach[8]       八个方向的冲击范围
```

`reach[8]` 固定采用以下顺序，避免客户端和服务端理解不一致：

```
0：+X
1：+X +Z
2：+Z
3：-X +Z
4：-X
5：-X -Z
6：-Z
7：+X -Z
```

这个数组不表示真实爆炸压力，而是表示“视觉冲击波在不同方向应该扩展多远”。

### 爆炸类型判断

服务端使用 `Heightmap`，也就是 Minecraft 保存的地形高度缓存：

```
爆心高度 - 地面高度 > 2.5格：AIR
爆心高度 - 地面高度 < -1格：BURIED
否则：GROUND
```

实际阈值应根据测试调整。

### 八方向范围计算

不必读取真实爆炸方块列表，第一版可以使用地形采样：

1. 以爆心为中心分成 8 个方向；
2. 每个方向采样若干个距离点；
3. 检查该方向的地面高度变化和障碍物；
4. 得出该方向的 `reach[i]`。

建议初始公式：

```
visualRadius = max(4, baseExplosionRadius × 2.5)

reach[i] =
    visualRadius × (0.65 + 0.35 × terrainOpenFactor[i])
```

其中 `terrainOpenFactor` 表示该方向是否开阔。这样可以得到：

- 平地：接近圆形；
- 山坡或建筑旁：冲击环不对称；
- 埋藏爆炸：冲击环更宽，但亮度更低；
- 空爆：不生成明显地面马赫杆。

`solidity` 可以先用视觉启发式计算：

```
GROUND  ≈ 0.7
BURIED  ≈ 1.0
AIR     ≈ 0.1
```

它表示“爆炸能量被地面约束的程度”，不是物理压力值。

## 四、客户端分四层绘制

### 1. 威尔逊云层

复用现有 [RVP_NuclearVisualManager.java (line 570)](D:\\WgameProject\\limitless-vehicle-rvp-addon\\src\\main\\java\\org\\ywzj\\rvp\\client\\nuclear\\RVP_NuclearVisualManager.java:570) 中的云团思想：

- `RING`：环形云；
- `CONDENSATION`：凝结云带；
- `STANDARD`：向上升腾的云。

### 2. 地面冲击环

在 `groundY + 0.05` 高度绘制一个扁平环形网格。

每个角度的半径由 `reach[8]` 插值获得：

```
radius(angle) = lerp(reach[sector], reach[nextSector], sectorFraction)
```

这样冲击环可以根据服务端给出的 8 个方向范围变形，不再是完美圆形。

地面爆炸效果：

```
GROUND：完整冲击环
BURIED：更宽、更厚、更暗的尘环
AIR：不绘制地面冲击环
```

### 3. 马赫杆近似

不做真实流体计算，而是绘制一个“低矮的竖直冲击前沿”。

建议结构：

- 一圈沿地面扩张的高亮环；
- 环内侧增加一圈竖直半透明墙；
- 墙体高度由 `solidity` 和爆炸半径决定；
- 靠近爆心的部分更厚、更亮；
- 随时间迅速向外扩张并衰减。

初始视觉公式：

```
stemHeight =
    clamp(visualRadius × (0.15 + 0.65 × solidity), 2, 24)
```

这不是马赫杆真实高度，而是保证画面中能看到“地面反射冲击前沿”的参数。

### 已落地的调用链

- `RVP_DefaultDetonationVisualResolver` 仅为 `rvp:wilson_mach_shockwave` 调用 `RVP_ShockwaveProfileSampler`。采样发生在实际爆炸破坏方块之前；八方向各八点，只读取已加载区块。未加载方向按爆心高度回退，不额外加载或生成区块。
- `RVP_ShockwaveProfile` 保存爆炸类型、地表高度、地面约束程度及八方向半径。方向顺序为 +X、+X+Z、+Z、-X+Z、-X、-X-Z、-Z、+X-Z。数据不可变，非法浮点数、方向数量及越界半径都会被拒绝。
- `RVP_VisualEffectEvent` / `S2CVisualEffectEvent` 增加可空的形状字段；视觉消息 schema（消息结构版本）为 2，网络通道协议 29 → 30，客户端和服务端必须一起更新。其它效果发送 null，不采样地形；不支持旧格式迁移。
- `RVP_WilsonMachEffectFactory` / `RVP_WilsonMachEffectInstance` 负责生成与回收效果。`RVP_WilsonMachRenderer` 绘制云柱、环云、凝结云、地面尘环、马赫杆近似墙和核心闪光。
- 核爆原来的云团运动与颜色算法移入 `RVP_ShockwaveCloudField`，核爆继续使用原参数；新效果用独立的短时间线。核爆保留专用 `RVP_NuclearShockwaveRenderer`；新工厂使用 `RVP_ShockwaveRenderer`。两者复用着色器资源和 `RVP_ShockwaveMesh` 的相同网格算法，球壳实例及控制参数相互独立。
- 新工厂折射在 `RVP_ClientVisualEvents` 中统一推进和绘制，每次世界绘制只为新工厂复制一次场景颜色；核爆按原顺序独立复制和绘制，二者同时出现时会有两次场景复制。热成像仅重画新效果几何，不复制屏幕或切换热缓冲。

### 启用方式

在选定武器的 `detonate_data.visual_effect_data` 数组加入下面条目。这里只提供配置示例，本轮没有修改任何武器或载具包文件：

```json
{
  "enabled": true,
  "effect_type": "rvp:wilson_mach_shockwave",
  "preset": "rvp:default",
  "scale": 1.0,
  "density": 1.0,
  "duration_ticks": 220,
  "broadcast_range": 8192,
  "sound": true,
  "flash": true,
  "shake": true,
  "suppress_native_explosion_effect": true
}
```

本类型目前使用固定内置形态，没有专属预设资源或额外 JSON 键。`scale` 控制尺寸，`density` 控制云团数量，`duration_ticks=-1` 使用 220 tick（约 11 秒），其它正值按比例伸缩整条时间线。`scale=0` 或 `duration_ticks=0` 不创建实例。`density=0` 不生成云团，几何环和折射仍存在。

- 标准密度为每次 384 个云团，最大 512 个，距离不会减少云量；同屏最多四个本类型实例，超出时清理最旧实例及其球壳、延迟音。
- 本类型的实际广播距离至少 8192 格；代码保留更大的显式配置，但设计验收范围为 8192 格。绘制远裁剪面为 10000 格。
- 基准视觉半径为 `min(2048, max(4, baseExplosionRadius × 2.5) × scale)` 格；2048 是视觉几何保护上限，不改变伤害半径。
