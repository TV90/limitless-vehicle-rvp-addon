# 冲击波游戏内调参

**当前状态（2026-10-26 白雾内浓外淡）：`explosion_data.radius >= 8` 自动追加的压力波，朝向玩家的中心通透；可见波带内侧白雾较浓，向外逐渐透明，最外层用空气折射表现薄而有力的前沿。** 地面环、马赫杆通过 `RVP_ShockwaveRuntimeTuning` 的 `GROUND_RING_ENABLED` / `MACH_STEM_ENABLED` 代码常量继续临时关闭；指令调参和 reset 不会重新开启它们，关闭组件也不延长实例寿命。

**实现半径、扩张、寿命、淡出和空气层压薄公式，在 Forge 1.20.1 中独立实现画面合成。** 每个像素先求视线穿过内外两个球体的位置，再只沿朝向玩家的一侧采样；背面不再叠上来。根据视线与波面的夹角，让正面中心逐渐透开，外围仍保留宽厚的空气层，内外边缘都平滑消失。波前向外推挤背景，后方有较弱的反向恢复；微弱色散让折射边缘略有颜色分离。雾形按爆心固定，转动相机不会带着纹理旋转。

2026-10-26 在同一外半径处叠加一道较薄的透明压力层。它只扭曲后方景物，不增加白雾；前 8% 寿命迅速建立推力，然后由强转弱。随后根据“中心应更透明、现在看起来像球”的反馈，改为正面通透画法。再根据“白雾透明度由内向外递增”的反馈，把白雾厚度从空气折射中独立出来，按内浓外淡分布；外侧空气仍有原来的推挤与回弹。压力层仍包含在雾层中，范围、速度、寿命、厚度曲线和力度参数沿用前一轮数值。

**经用户分别确认，先前新增 `pressure_wave_volume.vsh/.fsh/.json` 和 `pressure_wave_front.fsh/.json`，本轮另名新增 `pressure_wave_mist_gradient.fsh/.json`。** 每轮写入前均完整检查源码资源及载具包资源，未发现同名文件。当前使用白雾渐变程序，复用原 `pressure_wave_volume.vsh`，其余程序保留；既有 `shockwave_white.*`、`warp_world.*` 原样保留，HBM 核爆继续独立使用原 `warp_world`。

正面通透程度以实际波面为准，不固定在屏幕中央：令 `f` 为视线正对波面的程度（正对为 1，切线为 0），`u = sqrt(1-f²)`，中心可见强度 `C = smoothstep(0.12, 0.62, u)`。折射乘以 `C`，白雾乘以 `C^1.5`，保留清晰中心。计算到视线最靠近爆心处就停止，避免远侧球壳叠加；波面经过镜头、玩家进入内侧空腔后不再显示背面。

白雾和空气分别累计厚度：令 `q` 为从空气层内半径到外半径的进度（内为 0，外为 1），白雾在原平滑密度上乘 `2.2 × (1-q)^1.6`，使厚雾集中在内侧。令 `P` 为可见波带内缘到外缘的进度，白雾再乘 `(1-P)^1.35`，避免斜着看时外沿又变得更白；角度系数为 `0.35 + 0.65 × (1-f)^0.7`。内缘和外缘仍平滑消失。上述渐变只影响白雾，压力折射继续使用原空气厚度和原计算。

绘制程序读取当前画面的颜色与深度副本，再输出已经包含背景的最终颜色。颜色使用半精度浮点副本，保留光影画面中的高亮信息；深度使用最近点采样，避免物体边界被错误插值。每帧只复制一次深度；各层依次读取前一层合成后的颜色。最多保留 8 个爆炸，每个最多绘制一层宽厚空气和一层透明压力，共 16 次提交；压力力度为 0 或关闭折射时跳过压力层。离屏效果不复制画面；只在保守屏幕包围框内计算，每段空气最多采样 8 次。

**位置与遮挡：** 地爆、埋爆和空爆都从真实爆心向四周扩张，显示时只取朝向玩家的波面。完整世界画面合成后（`AFTER_LEVEL`）才读取背景，沿用世界绘制时保存的投影和包含镜头摇晃的观察矩阵；用场景深度裁掉被前景挡住的空气，折射采样也会检查前景，防止把近处物体拖入远处波面。不写入世界深度，不查询高度图、不加载区块。颜色及深度只在显存内临时复制；切换世界时释放，缩放窗口时按需重建。当前绘制缓冲、读取缓冲、纹理绑定、顶点绑定、混合与剪裁状态均在结束时恢复。

Forge 47.4.13 的 `GameRenderer.renderLevel` 在 `AFTER_LEVEL` 传出的 `PoseStack` 实际是构造投影时使用的栈，不能当成观察矩阵。实现先在 `AFTER_WEATHER` 保存真正的地形观察矩阵及配对投影，最后再读取完整画面合成；每帧消费后失效，切换世界时清理，避免相机转动后爆心跑偏。深度存在性通过当前缓冲的附件查询，兼容核心 OpenGL；不使用该模式已经移除的 `GL_DEPTH_BITS`。

参考目录中的光影路径提供内外半径、亮度及压薄参数，实际画面还取决于配套光影包。本实现直接完成空气层积分和背景折射，外观需要结合游戏内光影验收；Voxy/DH 的远景深度若不在当前场景深度中，仍需对应环境实机核查。没有新增武器 JSON、网络字段或 Mixin；自动门槛、主爆炸视觉和已有冲击波去重规则保持原样。显式威尔逊效果的独立云团、声音和闪光继续沿用原时间线。

2026-10-25 起，地面环和马赫杆按本次用户确认的近似方案处理。对照依据和未映射项见文末。

`/rvpshockwave` 是客户端指令，支持单机和联网，不需要服务器管理员权限。只影响自己看到的画面，不改伤害、破坏范围或其他玩家画面，不保存到 JSON。参数保留到退出游戏进程；重进世界不会自动重置。

覆盖范围是自动追加的三种冲击前沿，以及显式配置的 `rvp:wilson_mach_shockwave` 中相同的三个组件。HBM 核爆自己的球壳、温压工厂自己的压力波和地面组件不使用这组参数；威尔逊云团、声音、闪光也保持原时间线。

## 指令

```text
/rvpshockwave help
/rvpshockwave status
/rvpshockwave status sphere
/rvpshockwave set sphere speed 2
/rvpshockwave set sphere pressureStrength 1.5
/rvpshockwave set ring speed 2
/rvpshockwave set mach speed 2
/rvpshockwave preview 16
/rvpshockwave preview 16 10
/rvpshockwave reset sphere
/rvpshockwave reset
```

`sphere` 代表球形空气层；`ring` 是地面冲击环，`mach` 是马赫杆墙体（后两组当前停用）。指令的组名和参数支持 Tab 补全，`status <组>` 会显示启用状态、中文含义、当前值、默认值和允许范围。修改和重置均从**下一次爆炸或预览**生效，已开始的效果使用固定快照，避免画面突然跳变。

新增球体外观参数也支持 `/rvpshockwave set sphere <参数> <值>`：

| 参数 | 含义 | 默认 | 范围 |
| --- | --- | --- | --- |
| `brightness` | 凝结白雾强度，乘以生命周期淡出；0 可单独观察折射 | 0.2 | 0～2 |
| `thickness` | 空气层厚度基数；乘以下方压薄曲线，最终最多占外半径的 0.6 | 1 | 0.02～1 |
| `initialThicknessRatio` | 刚出现时的厚度倍率 | 1 | 0～2 |
| `finalThicknessRatio` | 动画结束时的厚度倍率 | 0.25 | 0～2 |
| `compressionPower` | 压薄曲线指数；1 匀速，>1 较晚变薄 | 1 | 0.05～4 |
| `refraction` | 背景扭曲强度；0 可单独观察凝结雾 | 1 | 0～1.5 |
| `pressureStrength` | 透明压力波前的力度；0 仅显示中心通透的宽厚空气层 | 1 | 0～3 |
| `dispersion` | 折射边缘的微弱颜色分离 | 0.06 | 0～0.2 |

例如 `/rvpshockwave set sphere brightness 0.1` 可减少白雾，`/rvpshockwave set sphere refraction 1.5` 可加强空气扭曲，`/rvpshockwave set sphere thickness 0.4` 可减薄空气层；`opacity` 同时控制白雾与折射。`meshSegments` 已删除，当前连续球体由视线求交得到，不依赖网格分段数。

`/rvpshockwave set sphere pressureStrength 1.5` 可加强前沿的冲击力，不增加雾量；默认 1。设为 0 可关闭加力层，对照同一正面画法的宽厚空气层。透明压力层厚度为 `min(雾层厚度, clamp(雾层厚度 × 0.22, 0.035, 0.14))`，这里的厚度均指占外半径的比例。令 `p` 为按尺寸和整体速度换算的寿命进度，压力折射系数为 `refraction × pressureStrength × smoothstep(0, 0.08, p) × (1.35 + 2.65 × exp(-p / 0.24))`，再乘同一整体淡出；寿命外直接为零。这个时序与强度为 RVP 观感增强，不改变基础运动公式。

空气层厚度比例为 `clamp(thickness × lerp(initialThicknessRatio, finalThicknessRatio, progress^compressionPower), 0, 0.6)`，`progress` 使用球体实际寿命时钟，整体提速也会同步加快压薄。内半径等于 `外半径 × (1-厚度比例)`。`cloudCount`、`cloudSize` 不用于当前画法；空气层不生成随机云片。

`preview <爆炸半径> [离地高度]` 在玩家水平朝向前方 20 格显示本地预览；高度默认 0，正数为高于地面，负数为埋入地面。无额外云团、声音、闪光、伤害或地形破坏。当前显示空气层，与正式爆炸使用同一绘制和调参快照；八方向轮廓仅保留给已关闭的地面组件。可先 `set sphere speed 0.5` 放慢观察，再用 `reset sphere` 恢复短促的默认速度。2026-11-01 起，波面抵达玩家时也会播放新增的 0.6 秒屏幕抖动；玩家移动时每帧重算距离，强度随距离线性衰减，受 RVP 爆炸震动设置控制，详见[通用屏幕震动复用指南](../RVP通用屏幕震动复用指南.md#冲击波抵达反馈2026-11-01)。

## 共同参数

所有时间使用标准时间线中的 tick，20 tick 为 1 秒。自动追加和本地预览的基准是 220 tick；显式威尔逊效果若另配 `duration_ticks`，时间参数按 `duration_ticks / 220` 同比缩放。下面的秒数以默认基准为准。

| 参数 | 含义 | 球体默认 | 地面环默认 | 墙体默认 | 允许范围 |
| --- | --- | --- | --- | --- | --- |
| `speed` | 整体速度倍率；扩张、升墙、淡出和寿命一起加快，最大范围不变 | 1 | 1 | 1 | 0.05～100 |
| `expansionSpeed` | 只改变向外扩张速度，不压缩寿命或淡出 | 1 | 1 | 1 | 0.05～100 |
| `radiusScale` | 环/墙为位移倍率，上限 2048 格 | 1.5 | 1 | 1 | 0～20 |
| `expansionTicks` | 扩张基准时间；球体另按尺寸缩放，环/墙走完整 15 tick 粒子路程 | 12 | 15 | 15 | 1～1200 |
| `lifetime` | 基准寿命；球体另按尺寸缩放 | 12 | 15 | 15 | 1～2400 |
| `fadeInTicks` | 淡入耗时，0 表示立即显示 | 0 | 0 | 0.461538 | 0～2400 |
| `fadeStartTicks` | 开始淡出的时刻；大于或等于寿命时在结束时直接消失 | 0 | 0 | 0 | 0～2400 |
| `fadePower` | 球/环使用 `1-progress^指数`，越大越晚淡出；墙使用 `(1-progress)^指数`，越大越早淡出 | 2 | 3 | 1 | 0.1～10 |
| `opacity` | 球体空气层或地面几何的整体可见强度；0 为隐藏 | 1 | 1 | 1 | 0～1 |

球体实际扩张耗时为 `expansionTicks × 尺寸时间倍率 / speed / expansionSpeed`，寿命为 `lifetime × 尺寸时间倍率 / speed`；尺寸时间倍率为 `clamp(球体标定半径 / 60, 0.45, 2)`。环和墙不使用尺寸时间倍率。显式事件的 `duration_ticks / 220` 还会同比缩放以上时间。两个速度倍率同时改变时会叠加；`expansionSpeed` 仍只改变运动，不改变淡出时长。

例如爆炸半径 24 时，默认球体扩张到 90 格，播放约 0.9 秒；`set sphere speed 2` 压缩到约 0.45 秒。默认已经是短促冲击波，不再是旧版 11 秒的缓慢扩张。`reset` 恢复的是这套新的值。

环和墙分别调速后可以分离；希望墙体继续跟随环时，将两组的 `speed`、`expansionSpeed`、`radiusScale`、`expansionTicks`、`particleSpeedScale`、`damping` 和 `sampledBlocks` 设成相同值。

### 球形冲击波：按执行公式

- 半径：`max(2, 60 × (explosionRadius / 24)^0.8 × meshSize)`，`meshSize` 默认 1.5。使用 0.8 次幂，配置注释里的线性 `power × 2.5` 已不符合此版本代码。
- 生命周期：`meshDuration × 20 × clamp(标定半径 / 60, 0.45, 2)`，默认 `meshDuration=0.6` 秒。浮点时间用于动画，向上取整后的 tick 用于回收。
- 扩张：`R × (1-(1-progress)^meshExpansion)`，默认指数 1，即匀速。
- 淡出：`1-(当前扩张进度)^2`。RVP 保留指令扩展：只改 `expansionSpeed` 时淡出时钟独立，避免改变已有指令含义。
- 球心使用实际爆心；云团和地面几何仍使用地表原点。事件 `scale` 继续只调视觉尺寸，不扩大伤害。

### 地面环：用户确认保留几何，按粒子运动近似

环实际是 `createbigcannons:shrapnel_smoke{lifetime:15}` 为主体，加上地爆时的 cloud/end_rod 混合粒子，不是几何环。

用户确认以 `N=round(2πr³/3)` 估算方块数，最低取 200，避免破坏原 `radius>=8` 自动启用规则；通过 `sampledBlocks` 可覆盖为实测数量。**这不是原始采样数**，不能声称在所有地形中完全一致。

| 采样方块数 N | 平均初速度（格/tick） |
| --- | --- |
| 200～1999 | `(0.3 + N × 0.0008) × 1.5` |
| 2000～17999 | `(0.5 + N × 0.00025) × 1.5` |
| ≥18000 | `(0.8 + N × 0.0002725) × 1.5` |

保留原档位边界，包括 2000 处速度下降的跳变；不擅自平滑。随机速度扰动取均值零。

目录不含 CBC 依赖实现，因此另外核对 [CBC 官方 ShrapnelSmokeParticle 源码](https://github.com/Cannoneers-of-Create/CreateBigCannons/blob/create-v6-1.21.1/src/main/java/rbasamoyai/createbigcannons/effects/particles/smoke/ShrapnelSmokeParticle.java)，核查文件 blob 为 `cb431fe09c9e5b2c19c1ecb74abfbe8f122cec49`：速度每 tick 乘 0.8，透明度为 `1-(age/lifetime)^3`。这是外部依赖的源码参照。

RVP 用 `distance(n)=v0×(1-0.8^n)/(1-0.8)` 累加整数 tick 位移，小数 tick 在相邻位置之间插值。保留八方向地形缩短比例、原环宽与颜色；忽略粒子随机扰动、风、碰撞、上下飘动和外围混合粒子。地爆、埋爆均映射主体；空爆无地面环。
