# RVP 火箭发动机高亮程序喷焰实现

日期：2026-10-30。当前发动机改用 RVP 自有程序喷焰。旧模型、动画、贴图与旧圆形喷口实现完整保留，在代码中暂停，没有删除或覆盖。

## 1. 外观与参数

喷焰沿弹体尾轴喷出，喷口细、随后膨胀、末端收尖，具有白热核心、橙色外焰与光晕。轴向明暗结节和小幅波动近似喷流中的激波结构，是视觉近似，不是流体/燃烧物理模拟。

不采样本体尾焰贴图，不新增图片、模型或动画。原始 HDR 核心峰值上限 60000，上屏核心可达到白点；HDR 是显卡内部保存的高亮数值，不代表 Minecraft 方块光等级。

| 既有 JSON 或运行事实 | 当前用途 |
| --- | --- |
| `projectile_data.has_rocket_engine` 与实际燃烧窗口 | 决定喷焰是否存在 |
| `projectile_data.engine_nozzle_offset` | 喷口局部位置，默认 `[0,0,-0.5]` 格 |
| `projectile_data.flame_scale` | 统一缩放长宽，默认 0.3，非法值回退默认 |
| 二脉冲、剩余燃烧时间、有效远端燃烧快照 | 控制启停和阶段亮度，不改变几何缩放 |

代码基准长度 10 格、最大半径 1.5 格。因此 `flame_scale=0.3` 对应长 3 格、最大直径 0.9 格；`0.6` 对应长 6 格、最大直径 1.8 格。轮廓在此范围内收尖，整条喷流并非一样粗。

不按武器 ID、速度或粒子数量改变大小，不增加武器光源 JSON。颜色、峰值、光晕和动画细节均由 Java/GLSL 代码控制。Shader JSON 只声明程序接口。

## 3. 喷口与生命周期

[RVP_RocketEngineLightQuery](../../src/main/java/org/ywzj/rvp/client/light/RVP_RocketEngineLightQuery.java) 统一查询燃烧事实。远端克隆只接受有效服务端燃烧快照，不沿用尾烟宽限。

局部喷口偏移和尾轴 `(0,0,-1)` 都按 X 俯仰→Y 负朝向旋转，与弹体模型一致。观瞄伪装期间，模型、新喷焰和环境光共用 `RVP_SightFireDisguiseRender.renderOffset` 的平移与平滑合流。远端先应用本帧模型朝向，再登记喷焰，防止用上次快照方向喷出。

每枚实体用 UUID（稳定唯一标识）登记一条喷流；两 tick 无心跳淘汰，明确燃尽/实体移除立即取消。换世界、重连和时钟回退清空；暂停不使用真实时间继续播放。没有改推进、命中或网络协议。

## 4. 三维形状与 DH/光影遮挡

程序先求相机射线与有限圆柱的相交区间，再沿区间采样 20 次，计算收尖轮廓、核心和橙焰。采样终点由当前像素的最近可见表面限制。

近景和 DH 使用各自的深度、投影与观察变换，重建到同一空间后选择最近表面；不直接比较两张深度图的 0～1 数字。光影提前绘制的手持物继续作为遮罩。新程序不写场景深度，避免尾焰自遮挡。

不再因喷口中心被挡就整条删除：喷口在弹体内或墙后、尾段实际露出时，只绘制露出部分；前景墙挡住整条喷流时没有直接喷焰贡献。Bloom 是可见亮部的图像扩散，可能跨过局部轮廓，不等同于火焰几何穿墙。

极远处小于像素的喷流只补足屏幕亮点覆盖，遮挡仍使用实际几何前缘。普通透明烟没有完整深度；当前没有读取烟尘真实密度，不具备精确的透烟衰减或体积自阴影。

DH 原生与 DH+光影沿用既有公开输入桥，不因检测到 DH/光影而禁用。绘制仍在光影世界最终合成之后、CRT/TV/HUD 之前。

## 5. 预算与光晕

环境光仍最多 8 盏，发动机照亮方块/实体的半径仍为 7 格，二脉冲 5.6 格。

**喷焰独立于八灯预算和环境光默认 256 格观察距离。** 最多保留 256 条输入、绘制 128 条可见喷流，优先附近；远程实体本身的授权范围仍由原远端系统决定。关闭环境照明或将 `maxLights`/环境光 `intensity` 设为 0，不取消喷焰；`bloom=false` 只关闭光晕，核心仍高亮。

同帧共用一次近景深度、可选的一次 DH 深度和一次最终颜色复制。每条喷流只绘制其屏幕包围矩形，不为每枚导弹复制背景，也不要求喷口本身位于屏幕内。

- 核心显示使用最高 60000 原始 HDR，映射到显示白点，保留原场景 Alpha（透明度）。
- 光晕输入保持橙色色相，以 `BLOOM_INPUT_PEAK=12` 软压缩；核心显示不降低峰值。这样避免 60000 直接模糊后把有限核外沿也烧成方框。
- 多条喷流以最大值合并，避免重叠齐射累加造成半精度纹理溢出。
- 有喷焰时共用光晕使用连续标准采样步长 1，避免细长亮部被稀疏采样拉成条纹；只有旧爆炸/炮口光时仍用原步长 2。

裁剪矩形、RGB/Alpha 混合方程和其它外部显卡状态由现有 `State` 作用域恢复。
