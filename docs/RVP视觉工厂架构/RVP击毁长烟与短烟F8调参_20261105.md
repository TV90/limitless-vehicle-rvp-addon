# RVP 击毁长烟、短烟 F8 调参

2026-11-05。本轮新增 **F8 → 载具击毁烟**，共8组69项：长烟37项、短烟32项。其中16项长烟参数沿用原指令，新增53项。全部连接实际出烟或粒子更新，继续使用已有烟雾贴图。

本轮只建立推荐的可调参数清单，**不填写推荐数值、不制作效果预设**。为保持游戏可运行，F8展示原有代码默认值或玩家已经明确修改的值；仅打开面板不会产生覆盖，也不自动保存配置。新增淡入、膨胀变薄、连续翻卷和局部受光默认关闭；其它新增项目把原公式中的固定值提取为参数。

## 使用与生效时机

- 按F8，选择“载具击毁烟”；长烟、短烟各有烟源与节奏、形状与消散、浓度与颜色、上升/上浮与气流四组。中文提示含作用、单位、原始默认值、合法范围及生效时机。
- 右键“击毁长烟 · 烟源与节奏”或“击毁短烟 · 烟源与节奏”组标题，分别选择本地预览。预览在准星命中点出烟60秒；未命中时在眼前六格，不生成载具或伤害。重新预览替换当前预览烟源，已有烟自然消散。预览后面板临时收起，按F8返回。
- 短烟预览使用模拟车体范围；真实残骸仍优先从发动机实时包围盒内取点。包围盒就是随车体姿态更新的空间范围，范围倍率只改变取点，不修改结构模型或受击盒。
- **短烟一轮生成共享一份出生快照，已有短烟保持原参数。** 受损、瘫痪发动机继续走普通近烟入口，固定使用原始默认值，完全不读取击毁烟覆盖；瘫痪发动机原有橙色出生帧和向下收缩保留。
- **长烟保留原指令的实时语义**：上升、风、随风响应、微摆、翻卷、按高度膨胀、成团过程、淡入淡出和局部受光下一刻作用于已有长烟。出生颜色、浓度、尺寸、初速、转动速度与寿命在下一枚出生时取得；烟源与生成间隔在下一轮生效。
- F8速度显示为格/秒；`/rvpwrecksmoke set <参数> <数值>`继续按格/刻输入，20刻等于1秒。加速度表示每刻速度增加多少，仍使用格/刻²。周期允许小数的项目保留小数，整刻项目由面板四舍五入。
- 最短/最长寿命和初速在面板中联动；指令严格拒绝倒置区间。单项、分组、分类重置，撤销和本地保存沿用通用F8机制。
- 本地配置 → 保存本地，写入当前客户端游戏目录的`config/ywzj_rvp-tuning-client.json`，重启自动加载。完整参数键为`wreck_smoke/<分组键>/<参数键>`。原`/rvpwrecksmoke preview start|stop`继续只启动长烟或停止当前预览。

## 推荐调参顺序

先用生成间隔、单团寿命和尺寸确定烟柱连续性及体积，再区分核心与外层的灰度、浓度；随后调整上升、风、微摆和连续翻卷，最后处理淡入、淡出、膨胀变薄与环境受光。短烟先确定发动机附近的取点范围和烟量，再看近处细节与消散。连续翻卷指邻近烟团随同一片平滑气流一起翻滚，区别于每团各自左右摆动。

下表不列推荐值；实际滑条范围和原始默认值可在F8悬停查看。

## 击毁长烟 · 烟源与节奏（`long_emission`，8项）

| 参数键 | 面板名称 | 单位 | 作用 |
| --- | --- | --- | --- |
| `emitPeriod` | 长烟生成间隔 | 刻（20刻=1秒） | 每轮生成一组深色核心和较浅外层，越小烟柱越连续。 |
| `lifetime` | 长烟单团寿命 | 刻（20刻=1秒） | 每枚长烟保留多久；不改变残骸持续出烟的总时长。 |
| `horizontalOffset` | 烟源水平移动半径 | 格 | 烟源围绕车体中心移动的半径；0固定在中心。 |
| `phasePeriod` | 烟源移动周期 | 刻（20刻=1秒） | 烟源完成一次水平循环的时间。 |
| `zPhase` | 烟源南北方向相位差 | 度 | 东西和南北移动错开多少角度，决定烟源轨迹形状。 |
| `longVerticalOffset` | 长烟出生高度偏移 | 格 | 在原车体取点上抬高或降低烟源；负值向下。 |
| `longVerticalJitter` | 长烟出生高度随机范围 | 格 | 在烟源基准高度上向上随机取点，避免完全重合。 |
| `longOuterOffsetScale` | 外层烟错位范围 | 倍 | 缩放外层相对核心的水平和竖直错位；0完全同心。 |

| `longFadeInTicks` | 长烟单团淡入时间 | 刻（20刻=1秒） | 每团从透明到正常浓度的时间；0立即显现。 |
| `longExpansionFade` | 长烟膨胀变薄强度 | 系数 | 烟团变大时额外降低浓度；0关闭，越大稀释越快。 |
