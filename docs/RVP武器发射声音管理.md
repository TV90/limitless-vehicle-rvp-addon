# RVP 武器发射声音管理

当前实现只接管**轮式或履带式地面载具发射、且有效口径达到 220 mm 的火箭发射声**。口径优先读取武器数据根级 `caliber`，根级为空时读取 `effects_data.caliber`；单位均为毫米，两个字段都没有有效值或小于 220 mm 时不使用大口径音频。火箭类型按 RVP 武器数据的 `ROCKET` 分类，或本体的火箭武器类型判断，不按具体载具或武器 ID 判断。

声音选择顺序：

1. 武器表现文件 `assets/<命名空间>/display/weapon/<武器 ID>.json` 的 `sounds` 中，只要有任何声音 ID 不属于 `ywzj_vehicle`，保留该武器现有的整套声音。包括 `fire`、`reload`、`sight_fire` 等键；例如自定义换弹声也会阻止默认发射声接管。
2. 满足 220 mm 门槛的地面火箭没有上述自定义声音，且 RVP 火箭音频存在时，发射声使用 `assets/ywzj_rvp/sounds/default/rocket_launch/large/large_rocket_launch.ogg`。没有武器表现文件的火箭也走此分支。
3. 两级口径都小于 220 mm、未填写口径或口径无效的火箭，其他武器/载具，以及 RVP 火箭音频不存在的情况，保持原有声音播放链；如果表现文件配置了 `ywzj_vehicle` 的声音，继续使用它。换弹声、弹壳声和爆炸声目前没有新增默认接管。

客户端通过开火完成事件选择声音，复用已有抑制机制取消同一发的本体发射声，避免叠音。已有的观瞄声和相机相对开火声处理器会在 RVP 默认声接管时让出；配置了 `audio_info.camera_relative_fire_sound_distance` 的载具仍让替换声沿用该定位方式。未配置时，替换声使用本体发射声的音量与位置。

火箭音频由客户端在内存中构造声音描述，再交给原版资源系统读取现有 `.ogg`，不修改或覆盖用户已有的 `sounds.json` 与音频文件。资源缺失时不抑制本体声。当前路径不依赖在 `sounds.json` 中注册 RVP 默认声音事件；正常的武器自定义声音仍使用载具包已有的 `sounds.json`。

验收建议：分别检查 M142 的 M-31、两种没有表现文件的 M30、ATACMS；检查一把配置了非本体声音的地面火箭，以及一把机载火箭。应分别验证车内、车外和多人观察者，只听到一次预期发射声；换弹声和其他弹种的声音保持原有配置。
