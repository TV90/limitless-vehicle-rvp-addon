# YWZJ RVP · RealVehiclePack

## 把现代载具的“玩法层”做深

**YWZJ RVP（RealVehiclePack）** 是 **Limitless Vehicle（ywzj_vehicle）** 的大型内容与机制扩展，适用于 **Minecraft 1.20.1 / Forge**。

它不是独立的载具模组，也不是只给本体换几台车。RVP 在本体的载具框架上，补齐了自己的武器系统、辅助设备、模块化损伤、车载无人机和战术地图玩法。

> 当前版本为 `1.0.0_preview_0.6.2.1`，内容、数值与平衡仍会调整。遇到问题请附上日志与复现步骤。

## 核心玩法

RVP 目前主要围绕五块内容展开：

- **武器系统**：反辐射、人在回路、攻顶、GPS 制导、激光架束、激光制导、红外制导等导弹；AHEAD、定距空爆、破障弹、PELE、霰弹等炮弹；坐标指示吊舱、目标指示吊舱与集成火力支援；激光致盲。
- **辅助设备**：ERA 爆反、APS 主动防护、主动 ECM、光电干扰机、DIRCM、热焰弹/箔条/烟幕、维修设备等。
- **模块化损伤**：按部位和模块结算伤害，打坏什么就损失什么；维修面板按优先级恢复。
- **车载无人机与辅助载具**：普通载具带无人机协同作战；山毛榉-M3 这类载具可以放下雷达车，切换控制，打“雷达车 + 发射车”的分体式防空。
- **战术地图**：与 GPS 制导武器、防空系统联动；另有炮兵地图和小型炮兵地图。

## 武器系统

RVP 的武器不是“每台车固定一门炮”。**几乎所有 RVP 载具都有丰富的武器改装**，可以按任务更换主炮、导弹、火箭、机炮、吊舱和辅助设备。

其中 **F/A-18F** 和 **J-16** 的改装种类最多，几乎囊括了 RVP 现有的各类武器，适合用来体验完整的武器树。

### 导弹

- **反辐射导弹**：追踪敌方雷达辐射源，专门压制雷达。
- **人在回路导弹**：进入弹载电视/热成像画面，手动操控导弹飞行；可锚定目标点、切换画面、缩放倍率，按弹种配置可在命中前空爆或退出。
- **攻顶导弹**：以 TOW-2B 为代表，飞越目标上方后向下攻击，专门打坦克顶部。
- **GPS 制导导弹**：支持四种装订模式，并与战术地图联动：
  - **单点**：装订一个坐标。
  - **多点**：最多装订多个坐标，按顺序使用。
  - **快速**：把当前观瞄/CCIP 点直接装订并发射，适合连续打击。
  - **雷达**：由雷达硬锁目标，飞行中可按间隔更新目标位置。
- **激光架束导弹**：沿载机/载车发出的激光束飞行，适合精确打击移动目标。
- **激光制导导弹/炸弹**：由激光照射指示目标，适合打击点状目标。
- **红外制导导弹**：包括空空、近程防空等型号；配合**头瞄**可以在大离轴角内快速捕获、锁定和发射。

### 炮弹

- **AHEAD 弹药**：在目标附近定距抛撒破片，拦截空中目标和小型目标。
- **定距空爆弹**：按设定距离或高度起爆，对付掩体后、树冠后和低空目标。
- **破障弹**：用于破坏墙体、掩体和障碍物，为后续部队开路。
- **PELE 弹药**：穿透薄装甲后产生横向破片，兼顾穿甲与破片效果。
- **霰弹**：近距离面杀伤，适合对付步兵、轻目标和近距离突袭。

### 吊舱

- **坐标指示吊舱**：搜索、观察并标记坐标，把目标点交给 GPS 制导武器或火力支援。
- **目标指示吊舱**：跟踪目标并提供制导指示，配合激光制导武器使用。
- **集成火力支援吊舱**：在吊舱内直接选择目标并呼叫火力支援，把“观察—标记—呼叫”放在同一个界面里完成。

### 激光

- **激光致盲**：用激光照射敌方光学/红外观瞄和导引头，短时间压制对方的观察与制导能力。

### 武器改装

- 载具普遍支持多武器站：主炮、副炮、车长机枪、导弹、火箭、干扰弹发射器等可以分别配置。
- 支持挂架、弹种、弹链和变体切换；不同弹种的备弹、射速、过热、装填和弹道各自独立。
- F/A-18F、J-16 这类多用途平台可以在一台载具上体验 RVP 的大部分武器类型。

## 辅助设备

RVP 的辅助设备不是装饰品：它们有独立血量、独立功能，被打坏后会真的失效，也可以按维修顺序恢复。

- **ERA 爆反装甲**：阻挡/削弱破甲战斗部；被击穿后该块爆反消失，后续弹药不再被它阻挡。
- **APS 主动防护**：按扇区探测并拦截来袭弹药；传感器或发射器被击毁后，对应扇区失去拦截能力。
- **ECM 主动干扰**：按键触发持续干扰，压制敌方雷达锁定和雷达制导导弹。
- **光电干扰机（软杀伤干扰机）**：对进入干扰扇区的光学/指令制导导弹实施压制，让对方导弹丢失或偏离目标。
- **DIRCM 定向红外对抗**：对红外导引头实施定向干扰，使来袭红外弹偏航；同时提供对应的 HUD 提示和干扰画面。
- **热焰弹 / 箔条 / 烟幕**：按载具配置抛洒，各自独立备弹和冷却；烟幕可以遮蔽光学观察与制导。
- **维修设备**：部分载具自带维修设备，可以修复部件、恢复设备；维修设备本身也可能被击毁。

辅助设备可以通过设备面板查看状态、安排维修顺序；先修什么、后修什么，会直接影响载具还能不能继续作战。

## 模块化损伤

RVP 的载具不是一条血条，而是按部位、按模块结算：

- **ERA 爆反**：被击穿后该块失效，外观同步变化。
- **履带 / 行走机构**：失效后仍参与碰撞，但动力下降，严重时无法移动。
- **发动机**：分受损、瘫痪两级；受损降功率，瘫痪后动力清零。
- **炮管**：受损后散布恶化、可能哑火；彻底损坏后禁止射击。导弹类武器在炮管一级受损时只会发射失败或成功，不会炸膛。
- **方向机**：受损后回转速度下降，彻底损坏后炮塔只能极慢转动。
- **火控系统（FCS）**：损坏后稳定器、弹道解算和观瞄功能降级；准星仍可见，但不再给出有效弹道计算。
- **雷达 / APS / 干扰机 / DIRCM / 干扰弹发射器**：对应设备被击毁后失去搜索、拦截、干扰或抛洒能力。
- **快速维修**：维修面板按优先级恢复部件；ERA、辅助设备和关键部件可以分别安排维修顺序。
- **殉爆与飞头**：部分载具拥有炮塔殉爆、飞头、火焰和火星表现。

部位有独立伤害倍率；爆炸方向、入射角、装甲厚度和弹种都会影响最终结果。

## 车载无人机与辅助载具

### 普通载具 + 无人机

不少 RVP 载具可以携带并部署辅助载具：

- 侦察无人机、C4 自爆无人机、RPG 武装无人机、SUAV 轻型侦察无人机，以及 RAWR 无人战车等。
- 部署后可以在母车和辅助载具之间切换控制；支持自动盘旋、信号范围限制、超距自动回收和重新部署冷却。
- 母车在辅助载具出动期间会被锁定，避免出现“无人机还在外面，母车已经被开走”的情况。

这让一台普通载具可以同时承担侦察、监视、骚扰或自杀式攻击，而不需要单独再开一台载具。

### 山毛榉-M3：雷达车 + 发射车

山毛榉-M3 可以放置一台 **96L6 雷达车**，作为独立的雷达中继：

- 雷达车与发射车分开部署，可以切换控制两台载具。
- 雷达车提供目标信息，发射车负责发射；两者通过数据链联动。
- 这是 RVP 的“分体式防空车”玩法：雷达和导弹不在同一台车上，阵地可以拉开，也可以互相掩护。

## 战术地图

RVP 有一套完整的战术地图，不只是“看位置”：

- 显示地形、玩家、载具、导弹和 GPS 目标点，支持缩放、拖动、跟随和快捷标记。
- 右键目标可以直接绑定为 GPS 目标，或把目标位置填入 GPS 面板。
- 支持高弹道/低弹道选择，配合不同射程和掩体条件使用。

### 与 GPS 制导武器联动

- 在战术地图上选择目标点，装订为 GPS 目标。
- 支持单点、多点、快速、雷达四种模式；多点和雷达模式可以直接在地图/雷达面板里管理。
- 发射后可在弹道飞行中按雷达模式更新目标位置。

### 与防空系统联动

- 战术地图可以打开雷达目标列表，查看方位、距离、高度、速度和敌我识别。
- 可以直接锁定目标，或对主动雷达导弹执行快捷发射。
- 适合防空车在后方地图上接管空情，而不是只靠目视搜索。

### 炮兵地图与小型炮兵地图

- **炮兵地图**：选择目标后计算仰角和落点距离，给出高/低弹道解算，左键即可开火；适合自行火炮和火箭炮。
- **小型炮兵地图**：选中炮兵武器时，在屏幕角落显示一张紧凑地图，不遮挡主要视野；同样支持选点和左键开火，适合快速转移火力。

## 安装与更新

### 先看这里

- **RVP 是 Forge 模组，不是整合包容器。** 下载到的 `-full.jar` 直接放进 `mods/`，**不要解压**。
- **不需要额外资源包。** 载具模型、贴图、音效和数据都包含在 `-full.jar` 内。
- **必须安装本体。** RVP 离开 Limitless Vehicle 无法运行。
- **首次启动会自动释放载具包。** 不需要手动把 `assets/`、`data/` 放进游戏目录。

### 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.x（建议 47.3.10 及以上；本项目使用 47.4.13 构建） |
| Limitless Vehicle | 0.6.2.1 |
| RVP | 1.0.0_preview_0.6.2.1 |
| 客户端与服务端 | 两端都需安装，且版本一致 |

### 安装步骤

1. 安装 **Minecraft 1.20.1 + Forge 47.x**。
2. 下载 **Limitless Vehicle 0.6.2.1**，将 `ywzj_vehicle-1.20.1-0.6.2.1.jar` 放入 `.minecraft/mods/`。
3. 下载 **RVP 完整版**，将 `ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar` 放入同一个 `mods/`。
4. 启动客户端或服务端一次。RVP 会把内置载具包释放到 `limitless_vehicle/rvp/`。
5. 进入游戏，在创造模式物品栏中确认 RVP 载具与物品已出现。

### 安装后的目录

```text
.minecraft/
├─ mods/
│  ├─ ywzj_vehicle-1.20.1-0.6.2.1.jar
│  └─ ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar
├─ limitless_vehicle/                 ← 首次启动自动生成
│  └─ rvp/
│     ├─ vehicle_pack.meta.json
│     ├─ assets/
│     └─ data/
└─ config/
   ├─ ywzj_rvp-client.toml            ← 首次启动自动生成
   └─ ywzj_rvp-common.toml
```

### 更新

替换 `mods/` 中的 RVP jar 即可。启动时安装器会比较磁盘上的载具包版本与 jar 内版本：

- 版本相同：保留现有 `limitless_vehicle/rvp/`。
- 版本不同：先把旧包备份到 `limitless_vehicle_backup/rvp_<时间戳>/`，再释放新包。

如果你修改过 `rvp` 内的文件，升级前请先备份；更推荐把自己的改动做成独立包名的扩展包，避免被自动更新覆盖。

### 专用服务器

服务端同样放入本体与 RVP 的两个 jar 到 `mods/`。首次启动会自动释放载具包，请确保服务端对游戏目录有写权限。客户端与服务端必须使用同一 RVP 版本与同一本体版本。

## 配置与性能

- 客户端配置：`config/ywzj_rvp-client.toml`
  - 观瞄灵敏度、LOD 缩放、温压粒子质量/音量/闪光/震动、爆炸屏幕震动、体积尾烟、远距载具渲染上限、Distant Horizons 兼容模式。
- 双端配置：`config/ywzj_rvp-common.toml`
  - 观瞄轴加速、残骸保留时间、超视距载具同步/授权/距离、区块租约与前瞻。
- 性能建议：
  - 为客户端分配 6–8 GB 内存。
  - 首次启动会从约 245 MB 的 jar 中解压载具包，磁盘较慢时请耐心等待。
  - 卡顿时优先降低温压粒子质量、屏幕震动和远距载具渲染数量；体积尾烟默认关闭。
  - 使用 Distant Horizons 时，可在客户端配置中选择兼容模式。

## 排障

**启动后没有 RVP 载具或物品？**
确认使用的是 `-full.jar`、本体 0.6.2.1 已安装、`limitless_vehicle/rvp/vehicle_pack.meta.json` 存在；在 `logs/latest.log` 中搜索 `Installed RVP vehicle pack`；首次启动后完全重启一次客户端。

**联机进不去、载具不同步或被踢？**
客户端与服务端必须使用同一 RVP jar、同一本体版本和同一载具包版本；服务端也要安装 `-full.jar`。

**更新后自己的修改消失了？**
安装器按载具包版本覆盖 `rvp`；旧包在 `limitless_vehicle_backup/rvp_<时间戳>/`。以后请把改动做成独立包名的扩展包。

**打开载具打印机崩溃，报 `NoSuchMethodError: Document.getLayout()`？**
`mods/` 中旧版 ApricityUI 覆盖了本体内置的 1.3.0。移除旧版外部 jar，保留本体内置版本即可；这不是 RVP 本身的崩溃。

**卡顿或内存占用高？**
分配 6–8 GB 内存；降低温压粒子质量、屏幕震动与远距载具渲染数量；体积尾烟默认关闭；使用 Distant Horizons 时选择合适的兼容模式。

**日志在哪里？**
`logs/latest.log`、`logs/debug.log`、`crash-reports/`。反馈时请附上 RVP 版本、本体版本，以及日志中与 `ywzj_rvp` / `RVP` 相关的片段。
