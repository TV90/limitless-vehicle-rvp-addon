# YWZJ RVP · RealVehiclePack

适用于 Minecraft 1.20.1 / Forge 的 Limitless Vehicle 载具扩展。

当前版本：`1.0.0_preview_0.6.2.1`。预览版的内容、数值与平衡仍会调整。反馈问题时请附上 RVP 版本、本体版本、日志与复现步骤。

## 功能概览

RVP 在 Limitless Vehicle 的载具框架上增加以下内容：

| 模块 | 内容 |
| --- | --- |
| 武器系统 | 反辐射、人在回路、攻顶、GPS 制导、激光架束、激光制导、红外制导等导弹；AHEAD、定距空爆、破障弹、PELE、霰弹等炮弹；坐标指示吊舱、目标指示吊舱、集成火力支援；激光致盲 |
| 辅助设备 | ERA 爆反、APS 主动防护、主动 ECM、光电干扰机、DIRCM、热焰弹/箔条/烟幕、维修设备 |
| 模块化损伤 | 按部位与模块结算损伤；部位和设备具有独立耐久、伤害倍率与失效效果；维修面板按优先级恢复 |
| 车载无人机与辅助载具 | 母车部署并控制辅助载具；山毛榉-M3 可部署 96L6 雷达车，形成雷达车与发射车分离的防空配置 |
| 战术地图 | 与 GPS 制导武器、雷达目标列表联动；提供炮兵地图与小型炮兵地图 |

## 武器系统

大多数 RVP 载具支持武器改装，可更换主炮、导弹、火箭、机炮、吊舱和辅助设备。F/A-18F 与 J-16 的可选武器种类最多，几乎囊括 RVP 现有的各类武器。

### 导弹

- **反辐射导弹**：追踪雷达辐射源，用于攻击雷达目标。
- **人在回路导弹**：进入弹载电视或热成像画面，手动控制导弹飞行。支持目标锚定、画面模式切换和倍率调整；按弹种配置可在命中前空爆或退出。
- **攻顶导弹**：以 TOW-2B 为代表，弹道飞越目标后在顶部起爆。
- **GPS 制导导弹**：支持四种目标装订模式，并与战术地图联动。
  - **单点**：装订一个坐标。
  - **多点**：装订多个坐标，按顺序使用。
  - **快速**：将当前观瞄或 CCIP 点装订并发射。
  - **雷达**：由雷达硬锁目标；飞行中可按配置间隔更新目标位置。
- **激光架束导弹**：沿载机或载车发出的激光束飞行。
- **激光制导导弹/炸弹**：由激光照射指示目标。
- **红外制导导弹**：包括空空、近程防空等型号；配合头瞄可在大离轴角内捕获、锁定和发射。

### 炮弹

- **AHEAD 弹药**：在预定距离起爆并释放破片，用于拦截空中目标和小型目标。
- **定距空爆弹**：按设定距离或高度起爆，用于攻击掩体后、树冠后和低空目标。
- **破障弹**：用于破坏墙体、掩体和障碍物。
- **PELE 弹药**：穿透薄装甲后产生横向破片，同时具有穿甲和破片效果。
- **霰弹**：近距离面杀伤，用于攻击步兵和轻目标。

### 吊舱

- **坐标指示吊舱**：获取目标坐标，可装订为 GPS 目标或用于火力支援。
- **目标指示吊舱**：跟踪目标并提供制导指示，配合激光制导武器使用。
- **集成火力支援吊舱**：在吊舱界面内选择目标并呼叫火力支援。

### 激光

- **激光致盲**：照射敌方光学/红外观瞄或导引头，使其短时间失效。

### 武器改装

- 载具支持多武器站配置：主炮、副炮、车长机枪、导弹、火箭、干扰弹发射器等可分别设置。
- 支持挂架、弹种、弹链和变体切换；不同弹种的备弹、射速、过热、装填和弹道独立配置。
- F/A-18F、J-16 可在单台载具上使用 RVP 的大部分武器类型。

## 辅助设备

RVP 的辅助设备按骨块模块配置，具有独立耐久和功能状态。设备被击毁后对应功能停止，可通过维修恢复。

- **ERA 爆反装甲**：阻挡或削弱破甲战斗部；被击穿后该块失效，外观同步变化。
- **APS 主动防护**：按扇区探测并拦截来袭弹药；传感器或发射器被击毁后，对应扇区停止拦截。
- **ECM 主动干扰**：按键触发持续干扰，用于压制雷达锁定和雷达制导导弹。
- **光电干扰机（软杀伤干扰机）**：对进入干扰扇区的光学/指令制导导弹施加干扰。
- **DIRCM 定向红外对抗**：对红外导引头实施定向干扰；HUD 显示干扰状态。
- **热焰弹/箔条/烟幕**：按载具配置抛洒，各自独立备弹和冷却；烟幕可遮挡光学观察与制导。
- **维修设备**：部分载具配置维修设备，可修复部件和设备；维修设备本身可被击毁。

设备面板显示辅助设备状态，并可设置维修顺序。

## 模块化损伤

RVP 的损伤按部位和模块结算。不同部位具有独立耐久、伤害倍率和失效效果。

- **ERA 爆反**：被击穿后该块失效，外观同步变化。
- **履带/行走机构**：失效后仍参与碰撞，动力下降，严重时无法移动。
- **发动机**：分受损、瘫痪两级；受损降低功率，瘫痪后动力清零。
- **炮管**：受损后散布恶化并可能哑火，彻底损坏后禁止射击。导弹类武器在炮管一级受损时只有发射失败或成功两种结果，不会炸膛。
- **方向机**：受损后回转速度下降，彻底损坏后炮塔低速转动。
- **火控系统（FCS）**：损坏后稳定器、弹道解算和观瞄功能降级；准星仍显示，但不提供有效弹道计算。
- **雷达/APS/干扰机/DIRCM/干扰弹发射器**：被击毁后失去对应功能。
- **快速维修**：维修面板按优先级恢复部件；ERA、辅助设备和关键部件可分别设置维修顺序。
- **殉爆与飞头**：部分载具具有炮塔殉爆、飞头、火焰和火星效果。

部位具有独立伤害倍率；爆炸方向、入射角、装甲厚度和弹种会影响最终伤害。

## 车载无人机与辅助载具

部分 RVP 载具可部署辅助载具，并在母车与辅助载具之间切换控制。

- 可部署的辅助载具包括侦察无人机、C4 自爆无人机、RPG 武装无人机、SUAV 轻型侦察无人机和 RAWR 无人战车。
- 支持自动盘旋、信号范围限制、超距自动回收和重新部署冷却。
- 辅助载具出动期间，母车座位锁定。

### 山毛榉-M3：雷达车与发射车

山毛榉-M3 可部署一台 96L6 雷达车：

- 雷达车与发射车分别部署，可切换控制。
- 雷达车提供目标信息，发射车负责发射，两车通过数据链联动。
- 雷达车可作为雷达中继使用。

## 战术地图

战术地图显示地形、玩家、载具、导弹和 GPS 目标点，支持缩放、拖动、跟随和快捷标记。右键目标可绑定为 GPS 目标，或将目标位置填入 GPS 面板；支持高弹道/低弹道选择。

### 与 GPS 制导武器联动

- 在战术地图上选择目标点并装订为 GPS 目标。
- 支持单点、多点、快速、雷达四种模式；多点和雷达模式可在战术地图或雷达面板中管理。
- 雷达模式下，导弹飞行中可按配置间隔更新目标位置。

### 与雷达目标列表联动

- 战术地图可打开雷达目标列表，显示方位、距离、高度、速度和敌我识别。
- 可锁定目标，并对主动雷达导弹执行快捷发射。

### 炮兵地图与小型炮兵地图

- **炮兵地图**：选择目标后计算仰角和落点距离，提供高/低弹道解算，左键开火；适用于 RVP 的炮兵武器。
- **小型炮兵地图**：选中炮兵武器时在屏幕角落显示紧凑地图，支持选点和左键开火。

## 安装与更新

### 安装前须知

- RVP 以 Forge 模组形式分发，`-full.jar` 放入 `mods/`，无需解压。
- 载具模型、贴图、音效和数据均包含在 `-full.jar` 内。
- RVP 需要 Limitless Vehicle 作为前置。
- 首次启动时，RVP 会将内置载具包释放到 `limitless_vehicle/rvp/`。

### 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.x（建议 47.3.10 及以上；本项目使用 47.4.13 构建） |
| Limitless Vehicle | 0.6.2.1 |
| RVP | 1.0.0_preview_0.6.2.1 |
| 客户端与服务端 | 均需安装，且版本一致 |

### 安装步骤

1. 安装 Minecraft 1.20.1 + Forge 47.x。
2. 将 `ywzj_vehicle-1.20.1-0.6.2.1.jar` 放入 `.minecraft/mods/`。
3. 将 `ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar` 放入同一 `mods/` 目录。
4. 启动客户端或服务端一次，等待内置载具包释放到 `limitless_vehicle/rvp/`。
5. 进入游戏，在创造模式物品栏中确认 RVP 载具与物品已出现。

### 安装后的目录

```text
.minecraft/
├─ mods/
│  ├─ ywzj_vehicle-1.20.1-0.6.2.1.jar
│  └─ ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar
├─ limitless_vehicle/
│  └─ rvp/
│     ├─ vehicle_pack.meta.json
│     ├─ assets/
│     └─ data/
└─ config/
   ├─ ywzj_rvp-client.toml
   └─ ywzj_rvp-common.toml
```

### 更新

替换 `mods/` 中的 RVP jar。启动时安装器比较磁盘上的载具包版本与 jar 内版本：

- 版本相同：保留现有 `limitless_vehicle/rvp/`。
- 版本不同：先将旧包备份到 `limitless_vehicle_backup/rvp_<时间戳>/`，再释放新包。

修改过 `rvp` 内文件时，升级前请先备份。

### 专用服务器

服务端需在 `mods/` 中安装本体与 RVP 两个 jar。首次启动会自动释放载具包，服务端需要对游戏目录具有写权限。客户端与服务端需使用同一 RVP 版本和同一本体版本。

## 配置与性能

- 客户端配置：`config/ywzj_rvp-client.toml`
  - 观瞄灵敏度、LOD 缩放、温压粒子质量/音量/闪光/震动、爆炸屏幕震动、体积尾烟、远距载具渲染上限、Distant Horizons 兼容模式。
- 双端配置：`config/ywzj_rvp-common.toml`
  - 观瞄轴加速、残骸保留时间、超视距载具同步/授权/距离、区块租约与前瞻。
- 性能建议：
  - 为客户端分配 6–8 GB 内存。
  - 首次启动会从约 245 MB 的 jar 中解压载具包；磁盘较慢时启动时间会延长。
  - 卡顿时可降低温压粒子质量、屏幕震动和远距载具渲染数量；体积尾烟默认关闭。
  - 使用 Distant Horizons 时，可在客户端配置中选择兼容模式。

- Minecraft 1.20.1 / Forge 47.x；不支持 Fabric。

## 排障

**启动后没有 RVP 载具或物品**
确认使用 `-full.jar`、本体 0.6.2.1 已安装、`limitless_vehicle/rvp/vehicle_pack.meta.json` 存在；在 `logs/latest.log` 中搜索 `Installed RVP vehicle pack`；首次启动后完全重启一次客户端。

**联机进不去、载具不同步或被踢**
客户端与服务端需使用同一 RVP jar、同一本体版本和同一载具包版本；服务端也需安装 `-full.jar`。

**更新后修改消失**
安装器按载具包版本覆盖 `rvp`；旧包位于 `limitless_vehicle_backup/rvp_<时间戳>/`。需要保留的修改应放在独立包名的扩展包中。

**打开载具打印机崩溃，报 `NoSuchMethodError: Document.getLayout()`**
`mods/` 中的旧版 ApricityUI 覆盖了本体内置的 1.3.0。移除旧版外部 jar，保留本体内置版本。

**卡顿或内存占用高**
分配 6–8 GB 内存；降低温压粒子质量、屏幕震动与远距载具渲染数量；体积尾烟默认关闭；使用 Distant Horizons 时选择合适的兼容模式。

**日志位置**
`logs/latest.log`、`logs/debug.log`、`crash-reports/`。反馈时请附上 RVP 版本、本体版本，以及日志中与 `ywzj_rvp` / `RVP` 相关的片段。
