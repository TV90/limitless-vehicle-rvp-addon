# Real Vehicle Pack

基于 Minecraft 1.20.1 / Forge 的 Limitless Vehicle的大型附属mod，在LV的基础上增加了大量新增的武器类型和玩法，最具特色的武器为反辐射导弹，人在回路导弹和各式各样的弹种等。
该附属mod制作了大量贴近现实军事的机制，模型采用较为逼真的Mesh模型，故而命名为Real Vehicle Pack。

当前版本：`1.0.0_preview_0.6.2.1`。预览版的内容、数值与平衡仍会调整。反馈问题时请附上 RVP 版本、本体版本、日志与复现步骤。

## 3. 安装

### 3.1 安装前须知

- RVP 以 Forge 模组形式分发，`-full.jar` 放入 `mods/`，无需解压。
- 载具模型、贴图、音效和数据均包含在 `-full.jar` 内。启动游戏后会进行自解压。
- RVP 需要 Limitless Vehicle 作为前置。
- 首次启动时，RVP 会将内置载具包释放到 `limitless_vehicle/rvp/`。

### 3.2 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.4.x（本项目使用 47.4.13 构建） |
| Limitless Vehicle | 0.6.2.1 |
| RVP | 1.0.0_preview_0.6.2.1 |
| 客户端与服务端 | 均需安装，且版本一致 |

### 3.3 安装步骤

1. 安装 Minecraft 1.20.1 + Forge 47.4.x。
2. 将 `ywzj_vehicle-1.20.1-0.6.2.1.jar` 放入 `.minecraft/mods/`。
3. 将 `ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar` 放入同一 `mods/` 目录。
4. 启动客户端或服务端一次，等待内置载具包释放到 `limitless_vehicle/rvp/`。
5. 进入游戏，在创造模式物品栏中确认 RVP 载具与物品已出现。

## 5. 武器系统

RVP 的武器数据目录包含 231 个武器与弹药定义文件，其中含战斗部、子弹药等从属条目。RVP 载具普遍配置多个武器站，可分别操作主炮、副炮、机枪、导弹、火箭等武器站；14 台固定翼/旋翼载具支持自定义挂架，F/A-18F 与 J-16 的可选武器种类最多。

### 5.1 枪炮与弹药

RVP 的枪炮包括车载/机载机枪、机炮与近防炮、坦克炮、舰炮和车载激光压制系统。不同武器使用的弹种不同，下面按游戏内实际行为说明主要弹药类型。

主要弹药类型：

- **APFSDS**：尾翼稳定脱壳穿甲弹。 APFSDS 为高直击、无爆破的动能穿甲弹，可穿透 2 格方块；穿墙后直击伤害会衰减，适合打装甲目标，且APFSDS对爆炸反应装甲有较高的抗性。
- **HEAT**：破甲弹。较高直击伤害并附带小范围爆炸，会被爆炸反应装甲削弱命中伤害。直击与爆炸的综合性能介于 APFSDS 与 HE 之间。对步战车等轻装甲目标可以造成巨额伤害。
- **HE**：高爆榴弹。直击伤害低、爆炸伤害和半径大；主要靠爆炸杀伤软目标和轻装甲目标，可以对轻装甲目标造成巨额伤害。
- **PELE**：横向效应增强弹。由APFSDS改造来的弹药，直击伤害较低，但命中载具或方块后释放大量弹射破片，破片能够有效破坏轻装甲和杀伤步兵；适合打击轻装甲目标和密闭空间的步兵，对重装甲杀伤效果有限。
- **AHEAD**：可编程弹药。需要雷达或武器站锁定目标自动解算提前量并装订空爆引信；开火时按提前量和弹道自动装订空爆距在目标前方约 40 米释放大量破片，在敌人行进路径中抛洒弹幕。未锁定时不装订空爆，弹丸按普通直射飞行。
- **定距空爆弹**：按锁定键（默认 R）对瞄准点测距（瞄准点需命中方块），沿弹道累计飞行到“测距 + 偏移”时起爆；用于在掩体上方或目标附近空爆，可以有效打击。
- **SAP**：破障榴弹。具有 1 格穿墙能力的高爆弹，可穿过墙体命中墙后/掩体内的目标并在目标处起爆，主要用于杀伤墙后步兵目标。
- **霰弹**：一次发射多枚弹丸，近距离覆盖软目标；弹丸伤害随距离衰减。
- **轨道炮：**ZTZ100和艾布拉姆斯X装备有实验性质的

### 5.2 火箭弹

- **无制导火箭弹**：Hydra 70、Zuni、S-13、S-8KO、FS70B、130-2 等火箭巢。弹道计算机会进行连续计算命中，确保打击的准确。

### 5.3 导弹

导弹按制导方式分类。

| 制导方式 | 说明与示例 |
| --- | --- |
| 红外制导（IR） | 红外导引头跟踪目标热源；AIM-9M、PL-10、FIM-92K、KD-88A 等。配合头瞄可在大离轴角内捕获、锁定和发射 |
| 主动雷达制导（ARH） | 发射初段接受机载雷达数据链引导，到底主动雷达导引头开机距离后，弹载导引头主动开机捕获目标；AIM-120D、PL-15、AIM-54C、YJ-19 等 |
| 半主动雷达制导（SARH） | 依赖载机/载车雷达持续照射；AIM-7P、R-27R、ESSM 等 |
| 激光半主动制导（SALH） | 由激光照射指示目标，被照射目标会被触发激光告警；AGM-114K、AGM-65E、LAHAT、AKD-10 等 |
| 激光架束制导（LBR） | 沿激光束架束飞行，被照射目标会触发激光告警；9M119M1、GP-125、9M127 等；9M119M1、GP-125 为炮射导弹 |
| 反辐射制导（ARM） | 追踪开启的雷达辐射源，关闭雷达可规避反辐射导弹；AGM-88E、LD-10、YJ-91 等 |
| 主动红外制导（AIR） | 雷达或数据链中段修正，末段红外导引头自主搜索；HHQ-10、HQ-13 等 |
| GPS/INS 制导 | 卫星与惯性组合导航，配合战术地图装订；AKF-98A、Storm Shadow、ATACMS、YJ-20 等。GBU-31、LS-6、GB-3 GPS 型为卫星制导炸弹，见 5.4 |
| 人在回路电视制导（HITL_TV） | 发射后进入人在回路导引头回传界面，发射手可以在人在回路界面不断选择导引头锁定目标，类似战争雷霆的人在回路导弹；KH-39、KD-88 等。 |
| 人在回路指令线电视制导（HITL_CLOS_TV） | 发射后进入人在回路导引头回传界面，发射手可以手动控制导弹舵面，进行转向，类似战地4的TV弹；TL-17、CM-502KG、弹簧刀巡飞弹等 |
| SACLOS 半自动指令线制导 | 操作员瞄准目标，导弹沿视线指令飞行，相较于LBR，操作性较难，但是不会触发激光告警；TOW-2A/2B、HJ-73E、95Ya6M 等；TOW-2B 采用自锻破片攻顶战斗部，导弹略顶后会爆炸并向下抛洒大量破片，适合打击墙后目标 |

部分弹种具有多模导引头模式：如Brimstone为半主动激光/主动雷达双模导引头，前半段使用激光照射，导弹往激光点飞行，后半段主动雷达导引头开机自主捕获目标。部分导弹支持双脉冲发动机、冷发射、高抛/掠顶弹道和近炸/触发引信。

### 5.8 火力支援

- **RVP 炮火支援终端**：主手/副手持有时右键，或按 K 打开炮火支援地图；支持呼叫、落区、弹数与停火。
- **火力支援模式**：急促打击、效力打击、监视打击、空中打击。
- **弹幕样式**：点状弹幕、条状弹幕、徐进弹幕。
- **支援弹药**：航空炸弹、火箭弹、集束火箭、白磷弹、ATACMS、9M723、GPS 巡航导弹等，具体条目由火力支援配置决定。
- **吊舱联动**：目标指示吊舱可标记实体或坐标；挂载“呼叫火力打击”/“呼叫空袭”的载具可在吊舱界面选择打击条目，标记坐标后自动呼叫。

## 6. 辅助设备

RVP 的辅助设备按骨块模块配置，具有独立耐久和功能状态。设备被击毁后对应功能停止，可通过维修恢复。

| 设备 | 功能 |
| --- | --- |
| ERA 爆炸反应装甲 | 拥有较高的免伤倍率，承担一定伤害后爆炸消失 |
| APS 主动防护 | 按扇区探测并拦截来袭弹药；传感器骨块被击毁后，对应扇区停止拦截 |
| ECM 主动干扰 | 释放后干扰一定范围内的雷达/卫星/无线电制导导弹，同时成为最高辐射源吸引反辐射导弹。电子战机的强效ECM甚至产生虚假信号能干扰战斗机的雷达与RWR |
| 被动 ECM | 被敌方雷达照射时生成假目标，干扰对方雷达判断；骨块失效后停止生成 |
| 光电干扰机（软杀伤干扰机） | 对进入干扰扇区的 SACLOS 导弹进行干扰，使其偏离攻击弹道 |
| DIRCM 定向红外对抗 | 对 IR、AIR，人在回路导弹以及**SBW**模组的SA18单兵弹实施定向干扰，使其偏离攻击弹道，但是火力通道有限，会被同时来袭的多枚红外导弹突防 |

## 7. 模块化损伤

RVP 的损伤按部位和模块结算。不同部位具有独立耐久、伤害倍率和失效效果。

| 部位/模块 | 失效效果 |
| --- | --- |
| ERA 爆反 | 被击穿后该块失效，失去防护弹药能力，外观同步变化 |
| 发动机 | 受损严重时失去大量动力，极速减半；<br />被彻底摧毁时失去全部动力无法移动。 |
| 炮管 | 受损严重时射击有概率失败，甚至炸膛，即使射击成功也会导致精度大幅度下降；<br />被彻底摧毁时无法射击。 |
| 方向机 | 受损严重时方向机转速大幅度下降；<br />彻底损坏时无法转动方向机 |
| 火控系统（FCS） | 损坏后稳定器损坏、弹道解算与 CCIP 停止、热成像/夜视与光电搜索不可用； |
| 雷达 | 被击毁后无法搜索/跟踪目标 |
| APS/干扰机/DIRCM/干扰弹发射器 | 被击毁后失去对应功能 |
| 维修设备 | 被击毁后无法使用快速维修 |

损伤计算使用部位 OBB 与独立伤害倍率；爆炸方向、入射角、装甲减伤参数、距离、弹种和 ERA 状态都会影响最终伤害。

维修面板按优先级恢复部件；可分别设置爆反维修顺序与辅助设备维修顺序。

## 8. 车载无人机与辅助载具

### 8.1 可部署辅助载具

部分 RVP 载具可部署辅助载具，并在母车与辅助载具之间切换控制。

| 类型 | 示例 |
| --- | --- |
| 侦察无人机 | SUAV 轻型侦察无人机、四轴侦察无人机 |
| 攻击无人机 | 四轴投弹无人机（投掷 PG-7V）、四轴自爆无人机 |

玩法推荐：海玛斯火箭炮放飞侦察无人机，侦察无人机通过侦察吊舱标记敌方载具位置，海玛斯可以通过战术地图上的敌军标记直接发射火箭弹轰炸。

- 支持部署、切换控制和无人机自动盘旋。
- 辅助载具受信号范围限制；超出范围会自动回收。
- 重新部署具有冷却时间。
- 辅助载具出动期间，母车座位锁定。

- 雷达车可作为雷达中继使用。

## 13. 配置与性能

- 客户端渲染与特效：`config/ywzj_rvp-client.toml`
  - 观瞄灵敏度、LOD 缩放、温压粒子质量/音量/闪光/震动、爆炸屏幕震动、体积尾烟、远距载具渲染上限、Distant Horizons 兼容模式。
- 客户端画质开关：`config/ywzj_rvp-lighting-client.toml`
  - 屏幕空间照亮、爆炸/炮口/发动机照亮、光晕、导弹外圈、光电干扰机红光、喷焰与空气散射。
- 双端通用：`config/ywzj_rvp-common.toml`
  - 观瞄轴加速、残骸保留时间、超视距载具同步/授权/距离、区块租约与前瞻。
- HITL 远程观察预算：`config/ywzj_rvp-hitl-remote.toml`
  - 会话数、相机区块半径、最大控制距离、每 tick 区块票据/发送量、待处理区块与额外实体上限。
- 服务端玩法参数：`config/ywzj_rvp-server.toml`
- 性能建议：
  - 为客户端分配 6–8 GB 内存。
  - 首次启动会从约 234 MB 的 jar 中解压载具包；磁盘较慢时启动时间会延长。
  - 卡顿时可降低温压粒子质量、屏幕震动和远距载具渲染数量；体积尾烟默认关闭。
  - 使用 Distant Horizons 时，可在客户端配置中选择兼容模式。
