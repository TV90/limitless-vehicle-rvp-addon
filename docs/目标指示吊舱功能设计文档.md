# RVP 目标指示吊舱（Targeting Pod）功能设计文档

## 一、需求概述

为 RVP 的 `TARGETING_POD` 武器类型实现完整的目标指示功能，参考 MCHR 的 `MCH_WeaponTargetingPod`。

### 核心功能
- **实体标记**：吊舱瞄准方向锥形范围内的实体（载具/玩家/生物）被标记，持续一定时间
- **方块标记**：吊舱射线击中的方块位置被标记为 GPS 目标点
- **战术地图联动**：被标记的实体和方块在 RVP 战术地图和炮兵地图上点亮显示
- **GPS 联动**：方块标记可直接作为 GPS 制导武器的目标点
- **团队共享**：标记信息在同队伍玩家间同步

## 二、MCHR 实现分析

### 2.1 架构总览

```
MCH_WeaponTargetingPod (武器逻辑)
  ├── target & 64 (方块标记模式) → MCH_Multiplay.markPoint()
  │     └── rayTraceBlocks → sendMarkPointToSameTeam → MCH_PacketNotifyMarkPoint
  └── target & 64 == 0 (实体标记模式) → MCH_Multiplay.spotEntity()
        ├── canSpotEntityWithFilter (目标类型过滤: planes/helis/tanks/players/monsters/others)
        ├── canSpotEntity (队伍判断: NONE/SAME_TEAM/OTHER_TEAM/NO_TEAM)
        ├── 角度+距离过滤 (锥形扫描)
        └── sendSpotedEntityListToSameTeam → MCH_PacketNotifySpotedEntity

MCH_GuiTargetMarker (客户端渲染)
  ├── entityPos: List<MCH_MarkEntityPos>  (实体标记屏幕坐标)
  ├── spotedEntity: Map<Integer, Integer>  (entityId → 倒计时)
  ├── drawMark(): 绘制三角形(实体) + 菱形(方块标记) + 距离文字
  └── 屏幕边缘指示器 (目标在视野外时在屏幕边缘显示箭头)
```

### 2.2 关键参数

| 参数 | 来源 | 说明 |
|------|------|------|
| `Target` | WeaponInfo | `block` = 方块标记模式；否则为实体标记，位掩码组合 planes(32)/helis(16)/tanks(8)/players(4)/monsters(2)/others(1) |
| `Length` | WeaponInfo | 标记距离（spotLength），默认 0 |
| `Radius` | WeaponInfo | 锥形半径角度，与 Length 计算 `angle = atan2(radius, length)` |
| `MarkTime` | WeaponInfo | 标记持续时间（tick），范围 1~30000 |

### 2.3 实体标记流程

1. 获取玩家前方方向向量 `(tx, tz)`
2. `getEntitiesWithinAABBExcludingEntity` 获取范围内所有实体
3. `canSpotEntityWithFilter` 按位掩码过滤目标类型
4. `canSpotEntity` 判断队伍关系（友军/敌军/无队伍）
5. `rayTraceBlocks` 检查视线是否被方块遮挡
6. 水平角度 `h < angle*2` 且垂直角度 `v < angle*2` → 在锥形范围内
7. 通过的实体 ID 列表发给同队玩家

### 2.4 方块标记流程

1. 从玩家位置沿视线方向 rayTrace 300 格
2. 命中方块 → 发送 `(blockX, blockY+2, blockZ)` 给同队
3. 未命中 → 发送 `(0, 1000, 0)` 表示清除标记

## 三、RVP 现有基础

### 3.1 已有的 TARGETING_POD 基础

**RVP_TargetingPodWeapon.java** — 已实现方块标记（GPS 目标点写入）：
- 射线检测方块 → `GPSTargetManager.applyCurrentMode()` 写入 GPS 目标点
- 通过 `S2CGpsStateSync` 同步给客户端
- **缺失**：无实体标记功能、无锥形扫描、无队伍共享、无战术地图联动

### 3.2 已有的战术揭示系统

**RVP_TacticalRevealSyncService.java** + **RVP_ClientTacticalRevealState.java**：
- 服务端每 5 tick 广播 `S2CTacticalRevealSnapshot`
- 包含 `fireRevealIds`（开火揭示）和 `markedRevealIds`（标记揭示，**当前为空 List.of()**）
- 客户端 `RVP_ClientTacticalRevealState.isVisible()` 判断实体是否在地图上可见
- **这正是吊舱实体标记的现成管道！** `markedRevealIds` 就是预留给吊舱的

### 3.3 战术地图 / 炮兵地图

- `RVP_TacticalMapScreen` 通过 `RVP_ClientTacticalRevealState.getVisibleIds()` 获取需要点亮的实体
- 地图已有实体绘制逻辑，被揭示的实体会以特殊颜色/图标显示

## 四、设计方案

### 4.1 两大标记模式

#### 模式切换

JSON 配置字段 `targeting_pod_mode`：

```json
{
  "type": "rvp:targeting_pod",
  "targeting_pod_data": {
    "mode": "entity",          // "entity" | "block" | "both"
    "spot_range": 200,         // 标记距离（格）
    "spot_angle": 15,          // 锥形半角（度）
    "mark_duration": 600,      // 标记持续时间（tick，30秒）
    "target_filter": [         // 实体标记的目标类型过滤
      "vehicle",               // 载具（AbstractVehicle）
      "player",                // 玩家
      "living"                 // 生物
    ]
  }
}
```

| 模式 | 行为 |
|------|------|
| `entity` | 实体标记：锥形扫描，标记范围内实体 |
| `block` | 方块标记：射线检测，标记命中方块为 GPS 目标点 |
| `both` | 同时执行实体标记和方块标记 |

#### 实体标记逻辑（新增）

```
发射吊舱(shot) →
  服务端:
    1. 取瞄准方向 (aim.direction)
    2. getEntitiesOfClass(AbstractVehicle/LivingEntity, AABB.inflate(spot_range))
    3. 对每个实体:
       a. IFF 判断（友军跳过）
       b. 视线检查 (rayTraceBlocks)
       c. 锥形角度检查 (水平角 < spot_angle && 垂直角 < spot_angle)
    4. 通过的实体加入 MarkedEntityManager
    5. MarkedEntityManager 每 tick 过期清理 + 广播
```

#### 方块标记逻辑（复用 + 扩展现有）

```
发射吊舱(shot) →
  服务端:
    1. 射线检测 (ClipContext)
    2. 命中方块 → GPSTargetManager.applyCurrentMode() 写入 GPS 目标点
    3. 同时将方块坐标加入 MarkedBlockManager
    4. MarkedBlockManager 广播给同队玩家
```

### 4.2 数据结构

#### 服务端：RVP_MarkedTargetManager（新建，非 Mixin）

```java
package org.ywzj.rvp.targeting;

public final class RVP_MarkedTargetManager {
    // 实体标记：entityId → 过期时间
    private static final Map<Integer, Long> MARKED_ENTITIES = new ConcurrentHashMap<>();
    // 方块标记：维度+坐标 → 过期时间
    private static final Map<BlockTarget, Long> MARKED_BLOCKS = new ConcurrentHashMap<>();

    public static void markEntity(int entityId, long expireTick);
    public static void markBlock(ResourceLocation dim, BlockPos pos, long expireTick);
    public static void tick(ServerLevel level);  // 过期清理
    public static List<Integer> getMarkedEntityIds();
    public static List<BlockTarget> getMarkedBlocks();
}
```

#### JSON 数据类：RVP_TargetingPodData（新建）

```java
package org.ywzj.rvp.weapon.data;

public class RVP_TargetingPodData {
    @SerializedName("mode")
    public String mode = "entity";  // "entity" | "block" | "both"

    @SerializedName("spot_range")
    public float spotRange = 200f;

    @SerializedName("spot_angle")
    public float spotAngle = 15f;

    @SerializedName("mark_duration")
    public int markDuration = 600;  // tick

    @SerializedName("target_filter")
    public List<String> targetFilter = List.of("vehicle");
}
```

### 4.3 网络同步

#### 复用 S2CTacticalRevealSnapshot

当前 `markedRevealIds` 字段已预留，只需在 `RVP_TacticalRevealSyncService.buildSnapshot()` 中填充 `RVP_MarkedTargetManager.getMarkedEntityIds()`：

```java
// RVP_TacticalRevealSyncService.java 第89行
msg.markedRevealIds = List.of();
// 改为:
msg.markedRevealIds = RVP_MarkedTargetManager.getMarkedEntityIds();
```

#### 新增 S2CMarkedBlockSync（方块标记同步）

方块标记需要独立网络包，因为包含坐标而非实体 ID：

```java
package org.ywzj.rvp.network;

public class S2CMarkedBlockSync {
    public ResourceLocation dimension;
    public List<long[]> markedBlocks;  // [x, y, z] 压缩
}
```

### 4.4 战术地图 / 炮兵地图显示

#### 实体标记显示

**无需修改地图代码**。`RVP_TacticalRevealSyncService` 广播后，`RVP_ClientTacticalRevealState` 自动更新，战术地图已有的 `isVisible()` 判断会让被标记的实体在地图上点亮。

#### 方块标记显示

在 `RVP_TacticalMapScreen` 和炮兵地图中新增方块标记绘制：
- 被标记的方块在地图上显示为菱形/十字标记
- 颜色区分：方块标记用橙色，开火揭示用红色
- 显示坐标文字

### 4.5 客户端 HUD（可选，后续迭代）

参考 MCHR 的 `MCH_GuiTargetMarker`：
- 被标记实体在屏幕上显示三角形标记
- 方块标记显示菱形 + 距离文字
- 视野外目标在屏幕边缘显示方向指示器

这部分作为第二阶段实现，第一阶段先完成地图联动。

## 五、与 MCHR 的关键差异

| 特性 | MCHR | RVP |
|------|------|-----|
| 标记模式切换 | WeaponInfo.target 位掩码（64=方块） | JSON `mode` 字段（entity/block/both） |
| 目标类型过滤 | 位掩码 planes/helis/tanks/players/monsters | 字符串列表 `target_filter` |
| 队伍判断 | scoreboard Team | RVP 现有 IFF 系统（6步优先级） |
| 视线检查 | rayTraceBlocks | ClipContext（更精确） |
| 同步方式 | 自定义 Packet | 复用 S2CTacticalRevealSnapshot + 新增方块包 |
| 地图联动 | 无（仅 HUD） | 战术地图 + 炮兵地图点亮 |
| GPS 联动 | 无 | 方块标记直接写入 GPSTargetManager |
| 标记渲染 | 独立 GuiOverlay | 复用地图渲染 + 可选 HUD |
