# RVP · RealVehiclePack

基于 Minecraft 1.20.1 / Forge 的 Limitless Vehicle 大型附属 Mod。RVP 在 LV 的载具框架上增加了大量贴近现实的武器、弹种、辅助设备与玩法，代表内容为反辐射导弹、人在回路导弹和丰富的弹药改装。

当前版本：`1.0.0_preview_0.6.2.1`。预览版的内容、数值与平衡仍会调整。

![RVP 画廊](https://gitee.com/DTC10/limitless-vehicle-rvp-addon/raw/master/docs/images/RVP_1.0.0_preview_gallery.png)

## 下载与安装

| 文件 | 说明 |
| --- | --- |
| `ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar` | RVP 完整版，必需；本页附件 |
| Limitless Vehicle 0.6.2.1 | 本体，必需；[CurseForge](https://www.curseforge.com/minecraft/mc-mods/limitless-vehicle) |

1. 安装 Minecraft 1.20.1 + Forge 47.4.x。
2. 将 `ywzj_vehicle-1.20.1-0.6.2.1.jar` 放入 `.minecraft/mods/`。
3. 将 `ywzj_rvp-1.20.1-1.0.0_preview_0.6.2.1-full.jar` 放入同一 `mods/` 目录。
4. 启动一次客户端或服务端，等待载具包自解压到 `limitless_vehicle/rvp/`。
5. 进入游戏，在创造模式物品栏确认 RVP 载具与物品已出现。

RVP 的模型、贴图、音效和数据都包含在 `-full.jar` 内，无需额外资源包。客户端与服务端需要安装相同的两个 jar，且版本一致。更新时直接替换 RVP jar；版本变化时安装器会备份旧包并释放新包。

## 主要内容

- **武器系统**：枪炮、火箭弹、导弹、航空炸弹、鱼雷、吊舱、激光武器、火力支援与武器改装。
- **辅助设备**：ERA 爆反、APS 主动防护、主动/被动 ECM、光电干扰机、DIRCM、热焰弹/箔条/烟幕与维修设备。
- **模块化损伤**：按部位与模块结算损伤，具有独立耐久、伤害倍率、失效效果和维修顺序。
- **车载无人机与辅助载具**：侦察/攻击无人机、无人战车、雷达中继车、UCAV 发射器与舰载直升机着舰。
- **战术地图**：GPS 目标装订、雷达目标列表、炮兵地图与小型炮兵地图。
- **界面与 AI 乘员**：人在回路 HUD、头瞄、焦点锁定、告警、CCIP、设备面板与炮手生成器。

## 武器与设备

### 枪炮与弹药

RVP 载具普遍配置多个武器站，可分别操作主炮、副炮、机枪、导弹和火箭。14 台空中载具支持自定义挂架，F/A-18F 与 J-16 的可选武器种类最多。

- **APFSDS**：高直击、无爆破的动能穿甲弹，可穿透 2 格方块，穿墙后直击伤害衰减；适合打装甲目标，对爆炸反应装甲抗性较高。
- **HEAT**：较高直击伤害并附带小范围爆炸，会被爆反削弱；综合性能介于 APFSDS 与 HE 之间，对步战车等轻装甲目标伤害很高。坦克炮 HEAT 无串联破甲，串联破甲仅见于导弹类。
- **HE**：直击伤害低、爆炸伤害与半径大，主要杀伤软目标和轻装甲目标。
- **PELE**：命中载具或方块后释放大量破片，适合轻装甲目标和密闭空间内的步兵，对重装甲效果有限。
- **AHEAD**：需要雷达或武器站锁定目标，自动解算提前量并装订空爆引信；未锁定时按普通直射弹飞行。
- **定距空爆弹**：按锁定键（默认 `R`）对瞄准点测距，沿弹道飞到“测距 + 偏移”时起爆，可在掩体上方或目标附近空爆。
- **SAP 破障榴弹**：具有 1 格穿墙能力的高爆弹，可穿过墙体命中墙后/掩体内的目标。
- **霰弹**：一次发射多枚弹丸，近距离覆盖软目标，伤害随距离衰减。

### 火箭弹

- **无制导**：Hydra 70、Zuni、S-13、S-8KO、FS70B、130-2 等火箭巢，弹道计算机会连续计算命中。
- **制导**：APKWS、FS70A 等激光制导火箭弹，可跟随激光点打击移动目标。
- **集束**：M30、M261、FS70B 集束型，接近地面时散布大量子弹药，面杀伤强、反装甲较弱。
- **白磷/燃烧**：M30 白磷空爆型等，接近地面时布撒白磷弹幕，进行大范围纵火。

### 导弹

| 制导方式 | 说明与示例 |
| --- | --- |
| 红外（IR） | 跟踪目标热源，可配合头瞄大离轴捕获与发射；AIM-9M、PL-10、FIM-92K、KD-88A 等 |
| 主动雷达（ARH） | 初段数据链引导，末段弹载雷达主动开机捕获；AIM-120D、PL-15、AIM-54C、YJ-19 等 |
| 半主动雷达（SARH） | 依赖载机/载车雷达持续照射；AIM-7P、R-27R、ESSM 等 |
| 激光半主动（SALH） | 由激光照射指示目标，被照射目标会触发激光告警；AGM-114K、AGM-65E、LAHAT、AKD-10 等 |
| 激光架束（LBR） | 沿激光束飞行，被照射目标会触发激光告警；9M119M1、GP-125、9M127 等 |
| 反辐射（ARM） | 追踪开启的雷达辐射源，关闭雷达可规避；AGM-88E、LD-10、YJ-91 等 |
| 主动红外（AIR） | 雷达或数据链中段修正，末段红外导引头自主搜索；HHQ-10、HQ-13 等 |
| GPS/INS | 卫星与惯性组合导航，配合战术地图装订；AKF-98A、Storm Shadow、ATACMS、YJ-20 等 |
| 人在回路电视（HITL_TV） | 发射后进入导引头回传画面，发射手在画面中选择并锚定目标；KH-39、KD-88 等 |
| 人在回路指令线电视（HITL_CLOS_TV） | 发射后手动控制导弹舵面转向；TL-17、CM-502KG、弹簧刀巡飞弹等 |
| SACLOS | 操作员瞄准目标，导弹沿视线指令飞行；TOW-2A/2B、HJ-73E、95Ya6M 等；TOW-2B 为自锻破片攻顶战斗部 |

部分导弹具有多模导引头、双脉冲发动机、冷发射、高抛/掠顶弹道和近炸/触发引信。例如 Brimstone 为半主动激光/主动雷达双模导引头。

### 航空炸弹、鱼雷与吊舱

- **常规航空炸弹**：MK-84 等无制导重力炸弹，弹道计算机会连续计算命中。
- **激光半主动制导炸弹**：GBU-24、GBU-48、GB-3 激光型、GB-500、YJ-1000；载机照射激光点，炸弹飞向激光点，可打击移动目标。
- **卫星/惯性制导炸弹**：GBU-31、LS-6、GB-3 GPS 型；可在战术地图标记 GPS 坐标，投掷后飞向坐标点。
- **红外制导炸弹**：GB-3 红外型，可跟踪目标热源，具有打击移动目标的能力。
- **鱼雷**：可在水下 1–2 米航行，对大型舰艇造成巨额伤害。
- **吊舱**：分为目标指示吊舱与坐标指示吊舱。目标指示吊舱可标记目标并显示在战术地图上；坐标指示吊舱可获取目标坐标，部分型号集成“呼叫火力打击/呼叫空袭”。TGP 见 EA-18G、F/A-18F、J-16D，EOTS 见 J-20A，SUAV 吊舱见轻型侦察无人机与四轴侦察无人机。

### 激光武器与火力支援

- **激光武器**：ZTZ100 的 10kW 激光压制系统可照射敌方载具，累计命中后致盲玩家与 AI 炮手。AI 炮手被致盲期间只能使用雷达制导或雷达中段武器；玩家被致盲时白屏影响视线。
- **炮火支援**：主手/副手持炮火支援终端右键，或按 `K` 打开地图；支持呼叫、落区、弹数与停火。
- **打击模式**：急促打击、效力打击、监视打击、空中打击；弹幕样式包括点状、条状与徐进弹幕。
- **支援弹药**：航空炸弹、火箭弹、集束火箭、白磷弹、ATACMS、9M723、GPS 巡航导弹等，具体条目由火力支援配置决定。

### 武器改装

RVP 的大部分载具支持较丰富的武器改装，玩家可以根据任务选择不同弹种或挂载：

- **SEAD**：战机选择反辐射导弹，压制敌方雷达防空车。
- **DEAD**：战机携带红外或激光制导导弹，打击关闭雷达的防空系统。
- **地面载具**：面对较多轻装甲目标时选择 PELE；打击重装甲目标时选择 APFSDS。

## 辅助设备

RVP 的辅助设备按骨块模块配置，具有独立耐久和功能状态；被击毁后对应功能停止，可通过维修恢复。

| 设备 | 功能 |
| --- | --- |
| ERA 爆炸反应装甲 | 较高免伤倍率，承担一定伤害后爆炸消失 |
| APS 主动防护 | 按扇区探测并拦截来袭弹药；传感器骨块被击毁后对应扇区停止拦截 |
| ECM 主动干扰 | 干扰一定范围内的雷达/卫星/无线电制导导弹，同时成为最高辐射源吸引反辐射导弹；电子战机强效 ECM 还能产生虚假信号干扰雷达与 RWR |
| 被动 ECM | 被敌方雷达照射时生成假目标；骨块失效后停止 |
| 光电干扰机 | 对进入干扰扇区的 SACLOS 导弹实施干扰 |
| DIRCM 定向红外对抗 | 对 IR、AIR、人在回路导弹及 SBW 的 SA18 实施定向干扰；火力通道有限，会被多枚同时来袭的红外导弹突防 |
| 热焰弹/箔条/烟幕 | 分别干扰红外/雷达制导导弹、使雷达脱锁、遮挡激光点与红外导引头 |
| 维修设备 | 修复部件与设备 |

设备面板显示状态并可设置维修顺序。ERA 与其它辅助设备使用独立维修队列；同一骨块同时具有 ERA 和其它设备时，按爆反队列捆绑恢复。

## 模块化损伤

RVP 的损伤按部位和模块结算，不同部位具有独立耐久、伤害倍率和失效效果。

| 部位/模块 | 失效效果 |
| --- | --- |
| ERA 爆反 | 被击穿后该块失效，外观同步变化 |
| 发动机 | 受损严重时动力大幅下降、极速减半；彻底摧毁后无法移动 |
| 炮管 | 受损严重时射击失败或炸膛，即使成功也会大幅降低精度；彻底摧毁后无法射击。一级受损的导弹类武器只有成功/失败两种结果，不会炸膛 |
| 方向机 | 受损严重时转速大幅下降；彻底损坏后无法转动 |
| 火控系统（FCS） | 损坏后稳定器失效、弹道解算与 CCIP 停止、热成像/夜视与光电搜索不可用；准星仍显示，但不提供有效弹道计算 |
| 雷达 | 被击毁后无法搜索/跟踪目标 |
| APS/干扰机/DIRCM/干扰弹发射器 | 被击毁后失去对应功能 |
| 维修设备 | 被击毁后无法使用快速维修 |

损伤计算使用部位 OBB 与独立伤害倍率；爆炸方向、入射角、装甲减伤参数、距离、弹种和 ERA 状态都会影响最终伤害。维修面板按优先级恢复部件，爆反与辅助设备可分别设置维修顺序。

## 车载无人机与辅助载具

- 可部署 SUAV 轻型侦察无人机、四轴侦察无人机、四轴投弹无人机、四轴自爆无人机和龙吼卫（RAWR）无人战车。
- 支持部署、切换控制、自动盘旋、信号范围限制、超距自动回收和重新部署冷却；辅助载具出动期间母车座位锁定。
- 山毛榉-M3 可部署 96L6 雷达车，部署后可切换控制，两车分开布置并通过数据链联动，形成分体式防空配置。
- 052D 配置直升机停机坪；直升机接近后按 `P` 进入自动着舰流程。该功能为实验性功能，目前仅 052D 配置停机坪。

玩法示例：海玛斯火箭炮放飞侦察无人机，无人机用侦察吊舱标记敌方载具，海玛斯通过战术地图上的敌军标记直接发射火箭弹轰炸。

## 战术地图与界面

### 战术地图

- 显示地形、玩家、载具、导弹和 GPS 目标点，支持缩放、拖动、跟随和快捷标记。
- 右键目标可绑定 GPS 目标，或将目标位置填入 GPS 面板；支持单点和多点标记。
- 雷达目标列表显示距离、高度、速度、NCTR 识别、敌我识别和锁定状态，支持锁定目标并对满足条件的当前导弹执行快捷发射。
- 炮兵地图选择目标后计算仰角和落点距离，提供高/低弹道解算，左键开火；小型炮兵地图按当前炮口朝向与俯仰正算落点，适合应急使用。

### 人在回路

- **HITL_TV**：发射后进入弹载电视/热成像画面，发射手用准星选择目标点，按锚定键（默认 `R`）锚定或重新锚定，导弹跟踪该目标点。HUD 显示速度、高度、距离、飞行时间、锁定状态和操作提示。
- **HITL_CLOS_TV**：发射后进入同样的电视/热成像画面，发射手直接控制导弹舵面转向，屏幕中心显示操纵游标，没有目标锚定流程。
- 两种界面均支持彩色/黑白/热成像切换、滚轮缩放、空爆引爆和退出。

### 头瞄、告警与 AI 乘员

- 红外制导导弹支持头瞄捕获与离轴发射；雷达武器站支持雷达头瞄快速锁定指向位置。
- 告警包括激光照射、锁定与导弹逼近提示，以及辅助设备、DIRCM、ECM、APS 和干扰物状态。
- AI 乘员为实验性功能：支持座位选择与配置模式切换，可驾驶载具、操作武器站、使用雷达和制导武器，并在威胁下自动抛洒干扰物。友好炮手攻击怪物和敌对炮手载具；敌对炮手攻击玩家、中立生物和友好炮手载具；阵营炮手攻击非同阵营目标。

## 配置与性能

- `config/ywzj_rvp-client.toml`：观瞄灵敏度、LOD 缩放、温压粒子质量/音量/闪光/震动、爆炸屏幕震动、体积尾烟、远距载具渲染上限、Distant Horizons 兼容模式。
- `config/ywzj_rvp-lighting-client.toml`：屏幕空间照亮、爆炸/炮口/发动机照亮、光晕、导弹外圈、光电干扰机红光、喷焰与空气散射。
- `config/ywzj_rvp-common.toml`：观瞄轴加速、残骸保留时间、超视距载具同步/授权/距离、区块租约与前瞻。
- `config/ywzj_rvp-hitl-remote.toml`：会话数、相机区块半径、最大控制距离、每 tick 区块票据/发送量、待处理区块与额外实体上限。
- `config/ywzj_rvp-server.toml`：服务端玩法参数。

性能建议：为客户端分配 6–8 GB 内存；首次启动会从约 234 MB 的 jar 解压载具包；卡顿时可降低温压粒子质量、屏幕震动和远距载具渲染数量，体积尾烟默认关闭；使用 Distant Horizons 时可在客户端配置中选择兼容模式。
