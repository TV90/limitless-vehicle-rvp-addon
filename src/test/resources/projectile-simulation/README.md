本目录保留原有 6 个通用场景，新增 **200 个 052D 场景**。每个 JSON 都是当前 `schemaVersion: 1` 格式，可以单独运行，也会被默认 `projectileSimulation` 任务自动读取；不用改 Java 或工作台插件。

## 运行

可视化生成用例：启动 `tools/three-test-workbench`，点页首 **弹体用例生成器 ↗**。可以载入本目录任一场景为副本，拖动目标/发射点与速度端点、预览目标轨迹、调整机头和初速方向，再保存为新的 `<id>.json`。编辑器给出单例仿真命令，运行后到工作台刷新目录查看真实导弹轨迹。[完整使用说明](../../../../tools/three-test-workbench/plugins/projectile-scenario/README.md)。

项目根 PowerShell：

```powershell
./gradlew build projectileSimulation
```

默认生成 **206 份回放**及 `build/projectile-simulation/index.json`。在 Three.js 工作台选择“RVP 弹体仿真”列表中以 `052D` 开头的场景，名称包含武器和编号。若工作台已经启动，刷新目录即可。

只跑一个场景（自定义输出目录，避免替换默认的全部场景索引）：

```powershell
./gradlew projectileSimulation "-PprojectileScenario=src/test/resources/projectile-simulation/052d_yj20_03_long.json" "-PprojectileOutput=build/projectile-simulation-052d-single"
```

## 怎样看结果

- 距离单位是“格”，速度是“格/秒”，20 刻等于 1 秒。航向 0 朝正 Z，90 朝负 X，负 90 朝正 X；俯仰正数抬头。
- 常规海面用例：海底 `groundY=48`、水面 `waterY=64`、示意发射点 `Y=78`。这是对照初态，未读取舰体结构模型或证明炮口位置正确。鱼雷默认海底为 0，给深度摆平留出空间；浅水和高度边界例有各自显式设置。
- 海红旗-9B、鹰击-19、鹰击-20 常规用例从舰上 `20` 刻、`[0,2,0]` 格/刻冷发射配置换算为场景的 `20` 刻、`[0,40,0]` 格/秒。10/40 刻和平台倾斜用例是刻意改变的初态，不代表舰上当前配置；9B/鹰击-19 的 109/111 度用例另外取消挂架弹射、保留武器点火延迟，避免竖直弹射改变速度轴后把角度门对照混在一起。
- 平台前进 15 格/秒、倒车 6 格/秒来自当前舰艇最大速度的换算。只有鱼-7 配置开启舰速继承，其他弹种输入舰速用来验证“不继承”的对照行为；平台速度并不驱动整艘船移动。
- 预测拦截是瞄准目标未来会到的位置；GPS 是飞向装订坐标；ARH 是主动雷达制导；预设路线是配置好的上升、巡航、下降过程；二脉冲是主发动机结束后再次提供推力。它们的阶段和速度都从真实实体读取。
- 鹰击-19 的目标高度门按**离地面/海底高度**计算：常规目标 Y=68、海底 Y=48，差为 20 格，位于 25 格限制内。24/26 格用例刻意跨越这个门，不能把超限拒转当作场景加载失败。
- 高度分档用例跨在世界 Y=80/128/200/256/512 的两侧；观察初帧的密度因子、初速及后续实际跨档，不要求导弹一直停留在某一高度层。
- 左右、角度、舰速、是否制导等对照例保持同一种子 721。鹰击-20 的另一个种子用例改为 722，用于观察配置中的 GPS 随机误差。重复运行同一输入应产生相同记录。
- 关注事件中的发动机阶段、入水/出水、制导阶段和结束原因，以及每帧的速度、深度、质量、推力和最近目标距离。`TARGET_REACHED` 只说明该刻运动段进入测试球；没有进入球、超角拒转、落地、寿命结束也都是有意义的观测，不能一律算成功命中。
- 场景不覆写射程、推力、寿命、制导或鱼雷参数，全部读取当前权威武器 JSON。鹰击-19 的第二脉冲配置比默认总寿命长，测试不能据此断言能完整燃烧 1800 刻。
- 当前海红旗-10 虽配置二脉冲，但制导类型为 `AIR`，不在 `RVP_ProjectileMotion.isDualPulseSupportedMissile` 的支持类型中。第 19 例记录这一现状，不声称已经测到二次点火；本次不修改武器或运动代码。

## 自动验证与环境边界

现有 `RVP_ProjectileSimulationTest` 会读取本目录**全部 JSON**，逐例运行两次并比较完整回放，检查同输入是否可重复；运行器遇到非有限位置、速度、姿态或角速度会直接失败。新增的 052D 专项测试另行检查武器覆盖、冷发射交接、二次点火、真实高度/跟踪门、舰速继承与鱼雷入水分支。

2026-11-02 验证：`./gradlew build projectileSimulation` 通过，1354 项 Java 测试全部通过（含 46 项新增 052D 专项断言）；206 份回放生成成功，其中新增场景共 86002 帧，输入与回放中的初态逐项一致。工作台 JavaScript 语法检查及 36 项测试全部通过，覆盖全部生成记录的读取、绘制和时间轴倒拖。

这里执行真实弹体运动和制导执行器。除 GPS 使用真实坐标制导源外，红外/雷达目标由场景提供理想观测；**不验证搜索、锁定、干扰、反舰制导源的跃升路线、火控提前量、弹药容量、射速、装填、引信、自毁检测、碰撞伤害、穿透、爆炸、模型或实际炮口位置**。水面/海底只提供简化环境与停止条件。移动 GPS 用例保持原始装订坐标，末段才提供移动实体观测，不模拟坐标更新或真实雷达重捕。

完整工具与输入字段说明见 [RVP 弹体仿真插件说明](../../../../tools/three-test-workbench/plugins/projectile/README.md)。
