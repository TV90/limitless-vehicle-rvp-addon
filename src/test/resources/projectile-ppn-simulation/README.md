# 实体 PPN 与高抛对照场景

这 6 个场景只设置发射初态与目标运动，读取项目根权威武器 JSON，不覆盖武器参数。
补充 AIR / SARH 横穿、AIM-120D 高抛横穿与缓慢机动、PL-15 高抛横穿与迎头。
原有 8 个低速、惯量和横穿场景继续复用 `../projectile-inertia-simulation/`。

`RVP_ProjectileInertiaSimulationTest` 默认验证全部 14 个场景，并为 4 个高抛场景增加自主捕获后的退出测试，共 18 项。
每刻检查真实机头总转角，按首次相对运动段评分，禁止绕圈后再次接近冒充首次命中；几何误差要求小于 2 格。
捕获事件仅通过正式状态入口提供，不伪装为真实导引头搜索验证。

实现、PIP 对照数值、输入指纹与复现命令见 [实施记录](../../../../docs/RVP弹体-fish/RVP实体寻的PPN闭环与高抛衔接_20261105.md)。
